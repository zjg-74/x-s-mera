## 容差带定义（本实验的产出）

> **B 级判读禁区（顶点带）** := { 数据 : |β̂| ≤ z · SE(β̂) }

- `β̂` 与 `SE(β̂)` 来自多元回归 `U = α + γ·E + β·k + ε`（经典最小二乘，手写 3×3 求逆）。
- `z` 为**约定性带宽参数**（与 η 同类：约定性输入，按可接受误判率选取；默认 z=1.96）。
- **判读输出三值**：`mid_drill`（钻研方向，β<0）、`mid_hollow`（空洞方向，β>0）、
  `vertex_band`（禁区，不判）——**不强行二分**。
- 判定只依赖 `(E, U, k)` 观测与 z；β̂ 是规范不变量（U5 通过）。
- 无噪声时 SE = 0，禁区退化为 |β| ≤ ε，**恰为顶点 ρ=1（零测集）**；带宽在 ρ 空间的
  换算 `δ_ρ = z·SE(β̂)/(κ_E ρ_exp)` 仅作解释，**判定不用 κ_E**（开实例可用）。

## 结果

- **V1 无噪声**：禁区恰为 ρ=1（其余网格点 {0.90,…,1.10} 判读符号全对）。
- **V2 有噪声**（σ=0.05 / 0.20，各 200 试次 × 7 个 ρ 点）：留空集中在顶点邻域，
  远端（|ρ−1| 大）几乎不留空；**噪声增大，近顶点留空率不减**（带宽随噪声增宽）。
- **V3 规范不变**：G_λ（系数乘 λ=7.3、速率除 λ）下 (E,U) 轨迹逐点不变，判读不变。

## 裁定

**OPEN-1 关闭**：容差带已定义（可观测、规范不变、三值输出），结构预言全部命中。
`27` §3.4 开放格①从【开放】改为【已解，R34】；B1 主表 B 行例外条款改写为
"ρ=1 顶点落入判读禁区，带宽由 z·SE(β̂) 给出"。

σ 只加在 U 上；未检验 E 噪声与模型失配情形。

## 与楔形分类的关系（一句）

顶点带不是"第三相"——它是**测量分辨率极限在判读规则里的显形**。
楔形分类（钻研 / 空洞两楔，共享顶点 ρ=1）的数学结构不变；变的是判读规则从
二值（sign）升级为三值（sign + 禁区），把"符号在原点测不准"这件事实话实说。
