## §1 模型与记号（与 R27 / R28 / R29 逐字一致）

**A_D**（补篇五）：

```
dE = dt*(r*e_+ - e_-),     dU = dt*(r*u_+ - u_-)
theta_E = e_-/e_+,         theta_U = u_-/u_+
rho_exp = u_+/e_+,         rho_res = u_-/e_-
恒等式： theta_U/theta_E = rho_res/rho_exp =: rho
```

**A_D^stat**（补篇七 / R28）：噪声进**过程层**

```
r_k = rbar_k * exp(s*Z_k - s^2/2),   E[r_k] = rbar_k
```

**驱动调度**（R29）：对数斜坡，r 从 `R_HI = 9` 单调降到 `R_LO = 1/9`，
`L = |ln(r_lo/r_hi)| = 4.394449`，`K = 241`，`dt = 0.01`。

**违反 A_D 的注入**（与 R19 配置 IV 同构）：

```
dE <- dE - dt*eps*r^2
Psi(r) := dE/dt = e_+*(r - theta_E) - eps*r^2
```

Ψ 由**直线**变为**开口向下的抛物线**，顶点值 `Psi_max = e_+^2/(4 eps) - e_+*theta_E`。

**临界值（推论 6.8）**：

```
eps_c = e_+ / (4*theta_E)
    eps <  eps_c  ⟹ 两个实根，E 有内部上升相
    eps >= eps_c  ⟹ 无实根，E 全程下降、峰退到 k = 0
```

### 三个判据的定义

- **判据 1（R24 原登记，跨任务）**：同一理解者的一组任务中，同时出现 `(+,−)` 与 `(−,+)` 两种签名。
- **判据 2（R24 原签名的任务内版）**：单个任务的轨迹上，增量云同时进入 `(+,−)` 与 `(−,+)` 两个象限；等价地，E 出现显著内部极小。
- **判据 3（定理 6.11，任务内线性失配）**：`min_v ‖Π^⊥(v·U − E)‖`，其中 `Π^⊥` 是关于 `span{1, k}` 的正交投影。

**判据 3 的严格性**：在 A_D 下把 `dU = ρ_exp·dE + e_−(ρ_exp − ρ_res)` 累加，得
`U(k) − ρ_exp·E(k)` 关于 k 仿射，故 `Π^⊥` 后恒为 0。取 `v = 1/ρ_exp` 即达最小值。
**⟹ 判据 3 在 A_D ∧ 共享驱动下逐样本（非统计）恒为 0。**

**臂 G（回归法复原四系数）**：

**臂 G2（规范自由度，定理 6.12）**：

| λ | θ_E | θ_U | e₊ | u₊ | e₋ | u₋ | max\|ΔE\| | max\|ΔU\| |
|---|---|---|---|---|---|---|---|---|

| 2.00 | 2.00 | 4.00 | 0.50 | 0.50 | 1.00 | 2.00 | **0.00e+00** | **0.00e+00** |
| 4.00 | 4.00 | 8.00 | 0.25 | 0.25 | 1.00 | 2.00 | **0.00e+00** | **0.00e+00** |

⟹ **λ 跨 16 倍，四个系数全部改变，而 `(E(k), U(k))` 序列逐点完全相同（差值为 0）。**

**推论**：任何只是 `(E, U)` 的函数的可观测量都是规范不变的，因而**永远无法**分离 `e₊` 与 `1/λ`。
可辨识的只有规范不变量 `ρ_exp = u₊/e₊`、`ρ_res = u₋/e₋`、`ρ = θ_U/θ_E`（三者满足 `ρ = ρ_res/ρ_exp`，故**独立不变量恰为 2 个**）。

⟹ **B-B23（ρ_res / ρ_exp 单独标定）不闭合**，原因是**规范自由度**，不是数据不足。
闭合条件是「r 的绝对尺度被外部标定」——这正是补篇四讨论的**标定通约性**问题。

## §6 不能声称的清单

1. **不能声称 A_D 已被检验为真。** 本实验只检查了 A_D 原型内部的推导结构，未接触任何真实认知数据。
2. **不能声称 ρ 在真实理解者中是否依赖任务。** 臂 B 只证明了「若依赖则 R24 原判据会误报」，是一个**条件命题**。
3. **不能声称残差判据对 ¬A_D 是充分的。** 它只证否 `(A_D ∧ 共享驱动)`（见 N5）。
4. **不能声称 ε 的探测窗口具有外部有效性。** 窗口依赖 K、dt、r 窗口、平滑宽度（见 N4）。
5. **不能声称四个系数在任何意义上被标定了。** 定理 6.12 表明它们在规范群下不可辨识。
6. **不能声称 η 的取值有心理学含义。** `ρ_i = ρ₀·exp(η z_i)` 是**操作化定义**，不是测量模型。

## §7 操作规程（补篇九 §7 的可执行版本）

对一组任务 `{i}`（每个任务跑一条 `(E_i(k), U_i(k))` 轨迹）：

1. **重复**：每个任务重复测量 `N ≥ 16` 次，逐点平均得 `Ē_i, Ū_i`（T16）。
2. **估噪声底**：由 `N` 次重复的组内散度估 `κ·σ_obs/√N`，作为残差判据的阈值 `τ`（**不要用绝对常数**）。
3. **判据 3（首选，任务内）**：算 `resid_i = min_v ‖Π^⊥(v Ū_i − Ē_i)‖`。
   - `resid_i > τ` ⟹ **`reject_A_D`**（与任务结构无关，逐样本）。
4. **判据 1（次选，跨任务）**：仅在所有 `resid_i ≤ τ` 后才使用。
   - 跨任务签名并存 ⟹ **`rho_task_dependent`**（A_D 仍成立）**。
5. 否则 ⟹ **`accept`**。

**关键**：判据 1 必须在判据 3 之后使用。R24 原登记把二者混为一谈，这正是 T12 的来源。

## §9 Lakatos 判决

**进步性**：本轮为**退化性的修正，但属于「保护硬核所必需的辅助假说调整」**，不构成拉卡托斯意义上的退化。

- **硬核**：XSM 生成、双约束、P/Q/U 关系、A_D 的线性叠加结构 —— **未被触动**。
- **辅助假说**：R24 的证否签名 —— **被证否并取代**。
- **新增内容**：定理 6.11（任务内线性失配守恒）、定理 6.12（规范自由度）、推论 6.8（临界违反强度）、推论 6.13（修正后的证否判据）。

**判决**：

> 本轮**证否了一个辅助假说**（R24 原签名），并**用两个新定理 + 一条操作规程取代之**，
> 同时**新登记了一个不可辨识性结果**（定理 6.12，B-B23 不闭合的原因）。
>
> 由于证否对象是辅助假说而非硬核，且取代物带来了**新的、可检验的结构预言**
> （`resid/ε` 与 θ_E 无关；`resid ~ N^{−1/2}` 平均律；`λ`-规范不变性），
> 本轮判为 **进步的问题转换**。

**可检验的新预言**（供后续实验）：

- **R38**：残差灵敏度系数 `resid/ε` 对任意 `(θ_E, u₊, e₊)` 组合保持常数。
- **R39**：重复测量平均下，残差按 `N^{−1/2}` 衰减至系统地板，地板值 ∝ ε。
- **R40**：`(E, U)` 序列在 `λ`-规范变换下不变 ⟹ 任何声称标定 `e₊` 绝对值的实验设计必然引入了外部标定。
