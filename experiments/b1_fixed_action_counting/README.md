# B1 · 固定动作计数注入（R33 / 命题 6.3）——方法 + 脚本准备

对应 `18-v3.3-formal-framework-charter.md` §6.2 **B1**（缺口 **B-B45** / **R45**，闭合 C 级）。
理论锚点：`docs/xs-framework/15-v3.2-gauge-fixed-framework.md` §7.3（命题 6.3 首选方案）。

## 目的与性质（必须诚实声明）

- **本实验是「方法 + 分析流程准备」**：在**合成 A_D 数据**上验证「四臂测量 → 单位系数 →
  一次闭合 → 与轨迹回归自洽」的整个分析流程正确（R33 判据原文）。**不是真人实验**。
- **真实实验需受试者做固定动作计数**（真人测量 `(e₊,e₋,u₊,u₋)`），属 B 组 B1 的**外部数据部分**；
  本脚本在其数据到达前**冻结可执行的分析流程与判据**，数据一旦注入即可套用。
- 「C 级闭合（R45）真正达成」**只在真人实验数据上才算**，本脚本不声称。
- 仅标准库、确定性合成（无随机），机械可复核。

## 理论（命题 6.3）

A_D 下每步动作由展开/消解双速率线性分解：

```
ΔE = a·e₊ − b·e₋，  ΔU = a·u₊ − b·u₋
```

**四臂固定动作计数**（直接测单位系数）：

| 臂 | 动作 | 测得的量 |
|---|---|---|
| 臂1 | 固定展开 1 次（a=1, b=0） | ΔE = `e₊`、ΔU = `u₊` |
| 臂2 | 固定消解 1 次（a=0, b=1） | ΔE = −`e₋`、ΔU = −`u₋` |

⟹ 四个单位系数全部可测 ⟹ **一次闭合**：

```
θ_E   = e₋/e₊        （Ψ=0 临界比）
θ_U   = u₋/u₊        （dU=0 临界比）
ρ_exp = u₊/e₊        （展开效率比）
ρ_res = u₋/e₋        （消解效率比 = ρ·ρ_exp）
κ_E   = e₋           （尺度系数，按仓库惯例 = e_minus）
β₀    = ρ_exp·e₋ − u₋  （A_D 桥项：ΔU = ρ_exp·ΔE + β₀）
```

**R33 判据**：由四臂测得的 `(e₊,e₋,u₊,u₋)` 与轨迹回归所得 `(ρ_exp, β₀)` 是否自洽。

## 方法

1. **合成 A_D 数据**：给定真实参数，`r(k)` 分段投入驱动主轨迹 `(E,U)`（U0 远离 0）。
2. **回归**：`U = b0 + ρ_exp·E + β₀·k`（多重线性回归，正规方程）得 `(ρ_exp, β₀)`。
3. **四臂注入**：模拟臂1/臂2 单步动作，测 `(e₊,e₋,u₊,u₋)`。
4. **闭合 + 自洽**：四臂算 `(θ_E,θ_U,ρ_exp,ρ_res,κ_E,β₀)`，与回归对比。

> 判据细节：`ρ_exp` 用**相对差**（非零量）；`β₀` 用**绝对差**（真值可为 0，相对差会因除零失效）。

## 结果（`b1_results.json`）

参数：`DT=0.01, K=3000`；三种配置借 R27 CONFIGS。

| 配置 | θ_E | θ_U | ρ_res | 回归 ρ_exp | 回归 β₀ | 自洽 rel_ρ | 自洽 abs_β | 判定 |
|---|---|---|---|---|---|---|---|---|
| drill（钻研型） | 1.0 | 3.0 | 3.0 | 1.000000 | −2.000000 | **1.1e-14** | **6.7e-15** | ✅ |
| converge（收敛型） | 3.0 | 1/3 | 0.111 | 1.000000 | 2.666667 | **1.8e-14** | **4.0e-14** | ✅ |

判据：`rel_ρ < 1e-6` 且 `abs_β < 1e-6`。全部通过。

## 结论

- **分析流程正确**：在合成 A_D 数据上，四臂固定动作计数一次闭合所得系数与轨迹回归自洽到
  `1e-14` 量级（含 β₀=0 的退化配置）。
- **可执行性落地**：一旦有真人实验的固定动作计数测量 `(e₊,e₋,u₊,u₋)`，即可直接套用本流程
  完成 θ_E/θ_U/ρ_exp/ρ_res/κ_E 的一次闭合，并检验与回归自洽（R33/R45）。

## 诚实边界 / 未做

- **合成数据，非真人实验**：四臂测量在真实实验中含测量噪声，本脚本为确定性基准；
  加噪稳健性可作后续扩展。
- **κ_E = e_minus 是仓库惯例**（a13 make_cfg），若理论定义与之不同需核对。
- **不构成 C 级闭合的经验达成**：真实闭合需 B1 的外部实验数据（B 组性质）。
- **主轨迹回归依赖 A_D 成立**：若数据违反 A_D，回归的 `(ρ_exp,β₀)` 语义需另行核验（推论 6.13 管辖）。
