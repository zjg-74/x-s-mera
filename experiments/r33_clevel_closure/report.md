## 做了什么

按命题 6.3 的"固定动作计数"设计四臂，在 A_D 动作计数原型（b=1 固定、a_k 按调度族变化）上：

| 臂 | 介入 | 读出 |
|---|---|---|
| 1 | 固定展开 1 次（a=1, b=0） | `e₊ = ΔE`，`u₊ = ΔU` |
| 2 | 固定消解 1 次（a=0, b=1） | `e₋ = −ΔE`，`u₋ = −ΔU` |
| 3 | 自由调度序列（4 调度族 × 60 步） | `(E_k, U_k)` 轨迹 |
| 4 | 回归 `U = α + ρ_exp·E + β·k` | `(ρ_exp^reg, β^reg)` |

自洽判定（R45）：T1 `ρ_exp^reg = u₊/e₊`；T2 `β^reg = e₋(ρ_exp − ρ_res)`（κ_E = b·e₋，b=1）；
T3 `v* = 1/ρ_exp`（v*U − E 对 k 仿射的零失配）；T4 恒等式 `ρ = θ_U/θ_E = ρ_res/ρ_exp`。

## 结果

- **36 行（3 θ_E × 3 ρ × 4 调度族）全部通过**，残差为浮点噪声（rel_resid < 1e-9）。
- **C 级量全部可由臂直接读出**：四系数、θ_E、θ_U、ρ_exp、ρ_res、ρ、κ_E。
  无需外部时间标定——"单位"由动作计数固定（代数上固定记号、实验上固定单位，同一动作）。
- **负对照有牙齿**：把 b 记错（2.0）破坏 T2（β 预测翻倍），但不动 T1（斜率不受 b 影响）。
  **退化豁免**：ρ=1 时 β 预测恒为 0，负对照在该点无牙齿——已登记。
- ρ=1 退化情形（β=0 对 0）同样自洽。

## 裁定

**R45 判据在原型内成立 ⟹ 命题 6.3 的"固定动作计数闭合 C 级"通过实测核验**（【原型确认】级）。
`27-v3.4-boundary-map.md` §3.2 表 B 的 C 行**辨识层**由【定理】补上【原型确认】。
**边界**：确定性原型、4 调度族、b=1 固定；噪声/异速消解/真实数据未做。

## 裁定辖域（v0.2 勘误，2026-10-24）

本实验验证的是**固定动作计数通道**（介入性设计，任何实例下合法）的读数与回归自洽。
它**不裁定**"这个实验设置算不算闭实例、算不算'不借助外部尺子'"——那是**观测工具
归属判据**（边界地图 OPEN-2，B1×B6 交叉，未解决）的辖区。因此：
R33 关闭的是"C 级量**能否**被读出并对上账"，**不**关闭"闭实例 C 级**自足**"；
后者在 OPEN-2 解决前是条件性结论（见 `27` §3.2 表 B 与 §5 R45×OPEN-2 交叉格）。

## 一处方法注记

回归取 `U = α + ρ_exp·E + β·k`（三参数）而非对 (E,U) 做单变量拟合：
A_D 下 `U − ρ_exp·E` 对 k 仿射（定理 6.11），但 (E,U) 点列一般不共线于一条直线——
"共线性"指的是对 `span{1, k}` 的零失配（R30 同口径）。单变量 U~E 拟合会把调度
混入斜率，不是 R45 的判据对象。
