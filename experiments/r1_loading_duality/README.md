# R1 · 加载度 σ(M,F_k) 与工程边界重合度 d 的同构对偶

对应 `docs/xs-framework/01-v3.1-main-dichotomy-macro-loading-trichotomy.md` **§4.4 + §9 推论 R1**：
加载度 σ(M, F_k)（宏与其可用事实的贴合度）与工程版边界重合度 d = exp(−r²/(2σ²))
（两系统边界的重合度）**同构、不同尺度**（宏-宏 vs 宏-事实）。推论 R1 的可检验形式：
**当多个宏的槽被同一批事实填充时，这些宏之间的 d 应显著高于随机配对的宏**。

## 目的（必须诚实声明）

- 在"宏-槽-事实"**离散原型**上验证该对偶的结构成立：构造一批共享事实 F，
  让"相关宏"（依赖 F 的核心）与"随机宏"（依赖 F 之外特征）在**同一批事实 F** 下
  分别计算两两边界重合度 d，比较二者。
- **不是经验验证**：离散原型只回答"结构对偶是否成立"，不构成对现实认知的断言。

## 模型定义

- **事实批 F**：特征空间上的一批实例（"同一批事实"）。
- **宏 M**：一组槽，每槽声明其期望特征子集与权重。
- **加载度 σ(M, F)** := 被 F 满足的槽的**加权比例**（槽满足 = 槽期望特征在 F 中均
  有足额实例）。【约定】槽间独立加权，不模拟嵌套依赖（补篇七 B-B29 除外）。
- **边界重合度 d(M1, M2)** := 两宏在"槽满足模式"（加权 0/1 向量）上的**余弦相似度**。

## 构造与判读

- `base`：共享核心特征池；`core`：相关宏共享依赖的核心事实（全供）。
- 相关宏 = 核心槽（依赖 core，F 供给 ⟹ 满足）+ 独有槽（依赖 excl 的随机子集）。
- 随机宏 = 槽全依赖 excl（F 不供给 ⟹ 不满足）。
- 共享事实 F = core ∪ excl 的部分供给。
- d 全部在**同一共享事实批 F** 下计算（公平比较）。
- 判读：`separation = mean_d_related − mean_d_random > 0.3 ⟹ HOLDS`。

## 结果（`results.json`，固定种子 20261029）

| 指标 | 值 |
|---|---|
| 相关宏对 d | **1.000**（同批事实完全填充 → 完全重合） |
| 随机宏对 d | **0.000**（无共享事实依赖 → 不重合） |
| mean_d_related / mean_d_random | 1.000 / 0.000 |
| separation | **1.000** ⟹ **HOLDS** |

## 关键发现（诚实登记）

1. **同批事实 F 填充相关宏的核心槽 ⟹ 相关宏边界完全重合（d→1）**；随机配对宏
   无共享事实依赖 ⟹ 加载模式不相交（d→0）。分离=1.000，推论 R1 的结构成立。
2. d_rel=1.000 是"相关宏被同一批事实**完全**填充"的**结构极限**体现——这恰是
   对偶的直接结果（共享事实依赖 ⟹ 边界重合）；随机对照组证明**非恒真**（去掉
   共享依赖，d 即降为 0）。

## 诚实边界

- 离散"宏-槽-事实"原型，非经验验证；σ/d 为约定操作化。
- d_rel=1.000 是"完全填充"的极端；未扫描"部分共享 → 中间重合度"的梯度
  （可作为后续参数敏感性扩展）。
- 槽间独立加权，未含嵌套依赖（B-B29）。
