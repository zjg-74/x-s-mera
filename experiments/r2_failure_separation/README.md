# R2 · F1 ↔ 发散（¬C1）/ F2 ↔ 伪收敛（C1∧¬C2）的条件分离

对应 `docs/xs-framework/01-v3.1-main-dichotomy-macro-loading-trichotomy.md` **§7.2 + §9 推论 R2**：
- **F1 ↔ 发散**：¬C1 时应观察到"发散现象：A_k = ∅ 且不可新构"；
- **F2 ↔ 伪收敛**：C1 ∧ ¬C2 时应观察到 ghost 伪力（加载成功但事后验证为错）。

此二者的**条件分离**在工程原型上应当是可分离的（与 v3.0 §7.2 R′ 同一条，本文精确化到三态）。

## 目的（必须诚实声明）

- 在"宏-槽-事实"离散加载原型上验证三态失效映射的**条件分离**：
  真收敛（C1∧C2）、F1 发散（¬C1）、F2 伪收敛（C1∧¬C2）在可观察量上可区分。
- **不是经验验证**：离散原型只回答"条件分离是否可操作化"，不构成对现实认知的断言。

## 判据与三态

- **C1（事实闭合可构）**：存在候选宏其加载度 σ ≥ 可加载阈值 σ_load。
- **C2（正确性）**：收敛到的宏 == 预设正确宏（ground truth）。
- 三态判定：
  - C1 ∧  C2 → 真收敛；
  - ¬C1     → **F1 发散**（A_k = ∅，无候选可构）；
  - C1 ∧ ¬C2 → **F2 伪收敛**（A_k ≠ ∅ 且完成加载，但收敛到错误宏 = ghost 伪力）。

## 构造（`facts_for_*`）

- 候选宏：`M_correct`（正确）+ `M_wrong`（错误但可加载）+ `M_rare`（稀有特征、不可加载）。
- 三批事实注入对应三态：
  - 足额供给正确宏所需 ⟹ 真收敛；
  - 所有候选 σ < σ_load ⟹ F1 发散（A_k = ∅）；
  - 足额供给错误宏、正确宏缺项 ⟹ F2 伪收敛（收敛到 M_wrong）。

## 结果（`results.json`，固定种子 20261029）

| 场景 | A_k | 收敛到 | 状态 |
|---|---|---|---|
| true_convergence | [M_correct] | M_correct | 真收敛 |
| F1_divergence | **[]（空）** | — | **F1 发散** |
| F2_pseudoconvergence | [M_correct, M_wrong] | **M_wrong** | **F2 伪收敛** |

`conditions_separated = true ⟹ HOLDS`。

## 关键发现（诚实登记）

1. **三态条件分离成立**：F1（A_k=∅、不收敛）与 F2（A_k≠∅、收敛到错对象）在
   "是否已加载 + 是否收敛到正确对象"这两个可观察量上**可分离**（¬C1 vs C1∧¬C2）。
2. 伪收敛（F2）的"ghost 伪力"被操作化为**加载成功但收敛到错误宏**——事后验证
   （C2）是唯一区分点，与主文"伪收敛事前不可判定（B-B3）"一致。

## 诚实边界

- 离散"宏-槽-事实"原型，非经验验证；σ_load/σ_star 为约定阈值。
- 单轮离散加载，未模拟时序震荡（震荡态 §5.2 未在此原型展开）。
- C2 需预设 ground truth（正确宏），现实认知中的"正确"本身是待证问题（B-B22 系）。
