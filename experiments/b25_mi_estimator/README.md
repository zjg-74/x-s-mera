# B-B25 · 互信息估计器 I(M; Ω | φ)

> **状态**：✅ 已实现（v1.6.46）。理论部分闭合（v3.2 审计 S8），本次完成**纯工程**——互信息估计器。

## 理论（已闭合，非本次新增）

跨理解者混合估计给的是 `H(M|φ)`，而

```
H(M|φ) = H(M|φ,Ω) + I(M;Ω|φ)
```

⟹ **混合偏倚恰等于 `I(M;Ω|φ)`**，是 `P := H(M|φ,Ω)` 定义的直接推论，
不是未知量（`15-v3.2-gauge-fixed-framework.md` §4.3）。
推论：**P̂ 的数值不可跨群体直接比较，除非同时报告 `I(M;Ω|φ)`**。

## 本次实现（纯工程）

`mi_estimator.py` 提供 `I(M;Ω|φ)` 的条件互信息估计器：

| 分量 | 含义 |
|---|---|
| `H(M)` | 无条件熵（整体） |
| `H(M|φ)` | 混合估计（**有偏**：跨 Ω 混合） |
| `H(M|φ,Ω)` | 分群体估计（无偏基准） |
| `I(M;Ω|φ) = H(M|φ) − H(M|φ,Ω)` | **偏倚**（跨群体比较须报告） |

方法：经验条件熵 + **Miller–Madow 修正** `Ĥ_MM = Ĥ_ML + (K−1)/(2N)`
（K 非零箱数，N 样本数）。
