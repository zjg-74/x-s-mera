# R44 报告 —— B-B44 取值原则锚定：可靠子区间

**实验**：`r44_eta_principle.py` → `r44_eta_principle.json`
**框架对应**：XS v3.4 · B-B44（η 取值原则）/ 承接 R-042、R-043
**证据硬度**：S2（纯内部仿真，复用 R-042/R-043 内核，纯标准库，固定种子可复现）

## 结论（先行）

**取值原则可锚定。** 在落带区间（R-043）内，加入噪声（σ∈{0.05,0.10}）后，η 的落带
可靠性并非处处一致：**A/C 场景可靠子区间≈落带区间，B（跨尺度弱）需收窄下界**。
据此给出 η 的取值原则 = **取目标场景"落带率≥90%"的可靠子区间内的值**，兑现
"把涨落误读为定向的可接受错误率"语义 ⟹ **B-B44 由"取值原则开放"推进为"已锚定"**。

## 方法

复用 R-042/R-043 内核（三类场景轨迹 + `ratio(w)=Var(块均值_dU,w)/ψ̄²` +
`τ*(η)=min{w:ratio(w)<η}`）。新增：**噪声注入**（σ=0.05/0.10 高斯涨落）+ **Bootstrap
重采样**（M=200 轨迹/场景/σ）估计落带率 `P(τ*(η)∈(8,128))`，在 R-043 落带区间内扫 η，
压出落带率 ≥ 90% 的连续**可靠子区间**。纯标准库、固定种子 20261027。

## 结果：可靠子区间（落带率≥90%）

| 场景 | 落带区间（R-043） | 可靠子区间（R44，σ∈{0.05,0.10}） | 最差落带率 |
|---|---|---|---|
| A 同尺度 | [0.0311, 0.0462] | **[0.0311, 0.0462]** | 0.975 / 0.920 |
| B 跨尺度弱 | [0.0311, 0.0713] | **[0.0322, 0.0713]**（下界收窄） | 0.715 / 0.610（近下界处） |
| C 结构性 | [0.0612, 0.0863] | **[0.0612, 0.0863]** | 1.000 / 1.000 |

- 每场景、每 σ 均存在**非空**可靠子区间 ⟹ 取值原则可操作。
- **B 收窄机理**：跨尺度弱扰动信号弱，`ratio(w)` 对 η 在落带下界附近敏感，噪声使 `τ*`
  易抖出窗口（近下界处落带率仅 0.61–0.72，即误读为定向率 0.29–0.39）；收窄到 0.0322
  后恢复 ≥90%。

## 判据核销

| 判据 | 内容 | 结果 |
|---|---|---|
| 可锚定 | 每场景/σ 存在非空可靠子区间（落带率≥0.90） | ✅ 全真 |
| 语义兑现 | 可靠子区间内误读为定向率 ≤ 10%（1−落带率） | ✅ A/C 最差 0.08 / B 收窄后 ≥0.90 |
| 带内不敏感 | 判定读数对 η 不敏感（R-042 已证） | ✅ 引用 R-042 |

## 机制含义

- **B-B44 闭合（取值原则）**：`η` 是观测协议的可接受错误率；取值须同时满足
  ① 落带（R-043）、② 可靠子区间（R44）、③ 带内不敏感（R-042）。三条件合起来给了
  `η` 一个可辩护、可操作、不引入外部显著性水平的取值规则（见 `33-v3.4-eta-scaling-principle.md`）。
- **场景相关**：三场景可靠子区间交集为空 ⟹ `η` 是场景相关协议参数，按场景声明；
  需全局单值时取保守交集 + 显式声明牺牲场景。

## 诚实边界

1. 可靠子区间是**原型内结果**：基于无噪声内核 + σ∈{0.05,0.10} 注入、默认窗口 (8,128)、
   REL_TH=0.90。换窗口/场景族/σ 需重跑，不预设外推。
2. REL_TH=0.90 是**约定水平**；更严（如 0.05）会收窄可靠子区间（B 尤其敏感）。
3. 不引入外部显著性水平（遵守 symbol_registry forbidden_readings）。
4. **D-SCALE 仍 provisional**：η 取值原则已闭合，但 B-B43（g 形式）未解，D-SCALE
   升级到 established 仍需 B-B43 处置。
