# B3 · 四类终态相图测绘（L2 仿真层）

> GAPS.md B3（归档推论 6：吸引子分类）：体系自发抵达四类终态
> （稳态 / 周期振荡 / 生态锁定 / 全局灭绝）。终态分类是动力学稳定性陈述，
> FOL 谓词层结构性不可达 → 交 L2 仿真层核验。

## 结论

| 轨道 | 测绘对象 | 结果 |
|---|---|---|
| Part A | 当前 LE 内核（`src/le_coupling_kernel.py` v3.4-le.1） | **单调稳定**：耦合参数网格（coupling_gain×d_threshold_c1）36 点**全部收敛唯一非零稳态** |
| Part B | 扩展生态动力学原型（本实验独立模型） | **四类终态可达**：extinction 29 / steady 41 / ecological_lock 33 / periodic_oscillation 37（s 14 档 × a 10 档网格） |

### Part A · 关键工程发现（诚实登记）

**LE 内核（v3.4-le.1）是单调稳定系统**：`_life_rhs`（逻辑斯谛增长 + Michaelis-Menten 摄食）、
`_env_rhs`（线性资源供给-消耗）构成全局稳定的资源-消费者不动点系统，耦合通量在自洽
不动点处趋于零。因此**当前内核只呈现稳态吸引子，不呈现振荡 / 灭绝 / 锁定**——B3
的"四类终态自发抵达"在当前内核版本**不可达**，须内核动力学扩展（捕食反馈 / 灭绝
阈值 / 多稳机制）。此项登记为 **B3-ext 待办**。

### Part B · 扩展原型相图（可达性证明）

在 b3 实验内实现独立原型模型（**非当前 LE 内核**，诚实标注）：

```
资源-消费者 Lotka-Volterra 型 + 密度约束 + Allee 效应双稳
dR/dt = s·R·(1 − R/cap) − a·C·R                    # R: 资源(logistic 自再生)
dC/dt = e·a·C·R − m·C − n·C² − allee·C/(A+C)      # C: 消费者(生命)
```

相图（s 资源再生率 × a 捕食率）呈现清晰分区：

| 参数区 | 终态 |
|---|---|
| 低 s（资源再生不足） | **全局灭绝**（资源枯竭，消费者归零） |
| 中等 s、低-中 a | **稳态**（资源-消费者不动点） |
| 高 a（强捕食反馈） | **周期振荡**（极限环，Hopf 型） |
| 临界/过渡带 | **生态锁定**（非灭绝、非稳态、非明确周期的被困波动） |

结论：**四类终态机制可被此类生态动力学表达**（可达性验证 HOLDS，原型层面）。

## 分类器（操作化口径，非现实生态学断言）

尾段 25% 窗口对消费者生物量分类，顺序 extinction → oscillation（峰谷幅 + 局部极大数≥2）
→ steady → lock。默认阈值与完整参数见脚本头部与 `results.json` 的 `classifier_defaults`。

## 运行

```bash
python b3_attractor_phase.py            # 标准双轨网格（Part A 36 点 + Part B 140 点）
python b3_attractor_phase.py --quick    # 小网格探测
```

产出 `results.json`（`part_A_LE_kernel` + `part_B_eco_prototype` + 分类器默认）。

## 诚实边界

- Part B 是**操作化原型模型**，不是当前 LE 内核；四类标签是对数值轨迹的操作化分类，
  非现实生态学断言。
- Part A 的"单调稳定"结论是对当前内核数值网格的观测，未覆盖全参数空间。
- 正式四类终态测绘须在 LE 内核引入振荡/灭绝/锁定机制（**B3-ext**），本实验为其
  可达性提供原型证据。
