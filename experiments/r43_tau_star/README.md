# R-043 · τ* 落点：η 的合理取值区间（已解决）

对应 `docs/xs-framework/reef_shturl.json` **R-043** 与 `boundary_map.json` B3 格。
R-042 的副产品：固定窗口 (8,128) 下，τ* 落带的 η 区间在 R-042 粗网格上几乎为空，
导致 η 取值原则（B-B44）未解除。**纯内部可解**（加密 η 网格 + 窗口扫描，不需外部数据）。

## 方法
- 复用 R-042 内核（三类场景轨迹 same_scale / cross_scale_weak / structural，固定种子）。
- **加密 η 网格**：0.001–1.0，200 点线性（R-042 仅 10 点，0.02→0.05 跳变会错过落带区间）。
- 预计算 ratio(w)=Var(块均值_dU,w)/ψ̄²，再对每 η 反解 τ*(η)=min{w:ratio(w)<η}。
- 统计 τ* ∈ (τ_fine, τ_coarse) 的 η 区间；对无落带场景扫描观测窗口。

## 结果（固定种子，可复现）

| 场景 | 默认窗口 (8,128) 落带 η 区间 | 宽 | 最佳窗口落带 η 区间 | 最佳窗口 |
|---|---|---|---|---|
| A 同尺度 | [0.0311, 0.0462] | 0.015 | [0.0010, 0.0462] | (4,512) |
| B 跨尺度弱 | [0.0311, 0.0713] | 0.040 | [0.0010, 0.0863] | (4,512) |
| C 结构性 | [0.0612, 0.0863] | 0.025 | [0.0060, 0.0863] | (4,256) |

## 关键发现
1. **R-042 的"几乎为空"是网格假象**：加密 η 后三类场景在默认窗口下均有非空落带区间。
   R-042 的 B 场景 η=0.05 恰落在 [0.0311,0.0713] 内，故只有它"恰好"落带。
2. **η 合理取值是场景相关的**：A∈[0.031,0.046]、B∈[0.031,0.071]、C∈[0.061,0.086]，
   三者**交集为空**（A 上界 0.046 < C 下界 0.061）。没有单一 η 使三类场景 τ* 都落带。
3. 重选观测窗口可显著拓宽落带区间（如 (4,512) 把 A 的下界扩到 0.001），但**场景相关不变**。

## 结论（B-B44 处置）
- **R-043 已解决**（内部一致性问题）：默认窗口下存在非空 τ* 落带 η 区间。
- **B-B44 降级**：从"η 取值原则开放"降为「**已给出各场景经验区间、待锚定取值**」。
- **诚实边界**：η 的合理取值**场景相关**（无统一值），且区间本身较窄；τ* 落带只在本仿真
  三类场景/固定种子下成立，不构成对现实的证据。D-SCALE 判定读数仍与 η 无关（R-042 结论不变）。
