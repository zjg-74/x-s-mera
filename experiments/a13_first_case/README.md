**性质**：**演示性映射**，非现实测量。对应章程 §6.1 触发点 A13——**投影空间与现实空间的第一个正式接触点**。
**日期**：2026-10-24

## 0. 一句话结论

> 对"换工作决策"这一真实认知案例，无框架只能给出「清楚/乱」的**程度描述**（并常被归因为
> 努力、智力、情绪等个体特质）；框架用 D-DRILL/D-CONV/D-IDENT 把同一段主观体验判读为
> **互斥类别 + 可定位的可辨识量**——这是"投影空间"第一次对着"现实空间"给出结构判定。

## 1. 案例与对照

| 维度 | 场景 A：越查越笃定（ρ=2） | 场景 B：越查越乱（ρ=0.6） |
|---|---|---|
| **无框架人工判断** | "越查越清楚，选项一个个排除，心里慢慢笃定，最后很确定。" | "好纠结，越查越多选项，越看越乱，反而更难决定。" |
| **D-DRILL 楔形** | **钻研相**（drill）：U 峰在前（kU=177 < kE=259），E 扩大、U 已降 | **空洞相**（hollow）：E 峰在前（kU=319 > kE=259），E 收窄、U 仍升 |
| **D-CONV** | **收敛方向**：U 降到峰高 7%（U_end=0.45, U_peak=6.73, \|A_K\|≈1.37） | **发散方向**：U 保持峰高 96%（U_end=26.9, U_peak=28.0, \|A_K\|≈1.2e8） |
| **D-IDENT** | ρ_exp=1.00（A 级，自足读）；sign(1−ρ)=−1（B 级） | ρ_exp=1.00（A 级）；sign(1−ρ)=+1（B 级） |
| **框架判读** | "笃定"不是程度——是钻研相的峰序 + 候选收窄的收敛方向 | "越查越乱"不是想得不够多——是空洞相：展开与消解的效率比倒挂，投入在扩大未决量 |

## 2. 对照点（框架做了什么无框架做不到的）

1. **程度 → 类别**：无框架的"清楚/乱"是连续程度副词；框架把它变成**互斥的钻研相/空洞相**，
   判据是同一组可测量（峰序、截距符号），不需要知道努力程度或智力（D-DRILL external_necessity）。
2. **归因去个体化**：无框架常把"越查越乱"归因于个人特质；框架把它定位为**结构性相位**（ρ<1），
   是展开/消解效率比倒挂的结果，不是人格缺陷。
3. **可辨识性分级**：D-IDENT 明确指出哪些量读得出（ρ_exp 斜率、sign(1−ρ) 截距符号），
   哪些读不出需外部单位（κ_E 时间尺度）、哪些是伪目标不该读（四个单位系数）。

## 3. 诚实边界（必须写明）

1. **非现实测量**：真实决策没有客观可测的 (E,U) 双序列。此处把两条叙事**翻译**为 A_D 轨迹，
   是"演示性映射"，不是对现实的经验断言（A 组性质，跨现实验证属 B 组 B4）。
2. **D-CONV 只判方向，不裁真伪**：真收敛 vs 伪收敛需要"外部证伪信息"（锁定者是否经外部检验），
   本演示无此信息，只判定收敛/发散**方向**（已用 `honest_boundary` 字段显式标注）。
3. **轨迹是构造的**：钻研相 U0=2、空洞相 U0=20 等参数是为让两相呈现典型峰序而选取，
   不代表真实决策的数值。
4. **可作素材**：本对照记录可作论文示例 / Graphical Abstract 素材 / 审稿演示案例。
