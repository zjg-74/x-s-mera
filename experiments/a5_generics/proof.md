## 1. 必要的形式精确化（对章程 §1.4 的澄清）

章程 §1.4 写作

$$\forall I_1, I_2: \quad R(I_1) = R(I_2) \ \Longleftrightarrow\ \text{不变量}(I_1) = \text{不变量}(I_2)$$

这是一个**双向 ⟺**。但它在"细粒度不变量"下**过强**，理由如下：

> **楔形分类反例**。楔形分类只分三档（钻研 / 空洞 / 无中间相），输出是 `sign(ρ−1)` 的离散化。
> 取 ρ=1/3 与 ρ=0.5，二者不变量不同（ρ 不同），**但输出都是「空洞相」**。
> 若要求 ⟺ 成立，则此二实例应输出不同——这违反分类规则的设计意图
> （空洞相本就涵盖所有 ρ<1，不区分 ρ=1/3 与 ρ=0.5）。

因此，**正确的 genericity 形式是函数性**：

$$\exists f:\ \ R = f \circ \mathrm{Inv}, \quad\text{即}\quad \forall I_1, I_2: \ \mathrm{Inv}(I_1) = \mathrm{Inv}(I_2) \ \Longrightarrow\ R(I_1) = R(I_2)$$

即：**输出是不变量的函数**（同不变量 ⟹ 同输出），**不要求 f 单射**。
粗粒化分类规则允许不同不变量映射到同一输出——这是分类的设计意图，不是违反。

> **诚实标注**：章程 §1.4 的 ⟺ 双向式在"规则的完整输入"意义下成立
> （给定全部不变量，输出唯一确定）；在"规则实际依赖的粗粒化不变量"意义下，
> 正确形式是单向前件。本证明采用后者，因为它是「输出只依赖不变量」的最精确机器可检形式。

## 2. 不变量的来源：A_D 的仿射定律

A_D（补篇五 §1.2）等价于一条仿射关系（R30 的 (*)）：

$$\frac{\mathrm dU}{\mathrm dt} = \rho_{exp}\cdot\frac{\mathrm dE}{\mathrm dt} + \kappa_E\cdot\rho_{exp}\cdot(1-\rho), \qquad \rho := \rho_{res}/\rho_{exp}$$

内禀自由参数是三个无量纲数 **(s, ρ_exp, ρ) + 一个时间单位 κ_E**，全部 λ-规范不变。
**不变量集合** = 这三者 + κ_E（κ_E 只进入 C 级，见 §3.3）。

所有分类规则都是这条仿射关系的**投影**，因此天然只依赖这些不变量——
这是 genericity 的代数根基，机器验证是对它的实证背书。

## 3. 四条分类规则的代数证明

### 3.1 规则 1 · 楔形分类（D-DRILL）

**规则**：中间相存在 ⟺ ρ ≠ 1；ρ > 1 ⟹ 钻研相；ρ < 1 ⟹ 空洞相（定理 5.2 / 定理 9.1）。

**不变量**：`sign(ρ−1)`。**输出**：drill / hollow / none。

**代数证明**：E 的增量符号是 `sign(s−1)`，U 的增量符号是 `sign(s−ρ)`。
中间相 = 二者异号 = `s` 严格介于 `1` 与 `ρ` 之间（两行证明，理论 §9.1）。
**分类由 sign(ρ−1) 完全决定，与调度 s(k)、θ_E、ρ_exp、初始值无关**。
⟹ 输出是 sign(ρ−1) 的函数。

### 3.2 规则 2 · 峰序（P3）

**规则**：ρ > 1 ⟺ U 峰在前 ⟺ 仿射式截距符号为负（推论 6.4）。

**不变量**：`sign(ρ−1)`。**输出**：U_first / E_first。

**代数证明**：截距 `c = κ_E·ρ_exp·(1−ρ)`。因 κ_E>0、ρ_exp>0，
`sign(c) = sign(1−ρ) = −sign(ρ−1)`。峰序由截距符号读，故由 sign(ρ−1) 决定。
**ρ=1 时 c=0（退化点）**：截距为 0，峰序无定义，机器验证豁免此点（同 R34 顶点带先例）。
⟹ 输出是 sign(ρ−1) 的函数。

### 3.3 规则 3 · 四级可辨识性（D-IDENT）

**规则**：A 级 ρ_exp 从斜率读（自足）；B 级 sign(1−ρ) 从截距符号读（自足）；
C 级 ρ 数值、κ_E 需外部单位；D 级四系数绝对值是规范冗余（伪目标）。

**不变量**：`(ρ_exp, sign(ρ−1))`。**输出**：四级判定。

**代数证明**：
- A 级：斜率 = ρ_exp，直接读出，不依赖任何调度量。
- B 级：截距符号 = sign(1−ρ)（同上），只依赖 ρ 相对 1 的位置。
- C 级：截距**绝对值** `|κ_E·ρ_exp·(1−ρ)|` 含 κ_E，κ_E 是时间单位，需外部标定（第二可辨识视界）。
- D 级：λ-规范冗余，任何参数化都不可分离，是伪目标。

⟹ 自足两级（A/B）只依赖 (ρ_exp, sign(ρ−1))；C/D 级的"需外部"性质本身也不依赖实例内容。

### 3.4 规则 4 · 共线性反解 ρ_exp（R30 V3-A）

**规则**：OLS 回归 `dU ~ dE` 的斜率 = ρ_exp。

**不变量**：`ρ_exp`。**输出**：斜率估计。

**代数证明**：因仿射关系 `dU = ρ_exp·dE + c` 逐样本精确成立（残差恒 0），
OLS 斜率 = ρ_exp（常数项被截距吸收），**与调度族、θ_E、初始值、ρ 均无关**。
机器验证：跨全部实例 max rel err 1.48e-16。

## 5. 结论与诚实边界

**结论**：generics 函数性在 A_D 原型内**全部成立**——四条分类规则 R = f∘Inv，
只依赖不变量，不依赖实例具体内容。判据 C3.1 由「⚠️ 部分（仅 R30）」推进到
「✅ 原型内函数性已证 + 枚举已核」。

**诚实边界（必须写明）**：
1. **原型级**：这是 A_D 数值原型上的代数/枚举证明，**不是对现实的断言**（同 R30 地位）。
2. **非 Lean**：产出为 Python 枚举 + 代数文档，**未做 Lean4 形式化**（Lean 归 A9，本机无工具链）。
3. **未覆盖 C 级调度依赖**：规则 3 的 C 级（ρ 数值依赖调度）在 R29/R30 已量化（36.8%–76.5% 偏差），
   本证明只覆盖"自足两级不依赖实例内容"，不宣称 C 级可自足标定。
4. **粗粒化不变量**：Inv 取的是规则实际依赖的粗粒化量（如 sign(ρ−1)），
   不是全部不变量元组。函数性针对的是"输出 = f(规则所依赖的粗粒化不变量)"。
