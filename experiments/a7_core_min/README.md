## 4. 诚实边界（必须写明）

1. **压缩率是依赖结构层面的，不是概念独立性层面的**。本分析证明的是
   "36 条可由 11 条核心经 `derives_from` 图导出"，**不证明 10 个根彼此概念独立**
   （例如 X/S 原始二分、F/O 公理对是否可再归并，是概念判断，不在图论机检范围内）。
2. **`derives_from` 的完整性假设**。本分析依赖注册表已登记正确的依赖边；
   若有遗漏边，导出表的"最小根集"可能偏大（保守方向）。
3. **A7 是结构压缩，不是语义简化**。记号数量减少不等同于理论更简单；
   导出规则的"心智负担"可能仍在。
4. 未改变任何记号的定义或层归属，**未触碰冻结文本**。
