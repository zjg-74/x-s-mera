## 0. 一句话结论

> **序可辨识，且逐样本守恒；距只可辨识到比值，且只在 r 调度族已知时。**

推论 6.5 是一条正确的公式，但直接拿它"反解 ρ"会静默出错——除非先满足两个前提（§6）。

---

## 1. 为什么还需要一个实验

补篇六 §3.6 已证明：在对数斜坡下 $\Delta = |k^\*_E - k^\*_U| = C\cdot|\ln(\rho_{res}/\rho_{exp})|$。

但**公式成立 ≠ 程序可用**。要把它当估计程序，至少得回答四件事：

1. 实测峰位（离散、有噪）能否落在解析预测上？
2. 估计量有无偏？方差多大？需要多少样本？
3. $C = (K-1)/L$ 依赖 r 调度。调度未知时，还能辨识什么？
4. 什么情况下程序会**静默地给出错误答案**？

## 2. 六个臂

| 臂 | 问题 | 设定 |
|---|---|---|
| **A** | 公式在无噪声下是否逐点命中 | 扫 ρ ∈ {1/6…6}，比对 Δ_obs vs Δ_pred |
| **B** | 恢复精度 vs 过程噪声 s | s ∈ {0, .1, .2, .4, .8}，bootstrap CI |
| **C1** | C 未知时比值能否消去 C | 两条件同 K=241 |
| **C2** | 若两条件 K 不同呢 | K=241 vs 121；raw vs 归一化 |
| **D** | 真调度非对数斜坡时偏多大 | linear / sigmoid / piecewise |
| **E** | ln ρ 超出什么范围后不可测 | θ_E=1 固定，扫 ln ρ 到 2.6 |
| **F** | 峰序判据何时失效 | shared vs indep 噪声 |
| **G** | U−E 线性恒等式是否精确 | 逐点残差，含 ρ_exp ≠ 1 |

模型与 R27 / R28 逐字一致：
$dE = dt(a e_+ - b e_-)$，$dU = dt(a u_+ - b u_-)$，$b=1$，$r:=a$；
$\theta_E = e_-/e_+$，$\theta_U = u_-/u_+$，$\rho_{exp}=u_+/e_+$，$\rho_{res}=u_-/e_-$；
恒等式 $\theta_U/\theta_E = \rho_{res}/\rho_{exp}$。

A_D^stat（噪声进**过程层**，补篇七）：$r_k = \bar r_k e^{sZ_k - s^2/2}$，$E[r_k]=\bar r_k$。

> 要提高分辨率只能加密采样（增大 K）或拉宽 r 跨度。

## 4. 臂 B：恢复精度 vs 过程噪声

估计量 $\widehat{|\ln\rho|} := \bar\Delta / C$。

| s | $sd(\Delta)$（步） | $sd(\widehat{\ln\rho})$ |  bias 量级 | 95%CI 覆盖 |
|---|---|---|---|---|
| 0.0 | 0.0 | 0.000 | ≤0.003 | 多数（CI 宽度→0，离散化偏主导） |
| 0.1 | 1.66–1.82 | 0.031–0.033 | ≤0.004 | 12/12 |
| 0.2 | 3.32–3.76 | 0.061–0.069 | ≤0.004 | 12/12 |

| 0.8 | 12.74–15.55 | 0.233–0.285 | ≤0.018 | 12/12 |

- **无偏**：所有档位 bias 均 $\le 0.018$，且随 $n_{rep}$ 增大而缩小 → 系统偏来自离散化，非估计量本身。
- **精度随 s 近似线性增长**：$sd(\widehat{\ln\rho}) \approx 0.35\,s$。
- **可操作的精度要求**：要在 $2\sigma$ 意义下分辨 $\rho$ 比值的因子 $e^{\varepsilon}$，需 $n_{rep} \gtrsim (2\cdot 0.35\,s/\varepsilon)^2$。

## 5. 定理 6.10：U−E 线性恒等式与峰序**路径级**守恒 ★

**这是本轮最重要的发现，它不在原计划里。**

> **定理 6.10（峰序守恒）**。在 A_D 下，设 E 与 U 由**同一** r 过程驱动。
> 令 $U^s := U/\rho_{exp}$（把 U 的单位按 $\rho_{exp}$ 归一化；这只缩放 U，**不改变其峰位**）。
> 则对每个样本路径、每个 k：
> $$U^s(k) - E(k) = \left(\frac{U_0}{\rho_{exp}} - E_0\right) + dt\cdot e_-\left(1 - \frac{\rho_{res}}{\rho_{exp}}\right)(k+1)$$
> **与 r 及噪声完全无关**。因此逐路径地：
> $$\rho_{res} > \rho_{exp} \implies k^\*_U \le k^\*_E,\qquad \rho_{res} < \rho_{exp} \implies k^\*_U \ge k^\*_E$$

**证明**：
$U(k)-U_0 = dt\sum_{j\le k}(r_j u_+ - u_-)$，$E(k)-E_0 = dt\sum_{j\le k}(r_j e_+ - e_-)$。
除以 $\rho_{exp}$，用 $u_+/\rho_{exp} = e_+$，且
$u_-/\rho_{exp} = \dfrac{u_- e_+}{u_+} = e_-\cdot\dfrac{u_-/e_-}{u_+/e_+} = e_-\cdot\dfrac{\rho_{res}}{\rho_{exp}}$，
得
$\dfrac{U(k)-U_0}{\rho_{exp}} - \big(E(k)-E_0\big) = dt\sum_{j\le k} e_-\left(1 - \dfrac{\rho_{res}}{\rho_{exp}}\right) = dt\,e_-\left(1-\dfrac{\rho_{res}}{\rho_{exp}}\right)(k+1)$。∎

**单调性推论**：$U^s - E$ 是 k 的线性函数，斜率符号为 $\mathrm{sign}(\rho_{exp}-\rho_{res})$。
设 $m=\arg\max E$、$n=\arg\max U^s$。若 $n>m$ 则
$U^s(n)\ge U^s(m)$ 且 $U^s(n)-E(n) < U^s(m)-E(m)$
$\implies U^s(n)-U^s(m) < E(n)-E(m)\le 0$，矛盾。故 $n\le m$。∎

**意义**：推论 6.4 只说"期望意义下峰序由 ρ 决定"。定理 6.10 说明——**在共享 r 噪声下，这对每一个样本路径都成立，不是统计倾向，而是守恒律**。

**失效条件（关键）**：证明只用到了"E 与 U 由同一 r 驱动 + $e_+=u_+^s$"。
若 E 与 U 带**独立**噪声，恒等式被破坏，峰序**可以判反**。臂 F 直接测了这一点。

## 6. 臂 C：比率设计（C 未知时还能辨识什么）

推论 6.5 含未知常数 $C=(K-1)/L$。取两条件之比可消去 C：
$$\frac{\Delta_1}{\Delta_2} = \frac{|\ln\rho_1|}{|\ln\rho_2|}$$

**C1（同 K=241）**：相对误差 **0.0015–0.0273** ✓ 比值设计成立。

**C2（异 K：241 vs 121）**：

| 指标 | 最差相对误差 |
|---|---|
| raw 比值 $\Delta_1/\Delta_2$ | **1.0059**（约 2 倍偏，即 $ (K_1-1)/(K_2-1) $） |
| 归一化 $\delta=\Delta/(K-1)$ 之比 | **0.1057** |

> **这修正了补篇六 §5 的表述**。原文说"r 调度保持相同"——
> 臂 C2 表明，实际需要的是**两端点 $(r_{hi}, r_{lo})$ 相同**（从而 $L$ 相同），
> **K 不必相同，但必须归一化**。
> 而且归一化只消除系统因子，**不恢复分辨率损失**：K 减半 ⟹ Δ 减半 ⟹ 同样的 ±1 步离散误差相对翻倍。

## 7. 臂 D：调度误设（负面结果）

若真实 r 调度**不是**对数斜坡，仍按推论 6.5 反解 $|\ln\rho|$：

| 真实调度 | 最差相对误差 |
|---|---|
| **log_ramp**（正确） | 0.0386 |
| linear_ramp | **0.7650** |
| sigmoid_ramp | **0.5484** |
| piecewise_ramp | **0.3678** |

**原因**：推论 6.5 依赖 $k^\*(\theta) = g(\ln\theta)$ 关于 $\ln\theta$ **仿射**——这只在对数斜坡下成立。一般调度下可辨识的量是
$$\Delta = \big|g(\ln\theta_E) - g(\ln\theta_U)\big|$$
即**两个阈值在对数尺度上的距离经 $g$ 映到 k 空间的长度**，而**不是** $\ln\rho$ 本身。

> **诚实表述**：R29 真正辨识的是 $\Delta$（k 空间中两阈值的间距）；
> 只有在 $g$ 仿射时它才等于 $C\cdot|\ln\rho|$。
> 这是 B-B23 只能"部分闭合"的根本原因。

## 8. 臂 E：可辨识性视界

可辨识条件：两个峰都必须是**内点**，即 $r_{lo} < \theta_E < r_{hi}$ 且 $r_{lo} < \theta_U < r_{hi}$。

由 $\theta_U = \rho\,\theta_E$：
$$\ln\rho \in \big(\ln r_{lo} - \ln\theta_E,\ \ \ln r_{hi} - \ln\theta_E\big)$$

> **视界律**：$\ln\rho$ 的可测窗口**宽度恰为 $L = \lvert\ln(r_{hi}/r_{lo})\rvert$**，中心为 $-\ln\theta_E$。

本原型 $L = 4.3944$，窗口 $\ln\rho \in (-2.1972, +2.1972)$。实测：
$\ln\rho = 2.1$ 仍可测（$\Delta=114$ 步），$\ln\rho \ge 2.2$ 峰落窗外、不可测 ✓。

**设计含义**：要标定更宽范围的 ρ 比值，必须让 r 扫过相应更宽的范围。
**这是一条硬约束，不是精度问题**——超出视界时程序不报错，只是测不到峰。

## 9. 臂 F：峰序分辨率极限——**并列 ≠ 判反**

关键区分：**判不出（并列）** 与 **判错（判反）** 是两种不同的失效。

| 噪声条件 | 最大 tie 率 | 最大 err 率 |
|---|---|---|
| **shared**（E、U 共享同一 r 过程） | 0.7625（s=0.8, $\lvert\ln\rho\rvert=0.05$） | **0.0000（全部档位）** |
| **indep**（E、U 各带独立噪声） | 0.0850 | **0.4125** |

- **shared**：误差率恒为 0，与 s 无关 → 印证定理 6.10。
  噪声增大只把结果推向"不确定"（并列），**不会推向"判反"**。
- **indep**：守恒律破裂，误差率随 s 上升、随 $\lvert\ln\rho\rvert$ 增大而快速降到 0。

> **操作规程推论**：峰序是一个**优雅退化的观测量**——它失效时告诉你"不知道"，
> 而不是告诉你错误的答案。前提是 E 与 U 确实共享驱动（B-B37）。

## 10. 臂 G：U−E 恒等式逐点验证

含 $\rho_{exp}\in\{0.5, 1, 2\}$、$\rho\in\{1/3, 3, 6\}$、$s\in\{0, .4, .8\}$，共 27 组：

- **峰前窗口最大绝对残差 = 5.684e-14**
- 全窗口 = 6.395e-14

→ 恒等式在该网格上**精确成立**（残差为浮点累加误差量级）。

> 注：本轮把 `U_START` 从 5.0 抬到 30.0，是因为扫到 ρ=6 时 U 会在末段跌破 0，
> 而 $U\ge0$ 是熵的正当约束（$U = H(M\mid\varphi, C_{in})$）。**触底发生在峰后**，
> 因此不影响任何基于峰位的观测量；峰前窗口的限定是作为保险保留的。

## 11. 本轮四个方法学陷阱（T8–T11）

- **T8（不可跨 K 直接比峰距）**：$C$ 含 $(K-1)$。K=241 vs 121 时 raw 比值差因子 2.000。必须归一化。
- **T9（绝对量值不可辨识）**：$|{\ln\rho}|$ 的绝对值依赖 $C$；只有组间比值可辨识。把"恢复值"写成绝对数是越界声称。
- **T10（边界有向内偏）**：峰靠近窗口边界时 argmax 被拉向内部。必须显式判定"峰是否为内点"，否则会把不可测报成"$|\ln\rho|$ 很小"。
- **T11（平滑会合并近邻双峰）**：臂 F 两峰很近时，移动平均会把双峰抹成单峰，造成峰序判定的**假阴性**。故臂 F 用 $w=1$。

## 12. 不能声称什么

1. **不是实证验证**：无真实理解者参与，系数/调度/量级全人造。
2. **$C = 54.6$ 步/e 倍不是普适常数**，是所选对数斜坡的产物。
3. **$|\ln\rho|$ 的绝对值不可辨识**（T9）；只辨识到比值。
4. **峰序守恒是有条件的**：依赖 E、U 共享同一 r 过程；真实系统是否如此**未检验**（B-B37）。
5. 全部结论条件于 **A_D**（→ B-B22，高，未闭合）与 **A_D^stat**。
6. 恒等式只在 **$k \le k^\*_U$** 的窗口内被验证；U 触底之后的部分未被检验（本网格中未发生）。
