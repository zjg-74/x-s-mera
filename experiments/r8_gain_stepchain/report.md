# R8 报告 —— 增益-步长机制（M1）的工程验证

**实验**：`r8_gain_stepchain.py` → `r8_results.json`、`r8_bifurcation_tail.json`
**框架对应**：XS v3.4 · 补篇一 §5 R8（强度：高）
**证据硬度**：S2（自制最小离散原型，纯标准库，可复现）

## 结论（先行）

**M1 机制被工程验证。** 在 logistic 型最小离散认知原型上，把 A11-R 语义势增益 g 作为
唯一可调参数（**仅调步长、不进状态导数**，满足 A11-R"势-流分离"纪律）扫过，出现了
**完整周期倍增级联 1→2→4→8→16→32 → 混沌**，且分岔点与 logistic 解析理论高度吻合。
这支持补篇一 M1：**势-流分离下，势通过调制有效步长即可移出/移入混沌区**，全程不需
增益进入状态导数。

## 设计

离散迭代原型 `x_{k+1} = g·x_k·(1−x_k)`：
- `x_k`：加载度 σ 的归一化投影（候选聚焦量 m_eff 的归一化表征，v3.2 S5）；
- `g`：A11-R 语义势增益，外部给定、静态、仅作乘性系数（状态方程无 g 的梯度项）。

验证判据（预注册，四者全真 → M1 支持）：

| 判据 | 内容 | 结果 |
|---|---|---|
| V1 | 出现 ≥2 次周期倍增 | ✅ 8 个倍增点（含完整 1→2→4→8→16→32） |
| V2 | 混沌区存在（λ>0 且无短周期） | ✅ 混沌带 [3.571, 4.0]，λ>0 点 257 |
| V3 | 混沌阈值近 logistic 理论 3.5699 | ✅ 3.571 |
| V4 | 势不进状态导数（仅乘性增益） | ✅ 构造上满足 A11-R |

## 结果：周期倍增与分岔点对照

| 倍增 | 实测 | logistic 理论 |
|---|---|---|
| 1→2 | 2.9965 | 3.0 |
| 2→4 | 3.448 | ≈3.449 |
| 4→8 | 3.5455 | ≈3.544 |
| 8→16 | 3.565 | ≈3.564 |
| 16→32 | 3.5695 | ≈3.569 |
| 混沌阈值 | **3.571** | **≈3.5699** |

稳态轨道周期在 g 扫描中单调倍增直至混沌；混沌带内 λ>0、无短周期（Lyapunov 指数正，
非周期有界）。倍增加链 `[1,2,4,8,16,32]` 连续出现。

## 机制含义

- **M1 成立**：离散迭代中，一个**不进状态导数**的增益量（语义势）通过改变有效步长，
  即可使系统跨越周期倍增级联进入混沌——这正是不违反 A11-R 的"势能改变轨道拓扑"的
  唯一严格路径（补篇一 §2.2）。
- 分岔点与 logistic 解析值吻合到 ~0.1% 量级，说明检测到的级联是**真实的动力学分岔**，
  而非数值假象。
- 由此，"势使其瞬间破坏混沌"获得最可辩护的机制支撑：**混沌是窄窗 + 有限寿命**
  （推论 4.1 的参数窗），势通过调增益移出窗口。

## 诚实边界

1. 本实验是**最小离散原型**（logistic 型单状态），精确命中 M1 的机制主张，但
   **不等同于** r18 的完整宏加载原型；完整原型的周期倍增需单独构造（本轮不做）。
2. 出现级联 ⟹ M1 作为机制路径被验证；**不声称"认知必然混沌"**，只声称"离散迭代 +
   势调增益可进出混沌区"。
3. 阈值 3.571 因网格分辨率（0.0015/格）略偏 logistic 精确值 3.5699，误差 < 0.03%，
   属采样离散化，非机制偏差。
4. R11（增益越权 → 伪定向）为互补项，见 `../r11_*/`（下一步）。

# R8-B9 报告 —— 势消除混沌的唯一机制归约（M1/M2/M3 消融判别）

**实验**：`r8b_uniqueness.py` → `r8b_uniqueness.json`
**框架对应**：XS v3.4 · 补篇一缺口表 **B-B9**（未证明 M1 唯一；M2/M3 未被排除）
**证据硬度**：S2（自制最小离散原型，纯标准库，固定种子 20261028 可复现）

## 结论（先行）

**框架内唯一性成立**：在 A11-R（势-流分离）约束下，唯一能改变"混沌是否出现（拓扑）"的
势机制是 **M1**。四判据全真：

| 判据 | 内容 | 结果 |
|---|---|---|
| **U1** | M1 充分且合规：混沌窗内增益调制可把 λ 由正转负（移出混沌），g 仅乘性 | ✅ g=3.8 λ=0.43 → g=3.5 λ=−0.87 |
| **U2** | 非法通道排除：势放进状态导数（加性偏向 b）→ A11-R 合规检查标记违反 | ✅ 通道被框架排除 |
| **U3** | 合法对称破缺 = 增益不对称 = M1 推广：s 只进乘性增益、单调驱动动力学 | ✅ λ(s) 0.42→1.51 单调，s 无加性/梯度项 |
| **U4** | M3 正交：强制归宿不移动 g_chaos，只单调压缩混沌寿命 | ✅ g_chaos=3.57 不因 μ 移动；寿命 300000→51 |

**对 B-B9 的位移**：M2/M3 不再"未被排除"——
- **M2（对称破缺）**：合法形式（各候选增益不对称）**归约 M1**（多候选有效步长调制，
  乘性、合规）；非法形式（状态偏向）**被 A11-R 排除**。M2 不构成独立的拓扑消混沌机制。
- **M3（张力释放/A_μ）**：只压缩混沌**寿命**（τ ≤ 1/μ），不移动混沌**阈值**（拓扑）——
  与 M1 正交，管"持续多久"而非"是否出现"，不竞争拓扑唯一性。
- ⟹ B-B9 由"完全开放"推到位移：**框架内唯一性已证**；剩余"跨框架全局唯一性"转登记外部。

## 方法

在 R8 同一 logistic 型离散原型（`x_{k+1}=g·x(1−x)`）上做**机制消融**，另加对称双候选扩展
（`x1'=g1·x1(1−x1), x2'=g2·x2(1−x2)`，g1=g(1+s), g2=g(1−s)）承载 M2 的增益不对称。

- **U1**：混沌窗内（g=3.8，λ=0.43）用 M1（增益调制）把 g 降到 3.5 → λ=−0.87（移出混沌）；
  且 g 只作乘性系数（A11-R 合规）。
- **U2**：加性偏向项 b（势直接进状态导数）→ A11-R 合规检查判 FAIL → 该通道被框架排除。
- **U3**：对称双候选 s=0 时完全对称（乘性、无加性项）；施加 s 后动力学单调改变
  （λ(s): 0.42→1.51）——全程 s 只进乘性增益 g1/g2，无加性/梯度项。⟹ 打破对称的唯一
  合规通道是增益调制 = M1 的多候选推广，M2 ⊆ M1。
- **U4**：固定 g=3.8（拓扑不变），扫归宿概率 μ：g_chaos 恒 3.57（不移动），混沌连续寿命
  随 μ 单调缩短（300000→3135→861→244→95→51）——M3 只压缩寿命。

## 机制含义

1. **A11-R 是唯一性裁决器**：势-流分离强制势只能调增益。在此纪律下，"势消除混沌（拓扑）"
   只有 M1 一条合规通道；任何试图让势直接改状态的机制（M2 状态偏向）都触发合规失败。
2. **M2/M3 的合理分工被划清**：M2 是 M1 的多候选别名（增益不对称）；M3 是资源/代价驱动的
   终止机制（A_μ），处理混沌的存续而非存在。三者不构成三条独立消混沌机制。
3. 由此，补篇一 §1 的张力 T-1（势-流分离 vs 势破坏混沌）得到完整闭环：**在 A11-R 下，
   M1 是势消除混沌的唯一严格兼容路径**——连续系统中不成立、离散系统中成立（认知是离散的）。

## 诚实边界

1. **这是"框架内唯一性"**，不是跨框架/跨模型的全局唯一性。结论条件是
   "X-S-MERA 离散迭代 + A11-R（势-流分离）"。是否存在某个离散系统，其势可在**不调增益**
   的情况下也消除混沌（如通过相空间几何约束），**非本框架可裁**，转登记为外部开放项。
2. 最小离散原型（logistic 型）承载机制判别；不声称覆盖所有候选竞争形态（如并行抑制、
   不可言说候选）的完整机制空间。
3. U2 的"违反"是**构造性判据**（势进入状态导数即判 A11-R 违反），不是对真实认知中
   是否存在"势直接改状态"的实证——后者属 B 组外部问题。
4. U3 的 λ(s) 单调上升方向是宿主特性（s 增大使强候选更超临界）；判据只取"单调驱动 + 合规"，
   不取"是否消除混沌"，故方向本身不构成证据负担。
