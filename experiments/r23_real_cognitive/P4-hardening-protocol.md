# P4 加硬 · 真实认知数据采集协议（多模型 / 真人）

目标：把 B 线从"单模型 Doubao 自生成轨迹（S1）"加硬为**跨模型 + 真人（S0）**，正式触发
X2 步骤 2（CognitiveBridge.lean 立项）。本协议供你在外部模型或真人上按统一格式采集，回传后分析。

## 1. 任务集（两类对照）

**A 组 · 酝酿任务**（预期 U 下降 → ρ_res>ρ_exp）：正常可收敛的歧义/权衡问题
（参考 `trajectory.json` 的 T1–T6）。

**B 组 · 反刍任务**（预期 U 上升 → ρ_res<ρ_exp）：无解/悖论/无信息/矛盾问题
（参考 `trajectory_rumination.json` 的 R1/R2/R4/R5）。

> 每组至少 3 个任务。两组都要采集——否则又是单方向样本，无法验证双向判别。

## 2. 外部 LLM 采集步骤（在 ChatGPT / Claude / Gemini / 本地模型任选其一或多个）
1. 对每个任务，让模型做多步推理（逐步展开考虑，**显式列出它正权衡的候选解释**）。
2. 记录 **k=0 到 k=末** 每步的"候选解释类 + 相对支持权重"（整数伪计数，总数建议 10 左右，
   模拟 N 个采样单位的解释分布）。
3. 不预设结果；如实记录模型每步的真实候选与权重（包括反复、不收敛、发散）。
4. 按 §4 schema 填入 JSON。

## 3. 真人 think-aloud 采集步骤
1. 被试对任务**出声思维**（边想边说），录音。
2. 转写（可用录音转写工具），按推理句段切分（每段 = 一步）。
3. 对每步标注当前候选解释类 + 权重（由转写判断，或让被试自报"现在觉得哪个解释更可能"）。
4. 若被试快速收敛（一步到答案），该任务无震荡——**如实记录**（不必制造震荡）。

## 4. 轨迹 schema（与 B 线脚本兼容）
```json
{
  "protocol": "...",
  "source": "<模型名 e.g. ChatGPT-4o / 真人thinkaloud>",
  "hardness": "S1 或 S0",
  "trajectories": [
    {"id": "<任务id>", "prompt": "<任务原文>", "classes": ["<解释类1>", "..."],
     "steps": [{"k": 0, "weights": {"<解释类1>": <伪计数>, "..."}}, " ...每步... "] }
  ]
}
```

## 5. 回传与分析
- 把填好的 JSON 放 `experiments/r23_real_cognitive/`（命名如 `trajectory_chatgpt.json`），
  或发我。
- 分析：`python -u analyze_trajectories.py <file>.json <results>_out.json`
- 验收：看该模型的 **A 组多数是否 ρ_res>ρ_exp、B 组多数是否 ρ_res<ρ_exp**；跨模型一致性。

## 6. 诚实要求
- 每步候选与权重是**实际观察**，不是为了让判定达标而填。
- 快速收敛的任务（无震荡）如实标记（脚本会判无震荡段，不强行）。
- 真人数据需**脱敏**（不记录可识别个人信息），经知情同意。
