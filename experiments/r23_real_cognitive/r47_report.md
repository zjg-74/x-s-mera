# R47 报告 —— δ-时间化检验：震荡/方向是否时间化算子的产物（B 线 P4 方法论）

**实验**：`r47_delta_temporalization.py` → `r47_delta_temporalization.json`（`r23_real_cognitive/`）
**框架对应**：XS · B 线 P4 方法论 / 承接用户命题（快思维 A→B 瞬时、震荡是时间化的产物）
**证据硬度**：S2（纯内部仿真，判别器逻辑与 `analyze_trajectories.py` 逐行一致，固定种子可复现）

## 结论（先行）

**对用户命题的三层裁决——快思维本体不可测（成立），但时间化不是"方向的制造者"而是"可测性的必要条件"（部分否定最强形式）。**

- **Q0 · 必要条件成立**：纯 δ 事件（无时间化、无时间结构）判别器 **30/30 无震荡段、无判定** ⟹
  判别器依赖时间结构，**快思维本体（瞬时选择，τ=0）原则上不可测**。这实证了用户的核心洞察：
  震荡/方向需要时间轴，而快思维无时间轴。
- **Q1 · 时间化不凭空造方向**：无结构的随机 δ 事件，经任何时间化算子（m×focus）展开，
  方向检出率 **全 0**（判空转/无判定为主）⟹ 时间化**不制造方向**，方向需已有结构才能展开。
  这**否定了"震荡/方向纯是时间化伪影"的最强形式**。
- **Q2 · 有结构的慢思维方向跨算子稳健**：带候选集中度结构（酝酿=收敛 U↓／反刍=发散 U↑）的
  δ 事件序列，经细分 m∈{1,2,3,5}、聚焦 focus∈{0,0.3,0.6} 展开，方向保持率**全 1.0**；
  仅在极端全聚焦（focus=0.9，单候选 r=1）下崩到 0。

⟹ **判别器测的方向部分反映慢思维真实结构、非纯时间化伪影**；但快思维本体方向不可测，
判别读数仍应登记为"**慢思维（时间化认知）轨迹**"。

## 方法

1. **快思维 δ 事件**：每次瞬时选择（τ=0、无内部步、无时间延展），只携带**候选集中度结构**
   （主导类占比 p 随事件演化）。三类结构：酝酿（p: 0.25→0.85，熵降）、反刍（p: 0.85→0.25，
   熵升）、随机（p 恒定 0.25，无结构）。每结构 30 次采样。
2. **时间化算子**：把 δ 事件序列展开成时间轨迹（每事件 m 子步，焦点沿主导类演化，
   focus 控制主导占比锐化）——**时间化是生成可判轨迹的必要操作**。总质量 T=100（避免量化
   平台/熵阶梯跳变）。
3. **三问检验**：
   - **Q0 必要条件**：纯 δ 单点（不时间化）→ 判别器应无震荡段、无判定（快思维不可测）。
   - **Q1 造方向否**：随机 δ + 时间化 → 是否被判出方向（若判出 ⟹ 算子伪影）。
   - **Q2 结构恢复**：酝酿/反刍 δ + 时间化 → 方向是否跨 (m, focus) 稳健（若漂移 ⟹ 依赖算子）。
4. **判别**：与 `analyze_trajectories.py` 同逻辑——最长震荡段（r≥2 连续步）内 U=P̂ 熵净变化：
   降→酝酿、升→反刍、≈0→空转；无震荡段→无判定。

## 结果

| 检验 | 内容 | 结果 |
|---|---|---|
| Q0 | 纯 δ 单点不可测比例 | **30/30**（无震荡段、无判定）✅ |
| Q1 | 随机 δ 时间化方向检出率 | **全 0**（flat/none 为主）✅ 不造方向 |
| Q2 | 酝酿 δ 跨算子保持率 | m=1–5, focus 0/0.3/0.6 = **1.0**；focus=0.9 = 0 |
| Q2 | 反刍 δ 跨算子保持率 | m=1–5, focus 0/0.3/0.6 = **1.0**；focus=0.9 = 0 |

## 判据核销

| 判据 | 结果 |
|---|---|
| 判别器需时间结构、快思维本体(δ)不可测（Q0） | ✅ 30/30 |
| 时间化不凭空造方向（Q1，否定伪影最强形式） | ✅ 检出率 0 |

## 机制含义（对 B 线 P4 / think-aloud 方法论）

1. **判别器的本体论边界被划清**：它测的是**慢思维（被时间化的认知）轨迹**的走向；对快思维
   （瞬时选择）**原则性失效**（无震荡段）。这与数据层证据一致——H6q 题4/5/6（自指/沙堆/平行线）
   单步作答→无震荡段→无判定，正是快思维的判别空转。
2. **时间化的作用是"提供可测性"，不是"制造方向"**：无时间化→不可测（Q0）；有时间化但无结构
   →flat（Q1）；有时间化且有结构→方向稳健恢复（Q2）。⟹ 采集时不必担心时间化"伪造方向"
   （Q1 否定），但要认识到它**把对象从快思维转成慢思维**（Q0）。
3. **采集协议约束（与 R46 一致且更强）**：只要候选集中度结构存在（被试在多路径间权衡），
   细分/适度聚焦不破坏方向；**唯一危险是极端单线聚焦（focus→1）**，使 r=1 无震荡段。
   引导语"保持多候选并存地出声"可规避。
4. **快思维本体不可触达**：要测快思维（瞬时选择），需**非时间化通道**（反应时、生理信号、
   鼠标速度、隐式启动）——同样只是间接指标，且不在"串行语言"通道上。

## 诚实边界

1. **S2 合成**：δ 事件是参数化构造（主导占比演化），时间化算子为（细分 m + 聚焦 focus）的
   模型选择；真实快思维更多元（并行候选、抑制、不可言说）。
2. **结构已编码为熵走向**：本实验的"潜在结构"= 候选集中度（主导占比）演化；若真实认知结构
   不以熵走向承载（如纯并行不收敛），则判别器本就读不到——这由 Q0 的不可测性体现。
3. **"现实参数"（focus≤0.6）是假设**：若真实语言化普遍单线聚焦，方向稳健性下降——但实验
   证明单线聚焦正是需规避的，采集引导可缓解。
4. **不越界**：Q2 的"结构恢复"是**慢思维**结构的恢复，非快思维本质；判别读数仍登记为
   "慢思维(时间化认知)轨迹"。
