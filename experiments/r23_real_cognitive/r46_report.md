# R46 报告 —— 语言化序列化算子 + 判别方向稳定性（B 线 P4 方法论）

**实验**：`r46_language_serialization.py` → `r46_language_serialization.json`（`r23_real_cognitive/` 目录）
**框架对应**：XS · B 线 P4 方法论 / 承接用户批评（think-aloud 采集污染）
**证据硬度**：S2（纯内部仿真，判别器逻辑与 `analyze_trajectories.py` 逐行一致，固定种子可复现）

## 结论（先行）

**语言化（think-aloud 的慢思维显化）不翻转判别方向，只在病理性语言化下抹平方向（判空转）。**
- **翻转率全部 = 0**：语言化在任何参数下都不把酝酿（U 降）判成反刍（U 升），或反之。
- **现实采集参数下方向保持 100%**：细分 m=2/3、聚焦 focus≤0.3 → 24/24 轨迹方向保持。
- **抹平（flat）仅发生在病理性语言化**：高聚焦（focus≥0.6 且 m≥3）或碎片化（m≥5，
  每子步伪计数太少→无震荡段）。

⟹ **用户的批评成立，但精确化为"抹平而非翻转"**：think-aloud 的污染不会让判别器
**读错方向**，而会让它**读不出方向**（判空转）。这比"污染导致错误结论"更温和，也更可操作。

## 方法

1. **合成已知方向轨迹**：4 候选类、8 步、伪计数总量 10。酝酿（主导类权重 0.25→0.85，U 降）
   与反刍（0.85→0.25，U 升）各 12 条，原始判别全对（ground truth）。
2. **语言化算子**（快→慢显化，两种机制分离）：
   - **模式A·纯时间细分** `subdivide_keep`：每步等比例拆 m 子步，**不改变相对分布**。
     检验"细分粒度"单独是否破坏方向（对照组）。
   - **模式B·聚焦锯齿** `subdivide_focus`：每子步向焦点类（权重降序移动）**放大**
     boost=1+focus，**保留原始相对结构与方向趋势**。模拟"说 A 时 A 表观权重更高"。
3. **判别**：与 `analyze_trajectories.py` 同逻辑——最长震荡段（r≥2 连续步）内 U=P̂ 熵
   净变化：降→酝酿、升→反刍、≈0→空转(flat)。
4. **对比**：原始 vs 语言化后的方向（保持/翻转/空转），参数扫描 m∈{1,2,3,5}、
   focus∈{0,0.3,0.6,0.9}。

## 结果

| 语言化参数 | 模式A·纯细分（保持率） | 模式B·聚焦锯齿（保持率） |
|---|---|---|
| m=1（不细分） | 24/24 = 1.00 | 24/24 = 1.00 |
| m=2, focus≤0.6 | 24/24 = 1.00 | 24/24 = 1.00 |
| m=3, focus=0.3 | 24/24 = 1.00 | 24/24 = 1.00 |
| m=3, focus=0.6 | 24/24 = 1.00 | **12/24 = 0.50**（12 flat） |
| m=3, focus=0.9 | 24/24 = 1.00 | **2/24 = 0.08**（22 flat） |
| m=5（碎片化） | 0/24（全 flat） | 0/24（全 flat） |

- **翻转率：全部格子均为 0**。
- **flat（空转）**：仅在 ① 高聚焦（focus≥0.6）+ 细分（m≥3）、② 碎片化（m≥5）出现。

## 判据核销

| 判据 | 内容 | 结果 |
|---|---|---|
| 方向不翻转 | 现实参数窗口翻转率 = 0 | ✅ 全部 0 |
| 现实参数方向保持 | m=2/3, focus=0~0.3 保持率 ≥ 0.9 | ✅ 1.000 |
| R46 结论 | think-aloud 判方向对语言化稳健 | ✅ 稳健（污染=抹平，可规避） |

## 机制含义（对 B 线 P4 / think-aloud 方法论）

1. **think-aloud 判"方向"（酝酿/反刍）对语言化显化稳健**：因为判别读的是 U 的**相对走向**
   （震荡段内熵的净变），而语言化（细分+适度聚焦）保留了这个走向。用户的担忧"方向被污染"
   被实验否定——污染不改变方向，只可能在病理性语言化下**抹掉**方向。
2. **污染的真实形式是"抹平→空转"**：当被试**单线聚焦**（只讲当前一条路、忽略仍在考虑的多条）
   或语言**碎片化**（话碎成单候选）时，判别退化为无震荡段/空转，方向读数丢失。
3. **采集协议可操作约束**：引导语应**强调"保持多候选并存地出声"**——明确要求被试在否定
   A、尝试 B 时，仍说出"A 虽然否了但 B 可行、C 还在考虑"，避免陷入单线聚焦。这与
   `thinkaloud-math-script.md` 的"多路径/多设元"设计一致，且现在有了量化依据。
4. **幅度/τ\* 仍失真**：本实验只保证**方向**稳健；语言化改变时间尺度（每步拉长、步数增多），
   τ\* 落带、D-SCALE 读数仍受污染——这些需非语言化通道或独立标定。

## 诚实边界

1. **S2 合成**：合成轨迹是参数化构造（4 类、线性主导度演化），语言化算子是两个参数化
   （细分 m + 聚焦 focus）的模型选择；真实 think-aloud 的污染更复杂（自我说服、抑制直觉、
   不可言说内容丢失），未全部建模。
2. **"现实语言化参数"（m≤3, focus≤0.3）是假设**：若真实语言化聚焦更强（被试普遍单线化），
   方向稳健性会下降——但本实验证明**单线聚焦正是需规避的**，采集引导可缓解。
3. **方向稳健 ≠ 读数精确**：只保证符号（方向），不保证幅度/τ\*；后者仍失真。
4. **不声称 think-aloud 是"干净观测"**：污染是真实的（结构性：时间尺度+序列化+聚焦），
   只是污染不改变方向判别；think-aloud 数据仍应登记为"语言化（慢思维显化）轨迹"。
