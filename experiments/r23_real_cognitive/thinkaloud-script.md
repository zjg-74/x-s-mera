# 真人 think-aloud 采集脚本（S0 级真实认知数据）

用途：采集**真人出声思维**轨迹，作为 B 线 P4 外部加硬的 S0 数据，补齐"多模型/真人"
局限。本脚本是**对真被试的完整操作手册**——拿去录音，转写后按 §5 填轨迹模板回传。

目标：每个被试录 **6 个任务**（3 酝酿 + 3 反刍），每任务约 2–3 分钟出声思维。

---

## 一、对被试的引导语（照读，不必背）
> "下面我会给你 6 道小题目。你不用急着给我答案，请**边想边说**：把你脑子里正在想的
> 都说出来——包括你在两个选项之间犹豫、你突然觉得'不对'、你换了个思路，都请说出来。
> 想到什么说什么，不用组织语言，也不要怕说错。每道题你说到你自己觉得'差不多了'就可以
> 停，然后告诉我'好了'。"

要点：
- 强调"出声思维"，宁可啰嗦不可沉默。
- 不做引导、不提示"应该纠结"，让被试自然反应。

## 二、任务清单（照此顺序念给被试）

**A 组 · 酝酿任务**（正常可收敛/权衡，预期 U 下降 → ρ_res>ρ_exp）
1. **A1 择校**："名校的冷门专业，和普通院校的热门专业，你会怎么选？"
2. **A2 买手机**："旧手机还能用但有点卡，你该买新手机，还是继续用旧的？"
3. **A3 周末安排**："周末只有一天，你要同时完成工作、锻炼、陪家人，怎么安排？"

**B 组 · 反刍任务**（悖论/无解，可能引发纠结，预期 U 上升 → ρ_res<ρ_exp）
4. **B1 理发师**："有个理发师说：我只给不给自己理发的人理发。那他给自己理发吗？"
5. **B2 堆沙**："多少粒沙才算'一堆'？1 粒不算，2 粒不算……那到底多少粒算？"
6. **B3 自指**："'这句话是假的'——这句话是真的吗？"

## 三、录音操作
- 手机录音即可；**安静环境**，避免旁人声/噪音。
- 每道题之间停 2 秒（留静默作分隔）；或每道题单独录一段。
- 单被试全程约 15–20 分钟。

## 四、转写 → 轨迹（归约规则）
对每道题的录音，做**逐句转写**，然后按以下规则归约成轨迹：

1. **切段 k=0,1,2,…**：把转写按"被试改变主要考虑方向"切段。例如从"名校牌子好"转到
   "但专业就业更重要"→ 这是新一步。同一考虑内反复重复不算新步。
2. **识别候选解释类**：每段中被试正在权衡的候选答案（如 A=名校冷门、B=普通热门、
   C=看个人）。写出候选类名。
3. **打伪计数（权重）**：按被试在该段的倾向强度给每候选打整数（总和约 10）。例如
   "明显偏向 A、略犹豫 B"→ {A:6, B:3, C:1}。
4. **如实原则**：
   - 被试**一步直接给答案**（无犹豫）→ 该任务只有 1 步，脚本会判"无震荡段"，**如实记**。
   - 被试**反复、发散、越来越乱**→ 权重如实反映候选增多/熵升。
   - 不要为了让判定达标而改权重。

## 六、诚实与伦理
- **知情同意**：告诉被试"录音仅用于认知过程研究，匿名处理，不用于识别个人"。
- **脱敏**：轨迹 JSON 不含姓名/手机号等可识别信息；用代号（如"真人_001"）。
- **客观性**：转写归约是分析者的判断，如实反映转写，不预设"应该酝酿还是反刍"。

或发我。分析：`python -u analyze_trajectories.py trajectory_human_001.json results_human_001.json`。
