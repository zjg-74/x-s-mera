# B2 · 桥检验（R31：A_D 一致性守卫）——方法 + 脚本准备

对应 `18-v3.3-formal-framework-charter.md` §6.2 **B2**（缺口 **B-B19** / **R43′**）。
理论锚点：`docs/xs-framework/15-v3.2-gauge-fixed-framework.md` §7.2（R43′）与 §7.4（R31）。

## R43′ 与 R31 的关系（必须分清，避免误读）

- **R43′（真桥检验）**：桥 B-B19 写成 `dU/dt = ρ_exp·Ψ + β₀`，其**可证伪形式**为
  `β₀ = −ρ_exp·Ψ(k*_U)`，其中 **Ψ 必须来自独立于 ΔE 的第三通道**（补篇四独立标定程序）。
  若用 ΔE 代替 Ψ，则**退化为重言**（U 内点峰蕴含 ΔU(k*)=0，由 ΔU=ρ_exp·ΔE+β₀ 即得）。
- **R31（本脚本实现）**：检验 `β₀ = −ρ_exp·ΔE(k*_U)`（重言形式）。它是 **A_D 一致性守卫**——
  **不是对桥的检验**，而是检验"数据是否满足 A_D + 内点峰自洽"：A_D 上应≈0 误报，
  故意违反 A_D 的注入族上误报率应 →1.0（R31 判据原文）。

## 目的与性质（必须诚实声明）

- 本实验是**方法 / 检验流程准备**：在合成数据上验证 R31 峰点检验的判别能力
  （正常族≈0、违反族→1.0）。**不是对现实认知数据的检验**。
- **R43′（独立标定 Ψ 的真桥检验）不在本脚本范围内**：它需补篇四的独立标定程序
  （经验分布熵 + Miller–Madow；Q=I(M;C_in|φ)），需要真实认知过程数据，无法在合成 A_D
  数据上忠实模拟。留待 B 组获得真实数据时实施。
- R31 是重言形式的守卫，**不能**被误读为"桥成立"的证据——它只暴露 A_D 一致性破坏。
- 仅标准库、确定性（pivot 网格），机械可复核。

## 方法

1. **合成 A_D 轨迹**（钻研型，ρ_res=3>ρ_exp=1，θ_U=3）：`r(k)` 分段投入使 U 有**内点峰**。
2. **回归**：`U = b0 + ρ_exp·E + β₀·k`（多重线性回归）得 `(ρ_exp, β₀)`。
3. **峰点检验**：在 U 内点峰 `k*_U` 处，A_D 预测每步 `ΔU = ρ_exp·ΔE_c + β₀·dt`；峰点 ΔU_c≈0，
   故检验相对偏离 `|ρ_exp·ΔE_c + β₀·dt| / (|ρ_exp·ΔE_c|+|β₀·dt|)` 应≈0。
4. **两族对比**：
   - **正常族**：纯 A_D 生成。
   - **违反族**：A_D⁺ 边界层注入（`ΔU += κ_E·ρ_exp·(1−ρ·g(U))·dt`，`g(U)=g_strength·U`）——
     A_D⁺ 是"故意违反纯 A_D"的规范形式（§15 §5.7），也是 B3 残差反演的背景。

> 判据细节：`β₀·dt`（每步）而非 `β₀·2·dt`——初版用 2·dt 是**量纲错误**，致正常族误报 1.0，
> 已修正（本项开发中暴露并修复）。

## 结果（`b2_results.json`）

参数：`DT=0.01, K=3000`，pivot∈{0.4,0.5,0.6,0.7}。

| 族 | g_strength | 峰点 rel_viol 范围 | 误报率 | 判定 |
|---|---|---|---|---|
| 正常（纯 A_D） | 0.0 | **1e-4 ~ 5e-4** | **0.000** | ✅ 不误报 |
| 违反（A_D⁺ g=0.4） | 0.4 | **0.95 ~ 1.0** | **1.000** | ✅ 抓到 |
| 违反（A_D⁺ g=0.8） | 0.8 | 1.0 | 1.000 | ✅ |

判据：正常族误报率 <0.05、违反族误报率 ≥0.9。全部通过。

## 结论

- **检验流程正确**：R31 峰点检验在合成数据上以 `正常族 0.000 / 违反族 1.000` 明确区分
  纯 A_D 与 A_D⁺（边界层）违反——它可靠地充当 **A_D 一致性守卫**。
- **用途**：真实 `(E,U)` 数据先过 R31 守卫确认满足 A_D（否则不能套用 A_D 结论）；
  再谈 R43′ 的独立 Ψ 真桥检验。

## 诚实边界 / 未做

- **R43′ 未实现**：独立标定 Ψ（补篇四）的真桥检验需真实认知数据，本脚本只做 R31 守卫。
- **合成数据非经验验证**：判别能力在合成数据上自洽，不构成对现实认知的断言。
- **重言性质**：R31 通过**不**意味着桥 B-B19 成立，只是数据未违反 A_D。
- **峰点存在性**：需 U 有内点峰（否则 R43′ 只能取边界值，判据另行）。
