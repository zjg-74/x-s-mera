# B3 · 残差反演 `g`（R32）——方法 + 脚本准备

对应 `18-v3.3-formal-framework-charter.md` §6.2 **B3**（缺口 **B-B43** / **R32**）：

> 「残差反演 `g`：把『残差是噪声』变成可检验假设。」

## 目的与性质（必须诚实声明）

- **本实验是「方法 + 脚本准备」**：实现在**已知 `g` 的合成轨迹**上从残差反演 `g` 的算法，
  并按 R32 原文判据验证「残差反演值与真值一致」。**不是**对现实数据的经验验证。
- **反演恢复 `g` 的变异 / 形状（相对路径均值）**；**绝对水平不可辨识**——常数平移被
  `∫(g−ḡ)dt` 吸收（规范自由度，B-B23），这是本方法的固有边界，不是缺陷。
- 「真实认知残差确实是 `g` 信号」**不由此声称**——那属于 **B4**（跨任务/跨人群验证）。
- 仅标准库、确定性合成（无随机），机械可复核。

## 理论锚点

`docs/xs-framework/15-v3.2-gauge-fixed-framework.md` §5.7 **推论 R43**：

A_D⁺（带边界层 `g(U)`，`g(0)=0`、`g` 单调增）下：

```
dU/dk = ρ_exp·dE/dk + κ_E·ρ_exp·(1 − ρ·g(U))
```

⟹

```
U(k) − ρ_exp·E(k) = α + βk − κ_E·ρ_exp·ρ·∫₀ᵏ (g(U(t)) − ḡ) dt
```

⟹ **推论 R43**：共线残差 ≡ 0 ⟺ `g(U(k))` 沿路径为常数；**残差的形状即 `g` 沿路径变化的反演**。

即残差不是噪声、是信号——这就是把「残差是噪声」变成可检验假设的机理。

## 反演方法（三步）

1. **残差**：`R(k) = U(k) − ρ_exp·E(k)`。
2. **去仿射趋势**：最小二乘拟合 `R(k) ~ a + b·k`（吸收 A_D 基线 `α+βk` 与 `g` 积分的线性部分），
   得 `D(k) = R(k) − (a+b·k)`。
3. **中心差分反演**：由 `dD/dk = −κ_E·ρ_exp·ρ·(g(U)−ḡ)`，
   `g_inv(k) = −D′(k) / (κ_E·ρ_exp·ρ)`，中心化后与真值变异对比。

> 说明：反演得到的 `g_inv` 与 `g(U)` 差一个常数平移 `ḡ`（未知）；因此比较用**中心化后的形状**
> （Pearson 相关 + 归一化 RMSE），振幅比例依赖 `κ_E·ρ_exp·ρ` 的独立标定（关联 B2 / B-B19）。

## 结果（`b3_results.json`）

参数：`ρ_exp=1.0, κ_E=0.5, ρ=1.5, STEP=0.01, N=2001`。

| 反演对象 | corr（中心化相关） | scale_std | norm_rmse | U 范围 | 判定 |
|---|---|---|---|---|---|
| `g(U)=U` | **1.000000** | 1.004 | **0.0000** | 0.73–1.00 | ✅ |
| `g(U)=U²` | **1.000000** | 1.007 | **0.0003** | 0.86–1.00 | ✅ |
| `g(U)=tanh(U)` | **1.000000** | 1.002 | **0.0000** | 0.94–1.00 | ✅ |
| `g(U)=U/(1+U)` | **1.000000** | 1.001 | **0.0002** | 1.00–2.33 | ✅ |

**负对照**（不应产生虚假结构）：

| 对照 | corr | g_inv 的 std | 判定 |
|---|---|---|---|
| `g≡0`（A_D 退化） | 0.0000 | **6.6e-14** | ✅ 无结构 |
| `g≡0.5`（常数，无变异） | 0.0000 | **2.8e-14** | ✅ 无结构 |

判据：`corr > 0.99 且 norm_rmse < 0.05`（正例）；`g_inv_std < 0.02`（负对照）。全部通过。

## 结论

- **反演方法正确**：在已知 `g` 的合成轨迹上，残差反演以 `corr=1.0`、`norm_rmse≲1e-3` 恢复 `g` 的变异形状；
  负对照确认方法**不会**把噪声/常数误判为结构。
- **可检验性落地**：方法已就绪，一旦有真实观测的 `(E,U)` 序列与 `ρ_exp/κ_E/ρ` 标定，即可套用
  反演器检验「残差是否为 `g` 信号」——把 B-B43 从「不可辨识」推进为「可检验」。

## 诚实边界 / 未做

- **U 动态范围较窄**（多数情形 U∈(0.7,1.0)）：受 `ρ·g` 平衡约束；当前范围已精确恢复，
  更宽范围与**加噪稳健性**留作后续扩展。
- **振幅比例依赖 `κ_E·ρ_exp·ρ` 标定**：形状（corr）不依赖系数，但振幅需独立标定（B2 关联）。
- **不是经验验证**：本方法在合成数据上自洽，不构成对真实认知过程「残差是 `g`」的断言。
