# G-26e · 非认知域对照——流行病防控（跨域可移植性演示）

对应 `docs/xs-framework/26-v3.4-coupling-channel-from-mms-engineering.md` §7.4 **G-26e** 行
（"单域 MMS；跨域对照未做；A13 排期后加非流体力学域"）与 `27-v3.4-boundary-map.md` §5 表 B6 行
（G-26e：非认知域对照）。

## 目的

A13 已在**认知域**（换工作决策）演示了 D-DRILL / D-CONV / D-IDENT 判定程序。本项把**同一套
判定程序机械移植**到一个既非流体力学、也非认知过程的领域——**流行病防控**（公共卫生 /
系统动力学域），检验框架判读的**跨域可移植性**。

## 映射（非认知域实例）

| 量 | 流行病防控域含义 | 认知域（A13）含义 |
|---|---|---|
| `E` | 累计已干预量（确诊/隔离/处置累计） | 已展开/已查证的信息 |
| `U` | 未决风险存量（潜伏/未识别/未处理风险） | 未决量（熵的演示代理） |
| `r` | 防控投入强度 | 检索/努力投入 |

## 方法

复用 `experiments/a13_first_case/a13_first_case.py` 的 `make_cfg / trajectory / d_drill /
d_conv / d_ident`（跨域**机械移植**，未改判定程序一行）。两条叙事翻译为 A_D 轨迹：

- **场景 A（有效管控，ρ=2）**：U0 小，未决存量后段收敛到接近 0
- **场景 B（防控失守，ρ=0.6）**：U0 大，未决存量后段继续扩大

## 结果（`g26e_contrast.json`）

| 场景 | 无框架人工判断 | D-DRILL | D-CONV | D-IDENT |
|---|---|---|---|---|
| A 有效管控 | 『管控有效，快清零了』 | **drill**（U_first） | **收敛**（U_end 0.45，峰高 7%） | ρ_exp 自足（A）；sign(1−ρ)=−1（B） |
| B 防控失守 | 『越防越多，失控了』 | **hollow**（E_first） | **发散**（U_end 26.9，峰高 96%） | ρ_exp 自足（A）；sign(1−ρ)=+1（B） |

**同一判定程序**在非认知域上仍产出：
- **互斥类别**（D-DRILL）：钻研相（有效管控）vs 空洞相（防控失守）
- **收敛方向**（D-CONV）：存量收敛 vs 存量发散
- **可定位可辨识量**（D-IDENT）：A/B/C/D 分级不依赖领域（ρ_exp 自足、sign(1−ρ)、κ_E/ρ_res 需外部、a/b/e/u 为伪目标）

## 结论（诚实限定）

- **判定程序跨域可移植（演示层面）**：A/B/C/D 分级、钻研/空洞楔形、收敛判据均不引用具体领域，
  在认知域（A13）与非认知域（流行病）上产出同构的互斥类别 + 可辨识量。
- **不构成对疫情机制或防控效果的断言**：仍是叙事→A_D 轨迹的演示性映射，非真实疫情数据。

## 诚实边界

- 演示性映射，非现实测量；真实疫情无客观可测 (E,U) 双序列。
- 只覆盖一个非认知域实例（流行病）；跨域可移植性的**经验**验证仍需多域真实数据。
- 与 A13 同构的限制：真/伪收敛需外部证伪信息，D-CONV 只判方向。
