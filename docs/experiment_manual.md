## 5 LE 生命–环境耦合仿真实验（LE Coupling, X-S-MERA 3.4-le.1）

### 5.1 实验目标

在生命（L）–环境（E）双投影子系统上验证四个理论命题：

1. **d 是边界重合度标量**（无量纲），不是时空尺度比；尺度差只是张力的发生器之一。
2. **D 是 d 的统计分布集合**；其封装性（A10 边界封装条款）充当 M-完备性指标。
3. **势–流分离（A11a/A11b/A11-R）**：语义势只调制耦合增益，状态演化完全由载体通量驱动。
4. **命题 2′（C1+C2 双条件）**：三区判定与 F1/F2 两类失效；F2 = 礁石伪收敛。

### 5.4 分段时序（注意：与早期方案不同，顺序不能换）

| 阶段 | 时间 | Φ | C2 | 预期 |

### 5.5 实测结果（seed=7）

| 阶段 | mean d | Var(D_L) | ghost 幅值 | 主导区 | 封装失败步数 |
| --- | --- | --- | --- | --- | --- |
| S1 稳定 | 0.981 | 0.00027 | 0 | high 300/300 | 0 |
| S2 F2 | 0.947 | **0.0166**（越界 0.01） | 0.833 | middle 300/300 | ~300 |
| S3 坍塌 | 0.236 | 0.0447（过渡混合峰 0.089） | 0 | high→low（t≈38.7 越阈） | 全部 |
| S4 恢复尝试 | 0.035 | 0.0007（回落） | 0 | low 300/300 | 收尾回落 |

全程占比：high 35.2% / middle 25.0% / low 39.8%；d ∈ [0.035, 0.997]。

### 5.6 结果解读

1. **S2 是本实验的核心证据**：d 保持 0.947（C1 成立、重合充分），但接口不兼容使 ghost 伪力
   （0.83）把副模态压到 0，同时 Var(D) 越过封装界——**表观耦合正常、D 已不可封装**。
   这就是「礁石伪收敛」的可操作判据：伪收敛不在状态上显形，而在 D 的统计形态上显形。
2. **F1 与 F2 的失效面不同**：F1 = I1 不存在（C1 失败，通量置零）；F2 = 细化不可实现
   （C2 失败，产生非守恒伪力）。分别对应命题 2′ 的两类失效，并与生物学配子前/配子后隔离、
   MMS 中支撑不相交/算子不相容（ghost force、伪波反射）同构。
3. **S4 滞后（吸收态）**：d 出现在通量的乘子里，d≈0 时通路自锁；势梯度恢复到 0.40 也无法重建
   耦合。恢复只能经由：外力重置状态（跨公理改写，A8）或经中介系统的中继链（每段满足局部
   C1+C2）。注意：**这一性质部分是建模选择的产物，不能直接当作生殖隔离不可逆的理论预测**，
   需与 Dobzhansky–Muller 型不可逆性做对照。
4. **封装性检验不能单独使用**：F1 稳态下 D 反而"可封装"（方差 0.0003）——因为根本无交互。
   封装性必须与 C1 联合判读：`C1 失败` 是交互缺失，`C1 成立 + 封装失败` 才是 M-不完备真信号。

### 5.7 理论对照

| 观测 | 理论条款 |
| --- | --- |
| S1：d 高、D 可封装、ghost=0 | A10 边界封装条款：边界张力封装为"边界宏"，不计入 M-不完备 |
| S2：d 高 + Var(D) 越界 + ghost>0 | 命题 2′ F2 + A10：D 偏离可封装形态 = M-不完备真信号；礁石伪收敛 |
| S3：d 跌破阈值、通量归零 | 命题 2′ F1；I1 不存在 |
| S4：恢复失败 | A8：直接通路关闭后只能经跨公理改写或中继链 |
| 势梯度改变不直接影响状态 | A11-R：势-流二分是瞬时分析性分层 |

### 5.8 已知局限与下一步

1. 参数未标定；3 维状态是占位。下一步把 L/E 状态映射到 LE 体系 F1–F17 / E1–E7 的量（生物量、损伤、资源、扰动）。
2. ghost 伪力需从界面算子不相容推导（对应 MMS 的提升/限制算子），当前是现象学项。
3. 需要 **阴性对照**：全程 C2 兼容、Φ 恒定的运行应全程 high 且封装不失败（可用 `run_le_simulation` 改 STAGES 实现）。
4. 需要 F1 恢复实验：经"中继"（人为引入第三子系统逐段重合）能否重建耦合——这是命题 2′ 中继链的直接检验。**（已在 §6 完成）**

## 6 中继链实验（Relay Chain, 命题 2′ 的中继部分）

### 6.1 实验目标

1. F1 吸收态能否经中继链恢复耦合；
2. 串联中继的**复合律**：乘积律 ∏dᵢ 还是调和律 1/Σ(1/dᵢ)；
3. F2 段在链中的角色：阻断还是污染。

### 6.2 脚本

| 项 | 路径 |
| --- | --- |
| 模块 | `src/relay_chain.py`（`RelayChain` / `simulate_transport` / `min_relay_count`） |
| 实验 | `experiments/sim_relay_recovery.py` |
| 测试 | `tests/test_relay_chain.py`（10 项） |
| 输出图 | `figs/relay_recovery_and_law.png` |

方法说明：传输率测量采用**夹持端点纯输运**（`clamped_ends=True`、关闭非负截断），
每段重合度作为**已测定常量**输入（对应 MMS 实践中重叠区性质一次性测定），
以隔离复合律本身；端点间距 1，理想单段（d=1）通量为归一化分母。

### 6.3 实测结果

**复合律（每段 d=0.9）**：

| n（段数） | 实测 T | 调和律 1/Σ(1/dᵢ) | 乘积律 ∏dᵢ |
| --- | --- | --- | --- |
| 1 | 0.900 | 0.900 | 0.900 |
| 2 | **0.450** | 0.450 | 0.810 |
| 3 | **0.300** | 0.300 | 0.729 |
| 4 | **0.225** | 0.225 | 0.656 |
| 不等段 [0.95, 0.7] | **0.403** | 0.403 | 0.665 |

**失效模式（n=2, d=0.9）**：

| 配置 | 传输率 T | ghost 污染（内部副模态偏移） |
| --- | --- | --- |
| 全兼容 | 0.450 | 0.000 |
| 一段 F2（C2 失效） | **0.450（不变）** | **0.0962 = 0.25/(1+1.6)，解析吻合** |
| 一段 F1（C1 失败） | **0.000（阻断）** | 0.000 |

**恢复实验**（端距 1.09 的坍塌对）：

| 配置 | 端距变化 | 末态最弱段 d |
| --- | --- | --- |
| 无中继 | 1.09 → 1.16（继续发散） | 0.035 |
| n=1（不足） | 1.08 → 1.16（**半途吸收，更糟**） | 0.035 |
| n=3（充分） | 1.08 → **0.26（恢复）** | **0.98** |

**中继数下限**：`min_relay_count`——坍塌对（gap 1.09）n_min=3；较近对（gap 0.6）n_min=1。

### 6.4 三个结论（其中两个是对命题 2′ 的修正）

1. **乘积律被否定，串联中继服从调和/短板律**：T = 1/Σ(1/dᵢ)，等长同质时 T = d/n。
   物理原因：串联链稳态下各段通量相等，等效电导为各段电导的调和组合；
   总传输由**最弱段**支配，不是各段独立事件的连乘。
   ∏(pᵢqᵢ) 只在"各段独立必要的并联/事件语义"下成立（例如：中继路径的
   存在概率 = 各段存在概率之积）。命题 2′ 须区分两种复合：
   **传输强度 → 调和律；路径存在概率 → 乘积律。**
2. **C2 不是通行必要条件，而是"可信度"条件**：F2 段的主模态照常传输
   （T 不变），但注入解析可预测的 ghost 污染（0.25/(1+1.6)，随链长增大）。
   这与"F2 = 伪收敛而非阻断"自洽，也解释了为什么伪力难以被端点察觉——
   它不削减传输，只污染传输。
3. **中继数下限由弱端尺度决定**：d 是尺度相对量，端距不变时端点范数越小、
   每段相对距离越大 → n_min 越大（gap 1.09 需 3 段，gap 0.6 需 1 段）。
   这是 I1 可构造性的定量代价，与 MMS 中"跨尺度必须分级桥接、不能一跳"
   （MAAD/bridging domain 的分级重叠区）直接同构，可作为可检验预测。

### 6.5 判读注意

- n=1 的"半途吸收"现象：不足的中继把弱端拉向中继而够不着强端，发散比无中继更快。
  推论：**中继不是越多越好，是"至少要够数"**；数量不足的桥接可能加剧失配。
- 传输率测量依赖"每段 d 为常量"的隔离假设；与状态反馈耦合时（`overlaps=None`），
  d 会随收敛动态变化，复合律的静态形式不再直接适用——这正是 §5 中 F1 吸收态的来源。


## 7 R2 跨域 D 形态审计（Constraint Strength vs D-Form Ordering）

### 7.1 目的

回归核验清单第 2 项：物理 / 生物 / 人文各选一个成熟投影系统，检验 D 形态排序与约束强度排序是否一致，并检验 A4 度量与 A10 封装性判据的可操作性。

### 7.2 脚本

`experiments/r2_constraint_ordering.py`，依赖 `src/d_form_audit.py`，输出 `figs/r2_d_form_ordering.png`。测试：`tests/test_d_form_audit.py`（8 项）。

### 7.3 三域标定（文献锚定，参数为近似）

| 域 | τ = 1/σ_quoted | κ | 路径数 m | 锚点 |
|---|---|---|---|---|
| physics | 1.9e6（540 ppb） | 0.98 | 2 | μ子 g−2 最终结果（2025-06）：实验 127 ppb，格点理论 540 ppb，差 0.6σ；二十年 3.7–4.2σ 反常经理论侧换路（数据驱动 → 格点 HVP）后消失 |
| biology | 10 | 0.85 | 2 | GWAS 效应量尾指数 α∈(1,2)（多项式尾）；双指数混合优于单指数 |
| humanities | 1.25 | 0.55 | 1 | 2008 年预测误差 ~6σ（高斯假设下）；高斯 VAR 对崩塌赋零概率 |

### 7.4 结果

1. 核心宽度排序与 τ 一致——但属**构造性**（核心宽度由申报精度生成），非独立支持。
2. z 峰度排序：生物(4.6) > 人文(0.6) > 物理(−0.5)——**与 τ 不一致**；高精度域因核心被路径偏移压扁，峰度趋 0/负。
3. 等峰度线呈对角：峰度=3 可由 (κ=0.90, ρ≈2.5) 或 (κ=0.60, ρ≈5.3) 给出 → 峰度对 (ρ, κ) 多对一，**跨域不可辨识**。
4. 可辨识的读出方式：τ 用外生申报精度；κ 用绝对标度尾部质量；路径数 m 用绝对标度模态计数。

### 7.5 理论落点

- A4 拆为 τ（外生申报精度）× κ（覆盖度）双轴，"正态性"度量废除。
- A10 失败信号改用绝对标度尾部质量与承诺兑现比（核心宽度/申报精度）；禁用 σ 倍数口径做跨域比较——物理 5σ 与经济学 6σ 是不同物理量（失配比 ρ 分别 ≈3.7 与 ≈1.25）。
- A3-02 获操作判据：指向同一可观测量的不同路线 = S 路径差异，可由**跨实现一致率**裁决（μ子 g−2 案例即域内纵向可辨识的实例；独立格点组彼此一致 vs 数据驱动内部矛盾）。C2 由此获得操作化定义。

### 7.6 局限

三域参数为单点锚定近似，非元分析；生成器假设未建模尺度与 τ 无关（真实相关会使不可辨识性更强）；峰度饱和值依赖路径几何（a_route/a 取 0.4–1.0）。

### 8.4 三联排除（elimination ladder）

```
① 区域门关闭（C1 不成立）            → A10 不适用
```

关键数值：SUB_1F β = −0.089（P5 触发）；SUB_OU β = −0.393（P5 不触发）；
F2 修接口后封装性回归（repair_ok = True），两类亚网格场景修复无效。

### 8.6 发现

1. **清单写得出来，且五个可判场景全部裁决正确**——A10-03 的"写不出失败现象"正式解除。
2. **D 形态判据（P2–P4）无判别力**：F2 / SUB_OU / SUB_1F 三者触发模式完全相同（●●●·）。
   单看 D 形态，礁石、分辨率不足、真坍塌不可分。三联排除不是可选项，是必要结构。
3. **排除顺序 load-bearing**：F2 在反序（先看标度律）下被误判为 resolution。
   系统性接口伪影在标度律上可与有限尺度噪声同形，只有"修接口"能分开。
4. **P5 的判别力边界（τ 扫描，表 4）**：β 随 τ 连续过渡（−0.52 → −0.07），
   在 τ≈40 步穿过阈值。τ∈[~25,128] 步的**有限尺度过程会被误判为坍塌**；
   τ 超出窗上界则与无尺度不可分（保守方向）。P5 的真实身份是
   "特征尺度是否落在扫描窗下部"的探测器。使用前必须先把扫描范围对齐到疑似尺度区间。
5. **盲区 G2 得到证实**：P2–P5 全是位置不变量，−6Δ_quoted 的系统性偏置被判为 M-完备。
   偏置只能靠跨实现一致率（R2 的 C2 操作化定义）捕获——与 R2 结论闭环。
6. **P2 阈值过松**：SUB_OU / SUB_1F 是单峰随机过程，BC 仍达 0.57/0.62 越过 5/9。
   2.4 万样本下 Sarle BC 对轻微厚尾敏感，"多峰"判据需配模态计数使用。

### 8.7 理论落点

- **A10 获得可执行形式**："必须无限细分才能解释" → "残差–粒度标度律 β ≥ −0.15，
  且扫描范围已对齐疑似尺度区间，且接口修复无效"。A10 从极限陈述变为三步可执行判据。
- **与 A11c 衔接**：collapse 裁决应触发"新势生成"检查（A11c：载体流生成新定义结构）——
  D 无特征尺度可能是新公理集正在形成的前兆，而非单纯失效。
- **与 MMS/HMM 闭环**：HMM 的有效性前提是尺度分离；P5 恰是尺度分离检验的实现。
  d/MMS 验证中的边界反例（HMM 不依赖空间重叠）由此获得统一处理：
  HMM 可用 ⇔ P5 说"有特征尺度" ⇔ A10 说"M-完备"。

### 8.8 局限（登记）

1. 亚网格驱动是**观测层叠加**代理：ε 不反馈状态方程。真实的未闭合自由度会反馈，
   可能改变宏观轨迹；此时礁石与坍塌的区分会更难而非更易。
2. 粒度扫描窗仅 2 个数量级（B = 1…128）。带外特征尺度不可判。
3. BIAS 只演示了常值偏置；时变漂移（非平移）可能部分可被判据看见。
4. 单种子结果；判据阈值未做多 seed 置信区间（P2 的 0.57/0.62 距阈值很近，需复验）。

## 9 R5：推论 3（演化无向择优）的 A9 资格审计

### 9.1 目的

回归核验清单第 5 项：判据②改统计版、判据③改 d 重合度重述之后，推论 3 的降级是否仍成立。
推论 3 原文（v3 定稿）：「无向变异提供素材，资源与环境约束完成筛选；演化仅趋向局部适配最优，
不必然复杂化、不必然进化」。原降级理由（A9-03）：内部干预后下游结果**不可预测的确定性**、
路径依赖——即判据②的**确定性读法**。

### 9.2 脚本与操作化

`experiments/r5_a9_qualification.py`，判据实现在 `src/a9_qualification.py`；
图 `figs/r5_a9_qualification.png`；测试 `tests/test_a9_qualification.py`（13 项，全套 66 项通过）。

现实 = 个体级 Wright–Fisher（二项采样）；M 层粗模型 = 扩散近似（高斯增量 WF，同 s 同 N）；
d = 分布直方图交叠（与内核边界重合度 d 同一构念）。预注册阈值：θ_d = 0.80、
θ_eff = 0.20、Δs = 0.02、T = 200 代、p0 = 0.10、reps = 2000。
仿真核正确性锚点：中性 P_fix ≈ p0；选择情形 P_fix 落在扩散解析式
(1−e^{−2Ns·p0})/(1−e^{−2Ns}) 上（测试锁定，偏差 < 0.04）。

### 9.3 结果（N ∈ {50, 200, 2000, 20000}，Ns = 1, 4, 40, 400）

| N | Ns | 确定性读法通过率 | 统计版 d | 干预响应 eff | ③冻结迁移 d | 裁决 |
|---|---|---|---|---|---|---|
| 50 | 1 | 0.001 | 0.988 | 0.124 ✗ | 0.002 ✗ | 干预失敏 |
| 200 | 4 | 0.059 | 0.933 | 0.419 ✓ | 0.097 ✗ | 语境内宏，不可迁移 |
| 2000 | 40 | 0.388 | 0.935 | 0.948 ✓ | 0.473 ✗ | 语境内宏，不可迁移 |
| 20000 | 400 | 0.897 | 0.951 | 1.000 ✓ | 0.967 ✓ | 语境内宏 M |

判据①闭合（N=2000）：m=0 时 d(低池,高池)=0.94 闭合；m=0.02 起即 0.00 泄漏，
且忽略 m 的粗模型预测同步劣化——①失败可测，非形式问题。
序层方向 D_seq = P(优等位固定) − p0：Ns=0.1 → 0.013（≈无向）；Ns=1 → 0.106；
Ns=400 → 0.900。「无向」在 s>0 时**不成立**，是 Ns→0 的极限性质。

### 9.4 发现

1. **原降级【理由】不成立**：它依赖判据②的确定性读法（点预测容差带），
   该读法在 Ns=40 时都只有 0.39 通过率；而统计版读法（预测分布重合度）全境 ≥ 0.93。
   被淘汰的是"点预测"，不是"可预测"——把两者混为一谈正是 A9-01 压测指出的问题。
2. **原【结论】部分保留、须改写**：②的统计版 + 干预版给出一条硬边界——
   Ns ≲ 5 时改 s 不改变下游分布（干预失敏，eff=0.12 < 0.2），此时机制失去宏资格；
   Ns ≳ 5 时②通过。③（d 重述版）表明**冻结参数跨数量级迁移即崩塌**
   （N=2000 处 d 仅 0.47），但按语境重标定后 d 回升 ≥ 0.94——失败是参数迁移问题，不是机制错误。
3. **正确表述**：自然选择是**逐语境的宏 M**，资格条件为
   「Ns ≳ 5 ∧ m = 0 ∧ (s, N) 逐语境显式申报」。不是"推论 3 降级为机制"，
   而是"宏 M 资格本身是逐语境的"。
4. **推论 3 自己的定性内容是语境量**：D_seq 随 Ns 连续从 0.01 → 0.90。
   「无向」只在 Ns→0 极限成立；「择优」在 Ns≳5 成立。同一条推论的两半
   各自带相反的资格条件——这解释了为什么它不能是无条件宏 M。
5. **A9 修订落点**：M 资格 = 三判据 ∧ 显式资格条件 C_q（Ns 区间 / 边界闭合 / 参数申报）。
   无 C_q 字段的 A9 会让同一机制在不同论文中得到相反的资格判定——
   这正是压测 A9-02/03 争论（演化择优该不该有 M 资格）的根源：双方在测**不同语境**。

### 9.5 局限（登记）

1. 现实核仍是 Wright–Fisher——它本身就是群体遗传学的标准粗模型，"现实"与"M 模型"
   的差距被低估。真实个体级模拟（含密度制约、年龄结构）下统计版 d 会下降，
   干预失敏边界 Ns≈5 也会移动。
2. 迁移闭合测试只钳制了池频率，未测空间结构（斑块种群）。
3. 干预只测了 s 的 ±Δs 阶跃；连续干预路径的响应积分未测。
4. 阈值 θ_eff=0.20 决定了边界 Ns≈5 的位置；该位置对 Δs 的取法敏感（Δs 越大边界越低）。
