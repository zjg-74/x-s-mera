# 审计：把「基底」实例化为「n 维向量空间的一组基」

> 原命题：对于一个 n 维空间的象，可以由一个 n 维向量空间来表示，它又可以由 n 个对应的向量组成的基底来作为事件公理。

**总判断**：真内核成立（基底 = 极小生成集），承载结构错配（向量空间 → 应为闭包系统）。三处错配 + 一条修正 + 一个适用域判据。

---

## 一、对的部分

上一轮「基底-完备」七条中的第③条（论域闭合）+ 第⑦条（极小可审计）合起来就是：**B 是 T_S 的极小生成集**。
「从这里出发能到那里，且去掉任何一条就到不了」与线性代数的基底同构。同构只到这一句为止。

---

## 二、错配一：span 与 ⊢ 不是同一种生成

| | 线性张成 span | 演绎闭包 Cn |
|---|---|---|
| 表示唯一性 | 有，坐标唯一 | 无，同一定理可有多条证明 |
| 步数 | 有限，等于 n | 无界，闭包可无穷 |
| 元素同质 | 是，同属一个 V | 否，公理类型各异（存在 / 等式 / 模式） |
| 可判定性 | 高斯消元，多项式时间 | 半可判定 |

线性组合是**一步到位的静态操作**且有唯一坐标；⊢ 是**递归闭包**。
故「n 个基向量」里的「n 个」在逻辑侧没有对应物——逻辑侧没有坐标系，没有「α₁ 份公理一 + α₂ 份公理二」。

---

## 三、错配二（致命）：n 不是内禀的

向量空间维数之所以内禀，靠**维数不变定理**；该定理依赖 **Steinitz 交换性质**：

> 若 a ∈ span(X ∪ {b}) 且 a ∉ span(X)，则 b ∈ span(X ∪ {a})。

**演绎闭包不满足它。命题逻辑反例：**

- X = ∅，b = p∧q，a = p
- p ∈ Cn({p∧q}) ✓
- p ∉ Cn(∅) ✓
- **p∧q ∉ Cn({p})** ✗

交换性质失效 ⇒ Cn 不是拟阵 ⇒ **无基底基数不变性** ⇒ 同一理论可有基数不同的极小公理集 ⇒ **「n」是呈现的偶然，不是结构的必然**。

**现实证据**：NBG 可单公理化（1 条）；ZFC 不可有限公理化（无穷多条模式）；Boole 代数有 Huntington 单公理与标准 3 条组；欧氏几何 Hilbert 20 余条 vs Tarski 一条公理模式。同一理论，「维数」从 1 到 ∞。

**推论 / 个人纪律**：写「n 个基本公理」必被追问「为何是 n 而非 n+1 或 1」。这与 XS 中「尺度向量为何恰好四个分量」是同一个问题——同一类直觉惯性已出现两次。

---

## 四、错配三：组合运算的类型

「事件」自带 0/1 语义。三条路线互斥，不可混用：

| 路线 | 组合运算 | 系数 | n 是否内禀 | 依据 |
|---|---|---|---|---|
| (a) 线性空间 | span | 任意标量 | 是 | 维数定理 |
| (b) 有限 Boole 代数 | 并 / 交 / 补 | 仅 0 或 1 | 是 | Stone 表示唯一性（n 原子 → 2ⁿ 事件） |
| (c) 演绎闭包 | ⊢ | 无组合运算 | 否 | 交换性质失效 |

不能既称「事件」（0/1）又用加权系数（0.45 / 0.30 / 0.25）。

## 五、适用域判据（可证伪）

> 当且仅当公理集可写成**齐次线性约束**时，向量空间隐喻完整成立；此时 n = 解空间维数，由 rank-nullity 保证内禀。

**成立的真实例子：**

1. **化学计量子空间**：化学计量矩阵 N；im(N) 维数 = rank(N)（内禀）；守恒律空间 = ker(Nᵀ)，维数 = n − rank(N)（内禀）。
2. **电路的基本回路基 / 割集基**：维数分别为 m−n+1 与 n−1，由图的圈秩保证。
3. **守恒律空间**：Noether 定理给出的守恒量模去平凡量后构成线性空间。

**共同点**：内容全是守恒与平衡关系，不是一般推断关系。含存在量词、归纳模式或非线性的理论，隐喻失效。

## 六、修正：该数的是 rank，不是 n

若「象」取**像（image）**义，降秩投影下：

- im(π) 的基**不是** {π(e₁),…,π(eₙ)}——它们线性相关；
- 基是其中的**极大线性无关子集**，个数 r = rank(π) ≤ n。

**rank-nullity 分解 = 「投影丢失」的精确版本：**

- **继承的部分（im，r 维）**：可由下沉映射 ρ 逐条给出 → 上一轮第②条。
- **生成的部分（ker，n−r 维）**：原本在 Ω 中无关的 π(eᵢ)、π(eⱼ) 在像中变为线性相关。该依赖是投影**生成**的，不是继承的 → 上一轮类型 C 范畴错误（向基底索要生成物）。

这是隐喻中**唯一能救的结构**，也是上一轮「给投影映射 π 并刻画其丢失」的可计算实现。

## 七、与「基底-完备」七条的接口

| 七条 | 向量空间对应物 | 可否机械化 |
|---|---|---|
| ① 表达充分 | im(π) 容得下 T_S | 齐次线性时：秩检验 |
| ② 下沉显式 | ρ 的矩阵表示 | 是 |
| ③ 论域闭合 | 子空间判据（运算不越出 im） | 是 |
| ④ 无环 | 基的无关性 | 是 |
| ⑤ 可检验 | — | 与隐喻无关，另判 |
| ⑥ 鲁棒 | 条件数 κ(A)，失效边界 = κ 发散处 | 是（κ 比 Kn 更通用） |
| ⑦ 极小可审计 | 极小生成集 | 仅当拟阵；一般闭包无基数不变性 |

**第⑥条的真增益**：线性理论下，失效边界有一个比 Knudsen 数更通用的量——系数矩阵的**条件数 κ(A)**。

## 八、代拟：可写入论文的修正命题

> 设 π: Ω → S 为投影。若 S 的目标定理集 T_S 可表示为齐次线性约束的解集，则 T_S 是向量空间，其维数由 rank-nullity 内禀确定；此时「基底」即线性空间的基，n = dim T_S 不依赖于基底选择，基底-完备七条中的 ①②③④⑦ 可机械化判定，失效边界由系数矩阵条件数 κ(A) 给出。若 T_S 不可线性化（含存在量词、归纳模式或非线性），则演绎闭包 Cn 一般不满足 Steinitz 交换性质（命题逻辑反例：p ∈ Cn({p∧q})、p ∉ Cn(∅)，而 p∧q ∉ Cn({p})），因而不是拟阵、无基底基数不变性；此时「n」不是结构量而是呈现的偶然，应采用闭包系统与极小生成集的语言，放弃「n 个」的说法，改用「极小生成集 B 且 ∀b ∈ B，B\{b} ⊬ T_S」。两种情形下，投影丢失均由 rank-nullity 分解刻画：继承的部分落在 im(π)，生成的部分落在 ker(π)，后者不可向基底索要。
