# G-26a · ghost_gain_ratio 的算子失配理论推导

对应 `docs/xs-framework/26-v3.4-coupling-channel-from-mms-engineering.md` §6 **G-26a**：
"ghost 伪力是现象学项，未从界面算子推导 【待验证】 | 从提升/限制算子失配条件推导 ghost_gain_ratio"。

## 目的

`src/le_coupling_kernel.py` 的 F2 分支把 `ghost_gain_ratio`（默认 1.60）当作**现象学注入参数**：
C2（接口算子 S-兼容）失效时，副模态通量被缩放 `ghost_gain_ratio` 倍，注入净能量 → ghost 伪力 → 礁石伪收敛。
G-26a 要求把它**从界面算子的失配条件推导出来**，而不是当作自由参数。

本文件完成该推导：**ghost_gain_ratio = 提升/限制算子（Restrict∘Lift）在副模态上的往返失配比 λ_i**。

## 背景事实（工程底账）

- **C2 = 接口算子 S-兼容**（`26` §2，M3 行）：对应 MMS 的"提升/限制算子一致性"。
- **F2 = C1∧¬C2**（`le_coupling_kernel.py` L230–234）：主模态（第 0 分量）勉强对齐守恒，
  但副模态（i≥1）幅值失配 `ghost_gain_ratio` 倍 → 净能量注入。
- **守恒残差解析真值**（`src/r4_component_attribution.py` L25–30）：

      r_i = −(ghost_gain_ratio − 1)·gain·δ_i − ghost_base_ratio·|gain|    (i ≥ 1)

  其中 δ = E.state − L.state，gain = coupling_gain·∇Φ·d；主模态 i=0 在 F2 下守恒（r_0 ≡ 0）。
  第一项 = 失配分量（∝ δ_i，状态相关、随 δ 翻号）→ 接口域；
  第二项 = 底噪分量（∝ |gain|，方向不变偏置）→ 载体域。
- **通量模型**（`src/relay_chain.py` L104）：`J = c·delta`，`c = coupling_gain·∇Φ·d` ⟹ `J_i = gain·δ_i`。

## 设定：界面算子对

两个投影子系统 L、E 经界面算子交互：

- **提升算子** `Lift : V_L → V_E`：把 L 侧状态提升为 E 侧界面状态（宏观→微观重构）。
- **限制算子** `Restrict : V_E → V_L`：把 E 侧界面状态限制回 L 侧（微观→宏观压缩）。

**S-兼容（C2 过）定义**：`Restrict ∘ Lift = Id_{V_L}`（提升-限制互为拟逆，往返无损）。

**模态分解**：状态空间 `V = ⊕_i span(e_i)`（`e_0` 主模态，`e_i` 副模态 i≥1）。在模态 i 上，

    (Restrict ∘ Lift)|_i = λ_i · Id_i ,   λ_i ∈ ℝ

`λ_i` 是第 i 模态的**往返增益**。一致性要求 λ_i = 1（无损往返）；λ_i ≠ 1 即失配。

## 推导：ghost_gain_ratio = λ_i（副模态往返失配比）

**F2 的算子刻画**：C2 失效 ⟹ `Restrict ∘ Lift ≠ Id`，具体在模态层：

    λ_0 = 1                 （主模态对齐，patch test 过——F2 定义的一部分，L232）
    ∃ i ≥ 1 : λ_i ≠ 1       （副模态失配）

**守恒残差**：L 侧发出通量 J。正常作用-反作用要求 flux_E = −J（守恒）。
经提升/限制算子往返后，E 侧第 i 模态通量被缩放 λ_i：

    flux_E,i = −λ_i · J_i

净残差（ghost 伪力 / 守恒破坏量）：

    r_i = flux_E,i + J_i = −(λ_i − 1)·J_i

当 λ_i > 1：|flux_E,i| > |J_i|，净能量注入——这就是 ghost 伪力的算子来源。

**代入通量模型** `J_i = gain·δ_i`：

    r_i = −(λ_i − 1)·gain·δ_i

**与内核失配分量对照**（r4 公式第一项 −(ghost_gain_ratio − 1)·gain·δ_i）：

    −(λ_i − 1)·gain·δ_i = −(ghost_gain_ratio − 1)·gain·δ_i
    ⟹  ghost_gain_ratio = λ_i        （当 gain·δ_i ≠ 0；gain·δ_i = 0 时无失配通量，不产生伪力，自洽）

**结论（主结果）**：

> **ghost_gain_ratio = 提升/限制算子（Restrict∘Lift）在副模态上的往返失配比 λ_i。**

正常耦合（C2 过，λ_i = 1）：ghost_gain_ratio = 1 ⟹ 失配分量 = 0，守恒。
F2（C2 失效，λ_i = 1 + δ_i）：ghost_gain_ratio = λ_i > 1 ⟹ 注入净能量。

## 推导：ghost_base_ratio（底噪分量）

底噪项 = −ghost_base_ratio·|gain|，∝ |gain|（与 δ 翻号无关，方向不变的偏置）。
来源（`experiment_manual` L43 注释 + M5 行）：**patch test 残余**——即使主模态往返一致
（λ_0 = 1），提升/限制算子的**离散化误差/混叠**仍产生一个不随状态差翻号的数值底噪。

设数值底噪 `e_num = −β·|gain|`（∝ 通量能量尺度 |gain|，方向不变），对照内核底噪项：

    ghost_base_ratio = β

> **ghost_base_ratio = 提升/限制算子离散误差（数值底噪）相对通量的比率。**

它与 ghost_gain_ratio 正交：失配项是**结构性**的（λ_i ≠ 1，随 δ 翻号），底噪项是**数值性**的
（算子离散误差，方向不变）。这与 R4 的分解（失配→接口域、底噪→载体域）一致。

## 一致性核验

- **纯失配对照**（r4：ghost_base_ratio = 0）：β = 0，只余失配分量 ⟺ 推导中 λ_i ≠ 1 主导。✓
- **纯底噪对照**（r4：ghost_gain_ratio = 1）：λ_i = 1，无失配，只余底噪。
  `tests/test_r4_attribution.py::test_pure_base_control` 验证 α→0、β→−0.25 ⟺ 推导中
  λ_i = 1 ⟹ 失配项消失，β 独立。✓
- **主模态守恒**：F2 下 r_0 ≡ 0 ⟺ 推导中 λ_0 = 1（主模态往返无损）。✓

## 诚实边界

1. **这是理论推导，不是数值测量**：把现象学参数 ghost_gain_ratio 还原为界面算子往返失配比
   λ_i = (Restrict∘Lift)|_{副模态}。它给出 ghost 伪力的**算子结构来源**，把"为什么 F2 会
   注入净能量"从现象学表述提升为算子失配表述。
2. **推导依赖通量模型** J_i = gain·δ_i（与内核一致）。若实际界面通量有不同模态耦合，λ_i 的
   具体解释需相应调整，但"失配比 = 算子往返增益"的结构不变。
3. **λ_i 的数值**仍需测量：G-26c 联合真实 MMS 求解器时，应实测 Lift/Restrict 的副模态往返
   增益 λ_i，与内核 ghost_gain_ratio=1.60 对比——若实测 λ_i≠1.60，说明当前现象学取值是
   标定而非推导，须按实测校准。
4. **未闭合**：lift/restrict 算子的具体实现（本仓库内核是直接注入失配，未显式构造算子）。
   本推导给出它们的**理论身份**；构造显式 Lift/Restrict 并测 λ_i 属 G-26c/后续工程。
