# 认知系统的动力学结构
## ——一个可测量、可证伪的最小理论

**摘要**：认知科学中存在一个长期的结构性缺口：符号计算传统给出了结构但放弃了过程，动力学传统描述了过程但拒绝给出可测量的状态变量。本文提出认知系统的一个最小动力学结构，它由四个构件组成且仅需四个构件：（i）范畴层的象/运算二分；（ii）作为二分之推论的"约束恰为双"——双约束不是假设而是定理；（iii）一个严格的信息论状态变量 U（净未决量，单位比特），兼有定义、测量程序与判别器；（iv）一组双速率动力学，经规范固定后等价于一条仿射核算律 dU/dt = ρ_exp·(dE/dt) + κ_E·ρ_exp·(1−ρ)。由此结构可推出：认知归宿的收敛/震荡/发散三分及其成立条件；震荡的酝酿/反刍双相及其操作化判别（已在真实大模型与真人出声思维数据上跑通）；认知失效的 F1/F2 正则分支及其可证明的可诊断性（Lean4 编码，零 sorry）。本文的全部命题携带显式证据等级——定理、原型确认、猜想、待验证、缺口、约定、局限——并如实登记：全套动力学的唯一承重假设 A_D 至今未证，且无已登记的有效证否途径。本文的目的不是宣称一个已被证实的认知理论，而是展示：一个认知理论可以被写成"能被机器检查、被实验否决、被数据修正"的对象，并且在经过四十余组实验与形式化审计之后仍然保持结构完整。

**关键词**：认知动力学；双约束；条件熵；仿射定律；可证伪性；证据分级

## 1. 问题：认知科学的动力学缺口

认知系统显然是一个过程——思维在时间中展开、摇摆、落定。但翻开认知科学的理论工具箱，会看到一个尴尬的分工：一边是以产生式系统、逻辑推理、贝叶斯推断为代表的**计算传统**，它精确地刻画了认知的输入输出映射，却把"过程"压缩成算法的执行轨迹——轨迹存在，但没有独立的理论地位；另一边是 van Gelder、Thelen 等人的**动力学传统**，它正确地坚持认知是实时展开的状态演化，却停留在相图、吸引子、轨迹的定性词汇上——四十年来，这一传统没有给出一个可以被独立测量、可以被实验否决的状态变量。

结果是两种对称的失败：计算传统有结构而无动力学，动力学传统有动力学的语言而无动力学的测量。本文把这一状况称为认知科学的**动力学缺口**。

弥合缺口需要的东西其实有明确的规格：一个认知动力学理论若要成立，至少应当提供——（a）不多不少的状态变量，每个都可定义、可测量；（b）状态变量服从的演化律，且该定律可以被数据否决；（c）由定律推出的相结构（哪些归宿可能、各在什么条件下）；（d）对"出错"的动力学刻画——认知错误不应是理论外的噪声，而应是相图上的正则区域。本文主张：满足这四条规格的一个**最小**结构已经存在，且只需四个构件。它的最小性在于：抽掉其中任何一个，其余三个立即失去意义——这是本文的构造性论证（§3–§7），也是它的可证伪性来源。

在构造之前，必须先陈述本文自我约束的方法纪律，因为它本身就是论点的一部分。

## 2. 方法纪律：四重门与证据分级

认知理论史上反复发生的失败模式是**隐喻通胀**：一个生动的类比（计算机、蒸汽机、神经网络、熵）被引入时附带一个精确的数学内核，流传三代之后内核丢失，只剩下词汇。防止这一退化的唯一办法是让理论在构造时就带上防伪装置。本文的每一个论断都须通过四重门：

1. **可表述**：能用已登记的概念体系表达，落在明示的适用域内；
2. **可执行**：存在对应的可运行实现，能通过回归测试；
3. **可证明，或已登记缺口**：核心不变量有机器检查的证明（Lean4）；证不出的进入公开的缺口登记，不得静默存在；
4. **可判别**：存在操作化的判别程序，使该论断能被经验数据支持或否决。

任何一重门不通过，论断停留在理论外围。与四重门配套，本文全部命题就地标注七级证据：**【定理】**纯逻辑推出；**【原型确认】**数值原型内算过并被回归锁定（不构成对现实的证据）；**【猜想】**未验证的关键假设；**【待验证】**有检验程序但未执行；**【缺口】**已登记未闭合项；**【约定】**人为声明的分析选择；**【局限】**已知不可读或不可迁移性。

这套纪律不是装饰。§8 将看到，它使本文能够做出大多数认知理论做不到的一件事：如实列出自己哪些部分是定理、哪些只是原型内确认、哪些是未证的猜想——包括那个承重的猜想。

## 3. 范畴地基：二分与"约束恰为双"

**定义 1（象与运算）。** 任何认知活动可以分解为两个面：被操作的素材——**象（X）**，与施加于其上的操作——**运算（S）**。这是范畴层的划分，不是认知系统内部两个实体的枚举；它不承诺任何神经实现。

这个二分看起来朴素到近乎空洞，但它有一个不平凡的推论：

**命题 1（约束恰为双）【定理】。** 约束是加在认知活动上的限制；象与运算恰有两面，每面各承受一类约束——因此约束恰为双，不是三个，也不是一个。

双约束因此不是经验发现也不是建模假设，而是范畴二分的投影：

| | 外约束 | 内约束 |
| --- | --- | --- |
| 内容 | 输入的物理形态 | 必须"理解" |
| 施加于 | X（象） | S（运算） |
| 逻辑类型 | 构成性（不可违反） | 规范性（可违反） |
| 违反的真实含义 | 对象被替换 | 任务被替换 |

两类约束的逻辑类型不同，这一点将在 §7 产生实质后果：认知失效的两个根源——外失效与内失效——正是沿着这条裂缝分开的。需要特别排除一个常见误读：算力、工作记忆、时间预算等**资源约束**不属于双约束；它们是相结构成立的条件（§6），而非约束本身。

## 4. 状态变量：净未决量 U

双约束各自留下一个可以严格定义的信息论量。设 M 为认知系统当前已固化的宏结构（可整体调用的压缩单元），φ 为理解者，Ω 为理解者集合，C_in 为输入内容，则【定理，定义层】：

$$P := H(\mathcal M \mid \varphi, \Omega), \qquad Q := I(\mathcal M; C_{in} \mid \varphi), \qquad U := P - Q = H(\mathcal M \mid \varphi, C_{in}) \ge 0$$

三个量的认知解读：P 是外约束留下的**欠定性**——给定理解者，输入的物理形态还留下多少未确定；Q 是内约束**已吸收**的部分——宏结构与输入之间已建立的信息耦合；U 是二者之差，即**净未决量**——系统在"理解"这一规范下尚未消解的不确定性，单位是比特。

U 是本理论的状态变量，它有三条性质值得立即指出。其一，U ≥ 0 是条件熵的直接推论，不是假设——认知系统不能把未决量消解到零以下，这条平凡的定理将在 §5 迫使动力学定律修改自己的边界行为。其二，**P 依赖理解者**，且跨理解者混合估计的偏倚恰等于 I(M;Ω|φ)——这是一条定理而非未知量，它的推论是：U 的估计值不可跨群体直接比较，除非同时报告该项【定理＋局限】。其三，认知存在的条件可以被严格陈述【定理】：0 < H(M|φ) < ∞ 且 Q > 0——P = 0 时"理解"退化为解码（无欠定性即无认知任务），Q = 0 时退化为生成（无输入耦合即幻觉的形式定义）。

至此，"认知熵"这类隐喻词汇可以退役了：凡本文说"未决量"，指的都是这个有条件熵定义的、以比特计量的 U。

## 5. 动力学定律：双速率、规范固定与仿射核算

有了状态变量，下一步是写出它的演化律。本文的全部动力学建立在一个假设上——这也是全套理论**唯一承重的猜想**，我们把它放在最显眼的位置：

**假设 A_D（双速率展开-消解）【猜想】。** 认知过程的每一步演化由两个子过程线性叠加：**展开**投入 a ≥ 0（驱动 E 增加 a·e₊，U 增加 a·u₊），**消解**投入 b ≥ 0（驱动 E 减少 b·e₋，U 减少 b·u₋）。附款（单一驱动）：存在唯一的过程 (a_k, b_k)，E 与 U 由同一对驱动；凡非同一过程驱动者，不属于本文所论的"同一认知过程"。

地位声明：A_D 至今**未证**，且经专门检验（R24）后无任何已登记的有效证否途径——这是本文对读者必须坦白的最重要一点。它的辩护只有结构性的：它足够弱（线性、两项），又足够强（能产生可检验的错开双峰结构，见 §6）。

从 A_D 到可检验定律还差一步。原始参数化有六个参数 (a, b, e₊, e₋, u₊, u₋)，但它们携带一个规范冗余：对时间尺度做仿射重参数化（λ-规范），可观测量不变。这一冗余可以在**定义层**消灭而非近似忽略【定理】，消灭后内禀参数只剩 (s, ρ_exp, ρ) 与速率尺度 κ_E；数值原型中让 λ 跨越 16 倍，可观测量偏差为 0【原型确认：R30】。规范固定后，A_D 等价于 dE/dt = κ_E(s−1) 与 dU/dt = κ_E·ρ_exp·(s−ρ)，消去中间变量 s 得主定理：

$$\boxed{\;\frac{dU}{dt} = \rho_{exp}\cdot\frac{dE}{dt} + \kappa_E\,\rho_{exp}\,(1-\rho)\;}$$

**这条仿射律是核算律（accounting law），不是变分原理。** 它不宣称认知系统"最小化"任何东西；它只声明：无论系统内部发生什么，U 的变化量与 E 的变化量之间必须满足这个账目关系，差额由 κ_E·ρ_exp·(1−ρ) 一项兜底。核算律与变分原理的差别是可证伪性的差别：变分原理几乎总能事后拟合，而仿射律在任意一段 (E, U) 轨迹上都可以被直接否决——残差超限即证伪。它的五个可观测投影（共线性、斜率、峰序、守恒、截距数值）是**同一仿射关系的五个投影而非五个独立机制**【定理】；其中前四个不需要知道 κ_E、不依赖调度方式，第五个则两者都需要——哪个读数可信、哪个读数需要尺度声明，因此是定理而非经验小贴士【定理＋约定】。

仿射律有一条紧的辖域。U ≥ 0 是定理，而线性动力学会把 U 推向负值——解决方式是状态依赖的边界层修正：消解项乘以 g(U)，g(0)=0、单调增、远处趋于 1。由此 **U = 0 成为动力学的稳定不动点**【定理】——状态空间的边界被动力学自身保护，而不是靠工程截断补丁。代价是：**仿射性只在 U 远离 0 时成立**。且 g 的具体形式不可辨识——1% 噪声即可使形式拟合崩溃【原型确认：R45】——因此理论只保留 g 的结构约束，形式选择登记为【约定】。

## 6. 相结构：三分与震荡双相

动力学定律的价值在于它推出的相结构。将净驱动力 Ψ = dE/dk 分解为定向与涨落之和（Ψ = ψ̄ + ξ），则归宿由 ψ̄ 的符号决定【定理】：ψ̄ < 0 时系统以概率 1 有限时间收敛，ψ̄ > 0 时跃迁或发散；**震荡不是归宿，而是 Ψ ≈ 0 附近的驻留**。

**命题 2（归宿三分及其条件）【定理】。** 给定新输入与宏库，认知过程有三条互斥归宿：**收敛**（唯一宏完成固化）、**震荡**（多宏并存不可取舍）、**发散**（无宏可填充，候选无界增殖）。三分成立的条件是资源有界（B < ∞）且统计定向非零（ψ̄ ≠ 0）。ψ̄ = 0 时熵轨迹是鞅，震荡与混沌持久存在，吸引盆分形化使概率权重无法鲁棒赋值——此时不是三分而是**四分**。三态的概率性来自三个独立的类比失效（事实集开放、资源有界、承诺可撤销），且偏离→归宿是多对多映射而非一一对应：资源有界既可致发散，也可致伪收敛【定理】。

需要如实标注："真实认知过程落在三分之内"本身是【猜想】——三分是结构命题，其现实适用性待验。

相结构中经验含量最高的是**震荡的双相**——这也是本文报告的第一个新现象学事实。震荡（多候选并存）内部存在一个此前未被区分的二分【定理，条件于 A_D】：

- **酝酿型震荡**：U 净下降（ρ_res > ρ_exp）——候选在收敛，系统在多候选博弈中持续消解未决量；
- **反刍型震荡**：U 净上升（ρ_res < ρ_exp）——候选在增殖，系统越"想"越不确定。

二者都是震荡，区别在 U 的走向；且这一区别**可测量**：判别器（R23）对震荡期（连续候选数 r̂ ≥ 2 的步段）做条件熵估计（含 Miller–Madow 修正），读 U 的净变化方向即可判相。在真实大语言模型的 18 项任务上，正常可收敛任务 12/18 判为酝酿，悖论与无信息任务判为反刍【原型确认】。尤其值得注意的是一个反直觉结果：判别器读的是实际熵变化而非任务标签——若干"悖论"任务（R7–R9）被判为酝酿，而个别正常任务（T8）被判为反刍。**"困难任务必然反刍"这一朴素映射因此被证伪**，这恰是操作化判别的价值所在。真人出声思维数据（S0）上判别器可判 3/6——日常作答多为单线决策、不进入震荡期，这本身是关于人类认知的真实发现而非判别失败【原型确认；Bootstrap 稳健性 75%，外部加硬待做】。

双相划分纠正了一个在直觉上极具诱惑力的错误：把震荡等同于"认知能量的积累"。事实相反——多数正常认知中的震荡是**未决量的净消解过程**（酝酿），积累型的震荡（反刍）是病态相。震荡不是"收敛失败"的残余范畴，而是具有两个可判别相位的一等认知状态。

## 7. 失效的正则分支：认知错误不是噪声

一个完整的动力学必须刻画自己的失效。本文框架中，失效沿着双约束的裂缝分成两个正则分支，其可诊断性是**机器证明的定理**（Lean4 编码：公理 DC1–DC8，定理 T1–T6，构建通过、零 sorry）：

**命题 3（失效可诊断性）【定理】。** 外约束失效（对象被替换）导致 **F2 型失效**——伪收敛：系统收敛了，但收敛到的不是输入给定的对象；内约束失效（任务被替换）导致 **F1 型失效**——不收敛：无宏可填充，候选空转或发散。两类失效互斥且不可互相伪装。判别签名：外失效时加载度 σ **不下降**（系统错了，但确信度与正确时无异），内失效时 σ 显著下降【原型确认：R18-a】；双失效并发时内失效主导 σ 读数（T6，非平凡）。

"外失效时 σ 不下降"有一条直接的认知科学含义：它给出了**错觉的操作化对应物**——"错了但一样确信"不是修辞，而是一个在判别签名上可读的物理量特征。认知错误由此从理论外的噪声变为相图上两个有名字、有签名、有定理的正则区域。

三处诚实标注：其一，DC6/DC7 两条公理是 800 次/臂数值实验的公理化，属【约定】，出现反例须降级或加条件；其二，定量签名（σ 相差一个数量级）是数值断言，在一阶逻辑层结构性不可表达，已登记为缺口 X1 并由回归测试锁死【缺口】；其三，伪收敛的判别是**事中可分离、事前不可判定**——没有任何签名能在失效发生前预告它，这一边界保留【局限】。

## 8. 经验通道与证据总账

本文报告的结构不是纸面构造。它与现实之间已有一条（且目前只有一条）已验证通道：R23 判别器在真实大模型（18 任务，双向判别干净）与真人出声思维（S0）上的运行结果（§6）。此外，约束强度与认知产出的倒 U 关系已在原型内测得——内约束强度操作化为 Q = log₂(|O_all|/|O_adm|)，峰位于 Q ≈ 1.0【原型确认：R21】；注意该实验的宏库是人造的，结论关于机制而非关于语言，且其测到的是数量效应，不得称为"措辞特异性"【局限】。

| **A_D（含单一驱动附款）** | **【猜想】** | 唯一承重假设；未证且无已登记证否途径 |

三条补充的边界声明：（i）仿射性只在 U 远离 0 时成立，g(U) 只保留结构约束；（ii）U 的估计值不可跨群体比较，除非同时报告 I(M;Ω|φ)；（iii）全部【原型确认】只排除实现错误，不构成对现实的证据。

## 9. 与相关传统的划界

本文的增量贡献可以通过与三个传统的精确划界来定位。

**对动力系统传统（van Gelder、Thelen 等）**：我们共享"认知是实时状态演化"的本体论立场，增量在于补上了这一传统四十年未提供的东西——可测量的状态变量（U，比特）、可被数据否决的演化律（仿射核算律）、以及可执行的判别程序（R23）。相图不再是修辞。

**对自由能原理（Friston 等）**：分歧是方法论性的。自由能原理是一条变分原理——系统最小化变分自由能——其普适性恰是其可证伪性的敌人：几乎任何观察都可事后纳入。本文的仿射律是一条核算律：不做任何最优化承诺，只做账目声明，并在任意轨迹上暴露于否决。两种取径的取舍——解释力优先还是可证伪性优先——是方法论选择，但本文认为认知科学当前更缺后者。

**对协同学（Haken）与更一般的"熵"话语**：序参量、熵增熵减在这类理论中扮演的是启发性角色；本文的 U 是有严格定义的条件熵差，"熵"的每一次出现都可换算成比特并附上测量程序。隐喻被收编为量，这是 G2 式的升级而非词汇替换。

此外，本文不做任何感知推理承诺（与预测加工划界），不承诺神经实现（X/S/M 均为功能角色），也不声称读出"快思维"本体（R47：快/慢只能作为时间化参数的两个尺度通道）。

## 10. 结论：最小结构的完整性与三个开放问题

回到 §1 的规格检验。本文给出的四个构件——范畴二分、双约束、状态变量 U、双速率动力学——构成一个自洽闭环：二分推出双约束（§3），双约束定义状态变量（§4），状态变量要求演化律而演化律经规范固定成为可证伪的仿射核算（§5），核算律推出相结构与双相（§6），约束的失效给出错误的正则分支（§7），判别程序把全部经验断言接到可测量的通道上（§8）。抽掉任何一个构件，其余三个立即失去意义：无双约束则 U 无定义，无 U 则动力学无状态，无 A_D 则仿射律无来源——最小性即在于此。

本文也如实报告了这个结构的代价与边界：唯一承重假设 A_D 未证；仿射性不覆盖 U ≈ 0 的边界层；经验通道目前只有一条且稳健性中等。开放问题按优先级登记为三个：其一，把 L2 动力学实现为可执行的认知架构内核（快慢耦合、非对称势阱），使 T 系列自证伪测试从设计变为回归；其二，判别器的外部加硬（多模型、真人严格出声思维、反刍对照），这是把【原型确认】升级为经验证据的必经之路；其三，涌现判别的操作化——结构跃迁目前只有定性判据，这是本结构尚未闭合的最大缺口。

认知科学是否需要一个这样的结构，可以由领域评判；本文只想确立一个较弱但较新的主张：**认知理论可以被写成这样的对象**——每条命题标明证据等级与辖域，每个量有测量程序，每个失效有签名，唯一承重的猜想被放在摘要里而不是藏在脚注中。
