# XS 框架 v3.4 · 真实数据获取方案（A 线：MMS / B 线：认知）

为剩余"需要真实数据"的待办项设计**可执行、可复现、可审计**的真实数据获取方案。
本方案是设计层交付，不是执行承诺；执行前需按 §7 拍板选型。

## 1. 真实数据需求清单（先纠正一处）

| 待办 | 状态判定 | 是否需真实数据 | 需要的数据 |
|---|---|---|---|
| **G-26c**（`26` §7.4） | 未与真实 MMS 求解器联合执行 | **是（A 线）** | Kn 过渡区算例上 C1/C2、patch test、HMM 判定并行输出的可比数据集 |
| **G-26a 遗留**（λ_i 数值实测） | 推导完成，数值待测 | **是（A 线，随 G-26c）** | 真实 MMS 求解器 Lift/Restrict 算子副模态往返失配比 λ_i 实测 |
| **X2 步骤 2 / R23 实证**（ρ_res>ρ_exp） | 测量协议已落实，实证待真实系统 | **是（B 线）** | 真实认知系统震荡期 U 走向（程序 P̂ 估计）→ 判 ρ_res>ρ_exp |
| **R-043**（τ\* 落点） | 纯内部可解 | **否（纠正）** | 不需外部数据；仅内部扫描 η 区间 |

**诚实分层（"真实"的三档硬度）**：
- **S0 真实世界实验测量**（最硬）：稀薄气体风洞实验、真人认知实验。获取成本最高。
- **S1 成熟求解器在真实算例上的输出**（中硬）：开源 MMS 求解器（NS/DSMC）跑 Kn 过渡区真实算例。
  这是 G-26c 的"真实 MMS 求解器"所指——仍属物理**模拟**，介于 S0 与自制仿真之间。
- **S2 自制内核仿真**（软）：现有 `src/*.py` 简化内核，不算"真实数据"。

> A 线目标层 = S1；B 线可达 S0/S1（见 §4）。

## 2. 两条数据线总览

```
A 线 · 真实 MMS 求解器（G-26c + G-26a λ_i）
  选求解器 → 选 Kn 过渡区算例 → 联合执行（XS 判定接求解器输出）→ 提取 λ_i → 比对分歧点
B 线 · 真实认知系统（X2 步骤 2 / R23 实证）
  选数据源 → 采集协议 → 程序 P̂ 估计 U → 识别震荡期 → 判 ρ_res>ρ_exp
```

## 3. A 线：真实 MMS 求解器数据

### 3.1 数据需求与判定对接
G-26c 要求：**Kn 过渡区算例上，C1/C2（界面算子 S-兼容）与 patch test / HMM 判定并行输出、比对分歧点**。
需要的数据形态：
- 宏观字段（密度/速度/温度）沿界面的通量轨迹（接 patch test、HMM）
- 微观-宏观界面算子对（Lift/Restrict）的往返映射误差（测 λ_i）
- C1（命题 2′）/ C2（S-兼容）判定所需的界面结构量

### 3.2 求解器选型（工具清单）
| 层次 | 求解器 | 开源 | 用途 |
|---|---|---|---|
| 连续介质 NS | **OpenFOAM** | ✓ | 宏观区流动求解 |
| 分子 / 稀薄 DSMC | **SPARTA**（Sandia）或 **dsmcFoam**（OpenFOAM 系） | ✓ | 过渡区/自由分子区 |
| 介观 LBM | **OpenLB** | ✓ | 过渡区可选替代 |
| 耦合框架 | NS–DSMC 手动对接（OpenFOAM + SPARTA 交界） | 自定义 | Kn 过渡区核心 |

> **诚实提示**：NS–DSMC 混合求解器的搭建是**重工程**（交界采样、守恒交换、统计噪声），
> 非开箱即用。备选降级：① 只用 DSMC（SPARTA）在过渡区跑单一求解器，绕开耦合；
> ② 用已发表 Kn 过渡区基准算例的公开数据（可引用，但非本机产出）。

### 3.3 算例选型（Kn 过渡区，0.1 < Kn < 10）
| 算例 | 物理 | 判定价值 |
|---|---|---|
| **Normal shock structure** | 激波内部过渡 | C1/C2 在强非平衡区的分歧点 |
| **Couette flow / cylindrical Couette** | 剪切驱动 | patch test 守恒性 |
| **Micro-channel (Poiseuille) flow** | 压力驱动微流 | HMM 尺度分离判定 |
| **Cylinder/micro-nozzle** | 绕流/喷流 | 混合求解器交界 |

### 3.4 联合执行协议（A 线）
1. **基准标定**：先在连续区（Kn≈0.05）与自由分子区（Kn>10）各跑一次，标定单求解器自洽。
2. **过渡区扫描**：Kn = 0.2 / 0.5 / 1 / 2 / 5 五档（覆盖 0.1–10）。
3. **XS 判定接入**：把求解器输出喂给 `src/le_coupling_kernel.py`（C2）、`src/xs_formal_checks.py`、
   patch test 与 HMM 判定程序，与 `src/relay_chain.py` 的通量模型对照。
4. **λ_i 实测**：在宏观-微观界面定义 Lift（微观→宏观）/Restrict（宏观→微观），
   测副模态往返失配比 λ_i = (Restrict∘Lift)|_副模态；对照 G-26a 推导的
   ghost_gain_ratio = λ_i、ghost_base_ratio = β。
5. **分歧点比对**：输出 C1/C2 与 patch test / HMM 的判定分歧点表。
6. **可复现**：固定算例网格/统计收敛判据/随机种子，脚本一键重跑。

### 3.5 A 线输出与验收
- `experiments/g26c_real_mms/`：求解器输入文件 + 驱动脚本 + 输出数据集（JSON/CSV）+ README
- λ_i 实测值（对照 G-26a 理论身份）
- C1/C2 × patch test/HMM 判定比对表
- 验收：数据可复现、判定程序无改动即接入、分歧点有物理/尺度解释、诚实标注 S1 层

## 4. B 线：真实认知系统数据

### 4.1 数据需求
X2 步骤 2 / R23 需要：**真实认知系统在歧义任务上的过程数据**，用程序 P̂（补篇四 §3.2：
解释分布 + Miller–Madow 修正）估计 U 走向，识别震荡期（Ψ≈0），判 ρ_res>ρ_exp。

### 4.2 数据源选型（按获取成本排序）
| 数据源 | 真实度 | 获取成本 | 适配 |
|---|---|---|---|
| **LLM 推理轨迹**（真实模型完整 token/工具序列） | S1（真实信息处理系统） | **低**（API/本地推理即可取） | 最快落地，可作为 B 线第一步 |
| **think-aloud 出声思维**（真人边解题边说） | S0（最硬） | 中（需被试+转写） | 人类认知，最贴 XS 本义 |
| **写作/编辑历史**（真实文档 git log、草稿序列） | S0 | 中（需现成项目） | 符合"草稿序列"判据 |
| **解题过程记录**（学生/专业解题步骤） | S0 | 中 | 认知过程数据 |

### 4.3 采集协议（B 线，以 LLM 轨迹为例）
1. **任务构造**：歧义性任务（多候选解释并存，制造震荡期）——如有多义句、未定约束的规划题。
2. **采集**：记录完整推理轨迹（含中间假设的生成/取舍/反复），每步提取候选解释集合。
3. **震荡期识别**：Ψ≈0（多候选间反复切换，无主导）——按补篇二 §1 震荡判据。
4. **程序 P̂**：对每个推理窗口的解释分布估计 P̂（补篇四 §3.2），得 U(k) 序列。
5. **U 走向判定**：震荡期内 U 净变化方向 → ρ_res>ρ_exp（降）/ ρ_res<ρ_exp（升）/ =（不变）。
6. **稳健性**：多次重复取多数方向（>90% 阈值，见 `30-v3.4-r23-verify-path` §3）。
7. **可复现**：固定 prompt/种子/模型版本；转写与归类规则事先公开。

### 4.4 B 线输出与验收
- `experiments/r23_real_cognitive/`：原始轨迹（脱敏）+ 标注 + P̂ 计算 + U 走向判定
- 一个真实系统（LLM 或真人）上的 ρ_res>ρ_exp 实证判定
- 验收：**触发 CognitiveBridge.lean 立项**（X2 步骤 2 的前置）；诚实标注数据源硬度（S0/S1）

## 5. 分阶段执行计划（化整为零）

| 阶段 | 内容 | 前置 | 产出 |

## 6. 风险与规避

| # | 风险 | 等级 | 规避 |
|---|---|---|---|
| R1 | NS–DSMC 耦合是重工程，可能卡死 | 高 | P2 先用 DSMC 单求解器跑通过渡区；耦合作为增量；或降级用公开基准数据 |
| R2 | "真实 MMS" 仍属模拟（S1），非实验 | 中 | 诚实标注 S1；需要 S0 再加稀薄气体实验数据（外协） |
| R3 | LLM 轨迹的震荡期可能稀少/难识别 | 中 | 构造歧义任务诱导震荡；用补篇二判据严格识别 |
| R4 | 真人数据伦理与样本量 | 中 | 脱敏、知情同意；样本量与统计功效事先设定 |
| R5 | λ_i 实测依赖 Lift/Restrict 显式构造 | 中 | 在求解器界面上显式定义算子（G-26a §5 已给构造方向） |
| R6 | 判定程序接口与求解器输出格式不匹配 | 中 | 先做数据格式适配层（schema），不改判定程序 |
