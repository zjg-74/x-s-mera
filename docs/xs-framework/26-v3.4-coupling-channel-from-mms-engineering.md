## §1 架空之后，"耦合"这个词还剩什么含义

v3.4 把前置生成理论 P 悬空登记了（`18` §2.5）：P1——P 未被认定为真；P2——P 的功能是**生成性**的（它解释我们为什么有权构造这个投影空间）；P3——内核的功能是**判别性**的（只定义合法区分与判定规则）。旧的 D2 界面规则一刀切，把"P 是否为真"和"投影空间与现实的结构对应"两件事一起切掉了；新 D2 只切前者，给后者留了一条**受控通道**，通道的内容是 §6.4 的三类探索谱系：对应（弱）／边界（中）／约束（强）。

于是"耦合"这个词必须重新定义，否则它会偷偷把 P 塞回来。本文采用的工作定义是：

> **定义 1.1（接触点意义上的耦合）**。XSM 与现实空间在某个尺度上的投影空间之间的耦合，是指存在一个**判定级**的对应关系：框架内核的判定输出（哪些量可读、哪段交互合法、何时耦合失效），能与该投影空间中**独立可做的工程判定**逐条比对，且比对结果**稳定、有差异、非平凡**。

三处收紧：比对发生在**判定层**而非本体层；带**尺度限定词**；**不预设 P**（薛定谔类比，`18` §2.5）。

定义不构成论证。v1.2 起本文有一条铁律：**任何关于"我们的判定与外部是否吻合"的争论，必须先回到我们自己跑过的工程结论——那是已知地面——再核对批判或猜想。**外来意见（包括措辞很强的批判）是待核对项，不是前提。

## §2 工程底账：耦合内核与中继链已经做出了什么

先盘家底。`le_coupling_kernel.py` 实现的是命题 2′ 的数值化：两个投影子系统 L、E 能否交互，由**双条件**判定——C1（边界重合度 d ≥ 阈值，存在满足粒度约束的公共细化构造）与 C2（接口算子 S-兼容）。三区：high（C1∧C2）/ middle（C1∧¬C2，F2）/ low（¬C1，F1）。两个**【定理】级**命题：

- F1 下通量恒为零——定义使然：C1 不成立意味着公共细化构造不存在，直接交互被禁止；
- d 是**尺度相对量**：d = exp(−r²/2σ²)，r 用两侧状态范数均值无量纲化。

数值原型的三条**【原型确认】**结果（`experiment_manual.md` §5–§6，均可复跑）：

1. **伪收敛在 D 的统计形态上显形，不在状态上显形。** S2（C2 人为关闭）：d 保持 0.947，但 ghost 伪力（0.833）把副模态压偏，Var(D) 从 0.00027 抬到 0.0166 越界。
2. **串联中继服从调和/短板律，乘积律被否定。** 实测 T(n=2)=0.450、T(n=3)=0.300、T(n=4)=0.225，与调和律逐位吻合，与乘积律（0.810/0.729/0.656）相差近一倍。F2 段不削减传输（T 不变），只注入解析可预测的污染 0.0962 = 0.25/(1+1.6)；F1 段整条阻断。
3. **中继数下限由弱端尺度决定。** gap 1.09 → n_min=3、gap 0.6 → n_min=1；不足的中继（n=1）半途吸收、比无中继更糟。

### §2.5 工程结论底账（先于一切比对的已知地面）

以下结论全部出自**我们自己跑过的工程**（`experiment_manual.md` §5–§9），按证据性质分三组：

**A 组：判定结构是 XS 原生的，不是从 MMS 抄来的（代码与手册可核查）**

- A1【定理】C1/C2 双条件、三区、F1/F2 二分，源自**命题 2′**（内核 L19–24 明写）。patch test 一词在全部源码中**只出现一次**，位于 ghost 底噪项的注释（L250–251）——它参照的是 F2 伪力**参数化形式**的物理图像，不是 C1 判定、不是三区结构、不是 F1/F2 二分。
- A2【原型确认】"d 是边界重合度标量，不是时空尺度比"是**实验验证目标本身**（§5.1 命题 1）。
- A3【原型确认】F2 的可操作判据（d 高 + Var(D) 越界 + ghost>0）来自 A10 与命题 2′ 的联合（§5.7）；测量值（0.947 / 0.0166 / 0.833）是跑出来的。

**B 组：原型有否决设计预期的记录**

- B1【原型确认】**乘积律被否定**（§6.4-1）：命题 2′ 原表述主张总成功率 ≈ ∏(pᵢqᵢ)，中继实验推翻了它，代之以调和律。
- B2【原型确认】R5（§9.4-1）：推论 3 的原降级理由被推翻，结论改写为"宏 M 资格本身是逐语境的"。
- B3【原型确认】R24 证否签名经检验无效、被推论 6.13 取代（补篇九 / `14` 审计）。

**B 组的认识论地位（v1.3 提升）**：攻破"自证机器"指控的根本证据在 B 组，不在 M7。以 B1 为典型：**如果设计时就在保证吻合，乘积律与调和律的差别根本不会成为问题——系统会直接产出调和律，而不经历"预期被否定"这一步。**"乘积律被否定"这件事本身，就是系统有能力说"我原来的设计预期错了"的证据。这与 Goguen 报告的概念融合形式化经验同型：OBJ 代码"并不总是第一次就能跑"，因为形式记号在初始版本里抓出了 bug——他以此论证形式记号的动机正是"非形式记号太容易犯微妙的错误"。（**收录标注**：Goguen 类比由第二轮批判引入，作为启发性对照收录；**原文献未独立核实**，其证据重量为零，仅作结构对照。）

**C 组：既有纪律已覆盖批判所建议的程序**

- C2 R6（§8.2）：**预注册纪律**已实施——判据表在任何运行前写定并快照进测试。

### §3.1 M7 的盲比记录（预登记格式；v1.3 补限定）

**第一步：预登记预测（比对前写下）。** 若 XS 的 F2 判定与 MsFEM 的中间尺度失效在判定层面同构，则 MMS 文献应报告：(a) 重合/重叠存在时方法不报错、不阻断，仍输出结果；(b) 错误是系统性的，而非随机涨落；(c) 触发条件是中间尺度的结构（与宏观网格可比），而非"完全无结构"。

**第二步：失败预案（比对前写下；v1.3 修正非穷尽性）。** 原预案只列了一种分歧形态：若失效形态是发散/报错（对应 F1 阻断）而非有限错误（对应 F2），标为分歧行。**修正：F1/F2 二分不是穷尽的。**存在第三种可能形态——误差有界但**不可预测**（有界匹配 F2，但缺 F2 的解析可预测性）——它既不匹配 F1 也不完全匹配 F2。预案非穷尽这一点本身登记为程序教训：**后续盲比的预案必须显式列出"以上皆非"出口。**

**第三步：执行比对。** Ming & Yue（2006, *J. Comput. Phys.* 214:421–445）：(a) ✓ "commits a finite error **even with overlapping**"；(b) ✓ O(1) 有限误差，系统性；(c) ✓ 触发条件正是"与宏观网格尺寸 H 可比的中间尺度"。附带对照点：无尺度分离时 HMM 与 MsFEM 都可能不收敛，但 HMM 质量不差于 MsFEM——与 F2 段的优雅降级同型。

**第四步：结果登记（v1.3 限定版）。** 三条预测全部吻合，预案未触发。**但对应强度必须分级**：
- (a)(b) 是**弱条件**——任何"有限误差"型失效都满足，区分度低；
- (c) 是**关键条件**——它把"中间尺度结构"与"完全无结构"分开，MsFEM 报告的正是 (c)；
- **定量可预测性无对应**：XS 侧 F2 有解析污染式 0.25/(1+1.6)；MsFEM 的 O(1) 误差在文献中**无对应解析形式**的报告。⟹ M7 的对应强度标注为"**失效语义同构（重合在、可信不在）；定量可预测性无对应报告**"。这是"盲比通过"的限定条件，不是未通过。
- 限定词照旧：单行、单域、右侧仍是工程事实而非认知现实。

### §3.3 注释层路径依赖与逆向检查（v1.3 新增）

**问题（批判引入，经核对成立）**：三层标注覆盖了"设计时是否参照"，但没覆盖另一种更隐蔽的侵蚀——**注释层的路径依赖**：文档化时写下的类比（如"d 和 Kn 是同类判据"），可能在**后续迭代**中不自觉地约束修改方向。它不是设计内生，而是"先写下的类比锁死后来的修改空间"。M7 可信是因为 MsFEM 全库零命中；M1–M4/M6 的注释层却都写着类比，其后续影响无法用"结构层原生"排除。

**逆向检查程序（两种形式，均已执行）**：

- **形式①：设计史检查。** 若注释层参照产生了实质约束，则注释写入后应能看到判定结构**朝着"更像 MMS"方向的修改**。执行：git 史显示 `le_coupling_kernel.py`、`relay_chain.py`、`experiment_manual.md` 三者自引入提交（`d91c2f6`，v1.6.1）起**零修改**——注释写入之后不存在任何后续修改可供约束。**在已有历史范围内，路径依赖无机会发生。**
- **形式②：重推导检查。** 从命题 2′ 重新推导判定结构，看推导路径是否引用注释层的类比。执行：命题 2′ 的双条件——(i) 公共细化构造存在（I1，命题 1 的载体）、(ii) 接口算子 S-兼容（运算侧条件）——全部由 XS 原生概念组成，**推导链不引用任何 MMS 概念**。通过。

**不可核查的残留（诚实登记）**：仓库git 史是粗粒度的——内核、中继链与手册在**同一提交**中引入，结构与注释同时写下。因此形式①无法回答："写下注释的那个设计会话内部，类比是否影响了当时的参数选择"（如 ghost_gain_ratio=1.6 / base=0.25 的具体数值为何如此取）。这个残留**原则上不可由现有记录排除**，只能靠前向纪律覆盖：今后凡修改判定结构或参数，提交信息必须声明"本次修改是否参照了注释层类比"。

**结论**：注释层独立性在历史范围内**部分被证明**（无后续修改 + 重推导不引用类比），残留为"同会话内的参数选择动机"不可核查。注释层路径依赖登记为 **G-26g**。

## §4 为什么架空不妨碍耦合：判定先行，尺度自选

**第一问：不需要 P。** 接触点检验的逻辑：内核判定输出 ↔ 现实侧判定输出，各自独立可算，然后比对。P 不出现（薛定谔类比）。MMS 侧判定的独立性给了比对**外部必要性**：映射失败则判别力归零（§6.4.4）。这是**【定理】级**逻辑：良定义性只依赖两侧判定各自可执行。证据地位另算（§3：过盲比的行才算接触点证据）。

**第二问：尺度限定词是内核推出来的。** 错位限定（v1.1 引入、v1.2 修正）：

> d 与 MMS 的"尺度分离"不是同一判定对象：后者是**结构性、时不变**的介质性质；d 是**状态性、时变**的动力学量。**但** XS 并非只有状态性判据：**P5（残差标度律，§8.3/§8.7）就是结构性的尺度分离检验**，"HMM 可用 ⟺ P5 有特征尺度 ⟺ A10 M-完备"已登记。错位限定只吊销 M1 的"判定同构"地位（降为形式类比），XS 与 MMS 在结构尺度判据上的对应走 P5，不走 d（G-26f）。

限定之后，推理链照写，辖域已收紧：

1. d 是尺度相对量（【定理】）⟹ C1 天然是**尺度窗口**判据；
2. 窗口之外是 F1 吸收态（【原型确认】，S4）——**框架内部可判定"此处不可耦合"**；
3. 窗口内再过 C2 ⟹ F2 伪收敛（【原型确认】，S2）——**框架内部可判定"耦合了但不可信"**；
4. 跨窗口移动有定量代价：中继数下限由弱端尺度决定（【原型确认】）。

1–4 连起来是"**尺度选择性耦合**"的完整含义：**XSM 内部可判定地在 C1∧C2 窗口上耦合、窗口外禁止、窗口内算子失配时给出第三态。**三态判别是"框架外做不出的区分"的候选实例。M7（限定版）给"第三态"提供了第一行设计外的外部呼应。

两个诚实注脚。其一，吸收态不可逆性**部分是建模选择的产物**（§5.6 已登记）。其二，ghost 伪力是**现象学项**，未从界面算子推导（§5.8）。

## §5 能声称什么、不能声称什么

**可以声称（按标记分级）：**

1. 【定理】判定级对应（定义 1.1）良定义，合法性不依赖 P。
2. 【原型确认】内核工程产出过一组非平凡判定：三态判别、伪收敛 D 形态判据、调和律、中继数下限、P5 尺度分离检验（预注册，六场景）。
3. 【原型确认】这组判定与 MMS 实践存在逐行可写出的对应（M1–M7），判定结构 XS 原生（§3）；且系统**有否决设计预期的记录**（B 组）——"自证机器"指控在全称形式下被证伪。
4. 【猜想】存在非平凡谓词映射 Π。当前由**过盲比的行**（M7，限定版）+ **判定程序级既有对应**（§8.7 P5–HMM 链）承载；其余行是待盲比假设。

**不能声称：**

1. **不能声称耦合已经建立。** 无联合执行（G-26c）。
2. **不能声称这对 P 有任何支持。** P 始终悬空。
3. **不能声称尺度选择性是现实投影系统的普遍结构。** 单域，同域准实证（`10` §5.3）。
4. **不能声称任一行是外部对应证据——除非过盲比；也不能反过来说整表只是自检。** 正确读法：**对照假设清单 + 一行限定版盲比通过记录（M7）+ 一条判定程序级既有对应（§8.7）**。
5. **不能越层读取（D1）。** "弱端支付代价"是 L2 原型现象，不许反读成 L0–L1 归宿命题。
6. **不能声称 D-SCALE 已成立。** 仍 provisional，待 R-042。
7. **（v1.3 新增）不能声称注释层独立性已完全证明。** §3.3 的逆向检查只覆盖"注释写入之后"；同会话内的参数选择动机不可核查（G-26g 残留）。

### §5.1 与 FEP 批评的结构相似性

FEP 的结构性批评：辩护者遇反例时添加"期望自由能"，它不是从原原则推出的，是为挽救原则额外加上的（ad hoc）。本文论证与该结构**形式相似**，异同写清：

- **异**：我们的 MMS 参照不是遇反例后打补丁；且工程记录里有**反向证据**——B1–B3 证明原型能否决设计预期。ad hoc 结构的定义性特征是"系统只能吸收、不能否决"；**我们的系统有否决记录，结构不闭合为 ad hoc**。
- **同**：单条对照行上，"吻合是否被设计保证"仍须逐行回答——三层标注是回答格式。
- **处置**（四条，缺一不可）：①逐行三层参照标注（§3）；②新行走预登记盲比程序（§3.1，R6 预注册是先例；**预案必须含"以上皆非"出口**）；③承认盲比存量有限——耗尽后 G-26b 不可解，**这个可能性必须被允许存在**；④（v1.3 新增）注释层独立性靠前向纪律维护：凡修改判定结构或参数，提交信息声明是否参照了注释层类比（§3.3 残留的对冲）。
