# X-S-MERA v3.4 · η（尺度分离阈值）取值原则

> **闭合缺口**：**B-B44**（η 取值原则未定 → 已锚定）
> **承接**：R-042（experiments/r42_dscale_eta）、R-043（experiments/r43_tau_star）、
> R44（experiments/r44_eta_principle）
> **纯内部可解**：不需外部数据；本原则全部由已有仿真 + 本补篇的锚定验证支撑。

---

## §0 一句话结论

**η 的取值原则 = 取"目标场景可靠子区间"内的值**：该子区间由三条件共同限定——
① η 使 `τ*` 落入观测窗口 `(τ_fine, τ_coarse)`（**落带**，R-043）；
② 落带率 ≥ 约定可靠性水平 `REL_TH = 0.90`（**可靠子区间**，R44，σ∈{0.05,0.10} 验证）；
③ 子区间内 D-SCALE 判定读数对 η 不敏感（**带内不敏感**，R-042）。
满足三条件的 η 即兑现"把涨落误读为定向的可接受错误率"语义，**B-B44 由"开放"推进为"已锚定"**。

## §1 η 的语义与身份（复核）

| 项 | 值 | 来源 |
|---|---|---|
| 符号 | `η` | symbol_registry.json |
| 层 | L2（观测） | symbol_registry.json |
| kind | observable，无量纲 | symbol_registry.json |
| 定义 | 把涨落误读为定向的**可接受错误率** | symbol_registry.json |
| identifiability | C | symbol_registry.json |
| allowed_readings | 可接受错误率 | symbol_registry.json |
| forbidden_readings | **不能读作显著性水平 h（h 是外部旋钮）** | symbol_registry.json |
| 作用 | `τ*(η) = min{w : Var(块均值_dU, w)/ψ̄² < η}` | R-042/R-043 内核 |

η 是观测协议里的**约定性输入**，不是推导量；它规定"允许把涨落误读为定向"的比例上限。
正因如此，取值原则未定曾是 B-B44 的核心——**不是"η 该取多大"缺一个数字，而是缺一个
可辩护、可操作、不引入外部旋钮的取值规则**。

## §2 取值原则（定稿）

> 记号：`R(τ)` = 尺度 τ 上的任务内共线残差；观测窗口 `(τ_fine, τ_coarse)`；
> 落带 `τ* ∈ (τ_fine, τ_coarse)`。

### P1 · 语义原则
`η` 是**可接受错误率**——允许把涨落误读为定向的概率上限。它是观测协议参数，
**不投射为外部显著性水平**（遵守 forbidden_readings，杜绝把 η 当成 h 这类统计旋钮）。

### P2 · 落带原则
`η` 必须落在能使 `τ*(η)` 落入观测窗口的**落带区间**内，否则该场景 D-SCALE 不可判定。
落带区间已由 R-043 登记（默认窗口 (8,128)）：

| 场景 | 落带区间（R-043） |
|---|---|
| A 同尺度 | [0.0311, 0.0462] |
| B 跨尺度弱扰动 | [0.0311, 0.0713] |
| C 结构性扰动 | [0.0612, 0.0863] |

### P3 · 可靠子区间原则（R44 新增，本补篇核心）
落带区间**并非处处可靠**：在噪声（σ>0）下，靠近边界的 η 可能使 `τ*` 抖动出窗口，
即"把涨落误读为定向"的比例升高。取值须落在**落带率 ≥ REL_TH=0.90** 的连续子区间内：

| 场景 | 可靠子区间（R44，σ∈{0.05,0.10}，落带率≥90%） | 与落带区间关系 |
|---|---|---|
| A 同尺度 | **[0.0311, 0.0462]** | ≈ 落带区间（worst 0.975/0.920） |
| B 跨尺度弱 | **[0.0322, 0.0713]** | **下界收窄**（近 0.0311 处落带率仅 0.61–0.72） |
| C 结构性 | **[0.0612, 0.0863]** | = 落带区间（worst 1.000） |

> **为什么 B 要收窄**：跨尺度弱扰动的信号弱，`ratio(w)` 对 η 在落带下界附近敏感；
> 噪声使 `τ*` 在该处易抖出窗口，误读率升至 0.29–0.39。收窄下界到 0.0322 后，可靠子区间内
> 落带率恢复到 ≥0.90。这是"可接受错误率"语义在 B 场景的实质约束。

### P4 · 带内不敏感原则（R-042）
可靠子区间内，D-SCALE 判定读数对 η 在 [0.005,1.0] 稳定、g 不进入判定流程。
⟹ **子区间内取哪个 η 不改变判定结论**——取值原则只需"落入可靠子区间"，无需再指定
更细的值。这使取值原则稳健：`η` 的选择只在"是否落入可判定可靠带"层面影响结果。

### P5 · 多场景原则
三场景可靠子区间交集为空 ⟹ `η` 是**场景相关**协议参数，**按场景声明**，不是全局常数。
- 单场景应用：`η` ∈ 该场景可靠子区间（P3 表）。
- 需全局单值时：取 A∩B 可靠区间的保守子区间（保留同尺度 A 这一最保守基线），
  显式声明 C（结构性扰动）单独取值或牺牲；或把 `η` 降级为"解释性装置"（当多场景
  无法同时满足时），不强行套一个假全局值。

## §3 无根状态处置（trace_gaps / symbol_registry）

- `η` 仍是**约定性输入**（不是推导量），因此**保留在 trace_gaps.json 白名单**；
  但 **reason/todo/severity 更新**——取值原则已给出（P1–P5），不再"未定"，
  severity 由"中"降为"已锚定（约定根）"。
- symbol_registry.json 中 `η` 的 definition 更新为含取值原则；`derives_from` 指向
  取值原则依赖的量：`{可接受错误率语义（约定）⊕ 场景落带区间（R-043）⊕ 可靠子区间（R44）⊕ 判定灵敏度（R-042）}`。
- 意义：`η` 不再让"尺度本身带约定性"成为开放缺口；约定性仍在（它是观测根），
  但**取值规则已闭合**——这正是 B-B44 要的。

## §4 边界与诚实登记

1. **可靠子区间是原型内结果**：基于无噪声内核 + σ∈{0.05,0.10} 的涨落注入、默认窗口
   (8,128)、REL_TH=0.90。换窗口/场景族/σ 区间需重跑 R44 脚本，不预设外推。
2. **REL_TH=0.90 是约定水平**：可接受错误率语义要求误读率 ≤ 0.10；若应用要求更严
   （如 0.05），可靠子区间会相应收窄（B 尤其敏感），需重算。
3. **不引入外部显著性水平**：η 的可接受错误率由**观测协议内**的落带率约束，不由外部
   统计检验旋钮设定（遵守 forbidden_readings）。
4. **D-SCALE 仍标 provisional**：η 取值原则虽已闭合，但 B-B43（g(U) 形式，阻塞 R32
   反演）仍未解；D-SCALE 升级到 established 需 R-042 的"判定对 η 不敏感"写入证书，
   且依赖 B-B43 的处置（见 boundary_map）。
