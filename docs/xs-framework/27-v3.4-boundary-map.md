## §1 为什么先画地图

v3.4 章程（`18` §6.1）的排序原则是：**先拿到可信、完整的边界地图。**
理由有三，都已在章程登记：(i) 边界地图是 generics 证明、Lean 形式化、对应探索的
共同前置——边界没画清就形式化，规则一改，证明代码反复重构；(ii) 一张地图同时服务
两条合法性判据：C1（内部一致性）看推导链是否触到边界，C3（跨实例可复用）看边界
是否随实例漂移；(iii) **框架的意义在边界上最浓**——"框架外做不出的区分"（读得出
vs 读不出、真目标 vs 伪目标、同尺度 vs 跨尺度）恰好都是边界命题。

与既有登记件的分工：**缺口表（B-Bxx）**记"框架的缺口"（推不出来的东西）；
**礁石台账（R-0xx）**记"边界探索中的待解问题"；**本文的地图**把两者的结果
**投影到同一张图上**，回答"现在哪个格子能站人、哪个不能"。

**逻辑桥**：地图要有坐标系。先给七维。

## §2 总图：边界的七个维度

**判定程序**——这是它区别于"散文式免责声明"的地方：地图上每个格子都是可执行的。

| # | 维度 | 判定问题 | 判定程序 | 挂靠 |
|---|---|---|---|---|
| **B1** | **可辨识边界** | 这个量读得出吗？ | 四级分类（A/B/C/D）× 实例资源（s(k) 可观测？） | R-041、定理 6.12、命题 6.3 |
| **B2** | **耦合边界** | 这两段能交互吗？ | C1/C2 三态判定（可耦合 / 禁止 / 耦合不可信） | 命题 2′、F1/F2、`26` |
| **B3** | **尺度边界** | 这是同尺度耦合还是跨尺度弱扰动？ | 双尺度残差对比 R(τ_fine)/R(τ_coarse) | D-SCALE、R-042、P5 |
| **B4** | **规范边界** | 这个目标是真的还是坐标幻觉？ | U5：真值随 G_λ 改变 ⟹ 不予登记 | 定理 6.12、D 级 |

## §3 主图：可辨识边界二维表（R-041 测绘结果）

### 3.1 测绘程序

R-041（`reef_shturl.json`）问：**四级可辨识边界是否随实例类型（闭实例 s(k) 可观测 /
开实例 s(k) 不可观测）变化？** 测绘方法不是仿真，是**推导**：把 `16` §10–§11 的
定理（第二可辨识视界、定理 6.12、命题 6.3）逐格投影到（等级 × 开闭）上，
能推出读法规则的格子标【定理】；推不出、只登记预期的格子标【待验证】或【开放】。

### 3.2 两张表：分级结构 vs 可读性条件（v0.2 拆分）

> **为什么要拆**：v0.1 把"分级"与"可读性"混在一张表里，C 行的**条件性**被
> "三条预期全部成立"的整齐结论掩盖了。拆分后第一张表可以干净地标【定理】，
> 第二张表把 C 行的条件性单独浮出来。两件事的证据地位不同：
> **分级**（等级标签随实例变不变）不依赖实例边界的划定；**可读性**（能不能读出来）
> 依赖——而 C 行的可读性恰好撞在 §3.4② 的归属判据上。

**表 A · 分级结构表（等级标签是否随实例类型变化）**

| 级 | 闭实例 | 开实例 | 同级？ | 证据 |
|---|---|---|---|---|
| **A** | `ρ_exp` = 斜率 | 同 | 是 | 【定理】第二可辨识视界 |
| **B** | `sign(1−ρ)` = 截距符号 | 同 | 是 | 【定理】 |
| **C** | 需外部单位的量 | 同 | 是 | 【定理】：C 级的**定义**（需外部单位）不随实例变 |
| **D** | 伪目标 | 同 | 是 | 【定理】定理 6.12：规范冗余是定义层的 |

**表 A 结论【定理】：四级分级不随实例类型变化。** R-041 担心的"条件分层结构"
在**分级**这一层不成立。

**表 B · 可读性条件表（每一级的可读性依赖什么）**

| 级 | 可读性 | 依赖 | 例外/辖域 | 证据 |
|---|---|---|---|---|
| **A** | 自足可读（两实例同规则：`U − ρ_exp·E` 共线性读斜率，调度无关） | 无 | A_D⁺ 下 `U` 近 0 有偏离；OPEN-4 噪声方差**已做（v1.6.22）**：E(A)观测噪声破坏共线性斜率、U(B)观测噪声影响小（`experiments/open4_noise_variance/`） | 【定理】+ 原型确认（R30）+ OPEN-4 仿真 |
| **B** | 自足可读（截距符号；顶点带用 β 形式，不需 `κ_E`） | 无 | ρ=1 顶点 → 判读禁区（R34 已解） | 【定理】+ 原型确认（R34） |
| **C** | **分层结论**：(i) **辨识信息齐备**（观测 s(k) 即补齐第二可辨识视界的缺失自由度；或固定动作计数通道，命题 6.3）；(ii) "**自足**"按约定分读——**约定 A（工具算界内）：C 级自足是定义上的真；约定 B（工具不算界内）：C 级自足是相对于观测协议的条件性结论** | (i) s(k) 观测或固定动作计数；(ii) **约定声明**（A/B，显式写在实例申报表上） | 未声明约定的实例，C 行读法**悬置**——不判自足也不判非自足 | (i)【定理】+ 原型确认（R33，辖域见 §5 交叉引用）；(ii)【约定】= §3.4② |
| **D** | 恒不可读（伪目标） | 无观测协议可救 | — | 【定理】定理 6.12 |

**表 B 结论（分层，v0.3）**：A/B/D 的可读性不依赖实例资源——【定理】。
C 的可读性 = 辨识部分【定理】+ 自足部分【约定】——**C 行不是被阻塞的缺口，
而是一个约定声明字段**：框架不裁定约定 A/B 哪个正确，只要求声明被显式写出；
未声明的实例，C 行读法悬置。附带勘误：v0.1 把 R33 写成 C 行的实测核验，
辖域过宽——R33 验证的是**固定动作计数通道**（介入性，任何实例下合法）
的读数自洽，它不裁定"某个设置算不算闭实例、算不算自足"（见 §5 R45 行交叉引用）。

### 3.4 测绘中浮出的开放点（地图上的空白格）

1. **`ρ = 1` 顶点奇点（B 级）——【已解，R34，2026-10-24】**。容差带定义：

### 4.2 B3 尺度边界（同尺度耦合 / 跨尺度弱扰动）

判定程序：双尺度残差对比（`18` §4.4）——`R(τ_fine) ≈ 0 ∧ R(τ_coarse) ≈ 0` ⟹ 同尺度
