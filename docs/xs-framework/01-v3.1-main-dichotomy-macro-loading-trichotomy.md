## 摘要

认知通常被呈现为一个**二元的**活动：有认知者与被认知者，有心智与世界。本文提出：认知活动的最小切分不是"主体—客体"，而是**对象面与运算面的二分**——认知一边投入"被操作的东西"（**X，象**），一边投入"施加于其上的操作"（**S，运算**）。这一**认知二分**是本框架的起点。

本文的核心工作是回答：**认知二分之后，为什么会出现三分？** 我们把认知过程类比为**基于事实公理与运算公理的系统演绎**：认知主体持有一批被当作起点的"事实"（**事实公理 F**），并持有一批允许施加于其上的操作（**运算公理 O**）。两者的推导闭包反复作用，产生可被压缩、复用、调用的**稳定压缩单元 M（宏）**——这一步称为**宏加载**。宏加载的完成使 X-S-M 三元架构（**XSM**）不再是预设，而是**被生成出来的**：因为宏一旦被加载，就获得了"可被再次调用"的地位，从而构成 X → M → X′ → M′ → … 的调用链。

但宏加载并非总能完成。给定一个新的输入象 X₀ 与既有宏库 K，加载过程有三条互斥的归宿：**收敛**（唯一宏的预条件被填充并完成固化）、**震荡**（多个宏并行满足预条件而不可唯一取舍）、**发散**（无宏的预条件可被填充，候选无界增殖而无沉淀）。这就是**认知的三分**。

本文最关键的一步是论证：**这一三分的落脚方式不是确定的，而是概率的**。原因在于认知的事实集 F 不是封闭的——它**持续被填充**。在经典形式系统中，公理集固定、推导确定；而在认知中，事实公理随迭代不断增长 F₀ ⊆ F₁ ⊆ … ⊆ F_k。于是：

- 在**任一有限迭代步 k**，系统只能依据当时的部分事实集 F_k 做出加载尝试，故三态的出现只能以**概率**刻画；
- 随着 k 增长、事实持续注入，**这一概率分布发生定向漂移**——但漂移的终点不是唯一的：它可能落入**收敛**（宏库覆盖内），也可能锁定于**发散**（宏库覆盖外，即伪收敛或流形断裂）。

因此，认知过程的准确刻画是：**在事实持续填充与认知结构迭代的共同作用下，三态概率分布走向定向漂移的吸收过程**。本文给出三态的操作性定义、转移结构的吸收 Markov 描述、漂移的两条上界定理，以及与 XS 既有体系（§2.4 涌现三源 S1/S2/S3、§3.9 推论 P、§3.8 流形-结构层、X-S-MERA v1.6.1 工程反哺）的接口。最后诚实登记本文的缺口：类比的三条形式偏离、伪收敛的不可事前判定、以及"为什么是三态而非四态"这一未被压平的问题。

**关键词**：认知二分；宏加载；XSM 架构；事实公理；运算公理；概率三分；收敛；震荡；发散；伪收敛；吸收 Markov 链；XS 框架

## §1 引言

### 1.1 一个被反复提出的、但未被恰当回答的问题

"人是怎么想明白一件事的？"这个问题的困难不在于缺乏答案，而在于**答案总是被过早地组织**。

最常见的组织方式是**按结果倒推**：把"想明白了"当作一个终点事件，然后反推通向它的路径。于是那些事实上长期犹疑、反复摇摆、多次失败后偶然成功的真实历程，被事后压缩成一条笔直的推理线。这种压缩有明确的好处——它使知识可表达、可教学、可传播；但它付出的代价是：**它把认知过程中的褶皱一并地熨平了**——真正的认知过程中的分支、并行、回跳、作废，在这条笔直的线上不留痕迹。

第二种常见的组织方式是**按"正确性"分手下**：把认知的输出分为"对的"与"错的"，并假定有一条能区分二者的稳定方法。这种二分对应于驾驶——它对**已形成的判断**有效，但对**尚在形成中的判断**失效：一个还在摇摆中的判断既不"对"也不"错"，它恰恰处在第三条路上。

本文要处理的正是这第三条路。我们的出发点是：

> **认知结果的正常形态不止一种，至少三种（收敛、发散、震荡），而且在任一给定时刻，落在哪一种上是概率性的。**

### 1.2 为什么必须是"三分"而不是"二分"

为什么既有的框架倾向于二分？因为二分与**演绎的确定性**相适应：给定前提 p 与规则 r，命题 q 要么可被推出，要么不可。这是一个 ~(推得出 / 推不出) 的二值问题，它干净、可判定、与形式逻辑同构。

但认知不是这样工作的。认知的三个无可回避的经验特征是：

1. **它不是一次性完成的**——它是迭代的。同一批输入在第 k 步与第 k+1 步上产出不同的中间状态。
2. **它的输入不封闭**——新事实会持续注入。系统的"事实库存"在使用期间会增长。
3. **它有资源约束**——运算步数与可用资源有限，无限迭代不被允许。

正是这三条，把二值结构撑开为三值。第 1 条意味着需要考虑迭代轨迹；第 2 条意味着在任一有限步上都不能确定终局，故只能谈概率；第 3 条意味着无限摇摆不被允许——**震荡必须有归宿**（收敛或发散），而它落到哪一个，取决于事实注入是否足以让某个宏完备。

这就是本文要论证的"三分/概率"的力学来源。我们将从**形式系统**这一已经被充分研究的确定性结构出发，逐条剥离它的三个理想化假定，观察每剥离一条会产出什么——而我们将看到：**三条假定的剥离，恰好产出三个归宿**。这是一个相当紧凑的结果。

### 1.3 本文的任务与边界

- **任务**（三条）：
  1. 给出**认知二分**（X / S）的严格表述，并说明它是**范畴层的划分**，而非层内对象的枚举（§2）。
  2. 给出认知作为**事实公理 + 运算公理**驱动的演绎系统的表述，由此导出**宏加载**与 **XSM 架构**的**生成**（§3–§4）。
  3. 给出**认知三分**的操作性定义、**概率性**的来源、以及迭代下的**漂移行为**（§5–§6）。
- **边界**（三条，事前声明）：
  1. 本文**不承诺**神经实现。X、S、M 是认知的功能角色，不是脑区、不是通路。任何将 M 直接读为"神经集群"的读法都超出本文辖域。
  2. 本文**不承诺**三分精细排序的常数值。本文给出判据与漂移方向，**不给具体数值**（§6.2 仅给出上界形态）。
  3. 本文把认知描述为公理系统，是**类比+移植**，不是同一性断言。§3.5 专门登记这一类比在何处失效——而**恰恰是这三条失效点构成了三分的力学来源**。

## §2 认知二分：X 与 S

### 2.1 X：认知的对象面（象）

**定义 2.1（X，象）**。认知系统中**被施加运算的那一侧**，记作 X。X 包括：

- 外部进入的初始刺激（X₁，输入态）；
- 在系统内部被重新表达出来的中间态（X₂，萃取态）；
- 可被报告、可被外显输出的成品态（X₃，输出态）。

这里的"象"取"像/表象"之义：**它是被呈递给运算面的东西**。一个关键限定是：**X 不是世界上自在的对象，而是被认知系统接纳为操作材料的那一面**。同一物理事件，在不同主体的不同时刻可以进入或不进入 X 的位置——是否被接纳，取决于当时的尺度向量（见 §3.4 与 v3.0 §3.3）与当时的宏库状态（§4）。

### 2.2 S：认知的运算面（对 X 的运算）

**定义 2.2（S，运算）**。认知系统中**施加于 X 的那一侧**，记作 S。S 包括：

- 截断算子 T（把 X 压缩为稳定单元的坍塌运算，v3.0 §3.4）；
- 联想、比对、回跳、递归、萃取等具体运算；
- 组合以上两者的复合操作。

**S 的关键性质**是它由**运算公理**规定（§3.3）。S 不是任意操作的空间——它是一个受约束的集合：只有被运算公理允许的操作才可被执行。

### 2.3 二分的规范性地位

一个必须提前压平的误读是：**把 X/S 读成"外来的刺激 / 内在的处理"，或读成"数据 / 程序"**。这两种读法都是错的，因为它们把 X/S 读成了**层内对象的两类**，而 X/S 是**范畴层的两类**——它们的区分方式是：**在同一个认知活动内部，区分"被操作者"与"施加操作者"这两个不可还原的角色**。

这一点的重要性在于它的**不可逆**推论：

> **推论 2.1（二分优先于具体列表）**。X 与 S 的具体实例清单是可变的、可修订的、可随任务而变的；但"任何认知活动都必须同时投入 X 面与 S 面"这一划分本身，不随具体清单改变。

这条推论看似平淡，但它有一个硬后果：**X 与 S 不能互相还原**。不可能只有 X 而没有 S（那是一个未被加工的表象，不构成认知）；也不可能只有 S 而没有 X（那是一个空转的算符，不作用于任何东西）。**认知的最小单位必须是 X-S 的一个配对**。

这就是"认知二分"这个词的确切含义：**不是把认知分成两半丢掉一半，而是确认认知的最小完整单位是一个双面结构**。

### 2.4 二分与后续的衔接

二分给出 X 与 S 之后，紧接着的三个问题是：

1. **S 凭什么被允许？** → 需要**运算公理 O**（§3.3）。
2. **X 从哪里来、会不会增长？** → 需要**事实公理 F**，且 F 持续被填充（§3.2）。
3. **X 与 S 反复作用之后留下什么？** → 留下可被复用的**宏 M**（§4）。

第 3 个问题的答案将把二分推向三分——因为 M 的形成不是必然的（§4.3）。

## §3 认知作为公理系统：事实公理与运算公理

本节把 §2 的二分提升为一个可操作的演绎结构。核心是一个类比：

> **认知过程** ≈ **一个形式系统对该事实/运算两类公理的反复作用**。

我们不是第一个这样做的人。意义在于：**这个术语在 XS 工程库中已有确切先例**——X-S-MERA v1.6.1 的 `formal/Formal/Axioms.lean` 中，公理被明确分成三类（§3.1）。因此本节是一种**把既有的工程实践上升为认知层表述**的工作，不是新造词汇。

### 3.1 术语的工程先例

X-S-MERA v1.6.1（`github/x-s-mera-src/formal/Formal/Axioms.lean`）的公理编码分三类：

| 类别 | 编号 | 性质 | 本文对应 |
|------|------|------|---------|
| **生命事实公理** | F1–F16 | 陈述"生命系统是什么样的"，作为起点被接纳 | **事实公理（F 轴）** |
| **环境事实公理** | E1–E7 | 陈述"环境是什么样的"，作为起点被接纳 | **事实公理（F 轴）** |
| **元公理** | M1–M2 | 陈述"系统行为遵循什么规律"（熵增、局部耗散最优） | **元约束**（对运算的二阶限制） |
| **耦合定理** | H_LE / H_EL | 双向耦合的存在性断言 | 跨系统调用关系 |

可以看到三点：

1. **"事实公理"这个说法不是本文发明的**，它是 XS 工程中已经在用的词。
2. 工程中 F 与 E 的分野提示：事实公理本身**按来源分伙**（生命侧 / 环境侧），这是认知版可借用的结构（内部事实 vs 外部事实）。
3. 工程中 **存在元公理与公理的层级区分**（M vs F/E），这是认知版需要的：**元公理约束运算本身，不直接参与 X 的加工**。

### 3.2 事实公理（F 轴）

**定义 3.1（事实公理）**。认知系统在某一时刻 k 所**接纳为推导起点**的命题集合，记作
$$F_k = \{f_1^{(k)}, f_2^{(k)}, \dots, f_{n_k}^{(k)}\}$$

**四点必须立即澄清**，每一条都是会被误读的位置：

**(a) "事实"不等于"真"。** 事实公理是**被当作起点**的命题，不是被验证为真的命题。它可以来自感知、记忆、被告知、或想象。**认知系统不在乎它的来源，只在乎它是否被接纳为起点**。这一条很重要：所谓的虚假信息、幻觉、错误记忆，在形式上都是完全合格的事实公理。这使得本文能够处理"基于错误前提的严密推理"这类现象，而不必引入额外机制。

**(b) F 是随时增长的：**
$$F_0 \subseteq F_1 \subseteq \dots \subseteq F_k \subseteq F_{k+1} \subseteq \dots$$
这就是用户提纲里"（可能持续填充的）事实"的形式化。**这是认知系统区别于经典形式系统的第一条、也是最要紧的一条偏离**（§3.5-A）。注意这里只写了单调增长：本文**暂不处理**事实被撤销（信念修正）的情形，这是一个显式登记的缺口（附录 B-B1）。

**(c) 事实分伙。** 借自工程的 F/E 结构，认知版区分：
- **外部事实**（感知所得、被告知、环境注入）→ 对应工程的 E 轴；
- **内部事实**（记忆提取、身体状态、先前固化的宏的输出）→ 对应工程的 F 轴。

这一分野的后果是：**同一轮迭代里，两类事实的注入节律不同**。外部事实依赖环境供给，往往以脉冲方式到达；内部事实依赖提取操作（一个 S），可以按需发起。这是 §6 漂移行为的直接动力来源之一。

**(d) 事实有附着强度。** 并非所有 f ∈ F_k 同等可用。本文**不为事实设置单一权重**（避免过早引入一个无处标定的参数），但明确承认：**事实的可用性受制于它被接纳的方式**（感知的鲜明度、记忆的新近度、被告知时的置信），并以 S 侧的**注意/提取运算**来间接体现。**这一点登记为简化，见附录 B-B2。**

### 3.3 运算公理（O 轴）

**定义 3.2（运算公理）**。规定哪些操作可以被施加于 X 的那一类公理，记作
$$O = \{o_1, o_2, \dots, o_m\}$$

每条运算公理 o_i **至少陈述三件事**：

1. **定义域**：什么样的 X 可被 o_i 作用；
2. **变换规则**：作用之后产出什么；
3. **前置资源消耗**：执行一次 o_i 需要支出多少迭代预算。

第 3 条是认知版**必须新增**的——经典形式系统的规则不消耗任何东西。**这是认知系统区别于经典形式系统的第二条偏离**（§3.5-B），而且它是"资源有界"这条 Girard-style 约束在 XS 中的落位。

**与元公理的关系**（借自工程 M1/M2）：
- **运算公理 O** 规定"可以做什么"（一阶）；
- **元公理 M**（如"总运算消耗单调不减""系统在约束下趋向局部耗散最优"）规定"所有这些做法本身遵循什么"（二阶）。
- **元公理不直接作用于 X**——它是 S 面的约束，不是对 X 的加工。工程的 A11-R（势-流分离：语义势只调增益、不进状态导数）正是这一"不越权"原则的实现（v3.0 §7.3）。

### 3.4 推导闭包 Cn 与 X 的演化

**定义 3.3（推导闭包）**。给定 F_k 与 O，一步推导闭包定义为：
$$\mathrm{Cn}_1(F_k) = F_k \cup \{\, t \mid \exists o \in O,\ \exists A \subseteq F_k,\ A \vdash_o t \,\}$$

迭代闭包：
$$\mathrm{Cn}_{j+1}(F_k) = \mathrm{Cn}_1(\mathrm{Cn}_j(F_k))$$

在 Th_k^{(j)} = Cn_j(F_k) 的基础上，X 的角色是：**X_k 是正在增长的闭包中、被选定为当前操作材料的那一部分**。不同时刻被选中的 X_k 不一样——这个选择本身是一个 S 运算（§2.2 的萃取）。

### 3.5 类比失效的三点——以及它们恰好是三分之源

**这是本文最关键的一节。** 我们不是在做一个装饰性的类比然后假装它成立。我们的方法相反：**逐条登记这个"认知 ≈ 形式系统"的类比在何处失效**，然后观察：三条失效各自把系统推向三态的哪一个。

#### 偏离 A · 事实集开放（F 持续填充）

**经典系统**：F 固定。给定 F 与 O，闭包 Cn(F) 是确定的，问题"t 是否可证"有确定答案。
**认知**：F_k 持续增长。因此**在第 k 步不能判定 t 最终是否可证**：
$$t \notin \mathrm{Cn}(F_k) \quad \not\Rightarrow \quad t \notin \mathrm{Cn}(F_{k+n})$$

**后果**：在任一有限步，**三态的落点不可确定，只能谈概率**。这就是"**概率**"这个词的确切来源——**不是认知本身有随机性，而是我们在有限信息下只能做概率判断；但更糟的是，这个"有限信息"是认知的内禀状态，不是观察者的无知。** 这是本文最重要的一句话：

> **认知的概率性不是观察者的无知，而是认知系统自身的未决状态。**

#### 偏离 B · 资源有界（迭代不能无穷）

**经典系统**：推导步数无界，可以一直推下去直到证出或证否。
**认知**：迭代预算 B 有限。每一步都消耗预算，预算耗尽即止。

**后果**：**震荡不可能无限延续**。若到预算耗尽时仍未完成唯一取舍，系统必然落到某一个"非震荡"的归口——它必须支付这个无果的代价。这个强迫性归宿就是**发散**（或 §5.4 的伪收敛）。因此：

> **资源有界性把"无限摇摆"压成了"发散"。** 传统把震荡视为"尚未决定"，其实在资源约束下它是"已经支付了一种失败"。

#### 偏离 C · 承诺可撤销（非单调性）

**经典系统**：一旦 ⊢ t，则永远 ⊢ t（单调性）。Cn 是幂等的闭包算子。
**认知**：一旦某宏被加载（承诺成立），**外部验证仍可将其推翻**，回到未完成状态。这就是 8 月版已经识别的**伪收敛**：动力学上完成了固化，事后验证为错。

**后果**：**收敛不是吸收态**。它为三态引入一条重要的回边：
$$\text{收敛} \xrightarrow{\ \text{外部证伪}\ } \text{震荡}$$

这也使得三态不是简单的线性序列，而是一个**带回边的转移结构**（§5.3）。

#### 小结：三条偏离 → 三个归宿

| 偏离 | 内容 | 推出的结构后果 |
|------|------|--------------|
| **A** 事实集开放 | F_k 单调增长 | → 终局**不可确定** ⇒ **概率性** |
| **B** 资源有界 | 迭代预算有限 | → 摇摆**必须归宿** ⇒ **发散**是强迫归宿 |
| **C** 承诺可撤销 | 非单调 | → 收敛**非吸收** ⇒ **伪收敛**回边 ⇒ 震荡可持续再入 |

这三条一起，把"确定性的二值演绎"撑开为"带回边的三分凝固过程"。我们将在 §5 把它写成明确的转移结构，并在 §6 论证它为什么表现为概率漂移。

## §4 宏加载：XSM 的生成

### 4.1 加载态三部：展开 — 加载 — 产出

**定义 4.1（宏，M）**。一个宏 M 是一个三元组：
$$M = \langle P_M,\ B_M,\ C_M \rangle$$

其中：

- **P_M = {p₁, p₂, ..., p_r}**：**预条件槽**集合。每个槽 p_i 规定一类必须被填充的条件。槽带**权重**（8 月版已明确："关键预条件权重高于次要条件"）。8 月稿中的原句是"并非简单统计预条件的数量占比"——本文采纳并保留这一加权口径。
- **B_M**：**固化行为**。一旦所有关键槽被填充，M 承诺执行的一段操作（即"加载完成后会做什么"）。
- **C_M**：**可调用性条件**。M 被加载到什么程度就可以被调用，而不必再完整展开。

**加载（loading）**的确切含义是：

> **定义 4.2（宏加载）**。给定输入象 X₀、事实集 F_k、宏 M ∈ K，**用 F_k 中的事实去填充 M 的预条件槽 P_M 的过程**，称为 M 的加载。记
> $$\sigma(M, F_k) = \sum_{p_i \in P_M,\ p_i\ \text{被填充}} w_i \Big/ \sum_{p_i \in P_M} w_i \in [0,1]$$
> 为 **加载度**（加权满足率）。当 σ 达到 C_M 规定的阈值 σ_M^* 时，称 **M 完成加载**，此时 M 由"待展开的候选"转为"可被调用的成品"。

**"加载"这个词的两种用法，本文明确区分**：

| 类型 | 发生场景 | 结果 | 对应 |
|------|---------|------|------|
| **编译型加载** | 学习期：某条推导链被反复成功执行 | 新宏被**加入**宏库 K | M 的**创生** |
| **调用型加载** | 应用期：既有宏的槽被新输入的事实填充 | 既有宏被**调用** | M 的**复用** |

两者共享同一套机制（都是"预条件槽填充"），因此**共享同一套三分归宿**——这是本文能用一个三分同时处理"学习"与"应用"两类现象的原因。

### 4.2 XSM 是被生成出来的，不是被预设的

这是本节的核心论点，也是"宏加载得到 XSM"这句话的确切含义。

在加载完成之前，只有 X 面与 S 面：系统在 F 与 O 的作用下做推导，产出中间态，如此而已。此时**没有 M 这个东西的独立地位**——M 至多是被轮流觊觎的一个目标。

**一旦加载完成，情况发生质变**：

$$X \xrightarrow{\ S\ } M \xrightarrow{\ \text{被调用}\ } X' \xrightarrow{\ S'\ } M' \xrightarrow{\ \text{被调用}\ } X'' \to \dots$$

也就是说：
- 加载的完成使 M 获得了**独立于本次推导的地位**（它不必被重新推导，可被直接调用）；
- 被调用后它的产出成为新的 X′，可作为下一轮的输入；
- 于是 **X-S-M 三元架构从加载过程中涌现出来**，而不是被预设在某个初始定义里。

这正是 v3.0 §3.5 所说"XSM 的运作机制：X 在 S 的作用下坍塌成 M，M 在另一个 S′ 的作用下可被调用为另一个 X′"的**生成性说明**：该文把 XSM 作为架构陈述，本文解释**这个架构是如何从加载中长出来的**。

> **XSM 不是认知的蓝图，而是加载成功后才成立的一种调用经济。**

### 4.3 加载的完成条件与不全的事件

**加载的完成**（记为大前提 T_load）需要同时满足：

1. **存在性**：∃ M ∈ K 使得 M 的关键预条件槽可被 F_k 填充；
2. **充分性**：该 M 的加权加载度 σ(M, F_k) ≥ σ_M^*；
3. **唯一性**（相对于竞争集）：在所有满足 1、2 的宏中，存在一个可据当前信息与约束被唯一选出的胜者。

三条缺一，就不发生正常加载。而**三条的缺失方式恰好有三种**——§5 的三分由此得到，无需额外假设：

| 缺失条件 | 现象 | 归宿 |
|---------|------|------|
| 无 M 满足 1 | 宏库中无任何候选可被贴合 | **发散** |
| 1、2 满足但 3 不满足 | 多个候选并行达标、不可取舍 | **震荡** |
| 1、2、3 全满足 | 唯一胜者完成固化 | **收敛** |

### 4.4 与既有 XS 术语的对齐

- 加载 ↔ v3.0 §3.4 **截断算子 T**：T 是"从 X 到 M 的坍塌运算"，加载是该坍塌在**槽结构上的具体实现**——T 说的是"压过去了"，加载说的是"每一个槽被填了什么"。两者是同一过程的外显/内显两面。
- 加载度 σ ↔ 工程版 d/D：工程版的边界重合度 d = exp(-r²/(2σ²)) 给出两系统边界的重合程度；加载度 σ(M, F_k) 给出单个宏与其可用事实的贴合程度。**两者同构，不同尺度**（一个是宏-宏，一个是宏-事实）。这一对应关系值得在工程中进一步验证（登记为推论 R1，§9）。
- 预条件权重 ↔ 基底-完备七条第⑦条极小可审计：每个槽（类比于每条公理 b）都应当是被某个 t 实际需要的；权重为 0 的槽应当被删除。

## §5 认知的三分：收敛 / 震荡 / 发散

### 5.1 三态的操作性定义

记 A_k = {M ∈ K : M 的关键预条件槽可被 F_k 填充} 为第 k 步的**可达候选集**。

**定义 5.1（收敛，Convergence）**。若 ∃! M\* ∈ A_k 使得 σ(M\*, F_k) ≥ σ^*_{M\*}，且对所有其他 M ∈ A_k 有 σ(M, F_k) 显著低于 σ(M\*, F_k)（差距超过判据 ε），则系统执行 M\* 的固化行为 B_{M\*}，产出稳定的 X₃。称系统**收敛**。

- **观测标志**：候选项由多变一；不再回跳；产出可复用；X₃ 可被再次调用为后续输入。
- **代价**：每一次收敛都是一次局部熵减——它终止该局部的震荡，打断该局部的熵增积累（8 月版原话）。**过早的全局收敛会关闭后续涌现的可能。**

**定义 5.2（震荡，Oscillation）**。若 |A_k| ≥ 2，且存在至少两个 M₁, M₂ ∈ A_k 使得 |σ(M₁, F_k) − σ(M₂, F_k)| ≤ ε（即两者加权加载度接近，无法据当前信息与约束完成唯一性取舍），则系统在这两个（或更多）候选间反复切换、并行维持、回跳。称系统**震荡**。

8 月版已识别出两种典型形式，本文继承：
- **平行震荡**（多候选并列）：两个及以上宏各自满足基础预条件，价值与适配性相当；
- **嵌套震荡**（互为因果回路）：宏 A 的预条件依赖宏 B 的输出填充，宏 B 的预条件依赖宏 A 的输出支撑，形成闭环。

- **观测标志**：周期性交替、螺旋式变异、有限候选反复回跳、结论摇摆不定。
- **关键限定（8 月版已强调）**：**震荡是系统层面的状态概念，不等同于主观感受到的犹豫。** 核心判据是多个宏或 X₂ 分支并行激活而尚未完成唯一性固化——该过程可发生在内隐无意识加工，不一定进入主观体验。
- **另一关键限定**：**单纯输入信息互相矛盾 ≠ 系统震荡**。震荡的必要条件是系统内部已生成多个具备一定预条件满足度的候选宏或 X₂ 分支；仅仅外部信息冲突、尚未形成内部候选，不产生震荡。

**定义 5.3（发散，Divergence）**。若 A_k = ∅（无任何既有宏的关键槽可被 F_k 填充），且在给定迭代预算 B 内也无法构造出满足 C_M 的新宏，则系统无沉淀、无固化行为可执行。称系统**发散**。

- **观测标志**：候选无界增殖但无一达标；产出碎片化；无法形成有效判断；无任何可被再次调用的 X₃ 被沉淀下来。
- **8 月版原话**："当有效约束不足、缺少可用认知宏作为基础时，无限延续的震荡会造成系统发散：多候选无限制增殖却无法完成筛选，无法沉淀任何稳定认知结构，输出碎片化。"

### 5.2 判据汇总表

| | 可达候选集 A_k | 最高加载度 vs 次高 | 是否有 X₃ 沉淀 | 是否为临界跃迁的前置 |
|---|---|---|---|---|
| **收敛** | ∃ 唯一胜者 | gap > ε | **有**，可复用 | 否（一旦固化即局部低熵） |
| **震荡** | \|A_k\| ≥ 2，无唯一胜者 | gap ≤ ε | 无（多个 X₂ 并行） | 是（临界跃迁的必要前置） |
| **发散** | A_k = ∅（且不可新构） | — | 无 | 否（连 X₂ 都无法沉淀） |

### 5.3 三态间的转移：一个带回边的结构

把三态写成状态集 S₃ = {收敛 Cn, 震荡 Os, 发散 Dv}，转移如下（箭头标注触发条件）：

```
                    ┌──────────────────────────────┐
                    │  （外部证伪/事后验证为错）      │
                    ▼                              │
        ┌───────────────┐                    ┌─────┴─────┐
        │    收敛 Cn     │                    │  震荡 Os   │
        └───────────────┘                    └─────┬─────┘
                    ▲                              │
      （新事实注入使某宏的关键槽被填充）                │（资源耗尽/          ）
                    │                              │（候选无界增殖/    ）
                    │                              │（有效约束不足    ）
                ┌───┴────┐                         ▼
                │ 发散 Dv │◄────────────────────────┘
                └────────┘
```

**转移明细（六条）**：

| 转移 | 触发条件 | 备注 |
|------|---------|------|
| Os → Cn | 新事实注入打破势均（某一候选 gap > ε），或其加载度单边跃升 | 主路径；8 月版"熵积累到临界后的固化" |
| Os → Dv | 迭代预算耗尽仍未取舍；或多候选无界增殖而无一达标 | **资源有界的强迫归宿**（§3.5-B） |
| Dv → Os | 新事实注入使 ≥2 个宏部分达标（A_k 由 ∅ 变为 ≥2） | 复苏路径 |
| Dv → Cn | 新事实注入使恰好 1 个宏达标（\|A_k\| = 1） | 罕见但可能 |
| Cn → Os | 外部证伪使已加载的 M\* 被推翻（**伪收敛暴露**） | **回边**（§3.5-C） |
| Cn → Dv | 已加载宏在新上下文中槽不再可填，且无替代 | 少见的退化路径 |

**关键结构观察**：

1. **震荡是非吸收的**——它必然离去（Os → Cn 或 Os → Dv）。这是 §3.5-B 资源有界的直接推论。
2. **发散是半吸收的**——若事实注入停止，它将永久停留；若注入继续，则复苏。**发散是唯一可由外部环境单向解救的状态**。
3. **收敛在无外部验证时是吸收的，在有外部验证时不是**。这条取决于主体是否处于接受反馈的位置——这是"孤立思考"与"在共同体中研究"的根本差别，也与 v3.0 §2.3 的知识注入测试**同构**（把外部反馈抽象为"注入新事实看结构如何变动"）。

### 5.4 收敛的再分：真收敛与伪收敛

务必不要忽视：**收敛不是一个干净的成功状态**。8 月版已明确区分两种：

- **真收敛**：加载的确实是对的那个宏，事后外部验证通过。
- **伪收敛**：动力学上完成了固化（"以为是"），事后验证为错。

**伪收敛的三种常见成因**：

1. **槽的错误填充**：某个关键槽被一个事实上错误但其实在某 k 步被接纳的 f 填满（对应 §3.2-a：事实不等于真）。
2. **错误的唯一性**：本来应当有多候选，但因约束过强或**过早地**取舍，把本该震荡的局面压缩成单点固化（8 月版"过早闭合/高频收敛"）。
3. **越界调用**：输入落在宏库覆盖范围之外，但系统加载了"最接近"的现有宏并报告成功——**这就是 v3.0 §3.9 推论 P 的分支 3 与 §3.10 流形断裂在认知层的样子**。

**本文的诚实登记**：**伪收敛在事前不可判定**。这不是技术困难，而是结构性的——因为在伪收敛发生**的当时**，系统拥有的全部信息（F_k、A_k、加载度）与真收敛**完全相同**。**两者只在事后可区分**（这正是 v3.0 §2.3 知识注入测试存在的理由：它是一条"事后注入、看是否消解"的判据）。登记为缺口 B-B3。

一句话：**"我确信我想明白了"这一体验，在三态结构中不构成区分真收敛与伪收敛的证据。** 这句话应当写进任何使用本框架的方法论章节。

## §6 概率三分：为何是概率的，以及它如何漂移

### 6.1 概率的确切来源

现在我们可以把 §3.5 的结论精确化。给定输入 X₀、宏库 K、初始事实集 F₀、迭代预算 B，**三态的最终落点在 k = B 时是确定的吗？**

**不是。** 理由是三条，全部源自 §3.5 的偏离：

**(i) 事实注入的不可预测性（主导来源）**。F_k 的增长 ΔF_k = F_{k+1} \ F_k **不由系统决定**——外部事实的到达受环境支配，内部事实的到达受提取操作的偶然性支配。既然每一步的新增事实不可预测，那么每一步后 A_k 与 σ(·, F_k) 的取值就不可预测，从而终局落点不可预测。因此：

$$P(\text{终局} = \text{收敛}) ,\ P(\text{终局} = \text{震荡}) ,\ P(\text{终局} = \text{发散}) \in [0,1],\ \text{三者之和为}\ 1$$

**(ii) 有限步截断（资源有界）**。即便假设事实注入完全确定，在 k < B 时尚未完成取舍的系统，其终局仍取决于"下一个到达的事实是不是恰好打破势均的那一个"——而这依赖于注入序列，而注入序列在 k 时刻尚未全部实现。**所以概率不是被常识掩饰的无知，而是有限资源的直接后果。**

**(iii) 并列打破的偶然性（tie-break 敏感性）**。当 |σ(M₁, F_k) − σ(M₂, F_k)| ≈ 0 时，微小的新事实、微小的注意波动、微小的提取顺序差异都可能决定胜负。这是混沌式敏感性，它使得即便注入序列已知，若初始条件不能无限精确给定，终局仍不可确定。〔**补篇 §1.3 追认**：此处已触及混沌的真正威胁——不是"第四态"，而是**吸引盆分形化**导致三态概率权重不可鲁棒赋值〕

**> 关键论断 6.1（概率的内禀性）**。认知三态的概率分布**不是观察者的无知测度，而是认知系统自身的未决度**。即使一个全知的外部观察者知道 F_k 的当前内容，只要 ΔF_{k+1} 尚未被指定，系统的终局就**客观上未定**——这不是认识论的局限，是本体论的状态。

这一点很重要，值得与 v3.0 的一个既有结论对照：v3.0 在该处主张"层次外显关系**不由任一层级的公理推出**——它是在坍塌算子 T 作用时**生成**的"（v3.0 §3.6）。本文的 §6.1 是同一主张在**概率层**的后随：**三态的分布本身，也是一个"在迭代中生成、不可由 F_k 与 K 的静态快照推出"的对象**。

### 6.2 迭代下的分布漂移

令 p^{(k)} = (p^{(k)}_{\text{Cn}}, p^{(k)}_{\text{Os}}, p^{(k)}_{\text{Dv}}) 为第 k 步的三态概率向量（服从和为 1）。问题是：**p^{(k)} 随 k 怎么动？**

我们可以给出两条不依赖具体数值的**定向结论**：

**漂移定理 6.2（震荡的非持久性）**〔**条件化修订见补篇 §2.3 的定理 6.2′**：须附加"势释放率 μ > 0"；μ = 0 时混沌构成第四态，且吸引盆可分形化使概率权重不可鲁棒赋值〕。在迭代预算有限（B < ∞）且外部注入在 B 步内不完全停机的条件下：
$$\lim_{k \to B} p^{(k)}_{\text{Os}} = 0$$
**即震荡必然消亡。** 这是 §3.5-B 资源有界的直接推论：预算耗尽时系统**必须**落到某个非震荡的归口。它的实际意义是：

> **震荡是一个瞬态，不是一个稳态。** 任何把"维持震荡"当作可持续策略的想法，都忽略了**震荡的账迟早要付**——代价或者是收敛（付得漂亮），或者是发散（付得难看）。

**漂移定理 6.3（事实持续填充下的单向改善）**。若事实注入持续不停（ΔF_k ≠ ∅ 对所有 k < B），且注入的事实与当前题域相关，则存在单调性：
$$p^{(k)}_{\text{Dv}} \ \text{非增},\qquad p^{(k)}_{\text{Cn}} + p^{(k)}_{\text{Os}} \ \text{非减}$$
**即：持续注入的相关事实不会让发散概率上升。**〔**条件化修订见补篇 §3.8**：本式仅在注入事实**不撤销既有断言**（肯定型 / N1 / N3 型）时成立；含 N2 型撤销时 p_Dv 可能上升，见定理 6.3″。缺口 B-B1 由此闭合〕 因为 A_k = ∅ 的状态只可能因新事实加入而变为非空，不可能因新事实加入而从非空变为空（注意：这里我们用了 §3.2-b 的单调增长假定；若允许事实撤销，此定理不成立——见缺口 B-B1）。

**两条定理合起来给出图像**：

| k 的阶段 | 主导态 | 原因 |
|---------|-------|------|
| **早期**（k 小，F_k 稀） | 多为**发散**或**空（未形成 A_k）** | 事实不足以填充任何槽 |
| **中期**（k 增长，F_k 变密） | 多为**震荡** | 多个候选部分达标，势均不可分 |
| **后期**（k → B） | **震荡 → 收敛** 或 **震荡 → 发散** | 预算强迫归宿；此时**运气与洞察同台** |

这是一个**纺锤形的演化**：发散（前）→ 震荡（中）→ 收敛/发散（后）。而最终落在收敛还是发散，**取决于注入的事实是否恰好补上了某个宏的关键槽**。这解释了为什么同样的认知主体、同样的任务，在不同时刻会有截然不同的表现——**不是状态变了，是注入序列变了**。

### 6.3 两种失败方案的参数敏感性

漂移定理 6.3 有一个重要的**前提**：注入的事实必须与当前题域**相关**。如果注入的事实与题域无关（噪声注入），则不保证。这引出两种典型的失败场景：

**场景 α · 事实注入停止（无知闭合）**。外部事实与内部提取都停了（如：主体拒绝新信息、信息源被切断、注意力锁定）。此时：
- 若当时处于**发散**，则永久停留在发散（半吸收性兑现）；
- 若当时处于**震荡**，则预算耗尽后落到**发散**（强迫归宿）；
- 只有当时已处于**收敛**，才得幸免——但这是**伪收敛的高发场景**（因为没有被足够多的事实检验过就锁定了）。

> **推论 6.4（闭合型认知的失败前期）**。在事实注入停止的条件下，"过早锁定"与"永久发散"是同一枚硬币的两面。这就是所谓的"认死理"与"想不出来"共享的同一个动力学：都是 ΔF = 0。

这个推论有一个相当强的解释力：它解释了为什么"思想保守"与"思维贫乏"常常出现在同一个主体身上——它们不是两个缺陷，是同一个参数（注入率 λ = 0）的两种呈现。

**场景 β · 注入噪声（信息过载的另一面）**。事实持续注入但大部分与题域无关。此时 A_k 会**虚假地膨胀**（噪声触发了槽的虚假匹配），导致：
- **震荡概率异常升高**（大量伪候选并列）；
- 且**自愈无法被指望**——因为新噪声总是比新有效事实来得快。

这两条，加上 §5.4 的伪收敛，构成了本框架对"认知失败"的完整分类：

| 失败模式 | 动力学参数 | 现象 |
|---------|-----------|------|
| **发散**（知识/宏库不足） | λ 低、K 覆盖不足 | 想不出来，无沉淀 |
| **伪收敛**（过早锁定） | 约束过强、λ 低 | 想错了但很确信 |
| **噪声震荡**（信息过载） | λ 高但相关性低 | 越查越乱，无法取舍 |
| **耗散震荡**（能量不足） | B 小、扰动多 | 想累了，在几个答案间跳来跳去然后放弃 |

### 6.4 "走向概率三分"的准确说法

现在我们能给用户提纲中的"走向概率三分"一个精确的表述：

> **描述 N（走向概率三分）**。认知过程在 X-S 二分基础上，由事实公理 F（持续填充）与运算公理 O（有资源地迭代）驱动，反复执行宏加载的三步完成条件（存在 / 充分 / 唯一）。**在任一有限迭代步 k，这三个条件的满足组合只能被概率地刻画**，由此产生收敛、震荡、发散三态的概率分布；**随着 k 增长与 F 的持续填充，该分布发生定向漂移**——震荡份额单调消亡，发散份额非增（相关注入下），收敛份额相应上升；**漂移的终点依赖于注入事实是否恰好补足宏库中某个宏的关键槽**——补足则收敛，不足则在资源耗尽时锁定于发散（或以伪收敛的形式**伪装**为收敛）。

这就是"走向概率三分"的完整语义。注意这里有一点**必须诚实**：

**漂移不保证收敛。** §6.2 的定理只给出**发散非增**，不给出发散→0。在事实注入完全停止、或宏库覆盖不足（输入在 K 的覆盖范围之外）的情形下，**发散份额可以永久保持为正**。这与 v3.0 §3.9 推论 P 的分支 3（"二者皆不可 → 坍塌失败 → 流形断裂 → 系统进入发散或伪收敛"）完全一致——**本节的概率三分是推论 P 在认知层的分布化版本**。这一对齐在 §7.2 详细展开。

### 7.3 与涌现三源 S1/S2/S3 的关系

- **S2（迭代不封闭）**：低阶截断后需引入 ad hoc 重正化。在认知层，这对应**认知结构在迭代中需要被修订**——新宏的加入会改变既有宏的**适用性**。**这也是伪收敛的一个来源：用旧的结构体去加载新输入。**
- **S3（极限奇异）**：Ising 双线性但 N→∞ 出现 Lee–Yang 奇异。在认知层，这对应 **8 月版已经识别的"临界跃迁/强涌现"**——系统各部分的**耦合**抵达临界点，完成结构跃迁。**须注意：本文 §5.1 指出震荡是这类临界跃迁的必要前置，但跃迁本身并不落在三态分类之内**——它是与三态正交的另一个维度：三态回答"这批输入能否压缩为可用的宏"，跃迁回答"这次压缩是否产出了新的结构层次"。这一点必须在 §8 缺口中登记。

**关键对接**：三态分类处理的是"这批输入能否压缩为可用的宏"；涌现三源处理的是"这次压缩产出是否包含新结构"。**两者正交**——一个成功收敛（三态分类的成功）完全可以是低水平的（无涌现）。这正是 8 月版"高频收敛强化的是过早闭合、降低了涌现概率"的动力学。

### 8.3 一处必须正视的内部张力

本文 §6.1 主张"概率是内禀的、不是观察者的无知"。但同时，本文 §6.2 的漂移定理依赖 ΔF_k 的实际取值。这里有一个微妙的循环：

> **若 ΔF_k 在某个更大系统中是确定的（例如物理决定论为真），那么本文的"概率"最终还是观察者的无知。**

本文的回应是分层的、且必须是谨慎的：

1. **在本文的自限辖域内**（不预设物理层决定论），概率是内禀的——因为本文不对 ΔF_k 作任何承诺。
2. **若有一天 ΔF_k 被证明在确定论意义上可预测**，那么本文的"概率三分"退化为"确定三分，但我们当前需要概率描述"。这一退化**不损害** §4（宏加载）与 §5（三态结构）的有效性，只损害 §6 的概率**解释**。
3. 因此本文的**可反证范围是分层独立的**：§4 与 §5 **不依赖** §6 的概率解释成立；§6 反而依赖前两者。**这是一个健康的依赖方向**（符合 U3 依赖追踪）。

登记为 **B-B4**，归类为**开放的哲学立场**，不伪装为已解决。

## §10 结论

本文从用户提纲中的三点出发，完成了一次认知层的重建。核心结果可压缩为三条：

**(1) 认知二分是一个规范性的先行切分，而不是一个经验性列举。** X（象，被操作的那一面）与 S（运算，施加操作的那一面）的区分不在层级之内，而在层级之前——**任何认知活动的最小完整单位都是一个 X-S 配对**（§2）。

**(2) XSM 是被生成的，不是被预设的。** 我们把认知表述为一个基于**事实公理 F**（可能被持续填充）与**运算公理 O**（消耗资源）的演绎系统，其反复作用产生**宏加载**——用事实去填充宏的预条件槽。**加载一旦完成，宏就获得"可被再次调用"的独立地位，X → M → X′ → M′ 的调用经济由此涌现**（§4）。这一步的关键在于：**"加载"这个术语并非本文发明，它继承了 X-S-MERA v1.6.1 工程中 F1–F16/E1–E7/M1–M2 三类公理的既有实践**（§3.1）。

**(3) 三分及其概率性是形式类比剥离的必然结果。** 我们逐条登记了"认知 ≈ 形式系统"这一类比在何处失效，并发现：**三条偏离恰好产出三个归宿**——事实集开放 ⇒ 终局不可确定 ⇒ **概率性**；资源有界 ⇒ 摇摆必须归宿 ⇒ **发散**是强迫归宿；承诺可撤销 ⇒ 收敛非吸收 ⇒ **伪收敛**回边（§3.5、§5.3、§6）。这使本文得出结论：

> **认知过程的准确刻画不是"三态的静态分类"，而是"在事实持续填充与结构迭代的共同作用下，三态概率分布走向定向漂移的吸收过程"。震荡必然消亡（瞬态），发散在相关注入下非增但**不保证归零**（半吸收），收敛在无外部反馈时是吸收的、在有外部反馈时不是（可被推回震荡）。**

最后，本文坚持一条自限原则：以上所有权利要求都建立在"§3.5 的三条偏离是仅有的三条"这一未证实的前提上。**本文明确接受：任何第四条的发现都可直接证否三分本身**（R4）。这是本文最硬的可证伪承诺，也是它区别于"涌现论式宣言"的地方。
