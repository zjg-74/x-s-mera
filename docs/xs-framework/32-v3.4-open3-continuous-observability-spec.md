# OPEN-3 规格：开/闭二分的连续化（s(k) 可观测度）

> 对应 `boundary_map.json` OPEN-3（B1 可辨识边界）："开/闭二分理想化：s(k) 可观测性
> 可能程度化"。本文件把该开放格从"规格未定"推进到**规格已拟、待评审**（纯内部设计，
> 不引入外部数据，不新增 L1 公理）。

## 1. 问题陈述（现状）

B1 维 C 级辨识层依赖 **s(k) 观测**（"s(k) 观测补齐第二可辨识视界缺失自由度"，见
`r041_table` C 行、命题 6.3 / R45 / R33）。当前框架把 s(k) 的可观测性**理想化为二值**：
要么**开**（可观测到 s(k)，可补自由度）、要么**闭**（不可观测，不能补）。这是"开/闭二分理想化"。

**真实现实**：观测协议对 s(k) 的响应通常是**程度化/概率化**的——同一 s(k)，不同观测
工具、不同噪声下，可观测强度介于"完全可读"与"完全读不出"之间。二分理想化把这一
连续谱压成两值，可能造成：① 把"弱可观测"误判为"闭"，丢失本可补的自由度；② 把
"边缘可观测"的稳定判读（噪声方差，OPEN-4 相关）无端纳入二值争议。

## 2. 规格（连续化方案）

### 2.1 可观测度 θ_k

以**可观测度** `θ_k ∈ [0,1]` 替代二值 `b_k ∈ {0,1}`：

- `θ_k` = 观测协议在逻辑时间 k 对 s(k) 的**响应强度 / 置信度**，由观测工具与噪声决定。
- 二值是退化特例：`θ_k ∈ {0,1}`（0=闭，1=开）。
- `θ_k` 的取值依赖**观测工具归属**，属 OPEN-2（约定 A/B：工具算界内/外）的范畴——
  即 θ_k 不是框架裁定的量，而是**实例申报的观测协议参数**（与 z、η、约定 A/B 同类）。

### 2.2 阈值 θ_min（可读判据连续化）

C 级"可读"判据从"∃ 观测到 s(k)（二值开）"**连续化**为：

```
∃ k : Tau, θ_k ≥ θ_min
```

- `θ_min ∈ [0,1]` 是**观测协议声明的阈值**（与 z 的 1.96 同类，约定性输入）。
- 极端情形：`θ_min → 1` 等价于原二值"开"（强可观测才读）；`θ_min → 0` 等价于"闭"
  （只要有一点信号就算可读）；中间取值为程度化判读。
- 同一 s(k)，不同 `θ_min` 声明 → 不同 C 级可读结论。因此 **θ_min 必须随实例申报**
  （与 OPEN-2 约定 A/B、z 同类，进实例申报表的约定声明字段）。

### 2.3 对 D-IDENT 分级的影响（论证）

连续化**不改变 A/B 级分级**：

- A 级（ρ_exp 斜率）与 B 级（峰序/截距符号）的判读规则**不依赖 s(k) 的程度**
  （见 `r041_table`：A/B 行 closed/open 规则均不引用 s(k) 强度）。故连续化后
  A/B 级仍为【定理】级稳定，分级担忧不因程度化复活。
- C 级**辨识层**：可读条件从"二值存在"变为"θ_k ≥ θ_min"。连续化只**加一个约定
  阈值参数 θ_min**，不新增判定逻辑层——与 OPEN-2 自足层"约定 A/B"、z 的"顶点带
  判读禁区"同构。
- C 级**自足层**：仍是约定声明（OPEN-2），连续化不改变其读法结构。

⟹ **OPEN-3 连续化不引入新定理，只把二值理想化参数化为"观测协议阈值声明"**，
与框架的"约定性输入（z/η/OPEN-2）"完全同类。

## 4. 诚实边界（不越界声称）

- 本规格是**设计草案**：把 OPEN-3 从"规格未定"推进到"规格已拟、待评审"。
  **未实现、未测**；连续化后 A/B 级稳定性是【定理】层推论（可论证），但 θ_min
  的实际取值依赖具体观测协议（约定层，框架不裁定）。
- 连续化本身不自动"解决" C 级闭合——它只把二值理想化换成"阈值声明的程度判读"，
  实际可观测度 θ_k 仍需真实观测（B 线外部数据）才能落地。
- 对 X2 / G-26c 等外部项无承诺。

## 6. 评审结论（v1.6.31，纯内部拍板）

对 §5 三个待评审点逐点评审并定稿。评审依据框架既有纪律：约定性输入（z/η/OPEN-2 同类）、
R34 顶点带三值判读先例、B 级判读【定理】级不依赖 s(k) 强度。

### 待评审点 1 —— θ_min 并入实例申报表约定声明字段：**通过**

- 依据：§2.2 已论证"同一 s(k)，不同 θ_min 声明 → 不同 C 级可读结论，故 θ_min 必须随实例
  申报"；§3.3 路线第 3 条已列此步；θ_min 是观测协议参数、非框架裁定量，正是"约定性输入"
  的定义（与 OPEN-2 约定 A/B、z、η 同类）。
- **定稿**：θ_min 作为显式约定声明字段（建议键名 `open3_theta_min`，取值 [0,1]）并入实例
  申报表约定声明字段，与 OPEN-2 A/B、z、η 并列登记。**未声明 θ_min 的实例，C 级辨识层
  可读条件悬置**（同 OPEN-2 纪律：未声明约定则自足层读法悬置）。

### 待评审点 2 —— 弱可观测降级规则：**通过**，采用 C 级三值降级版

- 依据：R34 顶点带三值判读（钻研方向/空洞方向/顶点带）是既有先例，其原则是对"统计/强度
  不确定区显式标注不判"。若不加降级，θ_k 恰在 θ_min 边缘会被强行二值化，重蹈 OPEN-3 想
  消除的"连续谱压成两值"之弊。
- **定稿**：C 级可读性输出三值——
  - `θ_k ≥ θ_min` → **可读**（进 C 级辨识层，可补自由度）；
  - `θ_k ∈ [θ_min − Δ, θ_min)` → **边缘可观测，不判**（登记"待更强观测"状态，不产出 C 级
    闭合结论）；
  - `θ_k < θ_min − Δ` → **闭**。
  - Δ（不确定性带宽度）为实例申报的约定性输入，与 θ_min 同表；**约束 `Δ ∈ [0, θ_min)`**，
    `Δ = 0` 退化回二值。
- **不新增判定逻辑层论证**：仍是"θ_k ≥ 阈值"的单一判定，只把二值的"否"细化为"否（边缘）/
  否（闭）"两种显式输出状态，与 R34 顶点带（把 β̂ 禁区细化为一个显式状态）同构，不是
  多层判定链。
- 诚实边界：Δ 取值为约定输入，框架不裁定；边缘带"不判"不产出任何闭合结论。

### 待评审点 3 —— 程度化范围：**只作用于 C 级辨识层**，不连带作用于 B 级峰序 z 容差带

- 依据：B 级峰序判读（推论 6.4：ρ_res>ρ_exp ⟺ U 峰在前；R27 峰序吻合率 1.000）是【定理】
  级、基于 (E,U) 序列几何，**不引用 s(k) 观测强度**（`r041_table` B 行 closed/open 规则
  均不依赖 s(k)）；B 级 z 容差带（R34，{|β̂| ≤ z·SE(β̂)}）针对 **β̂ 的统计不确定性**，是
  独立统计判读机制，与 s(k) 可观测度无关。
- **定稿**：程度化严格限定 C 级辨识层；B 级 z 容差带保持独立统计判读，不被 θ_k 程度化污染。
  维持 §2.3 已论证的"A/B 级不依赖 s(k) 程度"。
- 注意点（不属 OPEN-3 范畴）：若弱可观测导致 E/U 序列本身噪声增大，属 **OPEN-4 噪声方差线**
  （观测数据质量），通过 z 容差带/噪声方差处理，不并入 θ_k 程度化。

### 总评审裁定

**OPEN-3 连续化规格通过评审**，从"规格已拟、待评审"推进为**"已评审定稿（v1.6.31）"**。
- θ_min、Δ 为约定性输入，进实例申报表约定声明字段（与 OPEN-2 A/B、z、η 并列）。
- 程度化严格限定 C 级辨识层；B 级判读（含 z 容差带）不受影响。
- 实现路线（§3）不变：更新 `boundary_map.json` 状态；把 θ_min/Δ 纳入实例申报表约定声明
  字段模板（A13 对应探索的申报规范）。
