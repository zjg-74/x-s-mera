## §1 什么是"源头修改"：三个判据

不是所有"改定义"都叫源头修改。本文用三条判据筛选，只有全部满足才算：

| 判据 | 内容 |
|---|---|
| **P1 归因可定位** | 能指出工程症状挂在**源头的哪一条定义/参数化**上，而不是笼统说"理论不够" |
| **P2 修改后症状消失而非转移** | 修改源头后，原症状**结构性消失**；若只是把困难挪到别处（例如从"不可标定"挪到"需要新仪器"），不算 |
| **P3 消灭的是冗余不是内容** | 修改**减少**自由参数或**减少**假设条数；若为了修一个洞而新增一条假设，那是新补丁，不是源头修改 |

按此三条，§3 的八个病根中：**S1–S3、S5–S7 通过（6 个真源头修改）**；S4、S8 部分通过。

## §3 八个源头病根

### S1 · A_D 的参数化冗余 —— "投入比 r" 与 "系数 e₊,u₊" 不是两个独立实体 ★★★

**症状**：B-B23（不可标定）、B-B22 的一半。

**病根**：A_D 写 `dE = a·e₊ − b·e₋`。四个量 (a, b, e₊, e₋) 只通过 `a·e₊`、`b·e₋` **两个组合**进入动力学。
补篇九定理 6.12 的 λ-规范自由度，正是这个冗余的显式化。**自由度被数多了。**

**修正（规范固定）**：引入两个新记号

$$s := \frac{r}{\theta_E} = \frac{a\,e_+}{b\,e_-}\quad(\textbf{归一化投入比，无量纲})\qquad\qquad \kappa_E := b\,e_-\quad(\textbf{单一时间尺度})$$

则 A_D 等价于

$$\frac{\mathrm{d}E}{\mathrm{d}t} = \kappa_E\,(s-1),\qquad\qquad \frac{\mathrm{d}U}{\mathrm{d}t} = \kappa_E\,\rho_{exp}\,(s-\rho)$$

（推导：`dE = b(r e₊ − e₋) = b e₋(r e₊/e₋ − 1) = κ_E(s−1)`；
`dU = b u₊(r − θ_U) = b u₊ θ_E (s − θ_U/θ_E) = κ_E ρ_exp (s−ρ)`，用到 `b u₊ θ_E = b e₋·(u₊/e₊) = κ_E ρ_exp`。）

**消去 s** ⟹ 核心恒等式：

$$\boxed{\frac{\mathrm{d}U}{\mathrm{d}t} = \rho_{exp}\frac{\mathrm{d}E}{\mathrm{d}t} + \kappa_E\rho_{exp}(1-\rho)}$$

**内禀自由参数：3 个无量纲数 (s, ρ_exp, ρ) + 1 个时间单位 κ_E。**
`(s, ρ_exp, ρ, κ_E)` 全部 λ-规范不变 ⟹ **规范自由度在定义层被消灭**。

**验证（R30 V1/V2）**：

| 验证 | 结果 |
|---|---|
| V1 恒等式逐样本残差 | 60 组配置（3×θ_E × 5×ρ × 4×调度族），最大 **1.998e-15**，相对量级 **2.26e-16** |
| V2 规范不变性 | λ ∈ [0.25, 4]（16×），θ_E 从 0.25 变到 4.0（16×），而 `max|dE| = max|dU| = max|ds| = ` **0.0e+00**；(ρ_exp, ρ, κ_E) 恒定 |

**P1 ✓ / P2 ✓ / P3 ✓**（自由参数从「6 量」降到「3 无量纲 + 1 单位」）

### S2 · 「共享驱动」是 A_D 的定义成分，却被写成了定理的前提 ★★

**症状**：B-B38（不可区分）、B-B37（41% 判反）。

**病根**：定理 6.10、6.11 都说"在 A_D **∧** 共享 r 下"。但 A_D 原文就是"每一步由两个子过程线性叠加，投入 **a** 与 **b**"——**同一个 a、同一个 b** 同时驱动 dE 与 dU。共享性**已经包含在 A_D 里**，把它再列一遍，就制造出一个"额外假设"，进而制造出"这个额外假设没被检验"（B-B37）和"违反它跟违反 A_D 不可区分"（B-B38）两个洞。

**修正**：在 A_D 定义中显式写入**单一驱动条款**：

> **A_D 附款（single-drive）**：存在唯一过程 `(a_k, b_k)_{k}`；dE 与 dU 由**同一对** (a_k, b_k) 驱动。
> 凡 E 与 U 由不同过程驱动者，不属于本框架所论的"同一认知过程的 E 与 U"。

**后果**：
- 恒等式 `dU = ρ_exp·dE + const` 变成 **A_D 的代数推论**（消去 s），不再需要"共享"作为独立前提
- **B-B38 消失**：非共享驱动 ⟺ 测的不是同一个过程 ⟺ 不是 ¬A_D，而是**测错了对象**
- **B-B37 降级**：从"理论假设未检验"降为"操作上如何确认两条序列来自同一过程"（工程）

**P1 ✓ / P2 ✓ / P3 ✓**（减少假设条数，不新增）

### S3 · 峰距是"调度依赖量"，共线性不是 —— 换可观测量即消除 ★★★

**症状**：B-B34（36.8%–76.5%）、B-B35（归一化不恢复分辨率）、B-B40（探测窗口无解析刻画）。

**病根**：从恒等式可读出的三样东西，**对 κ_E 的依赖不同**：

| 可读量 | 从恒等式的哪一处读 | 需要 κ_E？ | 调度依赖？ |
|---|---|---|---|
| ρ_exp | 斜率 | 否 | **否** |
| 峰序 sign(1−ρ) | 截距**符号** | 否 | **否** |
| \|ln ρ\| 数值 | 截距**绝对值** | **是** | **是** |

**峰距法（推论 6.5）要的是第三行**——它试图读 ρ 的数值，而 ρ 的数值需要 κ_E，κ_E 需要调度族或外部标定。
所以"峰距法在非对数调度下偏 36.8%–76.5%"**不是公式的缺陷，而是它想读一个本就需要额外信息的量**。

**修正**：把标定程序的**首选可观测量**从"峰距"换成"仿射系数"：

- 斜率 ⟹ ρ_exp（**直接标定，调度无关**）
- 截距符号 ⟹ 峰序（**调度无关**）
- 峰距降级为**交叉检验**，仅在调度族已独立辨识时使用

**验证（R30 V3）**：

| 调度族 | 峰距法相对误差（中位） | 共线性法误差（最大） |
|---|---|---|
| log_ramp（推论 6.5 的适用族） | **0.38%** | **0.000e+00** |
| linear | **63.02%** | **0.000e+00** |
| sigmoid | **57.73%** | **0.000e+00** |
| const_blocks | **20.75%** | **0.000e+00** |

共线性法误差**恒为 0**（无噪声下 OLS 精确复原），跨 4 个调度族、15 组 (θ_E, ρ) 无一例外。
**B-B34 / B-B35 / B-B40 一次性消失。**

**P1 ✓ / P2 ✓ / P3 ✓**

### S4 · 框架缺一个内置的尺度（粗粒化）算子 ★★

**症状**：B-B31（高）、B-B27′、B-B28。

**病根**：单峰性路径层 0.000、E 层 1.000——两个都"真"，因为它们是**关于不同尺度的命题**。
但框架里没有"尺度"这个对象，h（显著度）与 w（窗口）是**从外部塞进来的旋钮**，所以无第一原理。

**修正**：补篇二已经有 `Ψ = ψ̄ + ξ`（定向 + 涨落）。**尺度就是这个分解的分离尺度**：

$$\tau^\* := \min\Big\{\tau:\ \frac{\mathrm{Var}(\xi_\tau)}{\bar\psi^{\,2}} < \eta\Big\}$$

其中 `ξ_τ`、`ψ̄` 是在尺度 τ 上的粗粒化量。于是"选 h 和 w"被换成"选 η"——
而 η 有明确含义：**把涨落误读为定向的可接受错误率**。

**为什么这算源头修改**：补篇二 §5 已主张"认知健康 = ψ̄ 落在适当区间 ∧ Var(ξ) 落在适当区间"，
即 **ψ̄ 与 ξ 的分离本来就是框架的核心判据**。把它提升为尺度定义，是把已有装置用起来，不是新增假设。

**残余**：η 的取值原则仍未定（见 §6 缺口 G2）。**P1 ✓ / P2 部分 / P3 ✓**

### S5 · m(k) = \|A_k\| 与 U(k) 的桥没搭 —— 因为 U 是熵、m 是计数 ★★

**症状**：B-B26（高）、B-B28。

**病根**：U := H(M | φ, C_in)（熵，单位 bit）；m := |A_k|（计数，无量纲）。
两者只在"候选均匀分布"时满足 U = log₂ m，一般情形 **U ≤ log₂ m**。这个不等式从未被写成定义，
于是"峰的承载量到底是 m 还是 U"悬空（补篇六 §1.2 标为"候选 ①"，措辞本身就说明未定）。

**修正**：定义**有效候选数**

$$m_{eff}(k) := 2^{\,U(k)}$$

并声明：**「峰」承载在 `m_eff` 上，不是 `m` 上。**

**后果**：
- 桥由**定义**给出，不再是待证命题 ⟹ B-B26 从"未证"降级为"m 与 m_eff 偏离多大"的经验问题
- `m_eff ≤ m`，等号在均匀分布取到 ⟹ 保留原有直觉
- **顺带解决 B-B28**：m_eff 连续，不存在 |A_k| 的整数跳变与"峰后陡度"问题

**P1 ✓ / P2 ✓ / P3 ✓**

### S6 · U ≥ 0 与 A_D 的线性演化冲突 —— 这**要求** A_D 带状态依赖 ★★

**症状**：B-B36（触底未检验）、B-B39 的一半。

**病根**：U := H(M|φ, C_in) ≥ 0 是**定理**（熵非负）。但 A_D 的 `dU = a·u₊ − b·u₋` 会把 U 推向负值，
工程上只能截断。截断是承认**动力学跑出了状态空间**。

**修正（A_D⁺）**：

$$\frac{\mathrm{d}U}{\mathrm{d}t} = a\,u_+ - b\,u_-\cdot g(U),\qquad g(0)=0,\ g\ \text{单调增}$$

物理含义：**无可消解时消解速率归零**。

**后果**：
- **B-B36 消失**：U = 0 不再是"截断点"，而是动力学的**稳定不动点**
- **反转 B-B39 的一半**：工程上把"状态依赖型"当作待扫的**违反族**（B-B39）；
  实际上**物理约束（非负性）本身就要求它** ⟹ 它不是违反，是 A_D 的正确形式

**注意**：这**削弱**了补篇九的某些结论辖域——补篇九的全部实验都在**线性 A_D** 下做。
按 U1 保留，但须标注：A_D⁺ 下共线性只在 U 远离 0 时成立（**B-B43 残余**）。

**P1 ✓ / P2 ✓ / P3 部分**（g 的形式是新增内容）

### S7 · 「三条偏离 → 三个归宿」被写成了 1:1，实际是多对多 ★

**症状**：B-B11（高）。

**病根**：主文 §3.5 小结表把 A→概率性、B→发散、C→伪收敛 写成**一一对应**。
但"资源有界"既可以导致发散（没资源继续摇），也可以导致伪收敛（为不发散而提前锁定）。
补篇二补的那一支（B-B11）不是漏了一个格子，是**映射的元数错了**。

**修正**：改为矩阵，并写明判别条件：

| 偏离 \ 归宿 | 概率性 | 发散 | 伪收敛 |
|---|---|---|---|
| **A** 事实集开放 | ✓（终局不可定） | — | ✓（槽被错误填充） |
| **B** 资源有界 | ✓ | ✓（A_k = ∅） | **✓（A_k ≠ ∅ 时提前锁定）** |
| **C** 承诺可撤销 | ✓ | — | ✓（外部证伪） |

**资源耗尽时的判别**：`A_k ≠ ∅` 且有剩余候选 ⟹ **伪收敛**；`A_k = ∅` ⟹ **发散**。

**P1 ✓ / P2 ✓ / P3 ✓**（不新增假设，只是把已有内容摆对）

### S8 · P 的混合估计偏倚是定义的**推论**，不是待补的程序 ★

**症状**：B-B25。

**病根**：P := H(M | φ, Ω)，Ω = 理解者。跨理解者混合估计给的是 H(M | φ)。而

$$H(\mathcal{M}\mid\varphi) = H(\mathcal{M}\mid\varphi,\Omega) + I(\mathcal{M};\Omega\mid\varphi)$$

⟹ **偏倚恰好等于 I(M; Ω | φ)，这是定义直接给出的，不是未知量。**

**修正**：B-B25 的理论部分**已闭合**；剩余只是"需要 I(M;Ω|φ) 的估计器"（纯工程）。
降级，不再列为理论缺口。

**P1 ✓ / P2 ✓ / P3 ✓**

### 本轮两个新方法学陷阱

- **T17 · 两种"不可辨识"必须分开**

## §6 修正后剩余的真缺口（按价值排序）

### ★ G1 · κ_E 的外部标定 —— B-B23 的真正剩余

规范固定后，所有内禀无量纲参数 (s, ρ_exp, ρ) 都可标定，**唯一剩下的有量纲量是 κ_E = b·e₋**。
它决定了 ρ 的**数值**（不只是符号）。

**已找到的具体闭合路径（新）**：由恒等式，在 U 峰处（s = ρ）有 `Ψ(k\*_U) = κ_E(ρ−1)`，
代入截距得一个**不含 κ_E 的可检验关系**：

$$\beta_0 \;=\; -\,\rho_{exp}\cdot \Psi(k^\*_U)$$

即：**仿射截距 = −ρ_exp × U 峰处的势**。而 Ψ = P − Q 的标定程序**补篇四已经给了**（P 用经验分布熵 + Miller–Madow，Q = I(M; C_in|φ)）。

⟹ **B-B23 从"卡在不可观测的 r 上"（B-B41）改为"卡在可观测但需标定的 Ψ 上"。这是实质推进。**

**R41（新推论，可检验）**：`β₀ = −ρ_exp·Ψ(k*_U)`。任何能同时测 E、U、Ψ 的轨迹都应满足。
**R42（新程序）**：`κ_E = Ψ(k*_U)/(ρ−1)`，给出 κ_E 的第一条标定路径。

### ★ G2 · 分离阈值 η 的取值原则 —— B-B31 的剩余

τ\* 的定义把"选 h 和 w"换成"选 η"，但 η 仍需原则。
候选：η 应等于"回落被误判为定向"的可接受错误率，可由 B-B28 那类误判率反解。**未做。**

### ★ G3 · g(U) 的函数形式 —— A_D⁺ 的边界层

只需 `g(0)=0` + 单调性即可保证 U ≥ 0（结构性，不需数值）。
但**共线性在 A_D⁺ 下只在 U 远离 0 时成立**，触底邻域的偏离量未知 ⟹ 补篇九全部结论的辖域须加此限定。

### ★ G4 · A_D 的经验地位（B-B22 核心）与 B-B19 的解耦

这是**唯一一个源头修改解决不了的**。规范固定让 A_D 更干净、更可检，但**没让它变成定理**。

目前定理 5.2′ 与推论 5.3 全部挂在 A_D 上。值得做的理论工作：
**能否不依赖 A_D 证明定理 5.2′？** 若能，B-B19 与 B-B22 解耦，风险减半。
