## 盲比对象

`docs/experiment_manual.md` §8.7 的 P5–HMM 闭环：
> HMM 可用 ⟺ P5 说"有特征尺度" ⟺ A10 说"M-完备"

本盲比只针对其中**一条可对照预测**：P5 的"无特征尺度"判定（在 τ≈40 步穿越阈值的区间）是否
对应 HMM 的失效区间。

## XS 侧判定事实（已登记，`experiment_manual` §8.3 / §8.6 / §8.7）

- **P5 判据**：残差 a(B) 对块长 B 的双对数斜率 β ≥ −0.15 ⟹ 判"无特征尺度"（collapse）。
- **判别力边界（τ 扫描）**：β 随 τ 连续过渡（−0.52 → −0.07），在 **τ≈40 步穿过阈值**；
  **τ∈[~25,128] 步的有限尺度过程会被误判为坍塌**（P5 触发但实为有限尺度）。
- **P5 的真实身份**：探测器"特征尺度是否落在扫描窗下部"；使用前须把扫描范围对齐到疑似尺度区间。

## 预登记预测（盲比行——在查文献前写定）

> **P1（对应关系）**：当被观测过程具有 **τ≈40 步**（或落在 P5 扫描窗下部、与观测/网格尺度可比）
> 的特征尺度时，P5 判定"无特征尺度/坍塌"（因 β≥−0.15）；盲比预测：**该尺度区间正是
> HMM 失效（或精度显著恶化）的区间**——因为 HMM 的有效性前提是**尺度分离**（特征尺度
> 须与宏观/网格尺度明显分离）；当特征尺度收缩到接近观测尺度时，尺度分离前提被破坏，
> HMM 应失效。
>
> **P2（方向）**：HMM 对"特征尺度过小（接近网格/观测尺度）"的失效，应比"特征尺度过大"更剧烈
> ——即 P5 的 τ≈40 步"误判为坍塌"区间，在 HMM 上对应的是**硬失效**而非优雅降级。
>
> **P3（反方向的判别力）**：当 P5 判"有特征尺度"（β<−0.15，特征尺度充分分离）时，HMM 应可用
> （这正是 HMM 的有效区间）——P5 的"有特征尺度"与 HMM 可用性在同一尺度区间对齐。

## 盲比结果（查文献后，2026-10-24）

### 文献证据（已核验来源）

| # | 来源 | 结论（对盲比相关） |
|---|---|---|
| L1 | Ming & Yue (2006), *J. Comput. Phys.* 214:421–445（LSEC） | "若存在与宏观网格 **H 可比**的中间尺度，MsFEM 即使重叠也提交**有限误差**"；无尺度分离时 HMM 与 MsFEM **可能都不收敛**，但 HMM 质量不差于 MsFEM |
| L2 | E, Engquist, Huang (2003), "Heterogeneous multiscale method: a general methodology"（HMM 原创） | HMM 的效率来自**利用尺度分离**提取缺失宏观数据；无尺度分离或特殊结构时，改用细尺度求解器而非 HMM |
| L3 | E & Engquist (2005), "The heterogeneous multi-scale method for homogenization problems" | **有尺度分离**时 HMM 精度与 MsFEM 相当、成本低得多 |
| L4 | arXiv 2411.00362 (2024) | HMM 可推广到**无尺度分离**的椭圆问题；LOD 是 HMM 特例（指数衰减基），仍可收敛 |
| L5 | arXiv 1803.03551 (2018) | 引入中间尺度 **H** 的方法，数值误差**有下界（≥ 常数·H）**；依赖尺度分离的算法只在尺度分离比 r→∞ 时误差才趋于 0 |

### P1–P3 判定

| 预登记预测 | 盲比判定 | 依据 |
|---|---|---|
| **P1**：特征尺度 τ≈40 步（扫描窗下部、≈观测尺度）时 P5 判"无特征尺度" ↔ **HMM 失效区间** | ✅ **成立** | L1：中间尺度≈H → 有限误差；L5：中间尺度 H 误差有下界；L2：无尺度分离 → 不适用/需细求解器。P5 判"无特征尺度"的区间正是 HMM 尺度分离前提被破坏的区间 |
| **P2**：该区间对应 HMM **硬失效** | ⚠️ **部分证伪，须修正** | 文献更倾向"**精度受限/需替代方法**"而非必然硬失效：L1 无尺度分离时 HMM 仍不差于 MsFEM；L4 有 LOD 等无尺度分离方法可恢复精度；L5 误差有界但非发散 |
| **P3**：P5 判"有特征尺度" ↔ HMM 可用 | ✅ **成立** | L3：尺度分离时 HMM 精度高成本低；L2 是 HMM 的设计前提 |

### 结论（诚实登记）

1. **P5 作为尺度分离探测器有效**：P5 判"无特征尺度"的区间（τ≈40 步）确实对应 HMM 尺度分离
   前提被破坏的区间（P1、P3 获文献支持）。这支持 §8.7 的闭环"HMM 可用 ⟺ P5 说'有特征尺度'"。
2. **"无特征尺度/坍塌"的后果措辞须限定**：预登记 P2 的"硬失效"过强。文献显示后果是
   **精度受限 / 需专门方法（LOD、oversampling、自相似 HMM、或细尺度求解器）**，而非必然发散。
   ⟹ P5 判"无特征尺度"应读作"**HMM 类方法的前提不满足，需降级或换方法**"，与 F2 段的
   优雅降级同型（也呼应 `26` §3.1 的"以上皆非"程序）。
3. **盲比强度分级**（承 `26` §3.1 的 M7 程序教训）：P1、P3 是**结构性对应**（尺度分离前提 ↔
   P5 特征尺度），判别力中等偏上；P2 的修正本身是一次**负面结果**（预登记过强被文献证伪），
   这恰恰是盲比的价值——它防住了"把 P5 坍塌等同于 HMM 必然失效"的过度解读。

### "以上皆非"出口的触发情况

- (E1) 未触发——文献未显示 HMM 在 τ≈40 步尺度下仍无条件有效。
- (E2) **部分触发**——HMM 的失效并非单纯由特征尺度主导（L4 显示 LOD 型可在无尺度分离时收敛），
  故 P2 的"硬失效"须修正；P1 的核心对应（中间尺度≈观测尺度 → 前提破坏）仍成立。
- (E3) 未触发——文献信息足以判定方向。
