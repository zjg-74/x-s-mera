## §1 第一个观察：两个约束分属两个范畴

先把用户的话按 XS 的范畴切开：

| 约束 | 内容 | 约束施加于 |
|---|---|---|
| **约束一**（物理约束） | 这句话本身的物理形态：它是这个字符序列而不是别的；它有限长、有噪声、是线性的 | **X**（象，被操作的那一面） |
| **约束二**（理解约束） | 你**必须理解**它，而不是改写它、续写它、评价它、附和它、忽略它 | **S**（运算，对 X 施行的那一面） |

> **推论 1.1（"双"的结构性论证）**。
> **双约束不是外加的两个经验条件，而是认知二分 X/S 在约束侧的投影。**
> 二分恰好有两个面，每一面各自承受一个约束，所以约束恰好是**双**——不是三个，也不是一个。

这一条的意义在于把"为什么是双约束"从**经验列举**变成**可推导的结论**。此前（8 月稿 [86]、补篇二 §1.1）双约束是作为**既定本体**被接受的——四大核心本体之一，无人追问其来源。现在它有了一个来源。

> **这也给主文 §2 推论 2.1（"二分优先于具体清单"）补上了第一个可推导的下游产物**：二分不只是在先的划分，它还**决定了约束的个数与归属**。此前推论 2.1 只断言了优先性，没有产生任何可单独检验的下游结论；推论 1.1 是它的第一个。

## §2 第二个观察：两个约束的**逻辑类型不同**（本补篇最关键的不对称）

这是把用户的话形式化之后**立刻暴露**出来的一点，也是我认为本轮最重要的一点：

| | 约束一（物理约束） | 约束二（理解约束） |
|---|---|---|
| 约束对象 | **X** | **S** |
| 逻辑类型 | **构成性**（constitutive） | **规范性**（normative） |
| 能否被违反 | **不能**——这句话的物理形态是既定的，你无法选择"不接受它" | **能**——你完全可以去续写、改写、批评、附和、忽略 |
| "违反"的真实含义 | 你加工的**已经不是这句话**了 → **对象被替换** | 你做的**已经不是理解**了 → **任务被替换** |

两者都是"替换"，一个换 X，一个换 S——**对称，但后果完全不同**：

> **推论 2.1（两类失效的分工）**。
> - **外约束失效 = 对象被替换** → 系统加载了**并非来自这句话**的内容 → 认知形态：**幻觉 / 误读**；工程形态：**F2 / ghost 伪力**（加载成功但事后验证为错）。
> - **内约束失效 = 任务被替换** → 系统没有执行收敛操作 → 认知形态：**不收敛**（震荡延长 / 发散）；工程形态：**F1**。

> **推论 2.2（给补篇一的 R2 补上机制）**。
> 补篇一登记了 **F1 ↔ 发散、F2 ↔ 伪收敛**，但那只是一张**对应表**。推论 2.1 给出的是**机制**：
> **F1 ↔ 内约束失效（没做该做的运算）；F2 ↔ 外约束失效（加载了不该加载的对象）。**
> 于是补篇一的 R2 从"两个标签对得上"升级为"两条失效路径在双约束上可分离"。

**一个直接后果——本框架第一次出现规范性内核**：

> **推论 2.3（认知的规范性维度）**。
> 正因为内约束**可违反**，"你理解了没有"才是一个**可以被追问的问题**，而不只是一个因果结果。
> 若认知是纯因果过程，则"失败"只能指"没发生"；但有了内约束，"失败"还可以指**"发生了，但做的是别的事"**。
> → **XS 因此不是纯描述性理论：它包含一个规范性内核，其来源是内约束。**（作为辖域性质登记，见 §7）

**推论 2.3 与推论 1.1 的分工**：推论 1.1 说约束的**个数与归属**由二分决定；推论 2.3 说约束的**可违反性**来自二分的 S 侧。二者独立成立——即便猜想 5.1 最终被证否，推论 2.3 仍然成立，因为它只依赖"约束二是对一个运算的要求"这一点。

## §3 P 与 Q 的构造（B-B10 的主闭合部分）

### 3.1 P 来自外约束：物理形态的**欠定性**

这句话的物理形态对意义的约束是**部分的**——它既排除了大量候选，又没有唯一确定某一个。理解的全部工作量，就落在这段"被排除之后仍剩下的不确定性"上。

**定义 3.1（熵增力 P）**。

$$P \;:=\; H(\mathcal{M} \mid \varphi)$$

其中 **φ** = 这句话的物理形态（字符 / 音素 / 像素序列及其噪声），**M** = 待求解的意义（解释变量）。
**P 是"给定物理形态之后，意义的条件熵"**，单位：**比特**。

**P 的四个可列举来源**（物理约束如何具体地产生欠定）：

| 来源 | 说明 |
|---|---|
| **歧义** | 一词多义、结构多解（如"看见了拿望远镜的男人"） |
| **省略** | 句子**有限长**，不可能把一切写明——省略是物理长度的必然后果 |
| **噪声** | 载体失真（笔迹、口音、截断、丢字） |
| **线性化** | 语言是**线性序列**，意义不是——结构信息在序列化中损失，理解必须**恢复结构** |

> **推论 3.1（认知存在的条件 · 关于 P）**。
> 两端的极限都不是认知：
> - 若物理形态**唯一决定**意义（P = 0）→ 理解退化为**解码**，没有认知发生；
> - 若物理形态**完全不约束**意义（外约束消失）→ 理解退化为**生成**，也没有认知发生——系统滑向**幻觉**（推论 2.1）。
>
> **认知存在于两者之间：$0 < H(\mathcal{M} \mid \varphi) < \infty$。**
> 外约束的全部分量，就是它**既约束（排除候选）又欠定（不唯一确定）**这两个条件同时成立。缺任何一个，认知都不存在。

### 3.2 Q 来自内约束：操作空间的剪枝

约束二做两件事：**① 指定目标（理解）；② 排除其他操作**。其中 ② 才是收敛力的来源——它把允许的操作集剪小。

**定义 3.2（收敛力 Q）**。〔**已由补篇四定义 3.2′ 取代**：本定义与 P 不可通约（两个不同随机变量的熵不能相减），Q 应改为 $I(\mathcal{M}; C_{	ext{in}}\midarphi)$；本定义降级为 Q 的**机制**。见补篇四 §2.2〕

$$Q \;:=\; \log_2 \frac{|\mathcal{O}_{\text{all}}|}{|\mathcal{O}_{\text{adm}}|}$$

其中 **O_all** = 对该输入物理上可执行的全部操作，**O_adm** = 在内约束下**被准许**的操作。
**Q 是操作空间被剪掉的信息量**，单位同样是**比特**。

两个端点：
- "对这句话做任何事" → O_adm = O_all → **Q = 0** → 无收敛力 → 只有震荡 / 发散；
- "只许理解，不许改写 / 续写 / 评价 / 忽略" → 剪枝量大 → **Q 大** → 强烈回落压力。

### 3.3 量纲一致，Ψ 第一次有了单位

$$P\;[\text{bit}], \qquad Q\;[\text{bit}], \qquad \Psi = P - Q\;[\text{bit}]$$

> **Ψ 的物理意义由此确定：它是"净未决信息量"**——外约束留下的欠定性，减去内约束已经吸收掉的那部分。
> 这是 Ψ 自补篇二提出以来第一次获得**量纲**，也是 B-B10 闭合的实质内容。

## §4 三条定量推论

### 4.1 收敛时间

设注入事实 f 在既有事实 F_k 之下关于意义 M 的**条件互信息**为

$$I_{\text{eff}}(f) \;=\; I(\mathcal{M};\, f \mid F_k)$$

——即这条事实**真正消掉多少歧义**（注意：不是这条事实本身有多长、与话题有多相关）。

> **定理 4.1（收敛时间）**。
> $$T_{\text{conv}} \;\approx\; \frac{\max(0,\ \Psi)}{I_{\text{eff}}}$$
> 即：**收敛所需步数 ≈ 净未决比特数 ÷ 每步有效消歧比特数。**

**推论 4.2（双约束如何分别影响理解速度）**：
- **P 大**（歧义重、省略多、噪声大、结构复杂）→ 未决量高 → **理解更慢**；
- **Q 大**（任务指定明确、排除彻底）→ 未决量被预先吸收 → **理解更快**。

### 4.2 资源有界与分叉（把补篇二推论 3.1 定量化）

B 步预算可注入的消歧信息总量 ≈ **B · I_eff**。

- 若 **B · I_eff ≥ Ψ** → 未决量可被消完 → **真收敛**；
- 若 **B · I_eff < Ψ** → 资源耗尽时仍有未决量，同时 Q 因资源压力剧增 → Ψ 转负 → 依 **A_k** 分叉（补篇二推论 3.1）：
  - A_k ≠ ∅ → **伪收敛**（在不充分证据上强制落定）
  - A_k = ∅ → **发散**（有回落方向却无处可落）

> **发散的定量条件：$B \cdot I_{\text{eff}} < \Psi \ \wedge\ A_k = \varnothing$。** 这把补篇二 §3 的分叉从定性变成了可核算。

### 4.3 相关性 ≠ 消歧力（本补篇最硬的新结果）

定理 4.1 的分母是 **I_eff = I(M; f | F_k)**，不是"f 与话题的相关度"。二者可以完全脱钩：

> **一条事实可以与话题高度相关，却对区分候选毫无贡献**——因为它的内容已经被既有候选所蕴含（条件互信息 ≈ 0）。

这给出补篇一极性定理的一个**更精确的机制版本**。补篇一说"确认偏误（只用肯定事实填充）→ 更久想不清楚"，机制被表述为"A_k 不减"；本补篇的机制更准：

> **推论 4.3（确认偏误的信息论机制）**。
> 确认偏误所选择的是**支持既有候选**的事实。这类事实与既有候选高度**冗余** → $I(\mathcal{M}; f \mid F_k) \approx 0$ → **I_eff ≈ 0** → 由定理 4.1，$T_{\text{conv}} \to \infty$。
> **"更久想不清楚"的原因不是注入得慢，而是注入的东西不消歧。**

> **推论 4.4（最优注入策略）**。〔**已由补篇四推论 4.4′ 修正**：据 R18 实测，主要收益是**降低伪收敛率**，收敛速度上的收益以资源紧张为条件。见补篇四 §5〕
> 由定理 4.1，缩短收敛时间的唯一途径是**最大化每步的条件互信息**：
> $$f^{\ast} \;=\; \arg\max_{f}\ I(\mathcal{M};\, f \mid F_k)$$
> 即：**每一条新事实都应当选"最能区分当前候选"的那一条**，而不是"最支持我最看好的那个候选"的那一条。

> **第 10 次"重复发明"登记（U2 诚实性要求）**。
> 推论 4.4 不是新东西：它是 **Lindley (1956) 贝叶斯最优实验设计**、**MacKay (1992) 信息增益准则**、**主动学习的不确定性采样**、以及**二十问游戏的最优提问策略**在 XS 词汇中的重述。
> 本补篇的贡献**仅在于**：把它接在 P / Q / Ψ 上，使"确认偏误为什么拖慢理解"获得一个**可计算的**解释，并与双约束挂上钩。**这是旧定理的接口，不是新定理。**

## §5 一个待证的收敛：三种二分是否是同一个切分

XS 现在有三组二分：

| 层 | 二分 | X 侧 | S 侧 |
|---|---|---|---|
| §2 认知二分 | **X / S** | 象（被操作的对象） | 运算（对 X 的操作） |
| §3 公理二分 | **F / O** | 事实公理（关于对象的既定断言） | 运算公理（规定运算如何执行） |
| 双约束 | **外约束 / 内约束** | 对 X 的约束（物理形态） | 对 S 的约束（必须理解） |

> **猜想 5.1（已裁定，见补篇四 §1）**。按用户指示"过强的描述往往需要过严的定义结构"，**本猜想只按弱形式保留**（双约束的个数与归属由二分决定），**不主张三组二分严格同构**。
>
> ~~**猜想 5.1（待证，勿当作结论）**~~。这三组二分**可能**是同一个切分在三个层上的投影。

**但我必须同时给出它的证否条件**，否则这就是模式匹配：

- **证否条件**：若能在**完全不引用 X/S** 的情况下独立定义 F/O 与外/内约束，而三组切分**不一致**（例如某条运算公理同时约束了对象，或某条事实公理规定了运算），则猜想 5.1 被证否。
- **当前最可疑的一点**：内约束的表述"**理解这句话**"中，"这句话"是 X——即内约束的定义**引用了** X。这说明内约束并非纯粹位于 S 侧，它是一条**关于 S 与 X 之间关系**的约束（"对 *这个* X 施行 *理解* 这种 S"）。
  因此猜想 5.1 很可能**只在弱化形式下成立**：外/内约束是 **X/S 二分的二元关系侧投影**，而非各自独立的单侧投影。

登记为 **B-B14（中）**。在它被裁定之前，§1 的推论 1.1 只按**弱形式**使用（双约束的个数与归属由二分决定），**不主张三组二分严格同构**。

## §7 辖域声明更新（在补篇二 §8 之上再加一层）

补篇二给出的是**三分的成立条件**；本补篇给出的是**认知本身的存在条件**——两者不在同一层，**不要混**：

> **认知存在的条件（双约束条件，本补篇新增）**：
> **(i) 外约束既约束又欠定：$0 < H(\mathcal{M} \mid \varphi) < \infty$；**
> **(ii) 内约束存在：$Q > 0$（至少排除了一个操作）。**
>
> 缺 (i) → 要么是解码、要么是生成，**都无认知**；缺 (ii) → 只有加工，**无理解**。

> **三分的成立条件（补篇二 §8，不变）**：资源有界（B < ∞） ∧ 统计定向（ψ̄ ≠ 0）。

**新增的辖域性质**：XS 含**规范性内核**（推论 2.3），来源为内约束的可违反性。这不是装饰——若去掉内约束，则"理解失败"不可定义，主文 §5 的三态分类将退化为对**任意加工过程**的分类，从而丧失认知特异性。
