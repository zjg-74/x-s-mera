## 摘要

跨学科研究中常出现两个学科各从一个被广泛接受的投影出发，对同一对象得出截然不同的命题，而每个学科的内部都可完全自洽的现象。本文提出并系统化 **XS 框架**（eXtension-Shrinkage Framework），分析此类跨投影理论冲突的根源、判定层级相容性、为冲突的可解决性给出可计算判据。

本文是 XS 框架的**统一重构版**，整合三版资产。**方法论层**（§2）建立基底-完备七条、三失效类型、知识注入测试、涌现三源、公共细化三粒度约束、共振三判据、双向张力与《XS 分析程序 P0–P8》，把可复现的分析能力与可证伪的预测能力作为论文本体的承诺。**理论层**（§3）以 X_obj（认知对象）、S_op（对 X 的运算）、M_all（稳定压缩单元）为术语账本核心，给出双公理、尺度向量四分量、截断算子 T、XSM 架构、层次外显关系，并以推论 P 的三分支版统一"何时可无损、不能无损时发生什么、连坍塌都做不成时发生什么"。**应用层**（§4–§6）展示三个不同成熟度的应用：量子-经典公共细化的显式 Wigner 函数 + IC-POVM 构造（验证无损路径可构造）、MMS 作为辅助实证（同域准实证验证机制普遍性）、对一组真实非专业观察者言论的诊断（验证"类比冒充同构"判据可承受命名压力）。**工程反哺层**（§7）把 X-S-MERA v1.6.1 的 d/D 边界测度、C1/C2 双条件、F1/F2 失效模式、A11-R 势-流分离上升到 XS 的可计算实现，由 134 项测试与 Lean4 机检背书。最后（§8）讨论从 8 月继承的三案例（GPT-2 微调、语言、教学）的回填程序，（§9）登记《XS 更新纪律》U1–U4 与 Lakatos 进步判据。

## §1 引言

### 1.1 问题的提出

当代科学方法论中两个难题同时存在。第一个：**跨学科冲突常常是结构性的**——两个学科各从一个被广泛接受的投影出发，对同一对象得出截然不同的命题，而每个学科的内部都可完全自洽。这不是任一学科的内部错误。冲突发生在**交集论域**——两投影系统的共同陈述范围。第二个难题是**解决方案的隐性替换**——当一个被广泛接受的骨架理论（如连续介质力学）遇到边界问题时，实践者几乎总是默认通过**添加补丁**（如滑移修正、外推插值）而不是**重新审视问题的投影结构**来消除冲突。但补丁本身从不能根除冲突——它只能转移冲突的可观测位置，冲突的边界始终由**被遮蔽的结构性参数**划定。

本文提出的 XS 框架（eXtension-Shrinkage Framework）以"**跨投影理论冲突的根源是投影系统的尺度向量错位**"为核心命题，把上述两个难题合并为一个能被分析与处理的对象。尺度向量错位是**关系性的**——它需要两投影系统在交集论域相遇才能被观察到，且它的消除方式是**尺度相容**（交集论域可达、可导航）而不是**补丁凑合**。

本文是 XS 框架三版历程的**统一重构**。三版的关系不是竞争、不是取代、不是应用，而是**同一机制在不同约束下的三个面**。

## §2 方法论层

方法论层是本论文的**中心装置**。此前多轮 XS 稿件在不显式书写方法论装置的情况下反复报出"三类错位""两投影冲突""跨学科案例"等核心术语，但始终没回答一个最根本的问题：**这些术语是怎样被使用的？**。本节集中交付这一问题的答案。

### 2.1 基底-完备七条

给定现实系统 Ω 与 Ω-完备公理集 A_Ω、子系统 S（论域 D_S）、目标定理集 T_S ⊆ L(D_S)。一个公理集 B 是 S 的**基底**（base），当且仅当下列七条成立：

| 编号 | 名称 | 要求 | 失守后果 |
|------|------|------|---------|
| ① | 表达充分 | T_S 每条命题在 L(B) 中可陈述；S 需要区分的状态对可分 | 系统化从第一步没开始 |
| ② | 下沉显式 | 限制映射 ρ: A_Ω → L(B) 显式给出，保真可证或失败条件明确 | 默认继承 = 隐性外借 |
| ③ | 论域闭合 | 证明链全程留在 D_S，不外借 Ω 层公理 | S 不是自持子系统 |
| ④ | 无环 | T_S 依赖图无循环、互举 | 表面闭合、实则环 |
| ⑤ | 可检验 | T_S 每条可证伪，不是现象学重述 | 不可验收 |
| ⑥ | 鲁棒 | 边界小扰动下结论结构稳定，失效边界可定位到具体参数 | 纯靠参数窗稊宝 |
| ⑦ | 极小可审计 | ∀b∈B，∃t∈T_S 使 B\{b} ⊬ t | 冗余掩盖缺口 |

七条按顺序检查，**前一条失守则后一条无意义**。这是"基底-完备"区别于 Ω-完备的关键：**完备性是 (语言, 论域, 目标命题集) 的三元关系**——从 A_Ω 限制到 B 时，三个轴同时收缩且不同步，故 Ω-完备既不蕴含也不排斥基底-完备。

### 2.2 三失效类型

当一个基底未能达成"系统化"时，故障落在三类之一，且需不同的修复动作：

- **类型 A · 可修补**：①②③⑦ 失守。补桥接公理、扩张语言、删冗余、把缺口登记进 GAPS。
- **类型 B · 目标设定错误**：基底没问题，是 T_S 定得太大。T_S 里混进了本质上量化 D_Ω\D_S 的命题——这类命题不该指望 S 自己推出。**缩小目标，而不是换基底**。
- **类型 C · 结构性失效**：把 B 一路扩张到 A_Ω，第③条闭合性**仍然**不成立。S 不是可分离的自主子系统——它是 Ω 的**投影 / 视角**。正确动作不是找更好的基底，而是**给出投影映射 π: Ω → S，刻画保留了什么、丢失了什么、在什么尺度上丢失**。

底层原理：**基底只能传递可继承的东西**。在投影、粗粒化、尺度坍塌中**生成**的规律——涌现、层次外显——不由基底给出，也无法通过修补基底得到。这就是 XS 里"层次外显关系"的要害。

### 2.3 知识注入测试

XS 诊断可主区分两类**冲突**：

- **知识缺失型冲突**：某方不知某事，被告知即撤回 → 操作错位 → 不是 XS 的研究对象。
- **投影结构缺失型冲突**：有知识者也会犯的错误 → 把关系当性质、把存在当唯一 → 才是 XS 的研究对象。

不分开则诊断力被污染——任何失败都能任意归因。

**测试步骤**：

1. 记录冲突命题（C, P, R, E）（冲突、投影、原因、环境）。
2. 对 P₁ 的某声称者调出缺失事实 f，重新推导该声称。
3. 判定：消解 → 操作错位（不是 XS 对象）；转移到另一个位置 → 理论错位（XS 对象）；反复注入后冲突不消解且不转移 → 语义错位（XS 对象，且语义错位是高阶错位）。

测试不是终点主义。

### 2.4 涌现三源 S1/S2/S3

涌现不是单一机制。本文归纳出三个**可区分、可证伪、挑出第四类即否证**的涌现来源：

- **S1 · 算子非线性**。截断算子 T 不保叠加：T(αa + βb) ≠ αT(a) + βT(b)。在该处宏观与微观不可线性连接。
- **S2 · 迭代不封闭**。RG 流在低阶项目下被截断、理论递推需要在某阶被引入 ad hoc 重正化。
- **S3 · 极限奇异**。Ising 哈密顿量是双线性的（微观点是 S1 = 0）；Lee–Yang (1952) 证明非解析性只在 N→∞ 的热力学极限出现。**线性基底 + 奇异极限 = 涌现**——这是 XS 与 Anderson (1972)、Batterman (2002) 共享的结论。

三源不是并列。实际上它们是 **必要不充分** 的：任一涌现必占其一，但占其一不一定涌现。**这是 XS 与认识论区别于"涌现论"式-宣言的关键**。

### 2.5 公共细化三粒度约束

公共细化是 XS 处理跨投影冲突的核心运算。三条粒度约束是细化可构造的必要条件（不充分）：

1. **必须可分离**：细化的粒度能分离需要分离的状态对。
2. **必须包含**：细化使二投影系统的都能被表达。
3. **必须可选出**：细化为三层结构（宏观层 + 中间细化层 + 微观层）。

三条约束中任一失守即不可构造，不可构造的细化会退到 §3.9 推论 P 的分支 2 或分支 3。

### 2.6 共振三判据

判定二投影系统"是否同一对象的不同视角"需通过三条共振判据：
- **投影可重复性**：从 P₁ 出发的运算能被 P₂ 表出可重复表述（表面可重复）。
- **系统生成性**：两者能生成共同的、可重复出现的结果（动态能生成）。
- **对应性**：两者能构造出公共细化（三粒度约束都满足）。

三条同时满足为强共振。仅①②成立为弱共振（仅表面重复，不生成）。仅③成立为静态共振（构造存在但生成不产生）。

### 2.7 双向张力

从直觉来看，"层层推高"似乎是一个**单调进程**——从线性逐步过渡到非线性。本文从构造层面否定这一单调性：

- **推向线性**的机制：n_freedom↑（广延可加性 + 热力学极限）；n_resolution 进临界窗之外的「快变」限制 + Kubo 线性响应（弱扰动）；n_context↑（反身性）。
- **推向非线性**的机制：n_resolution 进临界窗（标度律 / 重整化群流）；奇异极限（S3）；反身性（与上同轴）。
- **净结果** = 各分量贡献之和，可正可负可为零。

## §3 XS 体系

### 3.1 术语账本（X_obj / S_op / M_all）

本文首次给出三版统一的术语账本：

| 字母 | 范畴标签 | 出现于哪个版本 | 含义 |
|------|---------|---------------|------|
| **X** | **X_obj**（默认；8 月认知版 + 10 月哲学版） | 8 月 + 10 月 | **象（像）= 认知的对象**（认知节点、宏、向量场等具体实体） |
| X | **X_sys** | X-S-MERA 工程版 | 含 state + D 样本的投影子系统（X_obj 的工程化扩展） |
| **S** | **S_op**（默认；8 月认知版 + 10 月哲学版） | 8 月 + 10 月 | **对 X 的运算**（截断算子 T 上的操作） |
| S | **S_iface** | X-S-MERA 工程版 | 接口算子（S_op 在接口算子层的特化） |
| **M** | **M_all**（三版统一） | 三版通用 | **稳定压缩单元**（宏、演绎节点产物、边界宏） |

**默认范畴**：论文写作中 X 默认 X_obj、S 默认 S_op；工程版 X_sys / S_iface 单独标注以提示语体边界。**命名守则**：

- **规则 R-X**：出现 X 时默认 X_obj（与 8/10 月一致）；内容确属工程版范畴时显式标注为 X_sys。
- **规则 R-S**：出现 S 时默认 S_op（与 8/10 月一致）；工程版 S_iface 是 S_op 在接口算子层的特化，单独标注以提示其代数结构维度。
- **规则 R-M**：M 不分记，全文统一指"稳定压缩单元"。

### 3.2 双公理

**公理一（闭合性）**：二投影系统在同一交集论域的坍塌产出，能在该交集论域上以公共细化构造一个共同子结构。
**公理二（操作语义保持）**：跨投影的运算（截断算子 T 作用）在不同投影系统下保持语义不变——若 T 是物理量，则 T 在投影间的转化映射是同伦等价的。

公理一是公理二的前提。公理二是公理一能否成立的判据。**两者是架构性要件**：一个仅表达公理一则收敛失败为"在多投影间不可联合"；一个仅表达公理二则坍塌失败为"同一论域在不同投影下产生不同结论"。

### 3.3 尺度向量四分量

跨投影系统的差异可用尺度向量（n_freedom, n_resolution, n_temporal, n_context）四维刻画：

- **n_freedom**：保留的自由度数目（连续 vs 离散、宏观 vs 微观）。
- **n_resolution**：可区分的分辨率等级（粒子 vs 场、原子 vs 分子）。
- **n_temporal**：动力学时间尺度（演化时间尺度、因果响应时长）。
- **n_context**：所处的环境上下文数（独立变量数目、边界条件数目）。

四分量**互不冗余**：任何两个跨学科冲突都可归类为四个分量中一个或多个的错位。**这不是 XS 的发明**——这是从 MMS 实践（Knudsen 数 = 平均自由程/系统尺度）与 RG 实践（relevant/irrelevant 分类）抽取的**统一描述**。

### 3.4 截断算子 T

**截断算子 T** 是从 X 到 M 的坍塌运算。T 的关键性质：

- **不可逆**：T 不保留所有信息。它按三个粒度约束（§2.3）选取需保留的、可丢弃的。
- **依赖上下文**：T 的截断位置由 n_freedom、n_resolution、n_temporal、n_context 共同决定。
- **坍塌产出**：T 的产出是 M_all（稳定压缩单元），坍塌成功能生成可调用的宏，坍塌失败则在原系统上产生伪收敛或系统震荡。

### 3.5 XSM 架构

**XSM**（X-S-M）是 XS 框架的核心架构：

- **X**（对象）：认知对象 / 投影对象 / 坍塌输出对象
- **S**（运算）：对 X 的操作 / 截断算子 T 上的运算 / 接口算子
- **M**（宏）：稳定压缩单元 / 演绎节点产物 / 边界宏

XSM 架构的运作机制：X 在 S 的作用下坍塌成 M，M 在另一个 S' 的作用下可被调用为另一个 X'。这形成了 **X → M → X' → M' → …** 的坍塌调用链。

### 3.6 层次外显关系

**层次外显关系**是尺度坍塌与多投影统一的核心机制。它说的是**同一对象的两个不同尺度下能呈现完全不同质的关系**，例如微观的概率性与宏观的方向性：

- 微观：单个分子运动随机。
- 宏观：总体运动方向确定。
- 二者不是简单的"加和"或"平均"——它们是**同一物理系统的不同尺度的呈现**。

层次外显关系的机制是：

1. **微观尺度**的随机性在尺度增加时由 CLT（中心极限定理）收敛为确定性。
2. **奇异极限**在临界点突破统计收敛，产生跃迁（如相变）。
3. **层次外显**与涌现三源 S1/S2/S3（§2.4）同源。

**关键判断**：层次外显关系**不由任一层级的公理推出**——它是在坍塌算子 T 作用时**生成**的。向基底（公理集）索要层次外显是服从类型 C 结构性失效（§2.2）。

### 3.7 双向张力（连接 §2.7）

§2.7 给出推动线性与推动非线性的双向张力。XS 体系在**梯度阶段**上解释了为什么两者不互斥：

- **n_freedom↑ + CLT/广延可加** → 推向线性。
- **n_resolution 进临界窗 + 奇异极限** → 推向非线性。
- **n_context↑ → 反身性**（可能推向非线性）。

### 3.8 流形（结构层）

**流形**（manifold）是 XS 体系**结构层**的核心概念：

- **定义**：由宏（M）之间的可达关系构成的结构对象。其几何性质刻画**路径的可导航性与规律性**，不刻画路径的**连续性或平滑性**。
- **不是**：不是任何低维投影的外显（投影是几何操作，流形是结构对象）。**也不是**感知层体验（"想通了""流畅感"），后者在本框架中由「流畅感」与「叙事路径」承载（§9 元规则章）。
- **与「可导航」与「连续」的区分**：一条可导航的路径完全可以是断层跃进的。拉马努金从 1729 直接抵达数论结构——这条路径在流形上可导航，但在结构上并不连续。

**这一定义是三版一致的**。8 月版此前将"流形"同时用于结构层（三个层级清单）、感知层（"思维流畅性的几何描述"）与跨层等同（"收敛＝流形形成"），三处归属违反 8 月第八节自身规定的"跨层对应须显式声明为映射/类比"原则。本次按 10 月版"认知流形＝结构、非数学意义"统一归属结构层（见 §9 元规则章）。

### 3.9 推论 P（含 P2 合并）

两投影系统在交集论域的冲突，其解决路径按以下顺序尝试：

1. **公共细化可构造**（无损）：取二者，构造共同子结构 → 冲突消除。
2. **公共细化不可构造，但有宏可稳定**（有损取舍）：沿其中一投影坍塌到某一宏 → 必然伴随伪收敛风险，事后须复查。
3. **二者皆不可**（坍塌失败）：输入落在宏库覆盖范围外 → 流形断裂，能量流动截断，系统进入发散或伪收敛。

这是 §4 量子-经典公共细化的**补集**：§4 论证"何时可无损"（分支 1），P 论证"不能无损时的代价"（分支 2 与 3）。

**历史代码（解决文献识别）**：8 月版以"取舍式收敛"处理公共细化不可构造的情形，10 月版以"公共细化构造"处理可构造的情形。两者不是竞争或取代关系，而是同一机制的两条互斥路径。本节统一了"在两路径任一上会发生什么"。

**工程映射**（§7 详述）：

- 分支 2 判定 = F2 检查（C1 ∧ ¬C2）
- 分支 3 判定 = F1 检查（¬C1）

### 3.10 流形断裂

在推论 P 的分支 3 中，当**输入落在宏库覆盖范围外**时，发生的不是成功的坍塌（无论公共细化式还是取舍式），而是**流形断裂**：

- **可达关系不连通**：宏库中某个宏不能从输入经由应被调用的操作到达。
- **能量流动截断**：输入的"操作意图"不能转化为宏调用。
- **系统进入发散或伪收敛**：系统未坍塌但呈现稳定（伪收敛），或进入持续震荡（发散）。

**检测判据**：流形断裂检测可由 X-S-MERA 工程版的 F1 检查（C1 不成立，d < d_threshold）给出。

## §4 应用一：量子-经典公共细化

### 4.1 问题背景

量子-经典交界处的预测不一致是物理学史上最古老的跨尺度冲突之一。量子力学给出 W(x, p) 状态分布，经典力学给出 ρ(x, p) 状态分布，两者似乎描述同一对象却不可调和。

**冲突定位**：

- **P₁（量子投影）**：保留所有相干性、纠缠、叠加态。
- **P₂（经典投影）**：保相化为任意态、可区分、可观测。
- **交集论域**：宏观低速区的物理对象。

### 4.2 公共细化的构造（无损路径）

本文给出的构造步骤：

1. **从量子态 ρ 出发**，构造 Wigner 函数：W(x, p) = (1/πℏ) ∫ du exp(-2ipu/ℏ) ⟨x − u/2|ρ|x + u/2⟩。
2. **在交集论域**：当 |ρ⟩ 是经典可分辨的混合态，W(x, p) 满足正定性条件（无负曲率区）。
3. **构造 IC-POVM**：以 ρ 为中心、以 ∆(x, p) = (ℏ_α, ℏ_β) 为分辨宽度，给出 IC-POVM（信息-完整正算子值测度）。
4. **验证三粒度约束**：①可分离：IC-POVM 的分辨宽度满足分离要求；②包含：IC-POVM 覆盖 ρ 的所有可观测信息；③可选出：构造出宏观层 + 量子层 + 中间细化层三层。

**结论**：当 W(x, p) 满足正定性条件时，公共细化可构造（分支 1）——冲突无损消除。

### 4.3 测量问题的位置

但**测量问题**（Measurement Problem）不在交集论域：宏观测量仪的"塌缩"是一个量子态→经典指针的不可逆转变。它不属于 §4.2 的无损路径。

按推论 P，进入分支 2 或 3。判定如下：

- 分支 2：测量后的状态稳定 → 单一宏观指针 → 量子态被舍弃 → 这是取舍式坍塌 → 必然伴随伪收敛风险（事后才知哪个诠释正确）。
- 分支 3：测量过程不能被任一合取能稳定 → 这是流形断裂。

哥本哈根、多世界、退相干三派的诠释分歧是分支 2 的现实实例：**动力学上收敛，事后验证为伪收敛（如果未来实验证伪了某派）**。

### 4.4 学术意义

§4 是 XS 框架**首次使自身满足自身公理四的边界探视校验**——以前 XS 3.3 要求"边界探视"但未给出显式构造。本节使该标准字面达成。**这是 10 月哲学版的核心交付**。

### 4.5 与 MMS 的衔接

MMS（多尺度建模与模拟）实践中的稀薄气体动力学（Kn < 0.05 连续介质区与 Kn > 10 自由分子区）在过渡区（0.1 < Kn < 10）存在系统性不一致（NS 方程与 Boltzmann / DSMC 之间的连续滑移边界修正、Burnett 展开都是补丁）——这是 §4 的物理同型实例：分支 2 的取舍式坍塌，动力学上已记录真实收敛，但事后验证为有依据的补丁路径。

## §5 应用二：MMS 的辅助实证

### 5.1 问题定位

MMS（Multi-scale Modeling and Simulation）是科学计算领域处理跨尺度问题的成熟方法。问题：MMS 的成熟部分能否作为 XS 的实证？

### 5.2 辅助实证的判定（不作为核心命题的直接实证）

按 XS 3.3 的标准："**至少三个跨学科案例可独立复现，理论冲突可由尺度错位解释；单纯补丁无法根除冲突，交集尺度相容能够消除该类冲突**"。MMS 的成熟成果满足部分条件：

| | HMM 尺度桥接算子 | 均质化收敛 | RG 不动点 | 稀薄气体过渡区 |
|---|---|---|---|---|
| 两投影系统 | 宏观 + 微观 | 非均质 + 均质化 | 不同尺度有效理论 | 连续介质 + 动理学 |
| 不可归为操作失误的冲突 | 无（HMM 互补）| 无（互补）| 无（同一理论不同 RG 流）| **有（系统性不一致）** |
| 错位归因（Kn/尺度分离比）| 桥接需要 = 差异存在 | 尺度分离假设 = 错位条件 | 耦合常数差异 = 错位 | **Kn 数 = 错位分量比** |
| 多分支同型 | 不可根除（耦合型）| 不可根除（派生型）| 不可根除 | **Kn→0 时收敛、冲突消除** |
| 跨学科性 | 否（工程内部）| 否（工程内部）| 否（物理内部）| **同域（流体物理内）** |

**结论**：MMS 的成熟成果满足"辅助实证"条件——验证机制普遍性，**不影响跨学科性**。稀薄气体过渡区案例因属同域，只能作为**同域准实证**。

### 5.3 与 XS 的关系定位

MMS 提供"怎么桥接"的工程方法，XS 提供"能不能桥接、桥接到什么程度、什么时候桥接失效"的判定规则。**XS 是 MMS 的解释性框架，不是替代或前置判定工具**。具体而言：

- **MMS 的派生型操作**（均质化、RG、Chapman-Enskog）从微观投影显式构造宏观投影，对应 XS 的公共细化 → 与 §4 的 IC-POVM 构造同型。
- **MMS 的耦合型操作**（HMM 的提升/压缩）不构造细化，只在交汇处转移信息，对应投影映射。

### 5.4 XS 对 MMS 的唯一增量

不是判据的精确性——Kn 与尺度分离比已远为精确。**唯一的增量是统一描述**：Kn、尺度分离比、relevant/irrelevant 分类是尺度向量分量比在不同物理语境中的实例。**XS 让这些互不通约的物理量进入同一描述框架**。

## §6 应用三：观察者案例诊断

### 6.1 案例来源

本文不只接受"专业发表"的材料——一位真实、善意、有代表性的非专业观察者在接触 XS 后产出了一组言论。本文把它**作为 XS 的研究对象**，不作为外来投稿。

### 6.2 三条言论

观察者产生的三条言论：

- **L1（基底完备性）**："作为基底，它的完备性不足。"
- **L2（向量空间基底）**："n 维空间的象 → n 维向量空间 → n 个基向量作为事件公理。"
- **L3（线性→非线性进化）**："数学→物理→化学→…→人文的投影序列中，X₁ 往往是线性的，但在 X 层级提升过程中有非线性。"

### 6.3 诊断（用共振三判据 + 知识注入测试）

**共振三判据判定**：

| 判据 | L1 | L2 | L3 |
|------|----|----|----|
| ① 投影可重复性 | ✓ | ✓ | ✓ |
| ② 系统生成性 | ✗（基底-完备不是判定机制）| ✗（向量空间不是认识论生成器）| **✓**（生成了可检验预测：S3 极限奇异解释） |
| ③ 对应性 | ✗ | ✗ | ✗ |

签名：**可重复但不共振 = 类比冒充同构**。

**知识注入测试**：

- L1：注入"Ω-完备 ≠ 基底-完备" → 观察者承认修正基底概念的位置 → **操作错位**（不是 XS 的事）。
- L2：注入"演绎闭包不是拟阵、维数不变定理不成立" → 观察者承认 X/S 不是线性基底 → **操作错位**。
- L3：注入"GR、Yang-Mills、Navier–Stokes 在本体层非线性" → 观察者承认"X₁ 线性"是呈现层而非本体层 → **转移到投影结构**。

### 6.4 共同签名：形式先于问题

三条共享一个结构：**用最熟悉的已成型形式结构（向量空间 / 完备性 / 线性-非线性）承接一个尚无固定形式的问题**。

文献支持：

- **Gentner (1983)**：关系对齐 vs 属性相似。
- **Chi, Feltovich & Glaser (1981)**：新手按表面特征分类、专家按深层原理分类。
- **Hesse (1966)**：中立类比区——专业工作 = 探测中立类比区。

### 6.5 框架缺口

**缺口 1**：三类错位（操作 / 理论 / 语义）无法命名"类比冒充同构"。判据能筛、分类不能名 → 判据与分类不对称。

**缺口 2**：XS 无法区分知识缺失与投影结构缺失。

**补缺口的最小增量**：**知识注入测试**（§2.3 已给出）——不破冻结令，不新增概念。

### 6.6 XS 自检的两种读法

**读法 A（诊断）**：言论当数据，问"他为什么落在这里"。
**读法 B（规范）**：言论当候选命题，问"能不能进 XS"。

建议两读法分节并存：原始表述作为"中立类比区的直觉"保留，专家判定作为"探测结果"附后。

## §7 工程反哺：X-S-MERA → XS 的四条通道

X-S-MERA 工程版 v1.6.1（仓库 zjg-74/x-s-mera，134 项测试 + Lean4 部分形式化 + 三个案例预注册验证）为 XS 提供了**可计算形式**。本文提出四条反哺通道，按推论强度排列。

### 7.1 通道 A · d/D 反哺为「边界测度」（最硬、最稳）

**工程原型**：
```
d = exp(-r²/(2σ²))，r = ||z_L − z_E|| / scale（两侧状态差的相对范数）
D = {d_1, d_2, ..., d_n}
封装判据：BC 系数 < 0.7 + |skew| < 1.0 + var < var_max
```

**反哺位置**：XS §3 尺度向量四分量 + §3.9 推论 P。

**反哺形态**：
- XS 之前的 ρ（限制映射 A_Ω→L(B)）是抽象的——告诉审稿人"下沉要做"而不知怎么做。
- 引入 d/D 后，ρ 的**测度端**可以由 d 重合度给出：ρ 不仅存在，而且可量化。
- 引入 D 后，ρ 的**统计端**可以由 D 的封装形态给出：可封装 ⇒ ρ 内嵌一致；不可封装 ⇒ ρ 在该论域失守。

**可证伪推论 R**：对两投影系统 P₁、P₂，若 d(P₁,P₂) ≥ d_threshold 且 D 可封装，则 XS 判定两者层级相容；若 d < d_threshold 或 D 不可封装，则 XS 判定两者层级不相容，且按 F1/F2 分型。

### 7.2 通道 B · F1/F2 反哺为 P 推论的可执行分支（较强）

**F1/F2 工程实现**：

- **F1**：C1 不成立（d < d_threshold）→ 直接交互禁止（通量置零）→ 对应 §3.9 分支 3（流形断裂的特殊情形：根本无公共基底）。
- **F2**：C1 成立、C2 失效（d ≥ d_threshold 但接口不兼容）→ ghost 伪力（礁石伪收敛）→ 直接对应 §3.9 分支 2。

**反哺位置**：§3.9 P 推论的注释段。

**可证伪推论 R'**：任何被 XS 判定为"分支 2"的系统，在工程原型中执行 F2 检查，应当出现 ghost 伪力；若不出现则 P 推论失守。**可由 §4 量子-经典交集的新实验验证**。

### 7.3 通道 C · A11-R 反哺为基底 ⑦ 的动力学侧（中等）

**工程原型**：势-流分离 A11-R（语义势只调耦合增益，不进状态方程）。

**反哺位置**：§2.1 基底-完备七条的第⑦条——增加动力学侧约束：基底公理**不通过势函数越权改写状态方程**。

### 7.4 通道 D · X₁X₂X₃ 回填为 X 内部时序三层（最弱）
