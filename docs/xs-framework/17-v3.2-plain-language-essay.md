# 我对认知过程的一套理解：一条公式，五种读法

> XS 框架 · 2026-10-23
> ——一份写给普通人的自述，外加一份可以推翻它的清单

---

混迹认知科学、哲学、脑科学、AI 圈子的时间不算短，也系统读过不少"认知升级""底层逻辑"类的东西。
一路读下来，一个感受越来越强：**关于"人是怎么想的"的解释，要么太粗，要么太碎。**

粗的意思是，它给你一堆标签——"这叫认知重构""这叫思维升级"——听着痛快，但你拿它去处理一件具体的事，
会发现它什么也没说。

碎的意思是，它给你一堆互不相干的机制，每个都成立，合起来却推不出任何东西。
你没法用它预测：你今天下午到底会想通还是会想岔。

所以我自己动手搭了一套。搭的过程中也走过弯路、犯过蠢、被现实打过脸。
这一篇既是**讲述**，也是**交代边界**。

> **注**：本文说的是一套**我自己搭的**框架，不是客观真理，也不追求普适。
> 你觉得有用可以参考，觉得不适完全正常。
> 而且我保留随时推翻自己的权利——第九节专门写我自己错在哪。

## 一、先说清楚我在说什么：认知不是"想得对"，是"想的过程有形状"

我的核心主张只有一句：

> **认知不是一个结论，是一条有形状的过程。**

我们日常说一个人"聪明""想得清楚""钻牛角尖""想开了"，其实都在描述这个过程的**形状**，
而不是它的对错。这两件事必须分开，因为它们经常打架：

- 想得很顺，但结论是错的 —— 这是**伪收敛**，人最难受的时候往往就在这里；
- 想得很痛苦，但越想越清楚 —— 这是**钻研**，中间那段最难受，恰恰是最有价值的；
- 干脆不想了 —— 这是**发散**或**卡住**。

如果只讲"结果对不对"，这三种人会被混为一谈；如果只讲"过程形状"，
我们才有办法区分它们、预测它们。

### 这套框架能干什么、怎么检验

我不打算让这套东西"解释一切"。它只承诺四件事，而且每一件都要能被检验：

| 它承诺什么 | 怎么检验它 |
|---|---|
| **解释过往**：看清自己当时错在哪一步 | 我能不能指出"就是这一步错了"，而不只是"当时状态不好" |
| **判断当下**：分清现在这一段是什么形状 | 它给出的分类，和我的直觉一致吗；不一致时，谁对？ |
| **推演趋势**：事先算出大概率走向 | 它的推论能不能在事情发生**之前**算出来，事后复盘时是否被现实打脸 |
| **内化行动**：少一点内耗 | 用它之后，我是更少钻牛角尖，还是只是换了个说法继续钻 |

### 它必须具备的四个性质

| 性质 | 含义 |
|---|---|
| **完全内生** | 不属于任何书本、权威或他人。每一条结论都能一路追回我自己声明过的假设 |
| **逻辑自洽** | 内部没有根本矛盾。每个结论都能从前提一步步推出来，而不是"因为老师这么说" |
| **视角兼容** | 不被单一视角绑死。能容纳"我这条也可能错"，也能容纳和我相反的解读 |
| **动态生长** | 随复盘持续修正。**改错了要写下来，不删**——这一点是整套东西能不能活下来的关键 |

关于最后一条，我要多说一句，因为它是我和别人做法差别最大的地方：
**这套框架对我最大的价值，不是它现在有多对，而是它知道自己哪里可能不对，并且把"哪里可能不对"写成了可以被推翻的样子。**

## 二、先拆别人的框架：各有边界，皆非万能

在讲我自己这套之前，先说清楚它站在谁的肩膀上——以及它不接哪一块活。
这不是客气，是边界声明。

| 体系 | 核心关注 | 适用边界 | 不适合解决 |
|---|---|---|---|
| **心理学** | 信息加工、记忆、判断 | 解释认知过程与行为机制 | 世界观、价值取舍、内心安顿 |
| **传统哲学** | 主客观关系、真理 | 理论探索、理性思辨 | 日常选择怎么落地 |
| **脑科学** | 神经信号、生理活动 | 认知的生理基础 | 主观意识与精神感受 |
| **认知科学 / AI** | 可计算的表征与推理 | 形式化、复现、规模化 | 一个人此刻为什么这么想 |
| **玄学 / 灵修** | 觉醒、意义感 | 安慰与安顿 | 逻辑验证、现实问题落地 |
| **我这套** | **认知过程的形状与去向** | **过程分析、可证伪的推论** | **不负责证明结论对，不负责预测具体事件** |

上面这张表里我自己那一行是刻意写得保守的。
**我这套东西不告诉你"什么是真"，它只告诉你"你正在走哪一种形状"，以及"能读出什么、读不出什么"。**

这个分工是有代价的：它听起来没那么高。但换来的是——
**它说错的时候，你能指出它错在哪，而不是只能接受或拒绝二选一。**

## 三、这套框架的四次改写（它是怎么长出来的）

这一节讲过程，因为过程比结论更能说明这套东西值不值得信。
每一步都配了真实发生过的、我自己搞砸过的例子。

### 第一阶段：一台用胶带粘起来的机器

最初的形态很朴素：一个主文，讲"认知二分""宏加载""三分"（收敛 / 震荡 / 发散）。
之后每隔一段时间就出问题、出补丁，于是就一路补到了**九篇补篇**。

九篇补篇，每一篇都在补一个真问题。但它们之间的关系是"堆"出来的，不是"推"出来的。
更麻烦的是：**它们互相打架。** 有的结论要求这条曲线必须这样，有的又要求它必须那样。

**真实案例（我亲手废掉了自己唯一的证伪路径）：**

我给自己框架里最核心的那个假设（后面第七节会正式登场）设计了一条证伪判据：
如果同一个理解者在不同任务上同时出现"越想越乱"和"越想越清楚"两种形状，那这个假设就该被推翻。

我把这条判据做成了实验。跑完的结果是：**它在一种非常常见的情况下会疯狂误报，误报率一路涨到 100%。**
换句话说，我以为在抓"假设不成立"，其实抓的是"我的假设在任务之间换了参数"。

结果是——我把这条判据整个废掉了，换了另一条。
**一个框架最健康的时刻，不是它证明了自己，而是它有一条能被推翻的路，而且那条路真的被推了一回。**

### 第二阶段：不再打补丁，开始往上找病根

被推了一回之后我意识到一个问题：一直在补洞，说明**洞可能是我自己挖的**。

于是我换了个做法：把九篇补篇和所有实验留下的**全部 21 项没闭合的问题**摊在一张桌子上，
逐条追问一句——

> **这是"世界我还不知道"，还是"我定义写错了"？**

为了不让这个问题变成"感觉不对就重写"，我先立了三条判据：

1. **能定位**：必须指出症状挂在源头哪一条定义上，不能笼统说"理论不够"；
2. **症状消失而不是转移**：修完如果只是把困难挪到别处（比如从"标不出来"挪成"需要新仪器"），不算修好；
3. **消灭的是冗余不是内容**：修一个洞如果新增一条假设，那是新补丁，不算。

按这三条筛，21 项未闭合里，**13 项是我自己挖的坑**，而且能归纳成 **8 个病根**。
改完之后：7 项直接消失，6 项降级成工程问题，1 项缩小，7 项留下——而真正算得上"理论缺口"的，只剩 4 项。

**真实案例（我在为一个自己写的冗余找了大半年外部解释）：**

我的动力学方程里写了 6 个参数。后来我数了一下才发现，**这 6 个参数其实只表达了 3 个自由度**——
它们只以乘积的形式进入方程。多出来的那个不是世界的秘密，是我自己写进去的冗余。

更荒唐的是：我曾经把这个冗余**误判成了"世界的不可辨识性"**，
写了一段推理说"这四个系数在原理上就标不出来"，然后花了很长时间去寻找外部标定方法。

**我以为我在探索物理规律，其实在探索自己的记号。**

### 第三阶段：推翻自己写下的结论

这一阶段最不舒服，也最关键。规范固定之后，发生了三件事：

**第一件，我把上一轮的结论推翻了。**
上一轮我写"某个量可以这样标定出来"，这轮我核对发现：那个式子是**循环的**——
它要一个未知数才能算出另一个未知数，两个未知数绑在一起，谁也解不开。
于是它从"标定路径"降级成了"记账恒等式"，并登记成一个新的待办：**我们缺的不是更多数据，是缺一类新的观测。**

**第二件，我发现自己把一条桥写成了恒等式，于是它就永远合不上。**
框架里有两个量，一个是"还没想清楚的部分"（存量），一个是"每一步的推力"（通量）。
我一直觉得它们之间应该有条桥，但怎么都连不上。
后来才看清：我把这两个量**写成了同一个公式**。
写成恒等式的东西，是不需要证明的——所以从来没人去问"这条桥在什么条件下才成立"。
**桥之所以长期合不上，是因为它被伪装成了不需要证明的东西。**
把它们分成"存量"和"通量"之后，桥立刻变成一个**可以被推翻**的命题——问题也就有了着落。

> **（作者更正）** 上面这件事其实**不是这一轮才想通的**——v3.1 的一篇补篇里已经拆过一次，并登记成了待办。
> 我这一轮把一个**已经修过的错**当成了"这一轮才发现"，还写进了正文。
> 把它留在这里，是因为它比结论更有用：**靠人读，记号冲突是会漏检的。**
> 我能自己抓到一次，但下次不一定。
> 所以这一轮真正补上的不是"又一个洞"，而是**一套让这类洞能被机器抓出来的登记表和校验器**。

**第三件，我修正了自己对"框架能不能被证伪"的判断。**
上一轮我说"我的核心假设目前没有任何有效的证否途径"，听起来像是"这个假设不可检验"。
这一轮我意识到：那是**我自己定义写松了**导致的。有一条我一直写着的"额外假设"，
其实已经包含在原定义里了，把它再列一遍，就凭空造出了一个"没人检验过它"的假象。
去掉之后，那条早就写好的证否判据**本来就是有效的**。
于是这个缺口的性质完全变了：它不是"这个框架没法被推翻"，而是"**这个假设还没有拿到现实世界的证据**"。

**这两件事的区别很大。** 前者是逻辑问题，后者是证据问题——而后者是可以靠做实验解决的。

### 第四阶段：现在在哪

现在的结构，说起来其实很朴素：

- **第一层**：认知怎么被造出来、往哪去（生成与归宿）；
- **第二层**：认知为什么能撑住、为什么会塌（约束与失效）；
- **第三层**：认知的过程长什么样（动力学）。

**最要紧的是：第三层的全部内容，可以压缩成一条公式。**

而这正是下面四节要讲的事。

## 四、框架的核心：一条公式

前面九篇补篇、六七种技术说法，最后收敛成这一条：

$$\frac{\mathrm dU}{\mathrm dt}\;=\;\rho_{exp}\cdot\frac{\mathrm dE}{\mathrm dt}\;+\;\kappa_E\,\rho_{exp}\,(1-\rho)$$

翻译成大白话：

> **"还没想清楚的部分"的变化速度，等于"复杂度"变化速度的 ρ_exp 倍，再加上一个固定的偏移。**

用生活里的东西打个比方：你在整理一个库房。
`E` 是库房里东西的总量，`U` 是"还没归位、说不清是什么"的那部分。
这条公式说的是：**你每往库房里塞进一公斤新东西，账面上"说不清"的部分就跟着涨 ρ_exp 公斤；另外还有一个跟塞东西无关的固定偏移在起作用。**

就这么一句。看起来平淡，但它的作用是**把一整套看似无关的现象统一了**。

### 为什么一条公式就够了

在此之前，我有三块各自成篇的技术：

- 一套讲"两个峰谁先谁后"的**峰序**理论；
- 一套讲"两个峰隔多远、能反推出什么"的**峰距**理论；
- 一套讲"两条曲线是不是一条直线"的**共线**理论。

它们各有各的前提、各有的适用范围，彼此还有矛盾。
**用上面这条公式一统，三者全都变成了同一条关系的三种读法。**

三块技术、一个共同母体——这才是"框架"该有的样子。

### 但这条公式有前提

公式不是凭空来的，它站在一个**我提出的建模假设**上（第七节登场）。
而这个假设在第七节会被我明确标成"假设"，因为**它至今没有拿到现实世界的检验**。

这句话我必须放在最前面，不能放在脚注里。

## 五、这条公式的五种读法

下面五种读法，就是第三层全部的内容。全部来自同一条公式。

| 读法 | 读的是什么 | 需要外部尺子吗 | 会不会被"怎么安排过程"影响 |
|---|---|---|---|
| **共线性** | 两条曲线在图上是不是一条直线 | 不需要 | **不会** |
| **ρ_exp** | 那条直线的斜率 | 不需要 | **不会** |
| **峰序** | 截距的**正负号** | 不需要 | **不会** |
| **守恒** | 面积/积分形式 | 不需要 | 不会 |
| **ρ 的具体数值** | 截距的**绝对值** | **需要** | **会** |

这张表是整套框架里最实用的一张，因为它一眼就能看出**哪些结论稳、哪些结论脆**。

**真实案例（我靠这张表找到了一个"方法本身错了"的问题）：**

框架里原来有一套"用两个峰之间的距离反推参数"的标定程序。
在一种特定的过程安排下它很准；但换成别的安排，**偏差能到 36% 到 76%**。

我一开始以为是公式写错了，调了很久。
后来用上面这张表才看明白：**不是公式错了，是这套方法越层了。**
它想从一个"形状层"的量里，掏出一个"本来就必须借外部尺子才能测"的量。
**读不出来的数，怎么调都读不准。**

改法简单到有点可笑：把首选的读法换成"直线的斜率和正负号"——
这两个数**不需要任何外部尺子，也不受过程怎么安排的影响**。
换完之后，跨四种不同的过程安排，误差全部归零。

**教训**：一个方法长期不稳，第一反应不应该是"再调调参数"，而应该是"我是不是在读一个本来就读不出来的数"。

## 六、形态：钻研和空转，其实是同一块楔形的上下两半

![A_D 动力学的 (s, ρ) 平面楔形分类](../../figs/v32_wedge_classification.svg)

*图 1　把"投入比"和"效率比"摆到一张平面上，竖线和对角线把平面切成四块。
右上是"越想越乱"，左下是"正常收敛"，中间两片共享一个尖角的楔形，
上面一片是"钻研"，下面一片是"空洞"。虚线箭头是过程推进的方向。*

这块图想说的事情，用一句话讲完：

> **"越想越清楚"和"越想越乱但还在想"，是同一块楔形的上下两半。
> 你落在哪一半，不由你有多努力决定，由你自己"展开"和"收拾"的效率比决定。**

举个更贴近的比喻。
你在解一道题。**展开**是"再想一个思路、翻一页资料"，**收拾**是"检查、排除、确认"。
- 收拾的效率明显高于展开 ⟹ 你越挖越清楚 —— 钻研。
- 展开的效率高于收拾 ⟹ 你越挖越乱 —— 看起来很努力，方向感在流失。
- 两者效率相当 ⟹ 那块楔形直接塌掉，**中间那段时间根本不存在**：你要么一路冲到底，要么一路垮掉。

而且注意一件事：**两种形状互斥。** 一个人不可能在同一段时间里既越想越清楚又越想越乱。
这不是我规定的，是公式推出来的。

这张图还顺手解决了一个老问题：
我原来用四个参数描述这四种形状，规范固定之后**压成了两个**；
而且原来那个定理只写了"钻研"那一支（另一支散落在旁边的对照表里），
现在两支并成了一块完整的楔形。

## 七、能读什么，不能读什么

这一节是整套框架里我最愿意拿出来讲的部分，因为它讲的是一件很反直觉的事：

> **有些数，你天生就读不出来。不是因为你笨，是因为它需要一个外部的尺子。**

要读出来，得先说清楚**"读"的是什么。我的假设是这样的**：

> 每一步的认知变化，由两个动作叠加而成——
> **展开**（投入 `a`：往外长出新东西）和**收拾**（投入 `b`：往回收、排除、确认），
> 每一步各带一个效率系数。

这个假设有个特点：它**足够弱**（线性、两项、不记历史），
又**足够强**（能同时长出两个峰，而且两个峰可以错开）。
但它**是假设**，而且是全套理论**唯一**的承重假设。

在这个假设下，四类东西的可读性是这样的：

| 级别 | 是什么 | 要外部尺子吗 | 会被过程安排影响吗 | 状态 |
|---|---|---|---|---|
| **A** | 斜率那个数（ρ_exp） | 不需要 | 不会 | **自己就能读** |
| **B** | 截距的正负号（据此判断钻研还是空转） | 不需要 | 不会 | **自己就能读** |
| **C** | 截距的绝对值（进而拿到具体数值和那个时间尺度） | **需要** | **会** | **读不出来，得换一类观测** |
| **D** | 我原来那 6 个参数的绝对值 | — | — | **根本不该去读**（那是我自己写进去的冗余） |

D 那一行是重点。**曾经我把 D 当成正经目标，宣布"它们原理上不可辨识"。**
后来才发现，它们不可辨识只是因为**我自己没规定用哪把尺子去数**——
就像"这堆沙子有多重"没有意义，除非你先说清楚是按质量还是按体积数。
**一旦固定了单位，它们立刻就都能读了**（这需要一种"每次固定展开一次、固定收拾一次"的对照实验，
已经写好方案，**还没做**）。

至于 C 级，有个好消息也有个坏消息：

- **好消息**：C 级里"符号"那一半其实是 B 级，已经能读了。
- **坏消息**：C 级的"数值"那一半，**用再多数据也读不出来**——
  因为方程本身只给一个组合，不是两个独立的数。
  这不是数据量的问题，是**观测类别**的问题：你得换一种观测方式，不是多采点数据。

**这条推论直接改掉了我上一轮的一个说法。** 上一轮我以为"用某条公式反解"是一条标定路径，
这一轮核对发现那是**循环的**（要一个未知数解另一个未知数）。
我把它降级成记账恒等式，并把它变成一个明确的新待办。

## 八、这套框架会犯什么错

不写这一节，前面所有内容都不值得信。

### 一个关键的自我限制

我给这套框架定了一条纪律，叫**层间纪律**：

> **"往哪去"由生成层和约束层决定；"长什么样"由动力学层决定。
> 不许跨层去读。**

跨层去读会出什么事？第五节那个 36%–76% 的偏差带就是活例子：
**用一个"形状"的量，去推断一个"归宿"或"参数"的东西。**
在纪律生效之前，这类错误会一次又一次地冒出来，而且每次都伪装成"实验做得不够细"。

### 常见质疑，我一条条回

| 质疑 | 我的回应 |
|---|---|
| **"你这不就是把'想得清楚'换了个说法吗？"** | 区别在于能不能被推翻。它给出的是一条可检验的关系：两条曲线在图上必须是直线，斜率能直接读出来，而且不依赖你怎么安排思考过程。这三条都能被实验否掉 |
| **"公式谁都能编一个，凭什么信你这条？"** | 我不要求你信。我给你的是**一条带证伪条件的断言**和**一张缺口清单**。你可以照着去查，缺的地方我写在纸上 |
| **"你说它自洽，可自洽的偏执者多了。"** | 自洽不等于对，而且自洽很容易。所以我另外加了一条：**每个承重假设都配了证伪程序**。没有证伪程序的主张，我不敢写进正文 |
| **"这不就是元认知 + 批判性思维吗？"** | 概念上确实有亲缘。差别在两点：一是**它是关于过程形状的**，不是关于自我监控的；二是**它把不确定的部分写在明处**，而不是靠"全面辩证"来兜底 |
| **"纸上谈兵，实际用得上吗？"** | 有一条是真能用的：**判断自己现在这段是钻研还是空转**。这在日常里非常常见——同样一道题，有人越做越清楚，有人越做越焦虑，靠的不是努力程度，而是收拾效率够不够 |
| **"模型算出来的数，能当现实用吗？"** | 不能。数值实验排除的是"程序写错了"，不是"现实就是这样"。这一点我在正文里每一处都标了 |
| **"你凭什么说自己这套比别人的强？"** | 我不这么说。第七节那张表同样能指出我这套的软肋在哪：能自己读的就那么两个数，第三个直接读不出来 |

### 还剩下什么没解决

诚实地列一下。这张表和上面那些话一样重要。

| 编号 | 剩下的问题 | 性质 |
|---|---|---|
| **A** | **核心假设本身没有现实检验**。整套动力学建立在"每一步 = 展开 + 收拾"上，这个假设至今只在数值模型里跑过 | **唯一需要现实证据的一条**。框架的逻辑再自洽，这一条不落地，整套就还是空中楼阁 |
| **B** | 收拾效率掉到底时，边界怎么起作用（我只知道"掉到底会停住"，不知道停住的具体形状） | 形式未定 |
| **C** | 什么算"回落"、什么算"方向"的分界 | 阈值原则未定 |
| **D** | 读不出 C 级的那个数 | **已有方案，未执行**（固定动作计数的对照实验） |
| **E** | 跨人群、跨任务、跨人群差异 | 经验项，本文不碰 |

**这张表就是这套框架的边界。** 它的第五行告诉读者：这里面有一条是硬伤，其余四条是待补的活。

### 关于"自洽"这件事，我想多说一句

写到这里我想起一个很常见的误解：**"自洽"听起来像个褒义词，好像越自洽越高级。**

其实不是。我这套东西的自洽，靠的不是"我怎么编都能圆回来"，
而是**每一处接缝都标了号**：
哪里是公理，哪里是我的假设，哪里是算出来的，哪里只在模型里验过，哪里连验都还没验。
**接缝标得越清楚，框架越容易被别人拆。** 一个接缝都不标的框架，才是真的靠"自洽"活着——而那叫圆滑，不叫自洽。

## 九、我的边界，以及一次翻车

### 几条必须说清楚的

| 边界 | 说明 |
|---|---|
| **不追求普适真理** | 这套框架服务的是我自己的理解与判断，不宣称客观正确 |
| **不否定别人的价值** | 心理学、哲学、脑科学提供了基础概念；我是在这些之上重新组织，不是推翻 |
| **不保证任何结果** | 它能减少一点内耗、帮我看清形状，不等于有用、不等于正确 |
| **仍然会错** | 文中所有"自洽"都是阶段性的。我保留推翻自己的权利 |
| **不要求你认同** | 觉得有用可参考，觉得不适完全正常 |
| **还没到能被外部检验的程度** | 这是最要紧的一条。核心假设没拿到现实证据之前，它只是一套**内部自洽的说法** |

### 一次翻车

我不想只写自己判断对的例子。

框架里我曾经很确定地写下一条判据：只要"势"的曲线上出现一个**内部极小值**，
就说明假设被破坏了——直觉上，假设一坏，曲线上该出现一个不该有的凹陷。

后来做实验发现：**在这类违反情形下，那个凹陷会被压缩到最左边不到一步的位置，
网格扫描根本扫不到它。**
不是精度不够、不是步长没调细，是这套判据在这类违反上**结构性地失明**——
那个极小值在数学上确实存在，但它落在了采样点之间。

我当时的复盘结论是：**判据本身没错，错在我把"看不见"当成了"没发生"。**
一个判据能发现什么、**不能**发现什么，本身就是判据的一部分属性；
我以前没把它写进方案里，所以实验做完才发现那个洞。

于是我补了一条规矩：**每写一个判据，必须同时写清"它在什么情况下会失效"。**

写出来这段不是为了显得诚实。是因为——
**一套不能被自己拆的框架，和一套不能被别人拆的框架，是同一回事。**

## 结尾

认知这件事，最容易发生的误会是：以为它是一个结论，所以去找"正确答案"。

其实它更像一条河。
你的阅历、读过的书、遇到的人和事，是河床；
你的情绪，是水位；
你的性格，是流速。

河不会告诉你它要去哪儿，但**河有形状**。
你顺着走一段就知道自己在哪个弯上、是不是快到断流、要不要改道。
这形状不保证你到得了任何地方，但至少**你不会一边走一边怀疑脚下的地面是不是真的**。

我搭这套框架，不是为了找出那条河的名字。
是为了让自己在河里的时候，**知道自己在哪个弯上**。

还有一件更重要的：
**它得能让我在某个弯上判断失误。**
如果一套东西永远不会让我判断失误，那它多半什么都没说。

所以我把它写下来了，连同它的洞、它的假设、它的自相矛盾处，和它被现实打脸的那几次。

不清高，不炫技，不渡人。
能解释过往，能看清当下，能推演形状，能少一点内耗。
这就是它对我最大的用处。

**而它随时准备被推翻——包括被我自己。**

### 附：本文的标记约定

为了让读者随时知道"哪句是硬的，哪句是软的"，全文用四个标记：

| 标记 | 含义 |
|---|---|
| **【算出来的】** | 从前面已说清的前提一步步推出来的，没有额外假设 |
| **【我假设的】** | 我自己提出的建模假设，**尚未被现实检验** |
| **【只在模型里算过】** | 数值实验的结果：排除程序写错，**不等于现实** |
| **【还没验】** | 检验方案已写好，**尚未执行** |

按这个约定，本文里最硬的那些句子（形态分类、峰序、可辨识性）都挂在一个**【我假设的】**前提上；
而那个前提是整套东西唯一没有落地的地方。**这一点我放在开头，也放在结尾，因为它是全文最重要的一句话。**
