### 最关键的三条结构性事实

**事实 1：M 是三版唯一的可统一术语。** 不是巧合——M 在三版中指的是同一件事：**稳定压缩单元**。8 月把它放在认知层，10 月把它作为 XSM 架构的核心，工程版把它作为 M-完备性的判据载体。

**事实 2（v2 修订）：8 月与 10 月的 X/S 在范畴层完全对齐，工程版是独立的工程化扩展。** 根据 2026-10-19 用户对 8 月版的主动澄清：8 月认知版 **X = 象（像）= 认知的对象**；**S = 对 X 的运算**——它是"操作的动作 / 操作的对象"这一最一般的本体论二分在认知层的具体化。10 月版的 X_obj / S_op 与此完全同构。这清掉了上一版"三版必须分记三种范畴标签"的复杂度：**8 月稿第二篇那段"X 认知扩展变量 / S 认知固化变量"是 X_obj 与 S_op 的功能描述（扩展-固化倾向），不是 X/S 的范畴定义**。所以 X 在 8/10 之间范畴一致，S 同样。三版的真正分歧只在工程版 X_sys / S_iface（X 加上 state/D 样本，S 特化为接口算子），是工程化扩展，不是范畴对立。

**事实 3：X-S-MERA 工程版独有两个机制（d/D 与 F1/F2），恰好补齐 10 月哲学版的两条空白。**
- d/D = "边界测度"的工程实现——XS 自己从未量化"边界"的判定量
- F1/F2 = 失败模式的二分——P 推论（不可无损时的代价）从此有可代码化的判定分支

## 二、X-S-MERA 反哺 XS 的四条通道（不破冻结令）

冻结令：不新增概念，只把工程已有的**形式化**搬到理论侧。

### 通道 A：D/d 反哺为「边界测度」（最硬、最稳）

**工程原型**（`src/le_coupling_kernel.py`）：
```
d = exp(-r²/(2σ²))，r = ||z_L − z_E|| / scale（两侧状态差的相对范数）
D = {d_1, d_2, ..., d_n}  ⟹  封装判据（BC 系数 + skew + var）
```

**反哺位置**：XS 元规则章 —「基底-完备」第②条（下沉显式 ρ）与第⑥条（鲁棒）。

**反哺形态**：
- XS 之前的 ρ（限制映射 A_Ω→L(B)）是抽象的——告诉审稿人"下沉要做"而不知怎么做
- 引入 d/D 后，ρ 的**测度端**可以由 d 重合度给出：ρ 不仅存在，而且可量化
- 引入 D 后，ρ 的**统计端**可以由 D 的封装形态给出：可封装 ⇒ ρ 内嵌一致；不可封装 ⇒ ρ 在该论域失守

**可证伪推论 R**：对两投影系统 P₁、P₂，若 d(P₁,P₂) ≥ d_threshold 且 D 可封装，则 XS 判定两者层级相容；若 d < d_threshold 或 D 不可封装，则 XS 判定两者层级不相容，且按 F1/F2 分型。

**为何不破冻结令**：d/D 在 X-S-MERA 工程版中已存在（非新概念），只是理论侧未使用。

### 通道 B：F1/F2 反哺为 P 推论的可执行分支

**P 推论原貌**（合并 P2 后）：
1. 公共细化可构造 → 无损收敛
2. 公共细化不可构造但有宏可稳定 → 有损取舍 + 伪收敛风险
3. 二者皆不可 → 流形断裂 / 发散 / 伪收敛

**F1/F2 工程实现**：
- F1：C1 不成立（d < d_threshold）→ 直接交互禁止（通量置零）→ 对应分支 3（流形断裂的特殊情形：根本无公共基底）
- F2：C1 成立、C2 失效（d ≥ d_threshold 但接口不兼容）→ ghost 伪力（礁石伪收敛）→ 直接对应分支 2

**反哺位置**：P 推论的注释段——给分支 2 和分支 3 各加一个**工程判定入口**：

```
分支 2 判定 = F2 检查（C1 ∧ ¬C2）
分支 3 判定 = F1 检查（¬C1）
```

**可证伪推论 R'**：任何被 XS 判定为"分支 2"的系统，在工程原型中执行 F2 检查，应当出现 ghost 伪力；若不出现则 P 推论失守。

**为何不破冻结令**：F1/F2 是工程既有概念；只把它们作为 P 推论的形式化分支写出。

### 通道 C：势-流分离 A11-R 反哺为「基底不污染」原则

**工程原型**：语义势梯度 `semantic_potential_grad` 只调制耦合增益 `coupling_flux * grad`，状态导数完全由载体通量驱动。

**反哺位置**：XS 元规则章 —「基底-完备」第⑦条（极小可审计）。
- 反哺前：⑦ 的意思是"每条公理都有必须它的定理"——静态约束。
- 反哺后：⑦ 增加一条**动力学约束**——约束本身（基底公理）不能跨过载体通道污染状态更新。
- 形式化：若 B 是 S 的基底，则 B ⊨ ψ 的推导过程中，ψ 的状态量函数依赖 ρ(ψ)（来自基底本身），不依赖 Ω 层的势函数；势函数只能调制转移概率，不可越权直接写入状态方程。

**可证伪推论 R''**：在 LE 工程原型中，任何修改 `semantic_potential_grad` 的实验（仅调制增益），与任何修改基底公理（重新定义状态方程）的实验，可观察的输出维度应当正交；若不正交则势-流分离失效。

**为何不破冻结令**：A11-R 是工程既有公理；只把它解读为基底完备性的动力学一侧。

### 通道 D：X₁X₂X₃ 反哺为「X 的内部层级」（一次迁移丢失的资源）

**8 月独有**：X 内部的三层（输入/萃取/输出），10 月和工程版都没有。

**反哺位置**：XS 元规则章 — 「X 是什么」的注释段。

**反哺形态**：10 月版 X = "坍塌输出的对象"。这是单层描述，丢失了输入与萃取两层。引入 X₁X₂X₃ 作为**输入态 / 萃取态 / 输出态**的内部时间排序：
- X₁ = 输入系统（接收原文 / 自然语言 / 感官信号）
- X₂ = 萃取系统（推演、对比、联想）
- X₃ = 输出系统（固化、宏化、可调用结构）

**可证伪推论 R'''**：XSM 架构中的 M（宏）应在 X₂ 与 X₃ 之间出现——它是被萃取的产物，不是输入也不是输出。若在某实验中发现 M 出现在 X₁ 端或直接等于 X₃ 端点，则 X₁X₂X₃ 内部时序假设失守。

**为何不破冻结令**：X₁X₂X₃ 是 8 月既有概念；从 10 月体系升级时丢失，工程反哺是一次"找回"而非"新增"。但要注意：10 月版默认 X 是单层对象，强行引入三层会要求 X 的指涉对象**重载**，需用户先决定"X 是单层还是三层"——这是统一原则问题，待 §3 处理。

## 三、X/S/M 统一原则（命名守则，不是定义合并）

### 错误：把 X 合并为单一定义

三版的 X 范畴不同：
- 8 月：功能倾向（变量）
- 10 月：坍塌输出（对象）
- 工程版：投影子系统（含 state + D）

若强行合并，会引出三个问题：
1. 在 8 月，倾向 → 对象的迁移本身就要重写"满意解""熵变"等概念
2. 在 10 月，对象 → 子系统的迁移会丢失"运算"这一层
3. 在工程版，子系统 → 单一定义的迁移会丢失 d/D 的统计层

**结论：不合并，分记。**

### 正确：用「范畴标签」限定字母

| 字母 | 范畴标签 | 出现于哪个版本 | 备注 |
|------|---------|---------------|------|
| **X** | X_obj（object，认知对象 / "象"，8 月与 10 月共用） | 8 月 + 10 月 | 8 月：象；10 月：坍塌输出对象 |
| X | X_sys（system，投影子系统；工程版） | 工程版 | 含 state + D 样本（功能化扩展） |
| **S** | S_op（operation，对 X 的运算，8 月与 10 月共用） | 8 月 + 10 月 | 8 月：操作的动作；10 月：截断算子运算 |
| S | S_iface（interface，接口算子；工程版） | 工程版 | S_op 在接口算子层的特化 |
| **M** | M_all（统一！） | 三版通用 | 稳定压缩单元 / 演绎节点产物 / 边界宏 |

### 落地的三条具体规则（v2 修订）

**规则 R-X（修订）**：任何论文中出现 **X** 时，默认 **X_obj**（与 8/10 月一致）；仅当内容确属 X-S-MERA 工程版范畴时，须显式标注为 X_sys。

**规则 R-S（修订）**：同理，默认 **S_op**（8/10 共用）；工程版的 S_iface 是 S_op 在接口算子层的特化（S_op.subset(iface)），单独标注以提示其代数结构维度。

**规则 R-M**：M 不分记，全文统一指"稳定压缩单元"。

**v2 的关键简化**：原"必须分记三种范畴标签"是误判——8 月与 10 月其实一直用同一范畴。真正的范畴分叉只有"哲学层（X_obj / S_op）"与"工程层（X_sys / S_iface）"两条腿，不像初看那样三足鼎立。R-X / R-S 因此从"三分支标签管理"降为"默认 + 工程专属标注"，更轻。

## 四、统一方案可立即执行的 5 件事

按"成本最低、不破冻结令、增量最强"排序：

### 1. 立即可做（一句话级）

**在 10 月版附录 C 概念账本增加一条术语表**：
> **X/S 在本框架中按范畴标签使用（v2）**：
> - **X**：默认 **X_obj**——8 月认知版称"象（像）"，指认知的对象；10 月哲学版指坍塌输出的对象。两者范畴相同。仅 X-S-MERA 工程版使用时标注为 **X_sys**（含 state + D 样本的投影子系统）。
> - **S**：默认 **S_op**——8 月与 10 月均指对 X 的运算（截断算子上的操作）。仅工程版使用时标注为 **S_iface**（接口算子，S_op 的接口特化）。
> - **M**：三版统一指**稳定压缩单元**（与 8 月认知版、X-S-MERA 工程版的用法对齐）。
> 工程范畴（X_sys / S_iface）与哲学范畴（X_obj / S_op）混用时须显式标注。

### 2. 在第②节「公理」加入 ρ 的可量化形式

> ρ 在「基底-完备」第②条中原本是抽象映射；本节给出 ρ 的可计算实例，即 X-S-MERA 工程版中的边界测度算子：
> - ρ 的**测度端** = 边界重合度标量 d ∈ [0,1]，d = exp(-r²/(2σ²))；
> - ρ 的**统计端** = d 的统计分布 D 与封装判据（BC 系数 < 0.6，Skew 绝对值 < 1.0，Var 上界 var_max）；
> - 跨投影 ρ 的合规判定 = d ≥ d_threshold ∧ D 可封装。

### 3. 在推论 P 的注释段加入 F1/F2 分支

> P 推论分支 2 的工程判定 = F2 检查（C1 ∧ ¬C2，分支 3 的工程判定 = F1 检查（¬C1）。这一对应是 X-S-MERA 工程版（v1.6.1）经验证的。

### 4. 在元规则章加入「势-流分离」作为基底完备性第⑦条的动力学侧

> 第⑦条 极小可审计：基底公理不应通过势函数越权改写状态方程——对任何 B ∈ B，B 引入的状态量函数依赖 ρ(ψ) ⊆ ρ(B)，不依赖 Ω 层势函数的直接量。这与 X-S-MERA 工程版的 A11-R 公理同型。

### 5. 把 X₁X₂X₃ 作为附录 D 处理（备选）

如果用户希望迁回 8 月的内部时序三层，建议在 10 月版附录 D 加入「X 的内部时序分解」一节，标注为**待复测假设**：M 必出现在 X₂ 与 X₃ 之间；并在元规则章登记可证伪推论 R'''。

## 五、跨推论的批漏风险（透明度声明）

本方案涉及 4 条新的可证伪推论（R, R', R'', R'''），其中：

- **R**（d/D 反哺 ρ）— **最强**：直接由工程检验背书，BC<0.6 / Var 界已有预注册约束。
- **R'**（F1/F2 对应 P 分支）— **较强**：与工程分支一致，但需要新实验在 §4 量子-经典交集论域内执行 F2 检查（目前未做）。
- **R''**（势-流分离反哺基底）— **中等**：可立即被既有 LE 实验验证，但工程从未与基底完备性概念对接。
- **R'''**（X₁X₂X₃ 时序）— **最弱**：8 月有文本证据（X₁/X₂/X₃ 三类变体在 8 月稿中显式出现），但 10 月与工程版均无背书，且无独立证据支撑其"输入-萃取-输出"的时序解释。**v2 更新：用户的澄清确认了 8 月 X 是对象而非倾向，这使 X₁X₂X₃ 作为"对象的时序变体"有了文本根基，但工程侧仍无载体，故强度排序不变。**

递进原则：R 是回写，R' 需要新实验，R'' 需要重读既有实验，R''' 需要工程补做。在论文写作时建议严格按此顺序出现，避免把最弱的回填摆在最前的位置。
