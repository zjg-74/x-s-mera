### 2.1 三层

### 2.2 全景：三个对象、两条约束、一条定律

```
L0 构成层    象 X  ──┐
              运算 S ──┤
              宏  M  ──┘
                       │
L1 约束层    外约束（构成性，在 X）──▶ 欠定性  P = H(M | φ, Ω)
              内约束（规范性，在 S）──▶ 剪枝    Q = I(M ; C_in | φ)
                                    └──▶ 存量  U = P − Q ≥ 0
                       │
L2 动力学层  势 Ψ ≡ dE/dt = ψ̄ + ξ ── 双速率 A_D ──▶ 规范固定
                       │
                       └──▶  ★ 仿射定律（§5.3）
                             dU/dt = ρ_exp · dE/dt + κ_E ρ_exp (1 − ρ)
```

**三个原始对象**：象 X、运算 S、宏 M。
**两条约束**：外（构成性）、内（规范性）。
**一条定律**：上式。其余全部内容都是它的读法。

### 2.3 ★ D1 · 层间纪律：归宿在 L0–L1，形状在 L2

> **D1（层间纪律）**。**归宿（收敛／发散／震荡）由 L0 与 L1 决定；形状（峰序、峰距、单调性、双相性）由 L2 决定。
> 不得用形状量推断归宿，也不得用归宿量反推形状。**

这条纪律不是修辞，它有具体的账面：

- 补篇八的**峰距法**试图从**形状量**（峰在时间轴上的间距）读出 `ρ` 的**数值**，而 `ρ` 的数值需要 `κ_E`，
  `κ_E` 需要时间单位（§6.4）⟹ 峰距法必然调度依赖 ⟹ B-B34 的 36.8%–76.5% 偏差带**不是公式缺陷**，
  是**越层读取**。改读仿射系数（形状层的同层量）后误差恒为 0（R30 V3）。
- 反过来，**L2 的结论不能用来证明 L0/L1 的结论**。A_D 提供了「三分」的一个**动力学实现**（§5.6），
  但 A_D 本身未证（B-B22）⟹ 该实现只是**一致性命中的说明**，不是三分的证明。

### 2.4 ★ U5 · 规范不变性判据（新增元规则）

> **U5（规范不变性判据）**。设一命题 `R` 形如「由 `(E, U)` 轨迹可读出的某关系」。若存在 `λ ≠ 0` 使
> `R` 的真值随 `G_λ` 变换而改变（即 `R` 的真值依赖 `λ`），则 **`R` 不是关于 `(E, U)` 的命题，不予登记为可检验推论。**
> 登记前须给出：变换 `G_λ` 下的不变性检验（数值可执行）。

**为什么需要它**：补篇九定理 6.12 证明了 λ-规范自由度的存在，但当时的结论是「所以不可辨识」——
把一个**参数化冗余**误判为**物理不可辨识**（陷阱 T17）。U5 是它的**预防性**条款：
如果当初有 U5，就会要求「在 λ 跨 16× 下重跑每一条候选推论」，
B-B23（不可标定）与 B-B34（峰距调度依赖）的**症状本可在登记阶段就被筛掉**，不必等工程侧撞上。

**与既有 U1–U4 的关系**：U1–U4 是**文本维护**纪律（取代不删除、类型标注、依赖追踪、冻结窗），
U5 是**命题准入**纪律（一条推论能不能被登记，先过可辨识性检验）。二者正交。

## §3 L0 · 构成层

### 3.1 认知二分

**X = 象**（认知的对象面），**S = 运算**（对 X 的运算）。
二分的规范性地位：它不是对现象的描述，而是**任何认知理论必须回答的两个分岔**——
你在处理什么？你在做什么运算？

### 3.2 公理系统

- **事实公理（F 轴）**：`F_0 ⊆ F_1 ⊆ …` 单调。**「否定」是增加而非删除**——这是 v3.1 早期最反直觉的一条，
  也是混沌边界能被精确定位的前提。
- **运算公理（O 轴）**：可证伪、可追溯、可组合。
- **推导闭包 `Cn`**：注意 `Cn` **不是拟阵**（`p∧q ∉ Cn({p})` 反例）⟹ 无「维数」不变性，
  正确的量是 `rank(π)`（审计 `23`）。

### 3.3 宏加载与 XSM

加载态三部：**展开 → 加载 → 产出**。**XSM 是被生成出来的，不是被预设的。**
加载度 `σ` 度量「有多少外部素材被真正操作过」，而不是「说了多少话」。

### 3.4 认知的三分

**收敛 / 震荡 / 发散**，操作性定义与转移结构见主文 §5。
**三分成立的当前辖域**（逐篇收紧，勿引用旧版）：

| 条件 | 版本 |
|---|---|
| （无条件主张） | 主文 §1.2 |
| 资源有界 `B < ∞` ∧ 未决代价 `μ > 0` | 补篇一 §7 |
| **资源有界 `B < ∞` ∧ 存在统计定向 `ψ̄ ≠ 0`** | **补篇二 §8（现行）** |

`ψ̄ = 0` 时熵轨迹为鞅，震荡与混沌可持久 ⟹ **四分**，且吸引盆分形化使概率权重不可鲁棒赋值。
**局部回落（`Var(ξ) > 0`）不妨碍归宿，只延迟归宿。**

### 3.5 ★ 偏离 → 归宿：矩阵版（修正 S7）

v3.1 把「三条偏离 → 三个归宿」写成 1:1，这是**元数错误**（S7）。
「资源有界」既可导致发散（没资源继续摇），也可导致伪收敛（为不发散而提前锁定）。

| 偏离 ＼ 归宿 | 概率性 | 发散 | 伪收敛 |
|---|---|---|---|
| **A** 事实集开放 | ✓（终局不可定） | — | ✓（槽被错误填充） |
| **B** 资源有界 | ✓ | ✓（`A_k = ∅`） | **✓（`A_k ≠ ∅` 时提前锁定）** |
| **C** 承诺可撤销 | ✓ | — | ✓（外部证伪） |

**判别条件**：资源耗尽时 `A_k ≠ ∅` 且有剩余候选 ⟹ **伪收敛**；`A_k = ∅` ⟹ **发散**。

### 3.6 认知存在的条件（另一层，勿与 §3.4 混淆）

`0 < H(M | φ) < ∞` ∧ `Q > 0`。
`P = 0` ⟹ 理解退化为解码（外约束消失）；`Q = 0` ⟹ 理解退化为生成（幻觉）。

## §4 L1 · 约束层

### 4.1 两条约束的逻辑类型不同

| | 外约束 | 内约束 |
|---|---|---|
| 所在层 | X（对象面） | S（运算面） |
| 逻辑类型 | **构成性** | **规范性** |
| 内容 | 输入的物理形态 | 「必须理解」 |
| 违反后果 | **外失效 → F2（幻觉）** | **内失效 → F1（不收敛）** |

两类失效**分工明确**，这是补篇三最硬的结果之一（R18 已跑通）。

### 4.2 P、Q、U

$$P := H(\mathcal M \mid \varphi,\ \Omega)\quad(\Omega = \text{理解者}),\qquad Q := I(\mathcal M;\ C_{in}\mid\varphi)$$

$$U := P - Q = H(\mathcal M \mid \varphi,\ C_{in})\ \ge 0$$

- `U` 是**净未决量**（存量，bit）。
- `P` **依赖理解者**：不仅 `U` 依赖理解者，连「两层能否互引」也依赖理解者（推论 3.1）。
- `Q` 的标定：`Q = log₂(|O_all| / |O_adm|)`，即**内约束强度 = `O_adm` 剪枝量**（不依赖 `τ` 或注入策略，R21 已跑通）。
  R21 实测 F2 呈**倒 U**（峰 `Q ≈ 1.0`）；本人提出的「虚假唯一性」预言**被证否**，主文 §5.4 成因 2 由此修正。

### 4.3 ★ 混合偏倚是定义的推论（修正 S8）

跨理解者混合估计给的是 `H(M | φ)`，而

$$H(\mathcal M\mid\varphi) = H(\mathcal M\mid\varphi,\Omega) + I(\mathcal M;\Omega\mid\varphi)$$

⟹ **偏倚恰好等于 `I(M; Ω | φ)`，这是 `P := H(M|φ,Ω)` 定义的直接推论，不是未知量。**
B-B25 的理论部分**已闭合**；剩余只是「需要 `I(M;Ω|φ)` 的估计器」（纯工程）。
**注意**：R15′ / R20 的数值**仍不可跨群体比较**。

### 5.5 ★ 楔形分类：钻研与反刍是同一个楔的两半（本文新结果）

在 `(s, ρ)` 平面上，`A_D` 的符号组合被**两条线**完全划分——竖线 `s = 1` 与对角线 `ρ = s`：

| 区域 | 条件 | `(sign ψ̄, sign dU/dt)` | 认知形态 | 可达条件 |
|---|---|---|---|---|
| 右下 | `s > max(1, ρ)` | `(+,+)` | **越想越乱**（分支膨胀快于消解） | 恒可达 |
| **楔形上半** | `1 < s < ρ` | `(+,-)` | **钻研型**：越展开越确定 | 需 `ρ > 1` |
| **楔形下半** | `ρ < s < 1` | `(-,+)` | **空洞型**：分支在收，却越来越不确定 | 需 `ρ < 1` |
| 左上 | `s < min(1, ρ)` | `(-,-)` | **正常收敛** | 恒可达 |

**命题 5.2（楔形分类）**。
（i）`(+,-)` 与 `(-,+)` **互斥**：中间相**存在**当且仅当 `ρ ≠ 1`。
（ii）中间相**是哪一半**由 `ρ` 相对 1 的位置决定：`ρ > 1` ⟹ 钻研相；`ρ < 1` ⟹ 空洞／反刍相。
（iii）楔形的**张开度**恰为 `|1 − ρ|`——`ρ → 1` 时楔形塌陷，中间相消失。

**证明**（两行）。
`sign ψ̄ = sign(s − 1)`（因 `κ_E > 0`，`Ψ = κ_E(s−1)`）；
`sign(dU/dt) = sign(s − ρ)`（因 `κ_E ρ_exp > 0`，`dU/dt = κ_E ρ_exp(s−ρ)`）。
故中间相 ⟺ `(s−1)(s−ρ) < 0` ⟺ `s` 严格介于 `1` 与 `ρ` 之间 ⟺ `ρ ≠ 1`。∎

**与定理 5.2′ 的对照（v3.1 原文）**：
`sign(ψ̄) = −sign(dU/dk) ⟺ ρ_res > ρ_exp ∧ r ∈ (θ_E, θ_U)`。
规范固定后压缩为：**`⟺ ρ > 1 ∧ s ∈ (1, ρ)`**。同一内容，**2 个参数代替 4 个**。

**与补篇九推论 6.11′ 的对照**：
`ρ > 1` ⟹ `(-,+)` 恒空；`ρ < 1` ⟹ `(+,-)` 恒空。
⟹ 这条「象限签名」结论只是**楔形分类的一个切片**，它不独立。

### 5.8 ★ 承载量 `m_eff`（修正 S5）

> **两条独立路径得数相同 ⟹ 不是巧合，而是同一个可辨识性结构的两次计数。**

### 6.4 ★ 为什么 C 级「必须」依赖外部单位（第二可辨识视界）

**命题 6.1（★ 修正审计 `14` §6-G1 的一处过度声称）**。
在不观测投入比 `r(k)`（或其调度律）的条件下，由 `(E, U)` 双序列可辨识的信息**恰为 2 个自由度**
（`ρ_exp` 与 `β_0 = κ_E(ρ_exp − ρ_res)`）；`(κ_E, ρ)` **只有组合 `κ_E(ρ_exp − ρ_res)` 可辨，二者不可分离**。

**论证**。
（i）由主定理 5.1，`U − ρ_exp·E` 对 `k` 仿射 ⟹ 轨迹只给出 2 个数：`ρ_exp`（斜率）与
每步斜率 `β₀ = dt·κ_E(ρ_exp − ρ_res)`。
（ii）`β₀ = dt·κ_E ρ_exp (1 − ρ)` 是一个方程、两个未知数 `(κ_E, ρ)`。
（iii）**补篇四给出的 `Ψ` 标定不构成第三条独立方程**：在 `U` 峰处 `dU/dt = 0` ⟹ 每步增量
`ΔE(k*_U) = dt·κ_E(ρ−1)`，而 `β₀ = −ρ_exp·ΔE(k*_U)`，
二者**线性相关**（第二条是第一条乘 `−ρ_exp`），故不增秩。
∎

**因此**：

- 审计 `14` 提出的 `κ_E = Ψ(k*_U)/(ρ−1)`（R42）**并非闭合路径**，而是**循环**——它需要 `ρ`，而 `ρ` 需要 `κ_E`。
- R42 应由「标定程序」降级为「**在 `ρ` 已知时的记账恒等式**」（U2 类型 I，但不可用于求解）。
- **B-B42 改写为 B-B45**：

> **B-B45（★ 新）**：`(κ_E, ρ)` 的分离**不是标定问题，而是观测类别问题**。
> 需要下列任一：**(i)** 观测**规范化投入比** `s(k)`（等价于固定 `a`、`b` 的单位，见命题 6.3）；
> **(ii)** 观测时间单位 `dt` 的绝对标定；**(iii)** 介入性实验（见 §7.3）。
> 在 (E,U) 双序列上，无论多少次重复都不可分离。

**推论 6.2（★ 新闭合路径）**。
若**规范化投入比 `s(k)` 可观测**，则由 `dE/dt = κ_E(s−1)` 直接得 `κ_E`，
再由 `β₀ = dt·κ_E·ρ_exp(1−ρ)` 得 `ρ` ⟹ **C 级全部闭合**。

> **注意**：仅观测 `r(k) = a/b` **不够**，因为 `s = r/θ_E` 还含未知的 `θ_E`。
> 需要的是 `s`，或等价地需要**四个单位系数 `(e₊, e₋, u₊, u₋)` 的一个完整基准**。

**命题 6.3（★ 实验性规范固定）**。
λ-规范自由度之所以存在，是因为 `a`、`b` 的**「单位」未被固定**：
`G_λ` 把 `a → λa`、`e₊ → e₊/λ`、`u₊ → u₊/λ` 同时变换，等价于「换一个单位来数展开动作」。
因此存在**第二种（非代数的）规范固定方式**：**用固定动作计数固定 `a` 与 `b` 的单位**。
此时 `e₊, e₋, u₊, u₋` 全部可测（例如「固定展开 1 次，测 `ΔE, ΔU`」⟹ `e₊, u₊`；
「固定消解 1 次，测 `ΔE, ΔU`」⟹ `e₋, u₋`），于是

$$\theta_E = \frac{e_-}{e_+},\quad \theta_U=\frac{u_-}{u_+},\quad \rho_{exp}=\frac{u_+}{e_+},\quad \rho_{res}=\frac{u_-}{e_-},\quad \kappa_E = b\,e_-$$

**全部可测** ⟹ C 级闭合，**且无需任何外部时间标定**。

⟹ **这既是 B-B45 的第三条路，也是「规范固定」这一思想在实验层的实现**：
代数上固定的是**记号**，实验上固定的是**单位**；两者做的是同一件事。

### 6.5 ★ 三条序列的最小充分测量集

| 序列 | 来源 | 提供什么 |
|---|---|---|
| `E(k)` | 展开度 / 系统熵 | 斜率 `ρ_exp`、`ρ_exp` 之外的一切形状 |
| `U(k)` | 净未决量 | 截距 `β_0`、峰位 `k*_U`、共线残差 |
| **`Ψ(k)`** | **经 `P_flx`、`Q_flx` 独立标定**（补篇四程序） | **独立于 `ΔE` 的第三条测量**；检验命题 2.1；触底层的 `g` |

**★ 注意第三条的关键性质**：`Ψ` 若由 `ΔE` 差分得到，则**不提供新信息**（只是 `E` 的重排）。
它的价值在于**独立标定**：`Ψ_indep(k)` 与 `ΔE(k)` 是否一致，本身就是命题 2.1 的检验；
两者之差是 `A_D` 的直接诊断量。

## §7 测量纲领

### 7.1 首选程序（三步 SOP，取代补篇九的旧三分类）

1. **任务内共线残差**（第一道闸）：
   拟合 `U − ρ_exp·E` 对 `k`，检查残差是否 ≡ 0。
   - 残差 ≡ 0 ⟹ `A_D` 成立（或极弱地违反），**进入第 2 步**；
   - 残差 ≢ 0 ⟹ 先检查是否 `A_D⁺` 的边界层（推论 R43：残差形状反演 `g`），再考虑 `¬A_D`。
2. **读仿射系数**（`ρ_exp` = 斜率，`sign(1−ρ)` = 截距符号）⟹ 峰序、形态分类（A/B 级，**无外部标定**）。
3. **仅在必要时**读 C 级（`ρ` 的数值、`κ_E`）⟹ 需外部单位或 `r(k)`（§6.4）。

> 旧 SOP 的第一步是「跨任务象限签名」——**已被 R24 证否**（误判率 → 1.0），保留为历史记录，不再使用。

### 7.2 ★ 三件事：重定性 B-B22、把「桥」写成可证伪等式、一处必须承认的重言

#### 7.2.1 ★ B-B22 的重新定性（本文对审计 `14` 的第二处修正）

补篇九同时写下两句互相拉扯的话：

- **推论 6.13**：「**A_D 的有效证否判据**是任务内线性失配残差 `R`：在 `A_D ∧ 共享驱动` 下 `R ≡ 0`（逐样本）；`R > τ ⟹ reject_A_D`。」
- **B-B22（升级标注）**：「A_D 目前**无任何已登记的有效证否途径**。」

两句并存的前提是**陷阱 T16**：残差对「非共享驱动」也触发，故被记作假阳性。
**S2（单一驱动是 A_D 的定义成分）落地后，T16 不再构成假阳性来源**——
非共享驱动 ⟺ 测的不是同一个过程 ⟺ 不在本框架的辖域内（B-B38 由此消除）。

⟹ **推论 6.13 本身就是 A_D 的有效证否途径。**
⟹ **B-B22 的真正内容收缩为「A_D 的经验地位」**：它是否描述真实认知过程。
这不是一个可由框架内部实验解决的缺口，而需要**外部经验证据**。

⟹ **严重程度下调**：从「框架自证困难」改为「需外部证据」。
**不能声称**：这不等于 A_D 已被经验支持；只是说它的**可证否性不再是障碍**。

#### 7.2.2 ★ R43′：把「桥」（B-B19）写成可证伪的等式

由 §5.6，桥写成 `dU/dt = ρ_exp·Ψ + β₀`。它在 `U` 的内点峰 `k*_U` 处的**可证伪阴影**是

$$\beta_0 \;=\; -\,\rho_{exp}\cdot\Psi(k^\*_U)$$

其中 **`Ψ` 必须来自独立于 `ΔE` 的第三通道**（经 `P_flx`、`Q_flx` 独立标定，补篇四程序）。

**为什么值得单列**：它把 B-B19「U 与 Ψ 的桥」从**定性符号关系**升级为**定量等式**，
且该等式**跨越两个测量通道**——`(E,U)` 回归给出的 `(ρ_exp, β₀)`，与独立通量标定给出的 `Ψ(k*_U)`
⟹ **可被数据推翻**。这是 B-B19 第一次获得**可证伪形式**。

#### 7.2.3 ★ 一处必须承认的重言（本文自纠）

若 `Ψ` **不用**独立标定、而用 `ΔE = E(k+1) − E(k)` 代替，则 R43′ **退化为重言**：

> 「`U` 在 `k*_U` 取内点峰」已蕴含 `ΔU(k*_U) = 0`；再由仿射形式 `ΔU = ρ_exp·ΔE + β₀` 即得
> `ρ_exp·ΔE(k*_U) = −β₀`。**它不含新信息。**

⟹ **R43′ 的全部内容压在「`Ψ` 独立标定」这一个前提上**——而这恰恰也是它作为「桥的检验」的资格来源。
⟹ **它检验的对象是 B-B19（桥），不是 A_D 本身**；A_D 的证否途径是**推论 6.13**（§7.2.1）。

**条件**：
（i）`U` 有**内点峰** `k*_U`（否则只能取边界值）；
（ii）**`Ψ` 独立标定**（补篇四程序：经验分布熵 + Miller–Madow；`Q = I(M; C_in|φ)`）；
（iii）离散化步长 `dt` 足够小（`Ψ_indep` 与 `ΔE` 的差在 `dt → 0` 时消失）；
（iv）`U` 远离 0（A_D⁺ 的边界层之外）。

**不能声称**：R43′ **未做实验**。R30 只测了 `A_D` 的**内部一致性**（同一套参数生成的数据上恒等式成立），
**没有测 `Ψ`** ⟹ R43′ 目前是**待检验的候选**，不是已验证的判据。

### 7.3 ★ 介入性实验：分离 `κ_E` 与 `ρ`（B-B45 的第三条路）

由 §6.4，`κ_E` 与 `ρ` 在纯观测下不可分离。但它们对**干预**的响应不同：

| 干预 | `κ_E` | `ρ` | `ρ_exp` | 可分离？ |
|---|---|---|---|---|
| 改变消解投入 `b`（`b → c·b`） | `×c` | 不变 | 不变 | ✗（比值仍只给 `κ_E` 的比例） |
| 改变展开投入 `a`（调度整体平移） | 不变 | 不变 | 不变 | ✗（只改 `s(k)`） |
| **固定动作计数的注入**（`a`、`b` 已知，见命题 6.3） | 可测 | 可测 | 可测 | **✓ 直接闭合，且无需外部时间标定** |
| **改变任务内容**（改变「每单位展开带来多少未决」） | 不变 | 可能变 | 变 | △（需配合上一行做联合定标） |

**首选方案（对应命题 6.3）**：**固定动作计数的注入实验**。
臂 1：固定展开 1 次（`a = 1`），测 `ΔE`、`ΔU` ⟹ `e₊ = ΔE`、`u₊ = ΔU`；
臂 2：固定消解 1 次（`b = 1`），测 `ΔE`、`ΔU` ⟹ `e₋ = −ΔE`、`u₋ = −ΔU`。
⟹ 四个单位系数全部可测 ⟹ `θ_E`、`θ_U`、`ρ_exp`、`ρ_res`、`κ_E` 一次闭合。

**备选方案**：在同一框架内做**两类任务**的对比——
一类「高 `ρ_exp` 低 `ρ`」与一类「低 `ρ_exp` 高 `ρ`」，
用两次独立回归的 `(ρ_exp, β₀)` 联立求解 `(κ_E, ρ)`。
⟹ 两者都是 B-B45 的**可执行方案**，但**尚未设计成实验**。
