## §0 出发点与总结论

补篇六 §3.6 证明了推论 6.5（峰距标定式）。补篇六 §5 把它登记为 **R29**，
并评述"设计干净，是 B-B23 的唯一已知标定途径"。

但**公式正确 ≠ 程序可用**。本补篇要问的是：把它当估计程序用时，

- 什么是**可辨识**的？
- 在哪一段**可用**？
- 什么时候会**静默地给出错误答案**？

### 总结论

> **序可辨识，且逐样本守恒（定理 6.10）；**
> **距只可辨识到比值，且只在 r 调度族已知时（T9、臂 D）。**

> 峰序给出 $\ln(\rho_{res}/\rho_{exp})$ 的**符号**，峰距给出其**量值之比**；
> 前者在共享驱动下零错误，后者随调度误设可偏 37%–77%。

## §1 记号与模型（与 R27 / R28 逐字一致）

A_D（补篇五 §1.2）双速率分解：

$$dE = dt\,(a\,e_+ - b\,e_-),\qquad dU = dt\,(a\,u_+ - b\,u_-)$$

取 $b=1$、$r := a$，并定义

$$\theta_E = e_-/e_+,\quad \theta_U = u_-/u_+,\quad
  \rho_{exp} = u_+/e_+,\quad \rho_{res} = u_-/e_-$$

于是 $\mathrm{sign}(dE) = \mathrm{sign}(r-\theta_E)$、$\mathrm{sign}(dU) = \mathrm{sign}(r-\theta_U)$，且有恒等式

$$\theta_U/\theta_E = \rho_{res}/\rho_{exp}$$

A_D^stat（补篇七 §2）：噪声进**过程层**而非观测层，

$$r_k = \bar r_k\,\exp\!\big(s Z_k - \tfrac12 s^2\big),\qquad E[r_k] = \bar r_k$$

**灵敏度常数**：$C := (K-1)/L$，$L := \lvert\ln(r_{lo}/r_{hi})\rvert$。
本原型 $K=241$、$r:9\to 1/9$ ⟹ $L = 4.3944$、$C = 54.614$ **步 / e 倍**。

## §3 臂 A/B：公式精确性与恢复精度

### 3.1 臂 A（无噪声）

$\Delta_{obs}$ 与 $\Delta_{pred}$ 逐点比对：最大残差 **0.898 步**；
过原点最小二乘 $C_{fitted}=54.506$ vs $C_{theory}=54.614$（偏 −0.20%）。

> **0.898 步是离散化硬界，不是误差。** 峰位是"最后一个增量为正的索引"，
> 与连续穿越点相差至多 1 步；两峰各至多 1 步 ⟹ $\lvert\Delta_{obs}-\Delta_{pred}\rvert\le 1$ 恒真。

## §4 定理 6.10：U−E 线性恒等式与峰序**路径级**守恒 ★

**本轮最重要、且不在原计划内的结果。**

### 4.1 陈述

> **定理 6.10（峰序守恒）**。在 A_D 下，设 E 与 U 由**同一** r 过程驱动。
> 令 $U^s := U/\rho_{exp}$（按 $\rho_{exp}$ 归一化 U 的单位；这**不改变其峰位**）。
> 则对每个样本路径、每个 k：
> $$U^s(k)-E(k) = \Big(\frac{U_0}{\rho_{exp}}-E_0\Big)\;+\;dt\cdot e_-\Big(1-\frac{\rho_{res}}{\rho_{exp}}\Big)(k+1)$$
> **与 r 及噪声完全无关**。从而逐路径地：
> $$\rho_{res}>\rho_{exp}\ \Longrightarrow\ k^\*_U\le k^\*_E,\qquad
>   \rho_{res}<\rho_{exp}\ \Longrightarrow\ k^\*_U\ge k^\*_E$$

### 4.2 证明

**恒等式部分**：
$$U(k)-U_0 = dt\sum_{j\le k}(r_j u_+ - u_-),\qquad
  E(k)-E_0 = dt\sum_{j\le k}(r_j e_+ - e_-)$$
除以 $\rho_{exp}$，用 $u_+/\rho_{exp} = e_+$，及
$$\frac{u_-}{\rho_{exp}} = \frac{u_- e_+}{u_+}
  = e_-\cdot\frac{u_-/e_-}{u_+/e_+} = e_-\cdot\frac{\rho_{res}}{\rho_{exp}}$$
两式相减，$r_j e_+$ 项**完全相消**：
$$\frac{U(k)-U_0}{\rho_{exp}} - \big(E(k)-E_0\big)
  = dt\sum_{j\le k} e_-\Big(1-\frac{\rho_{res}}{\rho_{exp}}\Big)
  = dt\,e_-\Big(1-\frac{\rho_{res}}{\rho_{exp}}\Big)(k+1)\quad\blacksquare$$

**峰序部分**：$U^s-E$ 是 k 的线性函数，斜率符号为 $\mathrm{sign}(\rho_{exp}-\rho_{res})$。
设 $m=\arg\max E$、$n=\arg\max U^s$。若 $n>m$，则
$U^s(n)\ge U^s(m)$（n 是 U^s 的极大点）且 $U^s(n)-E(n) < U^s(m)-E(m)$（严格递减），
相减得 $U^s(n)-U^s(m) < E(n)-E(m)\le 0$（m 是 E 的极大点），矛盾。故 $n\le m$。∎

### 4.3 与推论 6.4 的关系

| | 推论 6.4（补篇六） | 定理 6.10（本补篇） |
|---|---|---|
| 断言强度 | 期望 / 确定性轨迹层面 | **每个样本路径** |
| 对噪声 | 未区分噪声位置 | 要求 E、U **共享**同一 r 过程 |
| 结论 | $k^\*_U < k^\*_E$ | $k^\*_U \le k^\*_E$（允许并列） |

> 定理 6.10 **强化**了推论 6.4（从集合层面到路径层面），
> 同时**明确**了它的前提（共享驱动）与边界情形（并列）。

### 4.4 失效条件

证明只用到了「$E$、$U$ 由同一 $r$ 驱动」+「$e_+ = u_+^s$」。
若两路噪声**独立**，恒等式被破坏，峰序**可以判反**——臂 F 直接测了这一点。

## §5 臂 C：比率设计（C 未知）

推论 6.5 含未知常数 $C$。取两条件之比可消去：
$$\frac{\Delta_1}{\Delta_2}=\frac{|\ln\rho_1|}{|\ln\rho_2|}$$

| 子臂 | 最差相对误差 | 判定 |
|---|---|---|
| **C1**（同 K=241） | 0.0273 | ✓ 成立 |
| **C2** raw 比值（K 不同） | **1.0059** | ✗ 约 2 倍系统偏 |
| **C2** 归一化 $\delta=\Delta/(K-1)$ | 0.1057 | ✓ 修复 |

> **对补篇六 §5 的修正**：原文要求"r 调度保持相同"。臂 C2 表明实际需要的是
> **两端点 $(r_{hi},r_{lo})$ 相同**（从而 $L$ 相同）；**K 不必相同，但必须归一化**。
> 且归一化只消除系统因子，**不恢复分辨率损失**：K 减半 ⟹ Δ 减半 ⟹ 同样的 ±1 步离散误差相对翻倍。

## §6 臂 D：调度误设（负面结果）

真实调度非对数斜坡时，仍按推论 6.5 反解：

| 真实调度 | 最差相对误差 |
|---|---|
| **log_ramp**（正确） | 0.0386 |
| linear_ramp | **0.7650** |
| sigmoid_ramp | **0.5484** |
| piecewise_ramp | **0.3678** |

**原因**：推论 6.5 依赖 $k^\*(\theta)=g(\ln\theta)$ 关于 $\ln\theta$ **仿射**——
这只在对数斜坡下成立。一般调度下可辨识的量是

$$\Delta=\big|g(\ln\theta_E)-g(\ln\theta_U)\big|$$

即两个阈值在对数尺度上的距离经 $g$ 映到 k 空间的长度，**不是** $\ln\rho$ 本身。

### 推论 6.5′（可辨识性的准确表述）

> R29 可辨识的量是 $\Delta$（k 空间中 E 峰与 U 峰的间距）；
> 仅当 $g$ 仿射（即 r 为对数斜坡）时，$\Delta = C\cdot\lvert\ln\rho\rvert$。
>
> **这是 B-B23 只能"部分闭合"的根本原因**：要得到 $|\ln\rho|$ 的绝对值，
> 除了峰距还须独立知道 r 调度族；否则只能得到**组间比值**。

## §7 臂 E：可辨识性视界

可辨识条件：两个峰都必须是**内点**。由 $\theta_U = \rho\,\theta_E$：

$$\ln\rho\ \in\ \big(\ln r_{lo}-\ln\theta_E,\ \ \ln r_{hi}-\ln\theta_E\big)$$

> **视界律**：$\ln\rho$ 的可测窗口**宽度恰为 $L=\lvert\ln(r_{hi}/r_{lo})\rvert$**，中心为 $-\ln\theta_E$。

本原型窗口 $\ln\rho\in(-2.1972,+2.1972)$。实测 $\ln\rho=2.1$ 仍可测（$\Delta=114$ 步），
$\ln\rho\ge 2.2$ 峰落窗外、不可测 ✓。

**设计含义**：要标定更宽的 ρ 比值范围，必须让 r 扫过相应更宽的范围。
**这是硬约束，不是精度问题**——超界时程序不报错，只是测不到峰（陷阱 T10）。

## §8 臂 F：峰序分辨率极限——**并列 ≠ 判反**

必须区分两种失效：**判不出（并列）** vs **判错（判反）**。

| 噪声条件 | 最大 tie 率 | 最大 err 率 |
|---|---|---|
| **shared**（共享同一 r 过程） | 0.7625 | **0.0000** |
| **indep**（各带独立噪声） | 0.0850 | **0.4125** |

- **shared**：误差率恒为 0，与 s 无关 → 印证定理 6.10。
  噪声增大只把结果推向"不确定"，**不会推向"判反"**。
- **indep**：守恒律破裂，误差率随 s 上升、随 $|\ln\rho|$ 增大快速降到 0。

> **操作规程推论**：峰序是**优雅退化**的观测量——失效时它说"不知道"，
> 而不是说错的答案。前提是 E 与 U 确实共享驱动（B-B37）。

## §9 R29 操作规程（标准用法）

1. **取双条件对照**：同一批理解者、同一任务族、不同宏库结构（改变 $\rho_{res}/\rho_{exp}$）。
2. **固定 r 调度端点** $(r_{hi}, r_{lo})$；K 可不同，但必须**归一化** $\delta=\Delta/(K-1)$。
3. **先判内点**：任一侧峰贴窗 ⟹ 该条件不可辨识，剔除（不是"ρ 比值很小"）。
4. **读符号**：由峰序（U 峰在前 ⟺ $\rho_{res}>\rho_{exp}$）得 $\ln\rho$ 的符号。
5. **读比值**：由 $\delta$ 之比得 $|\ln\rho|$ 之比；**不要**直接报绝对值。
6. **记录粗粒化尺度**：显著度 $h$ 优先于平滑窗口 $w$（$w$ 会移动峰位、合并近邻双峰）。
7. **报告 CI**：用 bootstrap，不要用"峰位 ± 1 步"的朴素估计（离散化偏是系统性的）。
