## §3 定理 6.11：任务内线性失配守恒

> **定理 6.11（线性失配守恒）**
>
> 设在单个任务上 `A_D` 成立，且 `dE` 与 `dU` 由**同一个**驱动序列 `{r_k}` 生成。
> 则对**每一条样本路径**（不取期望、不取极限）：
>
> $$U(k) - \rho_{exp}\,E(k) = \alpha + \beta k \qquad (\text{关于 } k \text{ 仿射})$$
>
> 其中
>
> $$\beta = dt\,e_-(\rho_{exp}-\rho_{res}), \qquad
>   \alpha = U(0) - \rho_{exp}E(0)$$
>
> 因而等价地
>
> $$\mathcal{R} := \min_{v}\ \big\lVert \Pi^\perp (v\,U - E)\big\rVert_{RMS} \equiv 0$$
>
> 且最小值在 $v^\* = 1/\rho_{exp}$ 处取得。

### 证明

由 A_D，对每个 `k`：

$$dU_k = dt\,(r_k u_+ - u_-),\qquad dE_k = dt\,(r_k e_+ - e_-)$$

由 $\rho_{exp} = u_+/e_+$ 得 $u_+ = \rho_{exp} e_+$，于是

$$dU_k - \rho_{exp}\,dE_k
   = dt\big[(r_k u_+ - u_-) - \rho_{exp}(r_k e_+ - e_-)\big]
   = dt\big[r_k(u_+ - \rho_{exp}e_+) + (\rho_{exp}e_- - u_-)\big]$$

第一项为 0。第二项中 $\rho_{exp}e_- = (u_+/e_+)e_- = \rho_{res}e_- \cdot (e_-/e_-)$… 直接用
$\rho_{res} = u_-/e_-$ 得 $u_- = \rho_{res}e_-$，故

$$dU_k - \rho_{exp}\,dE_k = dt\,e_-(\rho_{exp} - \rho_{res}) =: \beta$$

**关键**：$\beta$ 与 `k` 无关，也与 `r_k` 的实现无关。对 `k` 求和：

$$U(k) - \rho_{exp}E(k) = \big[U(0) - \rho_{exp}E(0)\big] + \beta k$$

即关于 `k` 仿射。`Π^⊥` 消去 $\mathrm{span}\{1,k\}$ ⟹ 残差逐样本为 0。∎

### 3.1 推论：R24 签名是定理 6.11 的推论

**推论 6.11′**：在 `A_D ∧ 共享驱动` 下，增量云 `{(dE_k, dU_k)}` **共线**，
所在直线斜率为 $\rho_{exp}$、截距为 $\beta$。因此：

| 条件 | 可进入的象限 | 不可进入的象限 |
|---|---|---|
| $\rho > 1$（$\beta < 0$） | `(+,+)`、`(+,−)`、`(−,−)` | **`(−,+)`** |
| $\rho < 1$（$\beta > 0$） | `(+,+)`、`(−,+)`、`(−,−)` | **`(+,−)`** |
| $\rho = 1$（$\beta = 0$） | `(+,+)`、`(−,−)` | 两者皆不可 |

⟹ **签名（哪个象限为空）完全由 ρ 的符号决定，与 θ_E、e±、u± 无关。**
这正是臂 A 的观察（跨任务签名一致）。

⟹ 同时，**R24 的象限签名严格弱于共线性**：它是共线性的一个推论，
只捕捉"云是否跨越了被禁止的象限"，而共线性捕捉"云是否偏离直线"。
任何使云弯曲但对禁止象限影响很小的违反（§3.2）都无法被 J1/J2 探测。

### 3.2 二次注入下残差的精确形式

在注入 `dE ← dE − dt·ε·r²` 下：

$$U(k) - \rho_{exp}E(k)
   = \alpha + \beta k + \rho_{exp}\,\varepsilon\,dt\sum_{j\le k} r_j^2$$

⟹

$$\boxed{\ \mathcal{R} = \rho_{exp}\,\varepsilon\,dt\,
   \big\lVert \Pi^\perp\,\mathrm{cumsum}(r^2)\big\rVert_{RMS}\ }$$

右侧只依赖**驱动调度**，与 $\theta_E, e_\pm, u_\pm$ **无关**。

**数值验证**（臂 E2，$\rho_{exp}=1$）：

$$\mathcal{R}/\varepsilon = 0.81459$$

在 $\theta_E \in \{0.5, 1.0, 2.0\}$、$\varepsilon \in [0.05, 1.0]$（跨 20 倍）上
**六位有效数字完全一致**。⟹ **预言 R38 确认**。

## §6 定理 6.12：A_D 的规范自由度

> **定理 6.12（规范自由度 / 标定不可辨识性）**
>
> 对任意 $\lambda > 0$，定义变换
>
> $$G_\lambda:\quad r_k \mapsto \lambda r_k,\quad
>   e_+ \mapsto e_+/\lambda,\quad u_+ \mapsto u_+/\lambda,\quad
>   e_-,\ u_- \text{ 不变}$$
>
> 则在 A_D 下，序列 $\big(E(k), U(k)\big)_{k=0}^{K-1}$ **逐点不变**。
>
> 因而在**任何只是 $(E,U)$ 的函数的可观测量**下，
> 量 $r$ 的绝对尺度、以及 $e_+, e_-, u_+, u_-$ 的绝对值，**均不可辨识**。

### 证明

$$dE' = dt\,(\lambda r_k \cdot e_+/\lambda - e_-) = dt\,(r_k e_+ - e_-) = dE$$

$$dU' = dt\,(\lambda r_k \cdot u_+/\lambda - u_-) = dt\,(r_k u_+ - u_-) = dU$$

逐点成立 ⟹ 从相同初值出发的累加序列逐点相同。∎

### 6.1 规范不变量

在 $G_\lambda$ 下：

| 量 | 变换 | 是否不变 |
|---|---|---|
| $\theta_E = e_-/e_+$ | $\to \lambda\theta_E$ | 否 |
| $\theta_U = u_-/u_+$ | $\to \lambda\theta_U$ | 否 |
| $e_+,\ u_+$ | $\to e_+/\lambda,\ u_+/\lambda$ | 否 |
| $e_-,\ u_-$ | 不变 | **是** |
| $\rho_{exp} = u_+/e_+$ | 不变 | **是** |
| $\rho_{res} = u_-/e_-$ | 不变 | **是** |
| $\rho = \theta_U/\theta_E$ | 不变 | **是** |

⟹ **独立规范不变量恰为 2 个**（三者满足 $\rho = \rho_{res}/\rho_{exp}$）。

**与推论 6.4 / 6.5 的一致**：峰序给 $\ln(\rho_{res}/\rho_{exp})$ 的符号，峰距给其量值 ⟹
可辨识的恰好是规范不变量 $\rho$。这解释了**为什么**只有 ρ 可辨识：不是技术的限制，是结构的限制。

| 0.25 | 0.25 | 0.50 | 4.00 | 4.00 | 1.00 | 2.00 | **0.00e+00** | **0.00e+00** |

## §7 操作规程（三分类 SOP）

给定一组任务 $\{i\}$，每个任务测得一对轨迹 $\big(E_i(k), U_i(k)\big)$：

**步骤 1 · 重复与平均（T16 必需）**
每个任务重复测量 $N \ge 16$ 次，逐点平均得 $\bar E_i, \bar U_i$。

**步骤 2 · 估计噪声地板**
由 $N$ 次重复的组内散度估计 $\tau_i \approx \kappa\,\sigma_{obs}/\sqrt{N}$。
**不要用绝对常数作为阈值。**

**步骤 3 · 判据 J3（首选，任务内）**

$$\mathcal{R}_i = \min_v \big\lVert \Pi^\perp (v\,\bar U_i - \bar E_i)\big\rVert_{RMS}$$

- $\mathcal{R}_i > \tau_i$ ⟹ **`reject_A_D`**（与任务结构无关，逐样本，不受 ρ-任务依赖影响）

**步骤 4 · 判据 J1（次选，跨任务；仅在步骤 3 全部通过后使用）**
- 跨任务签名并存 ⟹ **`rho_task_dependent`**（**A_D 仍成立**）

**步骤 5**
- 否则 ⟹ **`accept`**

**关键纪律**：**J1 必须在 J3 之后使用。** R24 原登记把二者混为一谈，这正是 T12 的来源。

**验证**（臂 F）：三类数据集 × 5 个噪声水平 = **15/15 全部判对**；
同一批数据上 R24 原判据 **5/5 误判 D3**。

## §11 作用域声明与不能声称的清单

**本补篇的全部结论都在 A_D 原型内部成立**（一个由 `dE = dt(r e₊ − e₋)`、
`dU = dt(r u₊ − u₋)` 定义的形式对象）。它们**不**是关于真实认知系统的经验断言。

不能声称：

1. **不能声称 A_D 已被检验为真。** 只检查了推导结构，未接触真实数据。
2. **不能声称 ρ 在真实理解者中是否依赖任务。** 臂 B 证明的是条件命题。
3. **不能声称残差判据对 ¬A_D 充分。** 它只证否 `(A_D ∧ 共享驱动)`（N5/T16）。
4. **不能声称 ε 的探测窗口具有外部有效性。** 窗口依赖 K、dt、r 窗口、平滑宽度（N4）。
5. **不能声称四个系数在任何意义上被标定了。** 定理 6.12 给出规范自由度。
6. **不能声称 η 的取值有心理学含义。** `ρ_i = ρ₀exp(η z_i)` 是操作化定义。
7. **不能声称 R24 在所有违反族下失效。** 只在二次族 `−εr²` 上验证（B-B39）。
