## §1 三句话的逐句形式化

### 1.1 "势是'双约束'下的动力学"

8 月稿的既定内容（先引原文，避免我替用户立论）：

- [86]：**双约束机制**是 XS 四大核心本体之一（认知宏结构 / 双约束机制 / 熵变动力学 / 状态竞合关系）。
- [57]：收敛是"系统在**内外约束**作用下，从多候选、不确定的高熵过渡态，**回落**至单一、确定、有序的低熵稳态"。→ **双约束 = 内约束 + 外约束**。
- [344]：**两股反向核心驱动力**——
  - ① 震荡持续推进，系统积累大量未调用 X₂ 分支，认知复杂度提升，完成**熵增积累**；
  - ② 约束持续作用，系统产生**收敛冲动**，试图固化结构、**回落稳态**。
  - "两股力量的博弈结果，直接决定系统走向。"

于是：

**定义 1.1（两股力）**。记
- **P(k)** = 熵增驱动力（展开侧：多路径关联、未调用分支积累、复杂度上升）；
- **Q(k)** = 收敛驱动力（约束侧：固化冲动、回落倾向、闭环判定）。

**定义 1.2（势）**。

$$\Psi(k) := P(k) - Q(k)$$

> **势不是全局场，也不是 Lyapunov 函数，而是双约束下两股反向驱动力的净差。** 它是 8 月稿 [344] 那"两股力量博弈"的**标量记账**。

### 1.2 "势是系统平衡性被破坏的因"

- **平衡** = Ψ(k) = 0，即两股力相等——这正是汉语"**势均**"（势均力敌）的字面含义，也是主文 §5.1 震荡判据（多候选加载度势均、gap < ε）的动力学底本。
- 8 月稿 [134] 的震荡发生条件——"多个认知宏同时满足各自的大多数预条件，且无法基于当前信息与约束完成唯一性取舍"——**正是 Ψ ≈ 0 的操作性表述**。
- **势是"因"**：Ψ ≠ 0 时，系统离开平衡，沿 Ψ 的符号方向运动。

> **注意一个容易滑走的细节**。势**同时**是"平衡的量度"（Ψ = 0 即平衡）与"平衡的破坏者"（Ψ ≠ 0 即破坏）。这不是循环，而是物理学中"力"的标准地位：F = 0 是平衡条件，F ≠ 0 是运动的原因，**同一个量兼任两职**。用户说"势是平衡性被破坏的因"，取的是后一职。

### 1.3 "对于统计定向、局部回落的系统，势是动力学因"

这两件事**不是张力，而是同一个过程的两个分量**：

- **统计定向** = Ψ 的**系统性成分**：长期看有一个方向（熵增定向或回落定向）；
- **局部回落** = Ψ 的**涨落成分**：即便长期是熵增定向，Ψ 的瞬时值仍可为负，导致**局部的、暂时的收敛回落**。

8 月稿 [129] 正是这个意思："子问题层面完成局部收敛，并不必然打断全局层面的熵增积累。"

**定义 1.3（势的分解）**。

$$\Psi(k) = \bar\psi + \xi(k),\qquad \bar\psi = \mathbb{E}[\Psi],\quad \mathbb{E}[\xi] = 0$$

- **ψ̄ = 定向分量**（统计定向）；
- **ξ = 涨落分量**（局部回落的来源）。

**于是"统计定向 + 局部回落"就是：ψ̄ ≠ 0 且 Var(ξ) > 0。**

## §2 结论：这是一个漂移-扩散过程，且它比 μ 更强

**命题 2.1**。设认知系统的熵（复杂度）E(k) 满足

$$E(k+1) - E(k) = \Psi(k) = \bar\psi + \xi(k)$$

则 E 是一个**带漂移的随机游走**（drift-diffusion）：**ψ̄ 是漂移项（定向），Var(ξ) 是扩散项（局部回落）**。

> 这不是比喻。它在数学上就是 **Ratcliff 漂移扩散模型（DDM）**、**序贯概率比检验（SPRT / Wald）**、**Busemeyer–Townsend 决策场理论**所共用的那个过程——证据累积 + 噪声 + 边界吸收。本文的贡献只是把"证据"换成了"势"，并把三态接在了边界上。

**定理 6.2″（取代补篇一的定理 6.2′；条件更弱、结论更强）**。
若 **ψ̄ ≠ 0**（存在统计定向），则 E 在有界熵区间 [E_min, E_max] 上**以概率 1 在有限时间内触及某一边界**：

| 定向 | 触及的边界 | 归宿 |
|---|---|---|
| **ψ̄ < 0**（收敛力占优） | 回落边界 | **收敛**（回落至低熵稳态） |
| **ψ̄ > 0**（熵增力占优） | 临界边界 | **临界跃迁**；若跃迁不可构造则**发散** |

因此 **震荡必然消亡**——震荡是 Ψ ≈ 0 处的驻留，而 ψ̄ ≠ 0 使无限驻留的概率为 0。

**为什么这比补篇一的 μ 强**：

1. **内生 vs 外挂**。μ 是我在补篇一里为了让定理成立而**加的公理**；ψ̄ 是系统**本来就有的**（两股反向力的净差）。→ 从"为了救定理而设"变成"定理本来就该这样写"。
2. **局部回落有位置**。μ 是单调释放，**不产生回落**——补篇一的模型里根本没有"局部回落"这个现象的位置。ψ̄ + ξ 的分解里，**ξ 就是局部回落**。→ 用户的模型比我的模型**更丰富**，也更贴合他自己的原始表述。
3. **结论更强**。μ 给出 τ ≤ 1/μ（有限寿命）；ψ̄ 给出**几乎必然到达边界**。

**推论 2.2（混沌的条件 · 最终版）**。

> **混沌被排除 ⟺ ψ̄ ≠ 0。**
> ψ̄ ≠ 0 → 定向漂移 → 震荡必亡 → **三分**；
> ψ̄ = 0 → E 是**鞅**（无偏随机游走）→ 震荡与混沌可持久 → **四分**。

> **与补篇一的关系**：补篇一说"μ > 0"；本补篇说"ψ̄ ≠ 0"。**μ 是结果，ψ̄ 是原因**——ψ̄ ≠ 0 时系统会自己走向归宿，无需额外引入 μ；μ 只在 ψ̄ ≈ 0（两力长期精确平衡）时作为兜底才有必要。

## §3 一个必须由势重写的分叉：资源耗尽的归宿

主文 §3.5-B 写道："资源有界 → 摇摆**必须归宿** ⇒ **发散**是强迫归宿。" 在势的框架下，这个推论**不完整**：

资源耗尽 → 维持未决的代价上升 → **收敛力 Q 剧增** → **Ψ 强负** → 系统产生强烈的回落冲动。此时分叉：

- 若 **A_k ≠ ∅**（还有候选可落定）→ 回落冲动**得以执行** → 在**不充分证据上强制落定** → **伪收敛**；
- 若 **A_k = ∅**（无候选可落定）→ 回落冲动**无法执行** → **发散**。

> **推论 3.1（发散的重新定义）**。
> **发散不是"没有方向"，而是"有回落方向却无处可落"。**
> 形式地：**发散 ⟺ Ψ < 0（想收敛）∧ A_k = ∅（无处收敛）。**

这给出一个**新的、可操作的发散判别签名**：一个处于发散的系统应当表现出**明确的收敛冲动**（Ψ < 0），而不是"无所谓""没方向"。→ 可检验推论 R10。

> **主文需要补的分叉（登记为 B-B11）**：§3.5-B 只写了 A_k = ∅ 那一支，**缺了 A_k ≠ ∅ → 伪收敛 那一支**。而这一支恰恰是**过早锁定（伪收敛成因 2）的动力学来源**——资源压力本身就是伪收敛的一个成因，主文此前只把它列为"约束过强"，未与资源有界挂钩。

## §4 势与 A11-R 的最终对位（补篇一张力 T-1 的解决）

补篇一登记的张力 T-1（"势-流分离"vs"势破坏混沌"）现在有了干净的解——**不是矛盾，是同名异物**：

| | 用户认知层的"势" **Ψ** | A11-R 的"势" **g** |
|---|---|---|
| 本体 | **净驱动力**（双约束下两股反向力之差） | **语义增益场**（外部给定、静态） |
| 在漂移-扩散中的角色 | **漂移项 ψ̄**（决定**方向**） | **增益**（缩放每步的**增量幅度**） |
| 是否进状态导数 | **是**——它本身就是流 | **否**——这正是 A11-R 的规定 |

**关键的技术点**：增益 g 同时缩放漂移与扩散（Ψ 与 ξ 都被 g 缩放），因此 **g 改变不了 ψ̄ / √Var(ξ) 这个比值**，即**改变不了定向性**。g 只改变走得多快，**不改变往哪走**。

> **推论 4.1（A11-R 的认知含义）**。
> **A11-R"势-流分离"的认知对应物是：禁止伪定向。**
> 若语义增益场越权进入状态导数，它就会**冒充漂移**——即把"**增量幅度大**"误认作"**方向正确**"。
> - **认知形态** = **伪收敛**（加载度高、体验确信，事后为错）；
> - **工程形态** = **F2 / ghost 伪力**（加载成功但事后验证为错）。
> 二者是**同一件事的两个面**。

> 这也顺带解释了主文 §8.2 / 补篇一 §8 那条最硬的诚实登记——**"我确信我想明白了"这一体验不构成区分真/伪收敛的证据**——的动力学机制：确信感来自**增益 g**（每一步都很有分量），而正确性来自**漂移方向 ψ̄**。二者可以独立变化，所以**确信与正确之间没有必然联系**。

**命名裁决（闭合补篇一的缺口 B-B6）**：

| 层 | 建议定名 | 说明 |
|---|---|---|
| 认知层 | **竞势 Ψ**（净驱势） | 双约束下两股反向力之差；有正有负 |
| 工程层 | **语义增益场 g** | 原"语义势"**改名**，以避与 Ψ 相混 |
| 数学层 | **势函数 V**（Lyapunov） | 保留原名，但**本文不再使用**——Ψ 不是 Lyapunov 函数（Lyapunov 函数沿流单调下降，Ψ 可正可负） |

## §5 局部回落的双面性

8 月稿对局部回落给出了**两个相反的评价**，二者并不冲突，而是频率问题：

- [129]（正面）："子问题层面完成局部收敛，并不必然打断全局层面的熵增积累。" → **局部回落是健康的**：子问题逐个解决，是认知分解的正常方式。
- [64]（负面）："**过度收敛**……总是在系统尚未积累足够熵增、未趋近临界条件时就反复完成回落，依然会构成系统层面风险。" → **回落过频**是伪收敛的系统级形态。

> **推论 5.1（认知健康的双参数条件）**。
> 认知健康 = **ψ̄ 落在适当区间** ∧ **Var(ξ) 落在适当区间**。
> - Var(ξ) 太小 → 缺乏局部回落 → 无法做子问题分解（无法"分而治之"）；
> - Var(ξ) 太大 → 回落过频 → 系统级伪收敛；
> - ψ̄ 过负 → 武断（过早锁定）；ψ̄ 过正 → 反刍（永不回落）。

这比补篇一推论 6.5 的单参数（μ 倒 U）**更准确**：那是把两个自由度压成了一个。

**一个可直接挂钩的经验抓手**（8 月稿 [201]）：8 月稿已识别**助词是"收敛加速器"**——助词标记语义边界、逻辑终点、时态范围、语气结论，为系统提供"收敛完成"的清晰信号，使其**提前判定认知闭环、快速退出震荡态、回落稳态**。

在势的语言里：**助词 = Q 的人工增强器**（它直接增大收敛力，使 Ψ 转负）。于是 8 月稿 [64] 的警告可以翻译成一个可检验的预言：

> **R12（语言学推论）**。助词（标记语义边界 / 逻辑终点 / 语气结论的成分）是收敛力 Q 的人工增强器。预言：**在论证性文本中，助词密度过高、且过早出现在熵增尚未充足的阶段，与伪收敛率正相关。** 即"语气上已经收了，但结构上还没到"。

> **三分的成立条件 = 资源有界（B < ∞） ∧ 存在统计定向（ψ̄ ≠ 0）。**
>
> **ψ̄ = 0** 时（两股反向力长期精确平衡，E 为鞅），震荡与混沌可持久，终局为**四分**。
>
> **局部回落（Var(ξ) > 0）不妨碍收敛，只延迟收敛**——一条可以边回落边前进的轨迹，仍然是收敛的。这是本框架与"收敛必须单调逼近"这种朴素收敛观的根本区别，也是"统计定向 + 局部回落"这一表述的全部分量所在。
