# 回归路径：方法论 → 体系 → 应用

> 项目原意：① 给出方法论 ② 给出 XS 体系 ③ XS 的一些应用。
> 现需从工程与旁支议题回归主线。本文为回归方案。

---

## 一、漂移诊断：不是做错事，是做在了错的层

这两天做的事情有三类：工程（x-s-mera / s-spiral-review）、外部言论审计（观察者三条）、理论旁支（基底-完备、向量空间基底、线性→非线性）。

问题不在于内容质量，而在于**它们没有归位**。结果是：

- 方法论层**一直是空的**——我们从未正面建立它；
- 体系和应用的成果是在**没有方法论的情况下**产出的；
- 于是每次应用都要临时造工具（七条、三源、知识注入测试），造完就散在那儿。

**所以"回归"不是"回去继续写论文"，而是：把散件归档到正确的层，然后补上空的那层。**

---

## 二、最尖锐的自洽缺口（必须先说）

XS 3.3 自己的实证标准是：**"至少三个跨学科案例可独立复现"**。

但 XS **从未写出复现步骤**。目前可以复现的是"某某人做了一个判断"，不是"某某人执行了一个程序"。

⇒ **XS 自身的实证标准，在字面上无法被满足。** 复现的对象不存在。

这个缺口不在体系层，也不在应用层，**正在方法论层**。它是"必须先做 1"的最硬理由，不是排序偏好。

## 四、回归三步

### 第一步（方法论）：《XS 分析程序 P0–P7》

方法论的实质是**程序**，不是清单。草案如下，**全部使用既有词汇，不新增概念**：

| 步骤 | 动作 | 产出 |
|---|---|---|
| **P0** | 界定两个投影系统 P₁、P₂，各自给出尺度向量 (n_freedom, n_resolution, n_temporal, n_context) | 两个尺度向量 |
| **P1** | 定位交集论域 O = O₁∩O₂，给出各自在该论域推出的命题 c₁、c₂，并确认冲突 | 冲突陈述 |
| **P2** | **知识注入测试**：注入双方缺失事实；冲突消解 → 操作错位，**终止**（非 XS 对象）；持续 → 继续 | 是否进入 XS |
| **P3** | 判定错位类型：理论错位（层级不一致）/ 语义错位（概念系统差异）；若属"借用形式结构"型，转共振判据 | 错位类型 |
| **P4** | 定位驱动分量：哪个尺度分量在动，据此预测结构量（如宏观线性度）的变化方向 | 可证伪预测 |
| **P5** | **共振三判据检验**（仅当主张同构时）：投影可重复性 / 系统生成性 / 对应性 | 共振与否 |
| **P6** | 尝试构造公共细化，逐条检查三粒度约束。可构造 → 层级相容；不可构造 → 记录障碍 | 相容判定或障碍清单 |
| **P7** | 障碍归类：可修补 / 目标设定错误 / **结构性（实为投影，非子系统）** | 失效类型 |
| **P8** | 输出：诊断 + 至少一条可证伪预测 + 失效条件 | 可复现的诊断报告 |

有了 P0–P8，"三个跨学科案例可独立复现"才有了字面意义：**复现的是执行这套步骤，不是复现某个人的直觉。**

### 第二步（体系）：对 XS 自身执行七条

上一轮建立的"基底-完备七条"，第一个该审的对象是 **XS 自己**。若不递归，XS 就是我们自己在批评的那种东西——有概念、有判据、没有对自身的检验。

**预测会失守的三条**（先登记，验证后修正）：

- **② 下沉显式 —— 极可能失守。** XS 的公理如何下沉到具体学科？ρ 是什么？目前没有显式给出，实际依赖"包含即继承"。
- **⑦ 极小可审计 —— 可能失守。** 尺度向量为何恰好四分量（第二次出现的老问题）；三类错位是否各自都有为它而存在的案例；"层次外显关系"是否有独立载荷。
- **⑥ 鲁棒 —— 可能失守。** BC < 0.6 与 VAR 界是经验值、未标定（x-s-mera README 已诚实标注）。

另需检查：③ 论域闭合（推导是否中途借用了 XS 之外的"信息""复杂度"等未定义量）。

### 第三步（应用）：三案例回填为 P0–P8 格式

现有三个案例（量子-经典 / MMS / 观察者）**格式互不统一，因此不可比较**。应用层的标准不是数量，是**按同一程序产出**。

回填后，三个案例才构成 XS 实证标准所要求的那种可复现集合。
