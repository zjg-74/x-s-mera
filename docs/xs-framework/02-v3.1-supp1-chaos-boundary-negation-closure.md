## §1 挑战一：混沌是不是第四态？

### 1.1 先把"混沌"的四个签名写清楚

不加定义地谈混沌会滑向修辞。动力系统意义上的混沌有四个签名，**缺一不可**：

| 签名 | 内容 |
|---|---|
| **C-1 有界** | 轨道不逃逸，停留在有界区域内 |
| **C-2 非周期** | 不落到不动点，也不落到周期轨（极限环） |
| **C-3 初值敏感** | 存在正的 Lyapunov 指数；任意小的初值差被指数放大 |
| **C-4 持续** | 是**吸引子**，不是瞬态；系统在其中停留不离去 |

### 1.2 定位：混沌 ⊂ 震荡，**不是第四态**

主文 §5.1 对三态的操作性定义中，震荡是**残余类**：非收敛、非发散的有界态。混沌满足 C-1（有界）与非收敛，故落在震荡内部。

> **结论 1.1**。就**分类**而言，混沌不是第四态，而是震荡的一个子类：**持续化的、非周期的、初值敏感的震荡**。三分的完备性**未被撼动**。

### 1.3 但真正的威胁在别处——而且主文自己已经埋下了它

主文行 411 写道：

> "当 |σ(M₁, F_k) − σ(M₂, F_k)| ≈ 0 时……这是**混沌式敏感性**。"

这句话是对的，但主文没有把它追到根。追下去会得到一个比"第四态"**硬得多**的结论：

**混沌的真正破坏力是吸引盆的分形化（riddled basins）。** 当"收敛盆"与"发散盆"的边界是分形集时，映射

$$\text{初始条件} \longmapsto \text{终局归宿}$$

是**处处不连续**的：在任意小的尺度上扰动初始条件，都会翻转归宿。此时三态的概率分布虽然在数学上仍然存在，但**不可鲁棒地赋值**——任何有限精度的测量都无法确定它，测量精度的提升不会收敛到一个稳定的数值。

> **结论 1.2（挑战一的准确表述）**。混沌威胁的不是"**三分是否完备**"，而是"**三分的概率是否可被赋值**"。后者是更严重的威胁：前者只要求增加一个格子，后者会使主文 §6 整节失去意义。

这一点必须正面回答，不能靠"分类上它归震荡"来回避：**把它归入震荡只是解决了分类，没有解决可赋值性。**

### 1.4 "势使其在瞬间破坏"——方向对，但不能写成结构必然

用户的直觉是：**认知有一个"势"，它不允许混沌态长期存在，所以混沌态瞬间被破坏。**

这个方向我接受。但"瞬间"二字不能作为结构必然，只能作为**参数取值**的命题。因为认知中确实存在长期的有界、非周期、不收敛状态：

| 现象 | 四个签名是否齐备 | 说明 |
|---|---|---|
| **反刍思维**（rumination） | 齐备 | 有界（就是那几件事）、非周期、不收敛、**可持续数月至数年** |
| **决策瘫痪 / 布里丹之驴** | 齐备 | 多候选长期势均，不归宿 |
| **创造性酝酿期**（incubation） | 齐备，且**有生产力** | 恰恰**需要**维持未决；快速释放会扼杀它 |
| **库恩式反常积累期** | 齐备 | 一个共同体可在反常中持续很久不收敛 |

前两条是混沌的**病理**实例，后两条是混沌的**功能性**实例。它们共同说明：**μ（势释放率）的取值可以很低，且低 μ 有时是被需要的。**

所以正确的表述是：

> **修订 1.3**。混沌态不是在"瞬间"被破坏，而是在期望寿命 **τ(μ)** 内被破坏，**τ 关于 μ 单调递减**。μ 大时 τ 小（接近"瞬间"），μ 小时 τ 大（反刍）。**"瞬间"是 μ 的经验取值命题，不是结构必然。**

### 2.1 先做一次概念消歧：三个"势"是三个不同的东西（登记 **I** 型内部张力）

这是本次审计中最需要先处理的问题——它与 8 月遗留下来的"平滑"消歧是**同一类型的病**：同名异物。

| 名称 | 出处 | 性质 | 是否进状态导数 |
|---|---|---|---|
| **语义势** | X-S-MERA **A11-R**，主文 §3.3、§7.5 已引用 | 外部给定、静态、**仅调增益** | **不进**（这正是 A11-R 的规定） |
| **未决张力** | 本补篇提出 | 内生于未决状态，随状态变化 | **要进**（它就是要驱动归宿） |
| **梯度势**（Lyapunov 函数） | 动力系统标准用法 | V: 状态 → ℝ，沿流单调下降 | 是（∇V 就是流本身） |

主文 §7.5 已经把 A11-R 的"势-流分离"认作"元公理不越权"这一原则的工程实现（行 545）。于是立刻出现张力：

> **张力 T-1（登记 I 型）**。若挑战一所说的"势"就是 A11-R 的**语义势**，则它按定义**不进状态导数**——而"破坏混沌"恰恰要求改变流的**拓扑**（把奇怪吸引子消除）。一个只调增益的量，如何能做一件改变拓扑的事？

**这个张力不能糊过去。** 若不解决，挑战一的回答就是自相矛盾的：我们一边用 A11-R 论证"势不越权"，一边又用"势破坏混沌"论证"势能改变轨道"。

### 2.2 三条可能的兼容机制（按可辩护程度排序）

**M1 · 离散步长机制（最可辩护，且可直接工程检验）**

关键事实：

> 势-流分离在**连续流**中意味着势只能**重参数化时间**、不能改变轨道（ẋ = g(x)·f(x) 与 ẋ = f(x) 有相同的轨道、不同的速度）。但在**离散迭代**中，增益调制等价于改变**有效步长 η_eff**，而离散映射的定性行为（包括混沌）**依赖 η_eff**。

而认知迭代恰恰是**离散**的（k = 0, 1, 2, …）。标准例证：logistic 映射 x_{k+1} = r·x_k(1 − x_k)，参数 r 即有效增益/步长；r 越过 ≈3.5699 后经周期倍增级联进入混沌。**调增益即可移出/移入混沌区，且全程不需要增益进入状态导数。**

> **结论 2.1**。M1 是 A11-R 与"势能破坏混沌"**唯一严格兼容**的路径：它不需要势进入状态导数，只需要势调制步长。**这一点在连续系统里不成立，在离散系统里成立——而认知是离散的。**

**M2 · 对称破缺机制**

混沌常生于**对称的多候选竞争**。势提供一个偏向序，打破对称，把对称竞争塌缩为有偏竞争——混沌所需的对称结构被破坏。可辩护，但机制描述比 M1 粗糙。

**M3 · 张力释放机制**

见 §2.3。它最直接地给出定理 6.2′，但它要求"势"是**未决张力**而非语义势，即需要 §2.1 的消歧成立。

### 2.3 势释放公理 A_μ 与定理 6.2′

**公理 A_μ（未决代价与释放）**。认知系统处于未决态（震荡 / 混沌）时，每步承担代价 c > 0——它必须**同时维持**多个候选的激活，占用工作记忆槽位、占用注意资源、并产生未决的失调感；系统以速率 μ ≥ 0 释放该张力，即每步以概率 μ 触发一次"**强制归宿**"（不再等待势均被打破，而是在当前最优候选上直接落定，或宣告无解）。

**定理 6.2′（混沌寿命的条件化上界）**。在 A_μ 下，混沌态（持续的非周期震荡）的期望寿命

$$\tau(\mu) \le \frac{1}{\mu},\qquad \tau \text{ 关于 } \mu \text{ 单调递减}$$

- **μ = 0** → τ = ∞ → **混沌成为第四态**，且吸引盆可分形化，概率权重不可鲁棒赋值（结论 1.2 兑现）；
- **μ > 0** → τ < ∞ → **混沌退化为瞬态，被震荡吸收，三分恢复，概率恢复可赋值性**。

> **推论 6.2′-a（三分的条件辖域）**。
> **三分 = μ > 0 的认知者的终局分类。**
> **μ = 0 的理想推理者**（无资源压力、无未决代价的机器推理）**的终局分类是四分**：收敛 / 震荡 / 混沌 / 发散。

这把主文 §1.2 的"为什么必须是三分"从**无条件主张**变成了**有条件主张**——而它的条件（有资源压力、有未决代价）恰好就是主文 §3.5-B 已经承认的偏离 B。因此**与主文自洽，不是外加补丁**。

### 2.4 μ 的经验下界：为什么 μ 不会真的是 0

用户可能会追问：μ = 0 的情形真的可设想吗？如果不可设想，四分就是空洞的。

回答：**对生物认知者，μ 有硬的经验下界。** 理由是：维持未决必须**同时保持**多个候选处于激活状态，而工作记忆容量是有限的（Miller 7±2 / Cowan 4±1）。候选数一旦超过容量，维持未决就有**不可回避的**代价——这是一个容量约束，不是偏好。

推论：**反刍不是 μ = 0，而是 μ 极小。** 它能持续数月，但不会持续到永久——这与临床观察一致。而 μ = 0 只在**无容量压力的系统**中才可能：无资源约束的机器推理、纯形式系统、无人值守的定理证明器。**四分不是空洞的，它描述的是那类系统的终局。**

### 2.5 代价：μ 不是越大越好（诚实登记）

这是势释放机制的真实理论张力，必须写出来：

- **μ 过大** → 强制过早归宿 → 系统性地放大主文 §5.4 的**伪收敛成因 2（过早锁定）**；
- **μ 过大** → **扼杀酝酿期**（创造性需要维持未决）与**扼杀库恩式反常积累**（科学革命需要长期容忍反常）；
- 因此存在一个**最优 μ 区间**：足够大以排除混沌与无限摇摆，足够小以允许震荡完成其筛选功能。

> **推论 6.5（有临床含义）**。**认知健康的标志不是"尽快想清楚"，而是"μ 落在适当区间"。** μ 过高者表现为武断与过早确信，μ 过低者表现为反刍与决策瘫痪——**这是同一个参数的两个方向，而不是两种无关的毛病。**

## §3 挑战二：用"否定"代替"减"，能否保住 F 的单调增？

### 3.1 命题的准确重述

主文 §3.2 假定 F₀ ⊆ F₁ ⊆ … ⊆ F_k 单调增长，并在行 153 与附录 B-B1 处**显式登记"不处理事实撤销"为高优先级缺口**；行 431 更进一步承认"**若允许事实撤销，定理 6.3 不成立**"。

用户的提议是：

> **撤销不必是"删元素"，可以是"加一个否定"。** 这样 F 仍然单调增，无需考虑"减"的状态，B-B1 随之闭合，定理 6.3 得以保住。

这是一个**正确的方向**，而且它正面打在主文自己标为"高"的那条缺口上。

### 3.2 审计结论：**在存储层成立，在后果层不成立。减没有被消除，被移位了。**

先看它为什么**不能**直接成立。设 p ∈ F_k，现加入 ¬p：

- 在**经典逻辑**下，Cn(F_k ∪ {p, ¬p}) **平凡化**（爆炸原理）——一切命题皆可导出。后果是：所有宏的所有预条件槽都"被满足"，σ ≡ 1，**三态全部塌陷为收敛**。这是荒谬的。
- 因此"加否定"要能代替"删元素"，**必须附带额外装置**。光说"加否定"是不够的。

### 3.3 三类否定必须分开（N1 / N2 / N3）

| 类型 | 内容 | 是否纯增 | 对 A_k 的作用 |
|---|---|---|---|
| **N1 补否定**（negative information） | p 此前**从未被断言**（属开放问题），现确立 ¬p | **纯增，无冲突** | 缩小（排除依赖 p 的宏） |
| **N2 撤销否定**（retraction-as-negation） | p **已被断言**，现加入"p 不成立" | **非纯增**（需元层撤销装置） | 缩小 |
| **N3 排他否定**（exclusion） | ¬p 作为约束，排除一类候选 | **纯增** | **缩小** |

> **结论 3.1**。用户的命题对 **N1 与 N3 完全成立**；对 **N2 需要额外装置**（§3.4）。

### 3.4 N2 的正确形式装置：带担保的事实集（这是闭合 B-B1 的关键）

把 F_k 从"命题集"升级为**带来源标注的断言集**：

$$F_k = \{\,\langle p,\ s,\ \tau\rangle\,\}\quad\text{——命题 } p,\ \text{担保来源 } s,\ \text{时间戳 } \tau$$

**"撤销 p" = 加入一条新断言** ⟨invalid(⟨p, s⟩), s′, τ′⟩，**而不是删除** ⟨p, s, τ⟩。

于是：**存储层严格单调增——用户命题成立。**

再引入**有效化函数** eff：

$$\mathrm{eff}(F_k) = \{\,p : \langle p,s,\tau\rangle \in F_k \ \wedge\ \neg\exists\,\langle \mathrm{invalid}(\langle p,s\rangle), s',\tau'\rangle \in F_k \text{ 且 } (s',\tau') \succ (s,\tau)\,\}$$

其中 ≻ 是优先级关系（也随 k 单调增长）。**eff(F_k) 是非单调的**——可增可减。

这套装置不是本文发明，它在文献里有标准名字，必须承认（第 9 次"重复发明"式的登记）：

- **AGM 的认识论牢固度序**（epistemic entrenchment，Gärdenfors–Makinson）：用牢固度序把"收缩"变为**派生**操作，而非原始操作；
- **真值维护系统 TMS / 理由维护**（Doyle 1979；de Kleer）：撤销的是**理由**，不是命题；
- **可废推理 / Dung 论证框架**：由优先级关系决定论证胜负。

### 3.5 由此得到一条比用户原命题更强的结果：**非单调性的局部化**

主文 §3.5-C 把"承诺可撤销（非单调性）"当作一条**独立的原始偏离**。有了 §3.4 的装置后：

> **定理 3.2（非单调性的局部化）**。**存储组件**（F_k 与优先级关系 ≻_k）**都是单调增长的**；整个系统**唯一的非单调性被局部化到有效化函数 eff 这一个映射上**。

**意义**：非单调性从"一个神秘的原始属性"变成"**一个被隔离到单点、可单独测试、可单独替换的组件**"。可检验性与可工程化都因此大幅提升。

这也是对主文 §3.5-C 的**降级**：它不再是原始偏离，而是**派生性质**。按 U2 登记为 **X+**（结构性改进），但须注意：它同时是对"三条偏离"这一主文核心论证的**结构改写**——三条偏离变成"**两条原始偏离 + 一条派生性质**"。这个改动要显式登记。

### 3.6 新结果：事实极性定理（A_k 涨落的极性来源）

设新增事实的**极性**为 σ_sign ∈ {肯定, 否定}。观察：

- **肯定事实**倾向于**使能**宏（使更多预条件槽得以满足）→ |A_k| **不减**；
- **否定事实**（N1 / N3）倾向于**禁用**宏（使某些槽不再可满足）→ |A_k| **不增**；
- **eff 的撤销**（N2）在**有效层**产生"减"，从而使 A_k **可以减小**——这正是主文行 431 担心的情形。但因为它发生在**有效层**而非存储层，定理 6.3 只需在更精确的条件下重述即可（§3.8）。

**极性定理 3.3**：

| 注入事实的极性构成 | A_k 的轨迹 | 主导态 | 风险 |
|---|---|---|---|
| **全肯定** | 单调不减 | 震荡延长、收敛延迟 | 发散风险↑、噪声震荡↑ |
| **全否定**（N1/N3） | 单调不增 | 收敛加速 | **过早锁定（伪收敛成因 2）↑** |
| **混合** | **非单调涨落** | **震荡** | —— 这是震荡的动力学来源 |

> **意义**。主文 §5.1 把震荡定义为"多候选势均"，但**没有给出震荡的动力学来源**。极性定理补上了这一点：**震荡源于注入事实的极性混合。**

由此得到一条有实证含义的推论：

> **推论 3.4（确认偏误的动力学后果）**。**确认偏误在动力学上是"只用肯定事实填充"。** 其后果**不是**"更快想清楚"，而是——按极性定理——A_k 单调不减、震荡延长、发散风险上升，即**"更久想不清楚，且更容易想不出来"**。
> 这是一个反直觉的、可检验的断言：只搜集支持性证据会**延长**而非缩短未决期。

### 3.7 对 σ（加载度）定义的修订

主文 §4 定义 σ(M, F_k) = 预条件槽 P_M 的加权满足率，其满足判定基于 F_k。修订为：

$$\sigma(M, F_k) :=\ P_M \text{ 在 } \mathrm{eff}(F_k) \text{ 的**可废后果**下的加权满足率}$$

即：槽 q 被满足，当且仅当 q 可从 eff(F_k) **可废地导出**，且不存在优先级更高的否定者。

**为什么必须改**：若沿用原定义，宏被证伪后 σ **不会下降**（因为被撤销的断言仍留在 F_k 里），于是主文 §5.4 的伪收敛**永远不会被识别**——该节会直接失效。这是挑战二带来的**一处必需的下游修正**，不是可选优化。

### 3.8 对定理 6.3 的修订（闭合 B-B1）

**定理 6.3′**。若注入持续不停（ΔF_k ≠ ∅），且注入事实**全部为肯定型或 N1/N3 型**（即不撤销既有断言），且注入与题域相关，则

$$p^{(k)}_{\mathrm{Dv}} \ \text{非增},\qquad p^{(k)}_{\mathrm{Cn}} + p^{(k)}_{\mathrm{Os}} \ \text{非减}$$

**定理 6.3″**。若注入含 **N2 型**（撤销既有断言），则 p_Dv **可能上升**；上升幅度由被撤销断言的**中心性**（有多少宏的预条件槽依赖它）决定：

$$\Delta p_{\mathrm{Dv}} \ \propto\ \#\{\,M : \text{槽 } q \in P_M \text{ 依赖被撤销的 } p\,\}$$

> **缺口 B-B1 的状态更新**：由"**未处理（高优先级）**"变为"**已处理，且给出了分条件结论**"。

## §4 两条挑战的交叉点（一个未预料到的联系）

两条挑战单独看是两件事，但它们交叉处给出一个更紧的结论：

- 混沌的存续需要**持续的多候选竞争**（C-1 有界 + C-2 非周期）；
- 极性定理说：混合极性维持 A_k 的涨落，**纯否定会清空 A_k**；
- 势释放说：μ 大会**强制归宿**。

因此：

> **推论 4.1（混沌的参数窗）**。**混沌只出现在 μ 小 ∧ 极性长期混合 ∧ A_k 保持非空 的参数窗内。** μ 增大 → 强制归宿（窗关闭）；极性转为纯否定 → A_k 清空 → 退化为**发散**（窗关闭）。

这解释了为什么混沌是"反例候选"却在日常认知中罕见：**它是窄窗现象，不是常态。** 这支持用户的直觉（势使其破坏），同时把"瞬间"精确化为"**窄窗 + 有限寿命 τ(μ)**"。

## §7 修订后的辖域声明（替代主文 §1.2 的无条件版本）

> **修订版辖域声明**。三分的成立条件是 **(i) 资源有界（B < ∞）** 且 **(ii) 存在未决代价（μ > 0）**。在此条件下，混沌被压缩为有限寿命 τ ≤ 1/μ 的瞬态，被震荡吸收，吸引盆恢复良态（可赋值），终局为三分。
> 若 **μ = 0**（理想推理者、无资源压力的机器推理、纯形式系统），终局为**四分**，且吸引盆可能分形化、使概率权重不可鲁棒赋值。
> 因此：**本文的"概率三分"是一个关于有界认知者的定理，不是一个关于推理本身的定理。**

> **修订版否定闭合声明**。事实公理集 F 在**存储层**严格单调增——撤销以"加入带担保的失效断言"实现，**无需"减"**。但"减"并未被消除，而是被**移位**到**有效层**（eff）并向下传播到**后果层**（A_k 与 σ）。**三层分工：存储层单调、有效层非单调、后果层涨落。** 这恰是本项目一贯的"分层纪律"的再一次应用：把一个看似矛盾的性质，拆到不同层上各自成立。
