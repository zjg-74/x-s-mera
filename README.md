It interprets AI hallucination, reasoning oscillation and cognitive stagnation as **endogenous information residuals caused by manifold dimensionality‑reduction projection**, rather than purely external engineering defects.

- Fast‑slow coupled nonlinear dynamical system ($x$ reasoning state, $q$ cognitive burr residual)
- Asymmetric potential‑well bifurcation mechanism; theoretical $\sigma_c=-0.385$, simulated $\sigma_c=-0.3784$ (deviation = 0.0066)
- Macro‑function retrieval‑completion‑selection pathway for novice‑expert cognitive difference
- Six self‑falsification consistency tests (T1‑T6, all passed)
- $\sigma$‑$W_\mathrm{crit}$ 2‑D phase‑diagram scanning
- Empirical‑weight training simulation reproducing novice‑to‑expert transition
